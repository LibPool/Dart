# flutter_dva_hooks

**Tag**: mobile, ui, state-management

## 简介

Declarative hooks for Flutter Dva state management. Provides useDvaConnect, useDvaProps, and useDvaStore hooks on flutter_hooks for reactive store access in Flutter widgets.
