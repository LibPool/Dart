# airship_flutter

**Tag**: mobile

## 简介

Cross-platform plugin interface for the native Airship iOS and Android SDKs. Simplifies adding Airship to Flutter apps.

## 官网

- 主页: https://www.airship.com/
- 源码仓库: https://github.com/urbanairship/airship-flutter
- 问题追踪: https://github.com/urbanairship/airship-flutter/issues
- pub.dev: https://pub.dev/packages/airship_flutter
