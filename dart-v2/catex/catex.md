# catex

**Tag**: mobile

## 简介

Fast math TeX renderer for Flutter written in Dart. Outputs TeX formulas (like LaTeX, KaTeX, MathJax, etc.) inline using only Flutter.

## 官网

- 主页: https://github.com/simpleclub/CaTeX
- pub.dev: https://pub.dev/packages/catex
