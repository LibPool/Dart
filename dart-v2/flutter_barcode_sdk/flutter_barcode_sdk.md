# flutter_barcode_sdk

**Tag**: web, mobile, desktop, ui, tooling

## 简介

The only Flutter barcode SDK for Android, iOS, Web, Windows, Linux, macOS. Empower developers to build 1D/2D barcode reader and barcode scanner.

## 官网

- 主页: https://www.dynamsoft.com/barcode-reader/overview/

- pub.dev: https://pub.dev/packages/flutter_barcode_sdk
