# bytebrew_sdk

**Tag**: web, mobile, testing

## 简介

Official ByteBrew Flutter SDK Plugin. ByteBrew is the free easy to integrate SDK that provides your app with Real-Time Analytic Tracking, Monetization Tracking, Attribution, Remote Configs and A/B Testing, Server-Side Purchase Validation, Push Notifications and more.
