# youtube_player

**Tag**: web, mobile

## 简介

A flutter plugin to play Youtube Videos "inline" without API Key in range of Quality (144p, 240p, 360p, 480p, 720p and 1080p).

## 官网

- 主页: https://github.com/sarbagyastha/youtube_player
- pub.dev: https://pub.dev/packages/youtube_player
