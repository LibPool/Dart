# animated_milestone

**Tag**: mobile, ui

## 简介

AnimatedMilestone is a lightweight and customizable Flutter package designed to help users effortlessly create milestone and timeline-related use cases. It offers customizable animations, versatile alignment options, and a minimalistic design for seamless integration into various applications.
