# flutter_page_tracker

**Tag**: mobile

## 简介

flutter_page_tracker is a flutter plugin which help tracking route events of PageRoute/PopupRoute/PageView/TabView. Route events include PageView and PageExit.

- 主页: https://github.com/SBDavid/flutter_page_tracker
