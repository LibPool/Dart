# flutter_gl_web

**Tag**: web, mobile, ui

## 简介

Web platform implementation of flutter_gl, cross-platform call OpenGL API by Dart through dart:ffi. Provides OpenGL with Texture Widget on Flutter.

## 官网

- 主页: https://github.com/wasabia/flutter_gl
