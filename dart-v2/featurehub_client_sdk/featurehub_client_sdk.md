# featurehub_client_sdk

**Tag**: web, mobile, desktop, ui, testing, tooling

## 简介

Dart SDK implementation for FeatureHub - open source Feature Flag management, A/B testing and remote configuration platform. Suitable for Flutter Web, Mobile and Desktop.
