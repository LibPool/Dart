# github_sign_in_plus

**Tag**: web, mobile, security

## 简介

Authenticate Using GitHub on Android & iOS You can let your users authenticate with Firebase using their GitHub accounts by integrating web-based generic OAuth Login into your app using the Firebase SDK to carry out the end to end sign-in flow.
