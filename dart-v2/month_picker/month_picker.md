# month_picker

**Tag**: web

## 简介

Based on the idea of unified push alliance, the month_picker platform of six vendors has been rapidly integrated, and the vendor push channel of the shared system has been shared to avoid the need for the APP to run in the background for a long time, killing the APP can also receive the push.
