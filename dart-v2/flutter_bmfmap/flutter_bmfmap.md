# flutter_bmfmap

**Tag**: mobile

## 简介

The flutter_bmfmap is a flutter plugin of basic map for baidu map, You can use it to develop map page for Flutter application.

## 官网

- 主页: https://lbsyun.baidu.com/index.php?title=flutter/loc
- pub.dev: https://pub.dev/packages/flutter_bmfmap
