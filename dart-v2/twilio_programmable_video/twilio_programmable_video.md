# twilio_programmable_video

**Tag**: web, mobile, ui, tooling

## 简介

Flutter plugin for Twilio Programmable Video, which enables you to build real-time videocall applications (WebRTC)

## 官网

- 主页: https://gitlab.com/twilio-flutter/programmable-video
- 源码仓库: https://gitlab.com/twilio-flutter/programmable-video/-/tree/master/programmable_video
- 问题追踪: https://gitlab.com/twilio-flutter/programmable-video/issues
- pub.dev: https://pub.dev/packages/twilio_programmable_video
