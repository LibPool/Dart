# pangle_flutter

**Tag**: mobile

## 简介

A Flutter plugin that supports ByteDance Pangle SDK on Android and iOS. Such as Splash Ads, Rewarded Video Ads, etc.

- 问题追踪: https://github.com/nullptrx/pangle_flutter/issues
