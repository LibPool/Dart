# torch_compat

**Tag**: mobile

## 简介

Plugin to turn on / off the torch (or flash of the camera) on all supported versions of Android (4.1+) and iOS

## 官网

- 主页: https://github.com/g123k/flutter_torch_compat
- pub.dev: https://pub.dev/packages/torch_compat
