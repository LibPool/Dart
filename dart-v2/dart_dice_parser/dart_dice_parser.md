# dart_dice_parser

**Tag**: library

## 简介

A dart library for parsing dice notation (`2d6+4`). Supports advantage/disadvantage, exploding die, and other variations.

## 官网

- 主页: https://github.com/Adventuresmith/dart-dice-parser
