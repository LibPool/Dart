# algolia

**Tag**: web, mobile

## 简介

Algolia is a pure dart SDK, wrapped around Algolia REST API for easy implementation for your Flutter or Dart projects.

## 官网

- 主页: https://www.algolia.com/doc/guides/building-search-ui/troubleshooting/faq/ios/#does-algolia-support-dart-and-flutter
- 源码仓库: https://github.com/knoxpo/dart_algolia
- pub.dev: https://pub.dev/packages/algolia
