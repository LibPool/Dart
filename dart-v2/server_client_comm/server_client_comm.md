# server_client_comm

**Tag**: web, serialization, networking, tooling

## 简介

This package will help you to communicate between server and client easilly!
All you have to do is use a `SocketMessage.shrinkT(x,[y])` to serialize into json, and
use `SocketMessage.expandT(x)` to serialize from json!
