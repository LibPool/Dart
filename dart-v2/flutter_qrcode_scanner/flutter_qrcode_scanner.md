# flutter_qrcode_scanner

**Tag**: web, mobile, networking

## 简介

QR code scanner that can be embedded inside flutter. It uses zxing in Android and MTBBarcode scanner in iOS. Copy from https://github.com/juliuscanute/qr_code_scanner
