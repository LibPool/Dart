# native_image_view

**Tag**: mobile

## 简介

该组件提供了一种方式，可以让flutter通过methodChannel调用原生的本地和网络图片的加载

## 官网

- 源码仓库: https://github.com/qianshou/native_image_view
- pub.dev: https://pub.dev/packages/native_image_view
