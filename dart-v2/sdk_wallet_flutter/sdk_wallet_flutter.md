# sdk_wallet_flutter

**Tag**: web, mobile, desktop

## 简介

SDKWalletFlutter is an open source protocol for connecting decentralized applications. Users can securely interact with any Dapp from their mobile phone, making Wallet a safer choice than desktop wallets or browser extensions.
