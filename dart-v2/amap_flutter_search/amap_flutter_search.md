# amap_flutter_search

**Tag**: mobile

## 简介

高德官方没有提供search相关的Flutter插件，本插件针对高德地图搜索功能官方原生插件进行封装

## 官网

- 源码仓库: https://github.com/dingjianjaja/amap_flutter_search
- pub.dev: https://pub.dev/packages/amap_flutter_search
