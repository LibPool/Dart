# signalr_flutter

**Tag**: mobile, tooling

## 简介

A flutter plugin for .net SignalR client. This client is for ASP.Net SignalR, not for .Net Core SignalR.

- 源码仓库: https://github.com/AS-Devs/signalr_flutter
