# dio_http_cache_thmoises

**Tag**: web, mobile, ui, networking

## 简介

http cache lib for Flutter dio like RxCache, based on dio-http-cache.It use sqflite as disk cache,and google/quiver-dart/LRU strategy as memory cache.
