# z_tools

**Tag**: mobile, ui

## 简介

Integrates some common tools used by flutter projects. Including computing widget size, some useful extensions like `Map.forceConvertMap`, `List.tryGet` and `String.isSafeEmpty`. It also includes base64 codec.
