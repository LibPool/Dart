# smtpd

**Tag**: web

## 简介

SMTP Server library for dart. Meant as a simple way to receive emails behind a postfix server.

## 官网

- 主页: https://github.com/authpass/smtpd.dart
- pub.dev: https://pub.dev/packages/smtpd
