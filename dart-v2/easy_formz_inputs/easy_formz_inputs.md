# easy_formz_inputs

**Tag**: mobile, ui

## 简介

The easy_formz_inputs library provides pre-built, validated input fields for use in Dart and Flutter applications. Inputs currently provided include email, password, confirm password, urls, date, phone, and non-empty fields.
