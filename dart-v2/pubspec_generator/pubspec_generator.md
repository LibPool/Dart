# pubspec_generator

**Tag**: pubspec, yaml, generator, build, version, ui, serialization, tooling

## 简介

Code generator pubspec.yaml.g.dart from pubspec.yaml. Just import `pubspec_generator` and then run `dart run build_runner build`
