# oktoast

**Tag**: mobile, ui

## 简介

A pure flutter toast library, support custom style/widget, easy achieve the same effect with native toasts.

## 官网

- 源码仓库: https://github.com/OpenFlutter/flutter_oktoast
- pub.dev: https://pub.dev/packages/oktoast
