# tweenmax

**Tag**: web, mobile, networking

## 简介

A tween library plugin package for Flutter project, inspired from GreenSock TweenMax: https://greensock.com/docs/TweenMax.

## 官网

- 主页: https://github.com/mrgoonie/flutter_tweenmax
