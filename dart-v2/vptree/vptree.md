# vptree

**Tag**: mobile

## 简介

Dart implementation for efficient neighbour search based on vantage-point (VpTree) data structure to be used in Flutter projects.

## 官网

- 源码仓库: https://github.com/quantal-solutions/vptree.dart
- pub.dev: https://pub.dev/packages/vptree

## 历史版本号

- 0.1.0 (2020-12-07)
