# zx_tape_to_wav

**Tag**: mobile

## 简介

Easy Flutter library to convert .TAP/.TZX files (a data format for ZX-Spectrum emulator) into sound WAV file.

## 官网

- 主页: https://github.com/semack/zx_tape_to_wav
