# opencv

**Tag**: mobile

## 简介

Flutter plug-in providing (a few) basic bindings to OpenCV-4.x. OpenCV methods implemented without the Core packages. WIP.

- 主页: https://github.com/AdityaMulgundkar/flutter_opencv
