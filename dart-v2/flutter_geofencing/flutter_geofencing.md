# flutter_geofencing

**Tag**: mobile

## 简介

A geofencing plugin for Flutter applications - Works on both Android and iOS - supports Android X - based on Ben Konyi's Geofencing.

## 官网

- 主页: https://github.com/KarimAbdo/FlutterGeofencing
- pub.dev: https://pub.dev/packages/flutter_geofencing
