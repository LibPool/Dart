# flutter_curl

**Tag**: web, mobile, desktop, networking

## 简介

Flutter plugin to use libcurl for HTTP calls in Android, iOS and macOS with support for HTTP2, ALPN, brotli compression and experimental support for HTTP3 and alt-svc.
