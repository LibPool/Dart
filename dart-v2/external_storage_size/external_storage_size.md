# external_storage_size

**Tag**: mobile

## 简介

A new Flutter plugin to get Android's External Storage Size (This plugin works for Android only). It uses Android's Enviroment package to obtain External Storage size.

## 官网

- 主页: https://github.com/andreshgkenility/external_storage_size
