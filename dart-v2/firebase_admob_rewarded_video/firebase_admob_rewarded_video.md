# firebase_admob_rewarded_video

**Tag**: web, mobile, ui

## 简介

A Flutter plugin for firebase_admob rewarded video that allows passing the user id and custom data for Server-Side Verification (SSV). This was built on top of the already existing firebase_admob flutter plugin.
