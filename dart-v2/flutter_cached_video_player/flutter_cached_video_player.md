# flutter_cached_video_player

**Tag**: mobile

## 简介

A new flutter plugin that is virtually a clone of official video_player plugin except that it supports caching( Android and iOS)

## 官网

- 主页: https://github.com/ductung-bfast/flutter_cached_video_player
- pub.dev: https://pub.dev/packages/flutter_cached_video_player
