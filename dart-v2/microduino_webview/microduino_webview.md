# microduino_webview

**Tag**: web, mobile, ui

## 简介

A Flutter plugin that allows you to add an inline webview or open an in-app browser window (inspired by the popular cordova-plugin-inappbrowser).

## 官网

- 主页: https://github.com/tangxiafeng/flutter_webivew_plugin.git
- pub.dev: https://pub.dev/packages/microduino_webview
