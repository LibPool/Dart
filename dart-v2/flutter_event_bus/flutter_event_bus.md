# flutter_event_bus

**Tag**: web, mobile, state-management

## 简介

A library to provide EventBus and Interactor to Flutter app.
It enables developer to write flutter app with Interactor pattern.
Interactor pattern is a pattern similar to bloc, but with less structure and restriction
