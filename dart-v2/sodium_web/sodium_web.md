# sodium_web

**Tag**: web, mobile, networking

## 简介

A new flutter plugin project for [libsodium](https://libsodium.gitbook.io/doc/) support on flutter web with the help of [libsodium.js](https://github.com/jedisct1/libsodium.js/).
