# hey_sd_reader

**Tag**: mobile, ui

## 简介

Sample Package for SoftwareDesign May 2023. This package includes one Flutter Widget named "HeySdReader". HeySdReader widget is just a simple ElevatedButton and that shows the Alert Dialog with message "HEY SD READER!!". This package is for explaining how to publish your original widget to 'pub.dev' .
