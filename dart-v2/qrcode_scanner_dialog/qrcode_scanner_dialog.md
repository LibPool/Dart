# qrcode_scanner_dialog

**Tag**: web, mobile

## 简介

Plugin to show a simple scanner dialog and capture Bar/QR code easily. Works with Android iOS and Web. It uses html5-qrcode scanner for web and qr_code_scanner for Android and iOS
