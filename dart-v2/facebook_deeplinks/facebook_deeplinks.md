# facebook_deeplinks

**Tag**: mobile

## 简介

A flutter plugin to get facebook deeplinks and transferring them to the flutter application.

## 官网

- 主页: https://github.com/rbcprolabs/facebook_deeplinks
- pub.dev: https://pub.dev/packages/facebook_deeplinks

## 历史版本号

- 0.1.0 (2020-01-22)

## 获取地址

- pub.dev: https://pub.dev/packages/facebook_deeplinks
- pub 安装: `dart pub add facebook_deeplinks`
- Flutter 安装: `flutter pub add facebook_deeplinks`
- 最新版本: 0.1.0
- 最新版归档: https://pub.dev/api/archives/facebook_deeplinks-0.1.0.tar.gz
- 版本锁定: `facebook_deeplinks: ^0.1.0`
- 中央仓库: https://pub.dev/
