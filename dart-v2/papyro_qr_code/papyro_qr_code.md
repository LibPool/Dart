# papyro_qr_code

**Tag**: web, mobile, networking

## 简介

A Plug-in for dart, which help you scanning barcode and qrcode with android and ios device derived from https://pub.dev/packages/qrscan.

## 官网

- 主页: https://pub.dev/packages/qrscan
- pub.dev: https://pub.dev/packages/papyro_qr_code

## 历史版本号

- 0.0.1 (2020-08-12)

## 获取地址

- pub.dev: https://pub.dev/packages/papyro_qr_code

- Flutter 安装: `flutter pub add papyro_qr_code`
