# ai_barcode_scanner

**Tag**: qr-code, barcode, scanner, camera, mobile-scanner, web, mobile, desktop, ui

## 简介

Barcode and QR code scanner for Flutter on Android, iOS, macOS and the web: a full-screen or embedded scanner UI in one call, built on mobile_scanner.
