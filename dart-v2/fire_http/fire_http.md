# fire_http

**Tag**: web, mobile, networking, tooling

## 简介

The fire_http is a Firestrarter plugin who helps you to implement client of HTTP/1.1 or HTTP/2 on Flutter Project.

- 源码仓库: https://github.com/DigitalKatalis/firestarter/tree/main/app/library/fire_http
