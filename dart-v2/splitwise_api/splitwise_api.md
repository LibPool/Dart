# splitwise_api

**Tag**: splitwise, api-client, oauth2, expenses, web, security, tooling

## 简介

A typed Dart client for the Splitwise API v3.0 with OAuth 2.0 and API-key authentication, covering users, groups, friends, expenses and comments.
