# flame_tiled

**Tag**: flame, tiled, tilemap

## 简介

Tiled support for the Flame game engine. This uses the tiled package and provides wrappers and components to be used inside Flame.

## 官网

- 主页: https://github.com/flame-engine/flame/tree/main/packages/flame_tiled
- pub.dev: https://pub.dev/packages/flame_tiled
