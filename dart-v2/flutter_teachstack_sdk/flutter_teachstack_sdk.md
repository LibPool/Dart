# flutter_teachstack_sdk

**Tag**: mobile

## 简介

Flutter SDK for teachstack. Use FlutterTeachstackSdk.liveClass("URL") from MethodChannel 'flutter_teachstack_sdk' to get our live class within your ios and android application.
