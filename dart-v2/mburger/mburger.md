# mburger

**Tag**: web, networking, tooling

## 简介

MBurger Dart client. You can use this package to interact with the MBurger headless CMS (https://www.mburger.cloud).

## 官网

- 主页: https://web.mburger.cloud
- 源码仓库: https://github.com/Mumble-SRL/MBurger-Dart
- pub.dev: https://pub.dev/packages/mburger
