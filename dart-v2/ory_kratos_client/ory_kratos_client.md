# ory_kratos_client

**Tag**: web, security, tooling

## 简介

OpenAPI API client for Ory Kratos, Ory&#39;s central identity management solution with hardened authentication, MFA, FIDO2, TOTP, WebAuthn, SSO, profile management, and more.
