# at_onboarding_flutter

**Tag**: mobile, security

## 简介

DEPRECATED THIS PACKAGE IS NOT BEING MAINTAINED. A Flutter plugin project for onboarding any atSign in atPlatform apps with ease. Provides a QRscanner option and an upload key file option to authenticate.
