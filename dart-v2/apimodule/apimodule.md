# apimodule

**Tag**: web

## 简介

Module ini digunakan sebagai Service dan Models untuk aplikasi Mirai Simpersaa dan Medis milik RSUD Arifin Achmad Pekanbaru. Penggunaan dalam hal lain tidak dibenarkan.
