# nostr

**Tag**: nostr, protocol, bitcoin, lightning, cryptography, web, mobile, security

## 简介

Pure-Dart Nostr protocol library. Events, signing, NIP-44 encryption, gift wrap, and 35+ NIPs. Transport-agnostic, Flutter Web compatible.
