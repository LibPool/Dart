# tfx

**Tag**: web, mobile

## 简介

TensorFlow Lite Flutter plugin provides an easy, flexible, and fast Dart API to integrate TFLite models in flutter apps.

## 官网

- 主页: https://github.com/RxReader/tflite
- pub.dev: https://pub.dev/packages/tfx

## 历史版本号

## 获取地址

- pub.dev: https://pub.dev/packages/tfx

- Flutter 安装: `flutter pub add tfx`

- 最新版归档: https://pub.dev/api/archives/tfx-0.0.1.tar.gz
