# dio_http_cache

**Tag**: web, mobile, ui, networking

## 简介

http cache lib for Flutter dio like RxCache.It use sqflite as disk cache,and google/quiver-dart/LRU strategy as memory cache.

- 主页: https://github.com/hurshi/dio-http-cache
