# dynamo_json

**Tag**: ui, serialization, tooling

## 简介

A Dart `build_runner` to generate `toDynamoJson` and `fromDynamoJson` support methods, similar to `json_serializable`, specifically supporting the `DynamoDB` attribute values.`
