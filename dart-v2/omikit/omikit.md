# omikit

**Tag**: mobile

## 简介

OmiKit Flutter is wrapper SDK for OmiCall for Application easy integrate features of Omicall Like Call App2App/App2Phone, Video Call.

- 主页: https://github.com/VIHATTeam/OMICALL-Flutter-SDK
