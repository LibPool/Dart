# zxing_lib

**Tag**: library

## 简介

A Dart port of zxing that encode and decode multiple 1D/2D barcodes, Supported qrcode, pdf417, oned, maxicode, datamatrix, aztec.

- 源码仓库: https://github.com/shirne/zxing-dart
