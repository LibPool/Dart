# flex_seed_scheme

**Tag**: theme, colorscheme, material3, color, materialdesign, mobile, ui

## 简介

A more flexible and powerful version of Flutter's ColorScheme.fromSeed. Use multiple seed colors, custom chroma and tone mapping.
