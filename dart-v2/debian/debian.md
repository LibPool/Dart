# debian

**Tag**: mobile, ui, tooling

## 简介

A command application to help you easily bundle your flutter app build into a debian package ready for production.

## 官网

- 主页: https://github.com/felipheallef/flutter_debian
- pub.dev: https://pub.dev/packages/debian

## 历史版本号

- 1.0.0 (2023-10-31)

## 获取地址

- pub.dev: https://pub.dev/packages/debian
- pub 安装: `dart pub add debian`
- Flutter 安装: `flutter pub add debian`
- 最新版本: 1.0.0
- 最新版归档: https://pub.dev/api/archives/debian-1.0.0.tar.gz
- 版本锁定: `debian: ^1.0.0`
- 中央仓库: https://pub.dev/
