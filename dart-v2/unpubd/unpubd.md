# unpubd

**Tag**: web

## 简介

Self hosted Dart Pub Server. Host your enterprise Dart packages internally using the same web interface and tools as pub.dev.

## 官网

- 主页: https://github.com/bsutton/unpubd
- pub.dev: https://pub.dev/packages/unpubd
