# mxflutter

**Tag**: mobile

## 简介

JavaScript Flutter Framework,Using mxflutter lib, you can use JavaScript to develop flutter or use Dart to develop and compile to JS.

## 官网

- 主页: https://github.com/mxflutter/mxflutter
- pub.dev: https://pub.dev/packages/mxflutter

## 获取地址

- pub.dev: https://pub.dev/packages/mxflutter
- pub 安装: `dart pub add mxflutter`
- Flutter 安装: `flutter pub add mxflutter`

- 最新版归档: https://pub.dev/api/archives/mxflutter-0.2.5.tar.gz
