# airnmapdb

**Tag**: mobile, database, tooling

## 简介

lutter plugin for airnmap Database, a cloud-hosted NoSQL database with realtime data syncing across Android and iOS clients, and offline access.

## 官网

- 主页: https://airnmap.com
- pub.dev: https://pub.dev/packages/airnmapdb

- 0.0.1 (2020-03-19)
