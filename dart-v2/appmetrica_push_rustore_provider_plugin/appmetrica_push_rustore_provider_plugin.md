# appmetrica_push_rustore_provider_plugin

**Tag**: mobile, state-management

## 简介

A Flutter plugin for RuStore provider for AppMetrica Push SDK by Yandex. The AppMetrica Push SDK is a set of libraries for working with push notifications.
