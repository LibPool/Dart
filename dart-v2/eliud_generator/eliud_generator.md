# eliud_generator

**Tag**: state-management, tooling

## 简介

Eliud Code Generator is used by most eliud packages to generates models, entities, repositories, blocs, components, etc based on details in spec files.

## 官网

- 主页: https://eliud.io
- 源码仓库: https://github.com/eliudio/eliud_generator
- pub.dev: https://pub.dev/packages/eliud_generator
