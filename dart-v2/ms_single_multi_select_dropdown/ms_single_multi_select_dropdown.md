# ms_single_multi_select_dropdown

**Tag**: dropdown, multi-select, keyboard-navigation, accessibility, overlay, mobile, ui

## 简介

A customizable Flutter widget for single and multi-select dropdowns dialog with search, styling, and focus control. Ideal for forms, filters, and dynamic lists.
