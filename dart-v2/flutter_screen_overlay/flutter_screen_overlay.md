# flutter_screen_overlay

**Tag**: web, mobile, desktop

## 简介

Flutter plugin for displaying persistent Android overlay windows above other apps. Supports foreground service lifecycle, draggable PiP overlays, and null-intent crash recovery on system-initiated service restarts.
