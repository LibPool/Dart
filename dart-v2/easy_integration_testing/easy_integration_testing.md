# easy_integration_testing

**Tag**: mobile, ui, testing

## 简介

A new Flutter package project. Create to make integrational testing easier. You can use several tapKey, tapWidget and other easy commands to make work faster. There will be possible not just to make integrational test, also to take screenshots of each test.
