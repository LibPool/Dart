# flame_forge2d

**Tag**: flame, forge2d, physics

## 简介

Forge2D (Box2D) support for the Flame game engine. This uses the forge2d package and provides wrappers and components to be used inside Flame.

## 官网

- 主页: https://github.com/flame-engine/flame/tree/main/packages/flame_forge2d
- pub.dev: https://pub.dev/packages/flame_forge2d
