# string_converters

**Tag**: library

## 简介

Converts strings via: toVarName(x), toLowerCamelCase(x), toClassName(x), toUpperCamelCase(x), toConstName(x), toUpperCaseWith(x,"_")\, toTableName(x), toLowerCaseWith(x,"_"), toPolyName(x), toLowerCaseWith(x,"-")
