# signalr_client_mrj

**Tag**: web, mobile, tooling

## 简介

A flutter client for ASP.NET Core SignalR. The client is able to invoke server side hub functions and to receive method invocations issued by the server. BETA extension of the original signalr_client library from Sörnt Poppe.
