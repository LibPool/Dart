# bayarcash

**Tag**: payment, payment-gateway, bayarcash, fpx, web, mobile

## 简介

Dart SDK for the Bayarcash payment gateway. A feature-parity, idiomatic port of the official PHP SDK, usable from Flutter apps and server-side Dart.
