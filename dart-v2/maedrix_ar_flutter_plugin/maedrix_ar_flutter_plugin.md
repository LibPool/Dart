# maedrix_ar_flutter_plugin

**Tag**: mobile, ui, testing, tooling

## 简介

This is a fork of the original CariusLars package.  It has latest graddle setting to allow building in FlutterFlow. Flutter Plugin for creating (collaborative) Augmented Reality experiences - Supports ARKit for iOS and ARCore for Android devices.
