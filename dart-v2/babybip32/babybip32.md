# babybip32

**Tag**: web, mobile, networking

## 简介

A BIP32 (https://github.com/bitcoin/bips/blob/master/bip-0032.mediawiki) compatible library for Flutter writing by Dart.

## 官网

- 主页: https://github.com/lpreimesberger/bip32-dart
- pub.dev: https://pub.dev/packages/babybip32

## 历史版本号

- 1.0.8 (2020-11-20)

## 获取地址

- pub.dev: https://pub.dev/packages/babybip32
- pub 安装: `dart pub add babybip32`
- Flutter 安装: `flutter pub add babybip32`
- 最新版本: 1.0.8
- 最新版归档: https://pub.dev/api/archives/babybip32-1.0.8.tar.gz
- 版本锁定: `babybip32: ^1.0.8`
- 中央仓库: https://pub.dev/
