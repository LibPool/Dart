# onnxruntime

**Tag**: onnx, tflite, pytorch, ai, web, mobile, desktop

## 简介

Flutter plugin for OnnxRuntime provides an easy, flexible, and fast Dart API to integrate Onnx models in flutter apps across mobile and desktop platforms.
