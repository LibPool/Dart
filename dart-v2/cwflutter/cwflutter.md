# cwflutter

**Tag**: mobile

## 简介

A plugin that implements the ConfigWise SDK to have AR capability with a flutter app.

## 官网

- 主页: https://www.configwise.io
- 源码仓库: https://github.com/configwise/configwise-sdk-flutter
- pub.dev: https://pub.dev/packages/cwflutter
