# bloc_widgets

**Tag**: mobile, ui, state-management, tooling

## 简介

A new Flutter package that provides an alternative to the `BlocBuilder/Listener/Consumer/Selector` with the idea based on the `ConsumerWidget` from `riverpod` library.
