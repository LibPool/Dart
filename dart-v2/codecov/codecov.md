# codecov

**Tag**: library

## 简介

Generates lcov and/or HTML coverage reports for Dart projects. (UNIX only)

## 官网

- 主页: https://github.com/codecov/dart
- pub.dev: https://pub.dev/packages/codecov

## 历史版本号

## 获取地址

- pub.dev: https://pub.dev/packages/codecov

- Flutter 安装: `flutter pub add codecov`

- 最新版归档: https://pub.dev/api/archives/codecov-1.0.0.tar.gz
