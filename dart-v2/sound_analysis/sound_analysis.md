# sound_analysis

**Tag**: mobile, tooling

## 简介

｜ Flutter Plugin for iOS's Sound Analysis framework. At present, It primaryly provides a feature：tell you the result of sound analysis to an audio file. The result lists every sound clip iOS recognized,including its name,range,and confidence.
