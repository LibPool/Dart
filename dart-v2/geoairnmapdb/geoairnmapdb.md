# geoairnmapdb

**Tag**: mobile, database, tooling

## 简介

flutter plugin for airnmap Database, a cloud-hosted NoSQL database with realtime data syncing across Android and iOS clients, and offline access.

## 官网

- 主页: https://airnmap.com
