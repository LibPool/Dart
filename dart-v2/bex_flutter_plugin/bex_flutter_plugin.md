# bex_flutter_plugin

**Tag**: mobile

## 简介

BKM Express Flutter Plugin, kullanıcının BKMExpress ile yapacağı ödemeler için kart eşleme ve güvenli ödeme yapma seçeneklerini sunmaktadır.
