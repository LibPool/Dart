# lightstreamer_flutter_client

**Tag**: web, mobile, desktop, tooling

## 简介

A Flutter plugin for Lightstreamer, a real-time data streaming server.  This plugin allows Flutter applications to connect to Lightstreamer  and subscribe to real-time data updates. It supports multiple platforms  including Android, iOS, Web, macOS, and Windows, enabling seamless  integration of real-time data streaming capabilities into your Flutter apps.
