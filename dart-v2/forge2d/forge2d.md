# forge2d

**Tag**: mobile

## 简介

A 2D physics engine for Dart, binding to the native Box2D v3 library. Also works with the Flame game engine in Flutter.

## 官网

- 主页: https://github.com/flame-engine/forge2d
- pub.dev: https://pub.dev/packages/forge2d
