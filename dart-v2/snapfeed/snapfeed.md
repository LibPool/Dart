# snapfeed

**Tag**: web, mobile, desktop

## 简介

Snapfeed is an interactive user feedback tool for Flutter apps. Its purely written in Dart and runs on Android, iOS, Desktop and the Web.

## 官网

- 主页: https://snapfeed.dev
- 源码仓库: https://github.com/snapfeed/snapfeed-sdk
- pub.dev: https://pub.dev/packages/snapfeed
