# flutter_emas_push

**Tag**: mobile, tooling

## 简介

A flutter plugin integrating EMAS push. You can  push offline notification to client by mobile channel. Now HuaWei、Xiaomi,Vivo,Oppo,MeiZu,GCM supported.
