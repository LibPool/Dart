# fast_poisson_disk_sampling

**Tag**: web, networking

## 简介

Dart port of the JS library https://github.com/kchapelier/fast-2d-poisson-disk-sampling. Fast 2D Poisson Disk Sampling based on a modified Bridson algorithm
