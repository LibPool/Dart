# install_apk

**Tag**: mobile

## 简介

A flutter plugin for install apk for android; and using url to go to app store for iOS.

## 官网

- 主页: https://github.com/epireyn/flutter_install_plugin
- pub.dev: https://pub.dev/packages/install_apk
