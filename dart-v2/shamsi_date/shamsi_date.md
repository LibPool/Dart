# shamsi_date

**Tag**: mobile

## 简介

A Flutter and Dart package for using Jalali (Shamsi, Solar, Persian, Jalaali or شمسی) calendar. You can convert, format and manipulate Jalali and Gregorian (Miladi) date and times.
