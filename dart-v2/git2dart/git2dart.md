# git2dart

**Tag**: mobile

## 简介

Dart bindings to libgit2, provides ability to use libgit2 library in Dart and Flutter.

## 官网

- 源码仓库: https://github.com/DartGit-dev/git2dart
- pub.dev: https://pub.dev/packages/git2dart
