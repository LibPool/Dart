# flutter_gl_windows_flutterflow

**Tag**: web, mobile, desktop, ui

## 简介

Windows platform implementation of flutter_gl_flutterflow. Fixed for Flutter 3.32.4+ compatibility. OpenGL API through dart:ffi with Texture Widget.
