# kakao_flutter_sdk_common

**Tag**: web, mobile

## 简介

A flutter plugin for Kakao API, which supports Kakao login, KakaoTalk Share, User API, KakaoTalk API and Navi API.

## 官网

- 主页: https://developers.kakao.com/docs/latest/flutter/getting-started

- 问题追踪: https://github.com/kakao/kakao_flutter_sdk/issues
