# wallpaperplugin

**Tag**: mobile

## 简介

Flutter plugin to set wallpaper in android, it can be used to directly set any image or crop and set as wallpaper.

## 官网

- 主页: https://github.com/ganeshsp1/wallpaperplugin
- pub.dev: https://pub.dev/packages/wallpaperplugin
