# device_information

**Tag**: web, mobile

## 简介

A flutter plugin to get device information such as device IMEI number,model name,API level,CPU Type,Product Name etc for both android & iOS.

- 主页: https://github.com/Hina-Hussain/DeviceInformationPlugin
