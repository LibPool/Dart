# horizontal_weekly_calendar

**Tag**: calendar, horizontal-calendar, schedule, events, date-picker, mobile, ui

## 简介

A beautiful, reliable, and fully customizable horizontal calendar UI kit for Flutter, with events, agendas, timelines, and foldable month views.
