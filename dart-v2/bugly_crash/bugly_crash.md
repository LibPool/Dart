# bugly_crash

**Tag**: web, mobile

## 简介

Flutter app can use this plugin to monitor exception happened and upload error or crash to bugly server.

## 官网

- 主页: https://bugly.qq.com
- pub.dev: https://pub.dev/packages/bugly_crash
