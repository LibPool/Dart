# halo_sdk_flutter_plugin

**Tag**: contactless, payment, card, mobile, ui

## 简介

A flutter plugin of the Halo Dot SDK that allows integrators to embed contactless payments into their own Flutter mobile apps. The SDK provides a fully isolated SDK that meets requirements of PCI MPoC.
