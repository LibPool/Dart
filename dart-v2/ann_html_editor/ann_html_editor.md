# ann_html_editor

**Tag**: web, mobile, ui, networking, tooling

## 简介

HTML rich text editor for Android, iOS, and Web, using the Summernote library. Enhanced with highly customizable widget-based controls, bug fixes, callbacks, dark mode, and more. fork from https://github.com/tneotia/html-editor-enhanced fix iOS build error and dependency conflict, optimize custom media embed features
