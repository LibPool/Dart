# flutter_accessibility_scanner

**Tag**: accessibility, a11y, wcag, semantics, testing, mobile, ui, serialization

## 简介

Scan Flutter widget trees for WCAG 2.1 accessibility issues (missing labels, low contrast, small tap targets, focus) with fix hints and JSON reports.
