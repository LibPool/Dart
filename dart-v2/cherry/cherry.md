# cherry

**Tag**: mobile, tooling

## 简介

Dart CLI template generator and package manager for flutter, generate MVC, MVVM and MVU patterns.

## 官网

- 主页: https://github.com/Sameerkash/cherry
- pub.dev: https://pub.dev/packages/cherry

## 历史版本号

## 获取地址

- pub.dev: https://pub.dev/packages/cherry
- pub 安装: `dart pub add cherry`
- Flutter 安装: `flutter pub add cherry`
- 最新版本: 0.0.1-alpha
- 最新版归档: https://pub.dev/api/archives/cherry-0.0.1-alpha.tar.gz
- 版本锁定: `cherry: ^0.0.1-alpha`
