# loui_flutter

**Tag**: mobile, ui

## 简介

loui_flutter is a library for generating TOTP codes, with easy registration and configuration through console.loui.io.

## 官网

- 源码仓库: https://bitbucket.org/vortexbirdsas/flutter-loui/
