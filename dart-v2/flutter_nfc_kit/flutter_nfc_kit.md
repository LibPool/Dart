# flutter_nfc_kit

**Tag**: web, mobile

## 简介

Provide NFC functionality on Android, iOS & Web, including reading metadata, read & write NDEF records, and transceive layer 3 & 4 data with NFC tags / cards

- 主页: https://github.com/nfcim/flutter_nfc_kit
