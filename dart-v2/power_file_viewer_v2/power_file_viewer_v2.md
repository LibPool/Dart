# power_file_viewer_v2

**Tag**: web, mobile, ui

## 简介

A powerful file view widget, support a variety of file types, such as Doc Eexcl PPT TXT PDF and so on, Android is implemented by Tencent X5, iOS is implemented by WKWebView.
