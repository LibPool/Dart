# webcolors

**Tag**: web, mobile

## 简介

Package exporting all 137 X11/CSS3 colors for Flutter projects.

## 官网

- 主页: https://github.com/caiopo/webcolors
- pub.dev: https://pub.dev/packages/webcolors

## 历史版本号

- 0.1.0 (2019-05-19)

## 获取地址

- pub.dev: https://pub.dev/packages/webcolors
- pub 安装: `dart pub add webcolors`
- Flutter 安装: `flutter pub add webcolors`
- 最新版本: 0.1.0
- 最新版归档: https://pub.dev/api/archives/webcolors-0.1.0.tar.gz
- 版本锁定: `webcolors: ^0.1.0`
- 中央仓库: https://pub.dev/
