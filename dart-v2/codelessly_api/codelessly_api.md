# codelessly_api

**Tag**: web, mobile, ui, serialization

## 简介

Flutter's layouts and widgets represented as models and JSON data. This API is used by the Codelessly Editor and CloudUI SDK to render Flutter Widgets.

## 官网

- 主页: https://codelessly.com/
- 源码仓库: https://github.com/Codelessly/CodelesslyAPI
- pub.dev: https://pub.dev/packages/codelessly_api
