# adobe_xd

**Tag**: mobile, ui, tooling

## 简介

Generate code for building apps with Flutter based on your designs in Adobe XD with the “XD to Flutter” plugin. This package contains helper widgets used by the plugin.

## 官网

- 主页: https://adobe.com/go/xd_to_flutter
- 源码仓库: https://github.com/AdobeXD/xd-to-flutter-plugin/tree/master/adobe_xd
- pub.dev: https://pub.dev/packages/adobe_xd
