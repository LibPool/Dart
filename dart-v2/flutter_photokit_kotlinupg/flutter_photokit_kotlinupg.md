# flutter_photokit_kotlinupg

**Tag**: web, mobile, networking

## 简介

Flutter plugin for interacting with PhotoKit on iOS. Contains methods for saving photos/videos to user's camera roll or custom albums. Re-published with upgraded kotlin version by https://github.com/shinyford/flutter_photokit
