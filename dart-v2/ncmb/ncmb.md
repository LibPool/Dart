# ncmb

**Tag**: web, mobile

## 简介

Dart and Flutter library for Nifcloud mobile backend(NCMB). Nifcloud mobile backend is a web service of mBaaS.

## 官网

- 主页: https://github.com/NCMBMania/ncmb-dart
- pub.dev: https://pub.dev/packages/ncmb
