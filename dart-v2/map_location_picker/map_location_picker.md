# map_location_picker

**Tag**: map-picker, location-picker, flutter-location-picker, google-maps-flutter, places-autocomplete, web, mobile

## 简介

A Google Maps location picker for Flutter with Places API (New) search, marker or centre-pin picking, and typed addresses. Android, iOS and web.
