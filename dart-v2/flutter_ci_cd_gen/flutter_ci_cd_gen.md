# flutter_ci_cd_gen

**Tag**: web, mobile, testing

## 简介

A flutter package that generates custom CI/CD for gitlab. Allows you to use SonarQube, to deploy your Tests Reports to Gitlab Pages and to deploy your web app to a Docker Image.
