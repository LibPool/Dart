# flutter_webview_plugin_enhance

**Tag**: web, mobile

## 简介

Plugin that allow Flutter to communicate with a native Webview. Fork from flutter_webview_plugin 0.3.0+2. Support host app handle schemas. Such as "tel", "sms", "alipays", "wechat"...
