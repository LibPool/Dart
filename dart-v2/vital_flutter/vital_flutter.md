# vital_flutter

**Tag**: web, mobile

## 简介

The official Flutter package for Vital APIs allowing fitness apps linking with tryvital.io and with support for HealthKit.

## 官网

- 主页: https://tryvital.io/
- 源码仓库: https://github.com/tryVital/vital-flutter
- pub.dev: https://pub.dev/packages/vital_flutter
