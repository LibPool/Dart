# schema_form

**Tag**: web, mobile, ui, serialization, networking, tooling

## 简介

Schema_form is a Flutter package based on two other packages that produces forms dynamically interpreting JSON objects:
* [dynamic_widget](https://pub.dev/packages/dynamic_widget) - Which builds forms through JSON interpretation; * [json_schema](https://pub.dev/packages/json_schema) - Identifying, defining and validating the properties of the object being edited.
