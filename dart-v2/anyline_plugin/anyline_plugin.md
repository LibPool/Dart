# anyline_plugin

**Tag**: mobile

## 简介

Flutter Plugin for Anyline OCR, which allows you to scan all kinds of numbers, characters, text and codes.

## 官网

- 主页: https://anyline.com
- 源码仓库: https://github.com/Anyline/anyline-ocr-flutter-module
- 文档: https://documentation.anyline.com
- pub.dev: https://pub.dev/packages/anyline_plugin
