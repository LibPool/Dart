# flutter_blue_plus_ohos

**Tag**: web, mobile

## 简介

flutter_blue_plus is an enhanced Flutter plugin for Bluetooth Low Energy (BLE) communication, providing a robust and feature-rich API to interact with BLE devices on OHOS platforms.
