# flutter_manager

**Tag**: mobile, ui

## 简介

A useful command line tool for Flutter, which support flutter component management, built-in commands and custom command etc.（一个实用的Flutter命令行工具，支持 flutter 组件管理、内置命令和自定义命令等）
