# play_webuic

**Tag**: web, ui, networking

## 简介

Web UI compiler wrapper that publish web_ui files dependencies.
Is is used by sbt-dart-plugin https://github.com/cheleb/sbt-dart-plugin

## 官网

- 主页: https://github.com/cheleb/sbt-dart-plugin
