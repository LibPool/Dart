# builder

**Tag**: ui, tooling

## 简介

Build tool library for Dart, to easily create flexible `build.dart` files compatible with the Dart Editor, and `pub` transformers for standard Dart tools.

## 官网

- 主页: https://github.com/groboclown/builder.dart
