# ascii_type

**Tag**: library

## 简介

Classification and conversion of ASCII characters. Includes functions: isalnum, isalpha, isblank, iscntrl, isdigit, isgraph, islower, isprint, ispunct, isspace, isupper, isxdigit, tolower, toupper.
