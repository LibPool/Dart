# xml2json

**Tag**: conversion, network, web, xml, json, serialization, networking

## 简介

An XML to JSON conversion package. Supports Badgerfish, GData, OpenRally and Parker conversions.

## 官网

- 主页: https://github.com/shamblett/xml2json
- pub.dev: https://pub.dev/packages/xml2json
