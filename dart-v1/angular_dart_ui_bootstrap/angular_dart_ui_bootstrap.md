# angular_dart_ui_bootstrap

**Tag**: web, ui, networking

## 简介

Port of angular-ui bootstrap (http://angular-ui.github.io/) to dart. It contains a set of native Angular.dart components based on  Bootstrap's 3.x CSS. No dependency on Bootstrap's JavaScript or Angular-ui is required.
