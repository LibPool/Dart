# crossdart

**Tag**: library

## 简介

Generates crossdart.info content. Also, allows to generate metadata for the project, and then use the Chrome Extension to add links to the declarations on Github

## 官网

- 主页: https://www.crossdart.info
- pub.dev: https://pub.dev/packages/crossdart
