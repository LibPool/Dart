# modulation

**Tag**: library

## 简介

A modulation library that can be used in conjuction with creating periodic saw, sine, square and triangle waveforms.

- 主页: https://github.com/pflannery/dart-modulation
- pub.dev: https://pub.dev/packages/modulation
