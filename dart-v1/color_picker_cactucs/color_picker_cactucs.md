# color_picker_cactucs

**Tag**: library

## 简介

The Color Picker control creates a Adobe Photoshop style HSV color picker  where the RGB values can be picked based on the Hue, Saturation and Value  parameters.  Multiple sizes are supported. This is a fork from original color_picker repository.
