# indicator_tab_bar

**Tag**: tab-bar, tabs, indicator, sliver, widget, ui

## 简介

A fixed-width tab indicator that underlines the label rather than the tab, and a sliver AnimatedSwitcher for cross-fading the body each tab selects.
