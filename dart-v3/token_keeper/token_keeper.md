# token_keeper

**Tag**: auth, token, oauth, dio, interceptor, web, security

## 简介

Auth tokens, handled. Pure-Dart token manager with single-flight refresh, proactive expiry, JWT parsing with metadata extraction, background refresh timer, reactive streams, Result-based APIs, and a Dio interceptor for drop-in 401 retry.
