# gputext

**Tag**: flutter, text, gpu, rendering, fonts, web, mobile

## 简介

GPU-accelerated vector text for Flutter. Analytic coverage shaders via Flutter GPU, with HarfBuzz shaping for complex scripts and bidirectional text.
