# model2vec

**Tag**: rag, nlp, embeddings, tokenizer, model2vec, mobile

## 简介

On-device Model2Vec text embeddings for Dart & Flutter — a self-contained Rust core via FFI and Native Assets. Fast, local, static, minimal memory.
