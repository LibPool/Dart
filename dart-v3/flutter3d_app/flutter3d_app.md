# flutter3d_app

**Tag**: game-engine, rendering, application, mobile, ui

## 简介

What any Flutter application on flutter3d is assembled from: which backend to open and the runtime fallback, the surface a frame reaches Flutter through, widgets drawn in the scene, a level loaded into a scene, and storage.
