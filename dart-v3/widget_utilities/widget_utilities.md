# widget_utilities

**Tag**: widgets, scanner, ocr, barcode, date-picker, mobile, ui

## 简介

Coleção de widgets utilitários para Flutter: scanner de texto e código de barras/QR com OCR, date picker e pull-to-refresh universais.
