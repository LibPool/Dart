# flutter_naver_map_web

**Tag**: maps, naver, web, geolocation, flutter-web, mobile, desktop, ui

## 简介

A Flutter web plugin for integrating Naver Maps API. Provides widgets and utilities to display interactive Naver Maps with markers, info windows, and various controls in Flutter web applications.
