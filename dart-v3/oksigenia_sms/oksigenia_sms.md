# oksigenia_sms

**Tag**: sms, android, telephony, messaging, emergency, mobile, state-management

## 简介

Permission-minimal Android SMS sender: sends one concatenated SMS using only SEND_SMS, no READ_PHONE_STATE. Works on Android 12-17 and GrapheneOS.
