# smf_bottom_tabs

**Tag**: flutter, navigation, layout, bottom-navigation, mobile, ui

## 简介

The SMF module of the main navigation of the Flutter app that SMF generates. It shows a tab for each destination in a bar at the bottom, in the colours of the theme.
