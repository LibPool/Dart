# flutter_esc_pos_usb_universal

**Tag**: usb, printer, thermal-printer, esc-pos, pos, web, mobile, desktop

## 简介

Print receipts on ESC/POS thermal USB printers from Android, Windows, macOS, Linux and Flutter Web, with one API. No printer driver needed.
