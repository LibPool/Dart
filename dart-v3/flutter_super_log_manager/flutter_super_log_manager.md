# flutter_super_log_manager

**Tag**: logging, debug, overlay, error-handling, mobile

## 简介

A comprehensive Flutter debug logging plugin with overlay bubble, error catching, and advanced log viewer. Supports RTL/LTR, custom navigation, and performance optimizations.
