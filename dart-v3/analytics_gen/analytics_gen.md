# analytics_gen

**Tag**: analytics, event-tracking, events-generator, analytics-generation, analytics-generator, serialization, testing, state-management, tooling

## 简介

Type-safe analytics event tracking with code generation from YAML configuration. Supports multiple providers, testing utilities, and export formats.
