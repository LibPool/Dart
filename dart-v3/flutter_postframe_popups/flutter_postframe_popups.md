# flutter_postframe_popups

**Tag**: widgets, lifecycle, dialog, async, mobile, ui, tooling

## 简介

Composable widgets for post-frame callbacks, dialogs, and modal bottom sheets with BuildContext, typed results, and shared async error handling.
