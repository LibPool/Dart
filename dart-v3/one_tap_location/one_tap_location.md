# one_tap_location

**Tag**: location, permissions, privacy, geolocation, widget, mobile, ui

## 简介

One tap gets the location: the Android 17 system location button, the iOS CLLocationButton, a fallback on Android 7–16. The button the Google Play location policy will require.
