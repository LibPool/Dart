# prism_toast

**Tag**: toast, notification, snackbar, ui, widget, web, mobile, desktop

## 简介

Beautiful adaptive toast notifications for Flutter — bottom-centered on mobile, stacked top-right on desktop and web, with icons, variants, and animations. Part of the Prism package family.
