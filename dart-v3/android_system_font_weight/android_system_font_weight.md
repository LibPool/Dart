# android_system_font_weight

**Tag**: mobile

## 简介

同步采集安卓系统字重原始 Map，提供 OPPO、小米、vivo、荣耀的取值参考函数。 调用方可自定义兼容策略；无法确定字重时返回 null，保留原有字体样式。
