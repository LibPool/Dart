# voxlang

**Tag**: web, mobile

## 简介

VOX - Lenguaje de programación 100% en español que transpila a Dart/Flutter. Diseñado para que personas hispanohablantes aprendan a programar y crear aplicaciones móviles, web y de escritorio.
