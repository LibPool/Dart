# drop_down_list_plus

**Tag**: ui, state-management

## 简介

A fork of drop_down_list with an optional clear button and a customizable empty-results state. Customizable dropdown widget supporting single/multiple selection, integrated search in a bottom sheet, generic support for flexible, type-safe handling of custom data.
