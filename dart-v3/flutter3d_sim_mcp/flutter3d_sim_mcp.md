# flutter3d_sim_mcp

**Tag**: game-development, mcp, tooling, ai, mobile

## 简介

A level an agent can play blind, of whatever game a host hands it — ai-00 — and why a frame of it is wrong: a debug view of normals and depth, the HDR value of one pixel, the passes the frame graph ran — par-02.
