# tap_tooltip

**Tag**: mobile, ui

## 简介

A highly customizable tap-to-show tooltip widget for Flutter. Supports four directions (top/bottom/left/right), custom arrow size, rounded corners, blur effect, overlay-safe positioning, and programmatic control via controller.
