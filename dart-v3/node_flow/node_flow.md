# node_flow

**Tag**: node-editor, flow, canvas, graph, diagram, mobile, ui

## 简介

React Flow-style node editor canvas for Flutter: pan/zoom viewport, draggable nodes, drag-to-connect edges, marquee selection, snap guides, and a minimap.
