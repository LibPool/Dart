# zero_tap_easy

**Tag**: authentication, android, credentials, passkeys, sign-in, web, mobile, security

## 简介

Zero-tap sign-in restoration for Android. Silently recreate a signed-in session on a user's new device using Credential Manager Restore Credentials.
