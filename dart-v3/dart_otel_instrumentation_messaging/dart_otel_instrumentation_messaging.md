# dart_otel_instrumentation_messaging

**Tag**: web, mobile, serialization, networking, tooling

## 简介

Traces a long-lived messaging connection (a WebSocket, a JSON-RPC socket) for flutter_otel: an HTTP client span for the upgrade, then a linked producer span per request and consumer span per server event.
