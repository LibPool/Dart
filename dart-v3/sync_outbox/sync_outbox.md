# sync_outbox

**Tag**: offline, sync, queue, retry, offline-first, mobile

## 简介

Storage-agnostic outbox for offline-first Dart and Flutter apps: queue mutations offline, then deliver them in order with retries, backoff, coalescing and conflict handling.
