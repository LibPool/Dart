# flutter_gl_web_flutterflow

**Tag**: web, mobile, ui

## 简介

Web platform implementation of flutter_gl_flutterflow. Fixed platformViewRegistry deprecation for Flutter 3.32.4+. OpenGL API through dart:ffi with Texture Widget.
