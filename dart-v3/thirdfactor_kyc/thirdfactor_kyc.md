# thirdfactor_kyc

**Tag**: web, mobile, tooling

## 简介

ThirdFactor / Obsidian KYC — Flutter client SDK. Opens the hosted verification flow in a WebView and returns one normalized result. Native ePassport/eID NFC reading plugs in via the thirdfactor_kyc_nfc companion.
