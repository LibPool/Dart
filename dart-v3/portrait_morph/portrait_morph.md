# portrait_morph

**Tag**: ui, animation, shader, widget, effects, web, mobile, desktop

## 简介

A pointer-driven image morph effect using a custom dart:ui fragment shader. Features fbm-noise wipe, edge ripple, and spring-eased transitions between two images. Supports hover (desktop/web) and press+drag (mobile).
