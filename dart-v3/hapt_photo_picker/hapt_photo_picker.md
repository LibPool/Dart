# hapt_photo_picker

**Tag**: photo-picker, image-picker, gallery, haptic, theming, mobile

## 简介

An Instagram-grade photo picker for Flutter with full token theming, fully overridable strings, choreographed haptics, and a pluggable post-processing pipeline.
