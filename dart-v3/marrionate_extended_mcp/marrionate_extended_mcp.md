# marrionate_extended_mcp

**Tag**: testing, e2e, flutter, automation, mcp, web, mobile, ui, tooling

## 简介

Unified Flutter end-to-end automation toolkit: MCP server, app-side bindings, scenario model, replay runtime, key injection builder, and vendored marionette/flutter-skill drivers behind a single package.
