# bfocus_monitor

**Tag**: monitoring, error-reporting, crash-reporting, logging, mobile

## 简介

Monitoramento de erros do bFocus para apps Flutter: captura os erros não tratados (FlutterError, PlatformDispatcher e zona) e manda para o bFocus.
