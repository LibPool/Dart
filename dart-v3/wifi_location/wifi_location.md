# wifi_location

**Tag**: mobile, ui

## 简介

A Flutter plugin to fetch available Wi-Fi SSIDs and user location, with built-in permission handling.

## 官网

- 主页: https://wiom.in
- pub.dev: https://pub.dev/packages/wifi_location
