# cipherbird_dart

**Tag**: cryptography, encryption, post-quantum, ffi, security

## 简介

Native cryptography for Dart over dart:ffi: hashing, AEAD, post-quantum, hybrid KEM, sealed messaging, Noise, recipes and easy-mode keys, engine bundled.
