# mermaid_flowchart

**Tag**: mermaid, flowchart, diagram, graph, visualization, web, mobile, ui

## 简介

Native Mermaid flowchart rendering for Flutter, no WebView: subgraphs, every node shape and link style, multi-line labels, orthogonal edges and light/dark themes.
