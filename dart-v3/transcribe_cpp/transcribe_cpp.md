# transcribe_cpp

**Tag**: speech-to-text, speech-recognition, transcription, offline, ffi, web, mobile, networking

## 简介

Offline, on-device speech-to-text for Flutter. Hands-free dictation with live text on iOS and Android: no network, no API keys, audio never leaves the phone.
