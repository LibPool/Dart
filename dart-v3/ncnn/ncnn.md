# ncnn

**Tag**: mobile

## 简介

ncnn (Vulkan) inference bindings for Dart/Flutter — a thin C shim over ncnn::Net exposed via dart:ffi. Runs image inference on CPU or any Vulkan-capable GPU (NVIDIA / AMD / Intel / Apple via MoltenVK / Android), with automatic CPU fallback. Ships ultralytics YOLO export conventions as defaults.
