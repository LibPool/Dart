# font_subset

**Tag**: fonts, flutter, hooks, web, mobile, desktop, ui, tooling

## 简介

Builds or fetches the Flutter font-subset binary for Linux, macOS, and Windows and provides a Dart API for subsetting TTF/OTF fonts.
