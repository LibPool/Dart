# flutter_corner_shape

**Tag**: mobile, ui, tooling

## 简介

CSS corner-shape for Flutter. Round, scoop, bevel, notch, squircle, and superellipse corners — per-corner control, smooth animations, and a drop-in ShapeBorder + Clipper.
