# didwebvh_wizard

**Tag**: did, didwebvh, ssi, identity, cryptography, web, security, tooling

## 简介

Interactive CLI wizard for did:webvh (create / update / resolve / export did:web). A faithful Dart port of didwebvh-java's didwebvh-wizard module.
