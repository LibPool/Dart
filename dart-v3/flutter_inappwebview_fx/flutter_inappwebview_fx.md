# flutter_inappwebview_fx

**Tag**: html, webview, webview-flutter, inappwebview, browser, web, mobile

## 简介

Inline WebView, headless WebView, and in-app browser for Flutter. Maintained fork of flutter_inappwebview with current Flutter/Dart, SPM-ready iOS deps, and no debug donation console banner.
