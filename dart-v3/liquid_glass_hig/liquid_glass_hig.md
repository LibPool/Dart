# liquid_glass_hig

**Tag**: ios, liquid-glass, cupertino, ui, design-system, mobile

## 简介

iOS 26 Liquid Glass UI primitives for Flutter — containers, sheets, nav bars, controls. Pixel-matched to Apple's HIG. Material 3 fallback on Android.
