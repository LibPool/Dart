# openlist_crypt

**Tag**: rclone, encryption, cryptography, openlist, webdav, web, security

## 简介

rclone / OpenList crypt storage format in Dart: scrypt keys, EME filename encryption, XSalsa20-Poly1305 content, optional libsodium FFI backend.
