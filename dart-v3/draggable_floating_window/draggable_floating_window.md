# draggable_floating_window

**Tag**: window, floating, draggable, desktop, dialog, mobile

## 简介

Draggable, resizable floating windows inside your Flutter app. Desktop-style window layer with minimize, maximize, priority stacking, dialog stacks and keyboard focus.
