# flutter_leak_sentinel

**Tag**: memory-leak, devtools, performance, testing, debugging, mobile, state-management

## 简介

Zero-config Flutter memory leak detection package. Detects un-disposed controllers, uncancelled stream subscriptions, and retained states with in-app floating HUD.
