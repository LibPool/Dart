# cloud_sync_s3

**Tag**: s3, aws, sync, storage

## 简介

S3 + S3-compatible adapter for the cloud_sync family. Works with AWS, R2, MinIO, B2, Wasabi, DO Spaces via endpoint override. Hand-rolled SigV4.
