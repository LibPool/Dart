# liteavsdk_voiceai

**Tag**: voice-ai, asr, tts, speech-recognition, speech-synthesis, mobile, desktop

## 简介

Flutter plugin for Tencent VoiceAI SDK. Provides realtime ASR (speech transcription), realtime TTS (speech synthesis) and audio denoise player, running on Android / iOS / macOS / Windows / OHOS.
