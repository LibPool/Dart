# in_app_mcp_gen

**Tag**: ui, tooling

## 简介

Build-runner code generator for in_app_mcp. Emits ToolDefinition and typed handler / previewer / undoer adapters from @McpTool, @McpToolPreview, and @McpToolUndo annotations.
