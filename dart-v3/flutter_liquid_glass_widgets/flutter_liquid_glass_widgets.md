# flutter_liquid_glass_widgets

**Tag**: liquid-glass, widgets, glassmorphism, flutter, apple, web, mobile, desktop, ui

## 简介

Flutter UI kit inspired by Apple’s iOS 26 Liquid Glass design language. A complete glass widget library featuring shader-powered blur, physics-based jelly animations, and dynamic lighting effects. Works out of the box across Android, iOS, web, desktop, and all Flutter-supported platforms.
