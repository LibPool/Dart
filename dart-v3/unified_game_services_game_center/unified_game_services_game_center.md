# unified_game_services_game_center

**Tag**: game-services, achievements, leaderboards, game-center, gamedev, mobile, desktop, state-management

## 简介

Apple Game Center provider for unified_game_services, backed by GameKit via pure-Dart Objective-C FFI (package:objective_c). macOS/iOS only.
