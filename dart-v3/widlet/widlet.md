# widlet

**Tag**: web, mobile, networking

## 简介

Open-source platform for isolated Flutter feature modules. Each widlet is a self-contained mini-app that runs inside a host Flutter app — deployable over WASM, Isolate, WebSocket, or in-memory transport.
