# fieldwise_sync

**Tag**: offline-first, sync, conflict-resolution, codegen, web, tooling

## 简介

Sincronização Offline-First em Dart com detecção de conflito por versão e resolução configurável por campo (LWW, Server Wins, mesclagem de três vias).
