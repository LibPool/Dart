# flutter_litert_lm

**Tag**: llm, on-device, litert, gemma, ai, mobile

## 简介

Flutter plugin for Google's LiteRT-LM — run Large Language Models on-device with CPU, GPU (OpenCL) or NPU acceleration. Supports Gemma, Qwen, Phi, DeepSeek and more.
