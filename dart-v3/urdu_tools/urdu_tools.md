# urdu_tools

**Tag**: urdu, nlp, unicode, text-processing, rtl, mobile

## 简介

Comprehensive Urdu text processing library — normalization, analysis, search, numbers, tokenization, string utilities, sorting, transliteration, compound word detection, and legacy encoding. Zero dependencies. Full Flutter support.
