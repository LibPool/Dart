# kata_cx

**Tag**: chat, chatbot, sdk, customer-support, web, mobile, ui, tooling

## 简介

Headless Kata CX Dashboard chat client for Flutter — iOS, Android and Web. Send messages, stream replies, run the CSAT survey, with no UI attached.
