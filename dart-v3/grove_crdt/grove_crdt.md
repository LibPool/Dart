# grove_crdt

**Tag**: web, networking, tooling

## 简介

Dart client for Grove's CRDT sync protocol. Hybrid logical clocks, LWW registers, counters, sets, lists, documents, text, presence, rooms, undo, and HTTP, SSE and WebSocket transports.
