# orvano_core

**Tag**: web, mobile, ui, tooling

## 简介

The core Dart client for Orvano, the open source backend you host yourself. orvano_flutter builds on it for apps, and orvano_dart for servers.

## 官网

- 主页: https://orvano.dev
- 源码仓库: https://github.com/orvanohq/orvano-dart
- pub.dev: https://pub.dev/packages/orvano_core
