# local_shared

**Tag**: secure-storage, local-storage, database, caching, crud, mobile, serialization, testing

## 简介

Lightweight cross-platform secure local storage for Flutter. Native-safe JSON collections and documents with tested CRUD, batch operations, migration semantics, and stream updates.
