# pdf_viewer_pro

**Tag**: pdf, viewer, drm, annotations, flutter, web, mobile, ui

## 简介

A full-featured Flutter PDF viewer for Android and iOS. Built on PDFium (pdfrx).
Includes annotations, bookmarks, full-text search, thumbnails, table of contents,
auto-scroll, dark/light themes, DRM screenshot protection, and optional
server-sync callbacks.
