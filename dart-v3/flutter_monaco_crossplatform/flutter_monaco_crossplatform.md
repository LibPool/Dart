# flutter_monaco_crossplatform

**Tag**: vscode, monaco, editor, flutter, cross-platform, web, mobile, desktop, ui

## 简介

Cross-platform Monaco Editor (VS Code's editor) for Flutter with Web and Linux support. Features 100+ languages, syntax highlighting, themes, and full API.
