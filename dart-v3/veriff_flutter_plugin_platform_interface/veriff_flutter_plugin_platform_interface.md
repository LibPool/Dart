# veriff_flutter_plugin_platform_interface

**Tag**: veriff, identity-verification, kyc, platform-interface, plugin, mobile

## 简介

A common platform interface for the veriff_flutter_plugin plugin. This package provides the abstract platform interface that platform-specific implementations must extend to provide Veriff identity verification functionality.
