# piratetok_live

**Tag**: tiktok, websocket, livestream, protobuf, web, serialization, networking

## 简介

Connect to TikTok Live streams via WSS. Zero external dependencies, no signing server. Chat, gifts, likes, joins, and 60+ event types.
