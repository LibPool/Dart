# flutter_db_inspector_shared_preferences

**Tag**: shared-preferences, storage, key-value, inspector, web, mobile

## 简介

SharedPreferences adapter for Flutter DB Inspector. Inspect and edit preferences (legacy, async and cached APIs) while your app runs.
