# plugin_scanner_qr

**Tag**: mobile, ui

## 简介

Plugin Flutter para leitura de QR Code no Android usando ML Kit e CameraX. Oferece leitura única em tela cheia e leitura contínua com preview embutido na árvore de widgets (PlatformView), com debounce e cooldown nativos.
