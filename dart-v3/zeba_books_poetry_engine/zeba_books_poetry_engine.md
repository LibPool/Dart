# zeba_books_poetry_engine

**Tag**: poetry, typography, flutter-widget, text-layout, rtl, mobile, ui

## 简介

Flutter UI library for poetry typography and advanced verse rendering. Provides hanging indent poetry lines, stanza translation layouts, automatic line numbering, RTL/LTR detection, and caesura spacing for classical and modern poetry applications.
