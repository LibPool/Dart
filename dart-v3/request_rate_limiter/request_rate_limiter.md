# request_rate_limiter

**Tag**: dio, http, rate-limiting, throttle, interceptor, web, networking

## 简介

A token-bucket rate limiter for Dio and http. Allows bursts, enforces a steady request rate, queues excess requests, and supports per-host limits, request costs and cancellation.
