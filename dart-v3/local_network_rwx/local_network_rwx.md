# local_network_rwx

**Tag**: web, mobile, networking, state-management

## 简介

Check and request the iOS Local Network permission reliably. Uses NWBrowser with debounced state handling to trigger the system dialog and detect whether the user granted or denied access. No-op on non-iOS platforms.
