# contract_fixtures_dio

**Tag**: testing, api, contract-testing, fixtures, dio, web, ui, tooling

## 简介

A dio adapter that answers with contract_fixtures fixtures, so a client built on dio reads the responses its API really gave. With a helper for the request.
