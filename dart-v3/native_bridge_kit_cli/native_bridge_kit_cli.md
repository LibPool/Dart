# native_bridge_kit_cli

**Tag**: mobile, tooling

## 简介

CLI tool for Android and iOS native_bridge_kit projects. Includes drift-check command for validating Dart contracts against native stubs. Install globally via `dart pub global activate native_bridge_kit_cli`.
