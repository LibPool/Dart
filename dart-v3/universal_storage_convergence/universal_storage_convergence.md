# universal_storage_convergence

**Tag**: library

## 简介

Convergence kernel shared by Universal Storage mesh sync and ecsly world sync: dual-mode op log + snapshots, hybrid logical clocks, version vectors, and pluggable merge strategies (ADR 0011).
