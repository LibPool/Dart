# logscope_flutter

**Tag**: logging, debug, dio, developer-tools, web, mobile, networking

## 简介

Zero-config in-app debug console with automatic issue-layer classification, structured HTTP cards, Dio interceptor, device info tab, and a draggable FAB overlay.
