# agent_kit

**Tag**: ai, agent, llm, tool-calls, ui, mobile

## 简介

Drop-in Flutter widgets for AI agent UIs — tool-call cards, thinking bubbles, citation chips, plan-progress timelines. Backend-agnostic. shadcn-for-agents.
