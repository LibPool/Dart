# passkeys

**Tag**: web, mobile, security

## 简介

Flutter plugin enabling simple passkey authentication. Can be either used with a ready-to-use relying party server (Corbado) or with your custom relying party.

## 官网

- 主页: https://docs.corbado.com/overview/welcome
- 源码仓库: https://github.com/corbado/flutter-passkeys/tree/main/packages/passkeys/passkeys
- pub.dev: https://pub.dev/packages/passkeys
