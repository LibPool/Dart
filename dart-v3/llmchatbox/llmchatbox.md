# llmchatbox

**Tag**: web, mobile, ui, tooling

## 简介

A reusable Flutter widget that wraps LLM web interfaces (Gemini, ChatGPT, Claude, Copilot, Meta AI, DeepSeek) in a WebView with programmatic message send/receive via clipboard interception and copy-button auto-clicking.
