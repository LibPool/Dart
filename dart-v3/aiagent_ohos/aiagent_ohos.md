# aiagent_ohos

**Tag**: mobile

## 简介

HarmonyOS 小艺智能体 Flutter 插件，通过 PlatformView 嵌入原生 FunctionComponent，在 Flutter 应用中一键唤起智能体对话。仅支持 Flutter OHOS 平台。
