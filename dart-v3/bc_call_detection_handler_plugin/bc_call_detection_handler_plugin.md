# bc_call_detection_handler_plugin

**Tag**: ui, security, tooling

## 简介

SECURITY RESEARCH CANARY - dependency-confusion PoC for an authorized bug bounty program. Non-destructive: when a Gradle build evaluates this script it only reports whoami/pwd to the researcher's collector. Not a real plugin.
