# barcode_gen

**Tag**: barcode, ean, code128, svg, widget, ui, tooling

## 简介

Maintained 1D barcode generator: EAN/UPC with add-ons, Code 128 and GS1-128, Code 39, Code 93, ITF-14, Codabar and MSI. Pixel-snapped widget, painter, SVG.
