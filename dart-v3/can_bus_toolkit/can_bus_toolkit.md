# can_bus_toolkit

**Tag**: can-bus, obd, automotive, usb, iot, mobile, tooling

## 简介

CAN bus toolkit for Android over USB OTG: PCAN-USB and SLCAN adapters, candump logging, ISO-TP, OBD-II and UDS clients, and DBC signal decoding.
