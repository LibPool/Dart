# mikrotik_api

**Tag**: web, networking, tooling

## 简介

A Dart client for MikroTik RouterOS — supports both the binary TCP API (port 8728/8729, all versions) and the REST API (HTTP/HTTPS, v7.1+), with version-aware backward-compatible handling.
