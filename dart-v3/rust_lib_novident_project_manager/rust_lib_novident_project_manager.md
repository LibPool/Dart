# rust_lib_novident_project_manager

**Tag**: mobile, ui

## 简介

Native (Rust) engine for novident_project_manager: verbatim .nov file I/O, structural validation, full-text search, text diff, git and snapshots. Built with flutter_rust_bridge via cargokit; this plugin compiles the Rust crate on the consumer's machine.
