# flutter3d_plugin_runtime

**Tag**: game-development, game-engine, plugins, webassembly, web, mobile

## 简介

Plugins loaded while a game runs: data plugins read from a .f3dplugin document, and sandboxed Wasm modules on a deterministic interpreter, held to the permissions granted.
