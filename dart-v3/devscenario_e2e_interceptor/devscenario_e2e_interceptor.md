# devscenario_e2e_interceptor

**Tag**: web, mobile, desktop, networking, testing

## 简介

Dev Tool E2E network interceptor for Dart & Flutter apps. Captures HTTP traffic (package:http, dio, raw dart:io) and exports it to the Dev Tool desktop Network tab, with optional request mocking — the Dart counterpart to the published Android (OkHttp) / iOS (URLProtocol) interceptors.
