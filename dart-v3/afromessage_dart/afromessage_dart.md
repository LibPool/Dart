# afromessage_dart

**Tag**: sms, ethiopia, afromessage, otp, flutter, web, mobile, security, tooling

## 简介

unofficial Dart/Flutter client for AfroMessage — Ethiopia's SMS API. Send SMS, bulk SMS, OTPs, and verify security codes.
