# deeplinknow

**Tag**: deep-linking, deferred-deep-linking, universal-links, app-links, dynamic-links, mobile

## 简介

Privacy-first deferred deep linking for Flutter. Wraps the native DeepLinkNow iOS and Android SDKs: one call to initialize, one call to get the link the user tapped before installing. No attribution, no ad tracking.
