# prism_changelog

**Tag**: changelog, whats-new, release-notes, widget, ui, mobile

## 简介

In-app "What's New" screens and changelog views for Flutter — parses Keep-a-Changelog markdown into version cards, tracks last-seen versions, and renders beautifully with zero dependencies.
