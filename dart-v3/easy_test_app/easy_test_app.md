# easy_test_app

**Tag**: mobile, ui, testing, tooling

## 简介

App-agnostic core for widget-testing Flutter apps. Ships the easyTestWidgets harness, an app launcher + journey model, value/matcher request helpers, header and error builders, the platform mock, and PatrolTester / PatrolFinder extensions. Each app composes it by injecting its own mocks (init) and journeys.
