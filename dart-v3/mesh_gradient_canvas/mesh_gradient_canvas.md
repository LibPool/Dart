# mesh_gradient_canvas

**Tag**: gradient, mesh-gradient, animation, canvas, ui, mobile

## 简介

An organic, multi-color mesh gradient canvas for Flutter inspired by Stripe and iOS 18 with floating color blobs, touch reactivity, and fluid physics.
