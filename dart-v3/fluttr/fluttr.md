# fluttr

**Tag**: mobile, tooling

## 简介

Dart CLI tool which simplifies the setup of new Flutter projects by automatically generating a well-structured folder and file layout,currently tailored for personal use. Suggestions are welcomed to improve this tool making it more valuable for broader audience
