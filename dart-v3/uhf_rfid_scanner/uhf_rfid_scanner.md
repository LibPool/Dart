# uhf_rfid_scanner

**Tag**: rfid, uhf, scanner, newland, urovo, mobile

## 简介

Flutter plugin for UHF RFID handheld scanners. Supports NewLand MT93 and Urovo DT610. Features tag scanning, power control, and SGTIN-96 to EAN-13 decoding.
