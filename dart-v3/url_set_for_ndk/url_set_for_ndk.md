# url_set_for_ndk

**Tag**: nostr, ndk, blossom, offline-first, web

## 简介

Relay and Blossom server sets for the ndk package, described rather than listed so they can be persisted offline and resolved later from the NIP-65, NIP-17, NIP-37 and BUD-03 lists accounts publish.
