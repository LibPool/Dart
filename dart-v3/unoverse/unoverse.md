# unoverse

**Tag**: web, mobile, ui, tooling

## 简介

Unoverse SDK for Dart and Flutter: an MCP client for Unoverse apps. Point it at your server and the app renders, because the app carries its own UI. Server-driven experiences without shipping UI code.
