# dart_otel_exporter_otlp_http

**Tag**: web, mobile, serialization, networking, tooling

## 简介

OTLP/HTTP (JSON-encoded) log exporter for flutter_otel. Pure Dart, no Flutter dependency, so it also works from non-Flutter Dart targets (server, CLI, web).
