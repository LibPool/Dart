# flutter_js_stable

**Tag**: mobile, ui

## 简介

A stable fork of flutter_js with Android runtime fixes. Uses QuickJS on Android and JavascriptCore on iOS.

## 官网

- 主页: https://github.com/abner/flutter_js
- pub.dev: https://pub.dev/packages/flutter_js_stable

## 历史版本号
