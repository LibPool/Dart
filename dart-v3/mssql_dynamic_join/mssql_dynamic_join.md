# mssql_dynamic_join

**Tag**: database, sql, mssql, query-builder, orm, mobile, ui, tooling

## 简介

Automatic SQL JOIN engine for Dart/Flutter. Define relationships once, and it discovers JOIN paths, generates parameterized SQL, and executes queries automatically.
