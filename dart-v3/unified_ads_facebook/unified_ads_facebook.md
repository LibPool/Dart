# unified_ads_facebook

**Tag**: ads, facebook, audience-network, monetization, networking

## 简介

Facebook Audience Network (Meta) adapter for unified_ads: banner, interstitial and rewarded. Links only the Audience Network SDK; production fill needs bidding.
