# floreville_upload_manager

**Tag**: upload, file-upload, retry, s3, offline, mobile, ui

## 简介

Offline-tolerant, persistent upload queue for Flutter: retries with backoff, resumable chunked uploads, S3 multipart, progress notifications and widgets.
