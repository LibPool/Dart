# uniswap_flutter_v3

**Tag**: mobile, ui, state-management

## 简介

A comprehensive Dart/Flutter SDK for Uniswap V3 DEX interactions. This plugin simplifies complex token swaps, and blockchain interactions across multiple chains including Ethereum, BSC and Polygon. Built by Medeet for developers seeking seamless decentralized exchange integration.
