# html_to_markdown_ffi_flutter

**Tag**: html-to-markdown-ffi, clean-architecture, zuraffa, mobile

## 简介

The Flutter plugin for html_to_markdown_ffi: one dependency gives a Flutter app the typed HTML to Markdown conversion and the native library linked in by the family itself.
