# llm_sdk

**Tag**: llm, ai, claude, openai, gemini, mobile, state-management

## 简介

Unified interface for talking to LLMs (Claude, OpenAI, Gemini) from Dart/Flutter: multi-provider, streaming, tool calling, structured outputs.
