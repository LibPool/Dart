# pwa_install_plus

**Tag**: web, mobile, networking

## 简介

This Flutter package is a fork of the pwa_install project by CodeOTR (https://github.com/CodeOTR/pwa_install). It enables you to prompt mobile web users to install your Flutter app as a Progressive Web App (PWA).
