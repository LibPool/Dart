# unipayscan

**Tag**: library

## 简介

Deterministic, local-first payment QR/address parsing - UPI, Pix, EMVCo, Bitcoin, Ethereum, and more, one normalized result. Dart FFI bindings over the same Rust core every SDK in this project uses.
