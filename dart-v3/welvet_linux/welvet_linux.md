# welvet_linux

**Tag**: desktop

## 简介

Linux (x86_64 + ARM64) native libraries for welvet — Loom Welvet C-ABI FFI. Add via `welvet` on pub.dev; do not depend on this package directly unless you know you need Linux-only artifacts.
