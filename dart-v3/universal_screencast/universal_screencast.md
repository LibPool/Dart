# universal_screencast

**Tag**: screencast, frames, pipeline, mjpeg, web, networking

## 简介

Declarative frame pipeline for automation targets: FrameSource (CDP screencast, paced polling) to FrameSink (binary WebSocket, MJPEG HTTP, file recorder) with fail-closed composition validation and audience policies.
