# flutter_entify

**Tag**: orm, sqflite, sqlite, entity-mapper, database, mobile, ui

## 简介

A lightweight and efficient ORM for Flutter, inspired by .NET's Entity Framework and built on Sqflite. Simplifies CRUD operations and query execution, entity mapping and database transactions.
