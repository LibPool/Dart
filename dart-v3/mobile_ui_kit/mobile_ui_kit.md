# mobile_ui_kit

**Tag**: ui, widgets, design-system, components, mobile

## 简介

A Flutter UI kit inspired by Cameroonian Ndop textile art. Includes 45+ shadcn/ui-style components with culturally-inspired design tokens for the Olkoo mobile app ecosystem.
