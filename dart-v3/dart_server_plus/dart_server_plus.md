# dart_server_plus

**Tag**: web, ui, database, tooling

## 简介

dart_server_plus is a Dart ORM library that simplifies server-side development with support for MySQL and PostgreSQL. It streamlines tasks such as server setup, schema definition, and CRUD operations. With features like advanced querying, relationship management, and optional logging, dart_server_plus makes building scalable and efficient applications straightforward.
