# tonara

**Tag**: library

## 简介

Pure-Dart Mandarin Chinese tone detection (tones 1-4) from raw PCM audio. Implements a full DSP pipeline: VAD, pre-emphasis, framing, probabilistic YIN pitch tracking, contour normalization, feature extraction, a rule-based classifier with KNN fallback, and DTW reference matching.
