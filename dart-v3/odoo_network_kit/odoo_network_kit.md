# odoo_network_kit

**Tag**: odoo, network, rpc, api, erp, web, serialization, networking, security

## 简介

Production-ready network layer for Odoo (JSON-RPC). Authentication, session persistence, ORM helpers (search_read, create, write, unlink, call_kw), typed exceptions, retries and pretty request/response logging.
