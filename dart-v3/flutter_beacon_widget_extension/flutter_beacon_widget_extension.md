# flutter_beacon_widget_extension

**Tag**: mobile, ui

## 简介

Automatic E2E UI map for Flutter. Auto-detects interactive widgets with ValueKey and generates *.beacon.dart files so AI tools (Maestro + Claude) can write stable E2E flows.
