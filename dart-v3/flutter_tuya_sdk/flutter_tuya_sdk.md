# flutter_tuya_sdk

**Tag**: tuya, iot, smart-home, ble, smart-lock, mobile

## 简介

A Flutter plugin for Tuya Home Automation — providing user, device, camera, and smart lock management via Tuya SDKs for iOS and Android.
