# plug_bottom_nav

**Tag**: mobile, state-management

## 简介

Plug-and-play Blinkit/Uber/Instacart-style bottom navigation for Flutter. Auto-generates GoRouter StatefulShellRoute, Riverpod tab state, per-seller carts and an automatic add-to-cart button. No manual shell-route code.
