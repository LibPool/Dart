# hallmark_ui

**Tag**: ui, design-system, components, toast, modal-sheet, mobile, state-management

## 简介

The six Flutter components Material has no good answer for. Buttons, inputs, cards, chips, list rows and tabs are Material's own, themed by hallmark_tokens — this package does not wrap them. What lives here is the gap: a layout-stable toast, a bar-first progress indicator, a top bar that does not tint on scroll, a themed sheet, a real empty state, and an eyebrow that makes the single-column rule structural.
