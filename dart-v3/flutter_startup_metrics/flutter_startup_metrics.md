# flutter_startup_metrics

**Tag**: startup, performance, monitoring, observability, metrics, mobile, ui, tooling

## 简介

Measure Flutter app startup time and cold start in production: time to initial display (TTID), time to full display (TTFD), and a phase breakdown. Works in release builds.
