# wifi_ftm

**Tag**: wifi, ftm, rtt, positioning, ranging, mobile

## 简介

A Flutter plugin for WiFi Fine Timing Measurement (FTM) and Round-Trip-Time (RTT) ranging, supporting both 802.11mc and 802.11az (Android 15+).
