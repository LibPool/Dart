# super_tab_bar

**Tag**: web, mobile, ui, state-management, tooling

## 简介

A browser-style Flutter workspace tab bar with pinned, dirty, closable, unique, and required-pinned tabs. Supports per-tab page builders, drag-to-reorder, context menus, overflow dropdowns, hover previews, state-preserving pages, localization, callbacks, accessibility, RTL, dirty-aware back navigation, responsive compact mode, draggable mobile thumbnail previews, optional compact FAB, and automatic breakpoint switching. Integrates with the GeniusLink super_core design system.
