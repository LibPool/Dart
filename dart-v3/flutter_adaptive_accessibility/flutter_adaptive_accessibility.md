# flutter_adaptive_accessibility

**Tag**: accessibility, responsive, adaptive, ui, flutter, mobile

## 简介

A Flutter package for accessibility-aware responsive layouts, adaptive font scaling, automatic Row-to-Column transformations, adaptive grids, forms, navigation, dialogs, and responsive utilities.
