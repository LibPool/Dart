# flutter_markdown_community

**Tag**: markdown, widgets, web, mobile, ui, networking

## 简介

A fork from the original [Flutter_Markdown](https://pub.dev/packages/flutter_markdown). A Markdown renderer for Flutter. Create rich text output, including text styles, tables, links, and more, from plain text data formatted with simple Markdown tags.
