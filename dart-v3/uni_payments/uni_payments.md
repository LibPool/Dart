# uni_payments

**Tag**: payments, stripe, razorpay, paypal, flutter, web, mobile

## 简介

Unified Flutter API over Razorpay, Stripe, PayPal, Paystack, Flutterwave, Paytm, Cashfree, PhonePe, PayU, Square, Airwallex, Google Pay and Apple Pay.
