# pixel_ui

**Tag**: widgets, design-system, pixel-art, retro, game-ui, mobile, ui

## 简介

Pixel-art design system for Flutter — retro / 8-bit primitives, tile grids, interactive buttons, and a bundled pixel font for game UI.
