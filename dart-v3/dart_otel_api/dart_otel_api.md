# dart_otel_api

**Tag**: web, mobile

## 简介

Platform-agnostic OpenTelemetry core API for flutter_otel: Resource, signal interfaces (logs now; trace/metric stubs for later), and the processor/exporter pipeline contracts. Pure Dart, no Flutter dependency.
