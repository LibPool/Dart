# flutter_band_fit

**Tag**: bluetooth, ble, wearable, health, fitness, mobile

## 简介

Flutter plugin for UTE smart bands using the UTE SDK (the GloryFit SDK) for BLE connectivity, sync, and vitals on Android and iOS.
