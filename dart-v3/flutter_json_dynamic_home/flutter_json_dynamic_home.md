# flutter_json_dynamic_home

**Tag**: web, mobile, ui, serialization, tooling

## 简介

A powerful JSON-to-Flutter-UI rendering engine. Build entire Flutter screens from JSON configuration. Perfect for server-driven UI, no-code app builders, and dynamic content delivery.
