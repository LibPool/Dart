# flutter_chaoxing

**Tag**: chaoxing, xuexitong, sign-in, captcha, education, mobile, tooling

## 简介

Typed Chaoxing (学习通) protocol clients for Dart: request signing, device registration, passport2 login, classroom sign-in across all nine sign flavours, and a solver for the captcha.chaoxing.com slider captcha.
