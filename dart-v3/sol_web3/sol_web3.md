# sol_web3

**Tag**: web, serialization, tooling

## 简介

Pure-Dart Ethereum JSON-RPC client, transaction signing (secp256k1/ECDSA, RLP), and contract deployment for the sol_pkgs Solidity compiler. The "last mile" that turns compiled bytecode into a transaction on a real chain — no solc, no web3.js, no Node.js.
