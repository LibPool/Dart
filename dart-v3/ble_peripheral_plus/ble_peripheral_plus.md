# ble_peripheral_plus

**Tag**: bluetooth, ble, gatt, peripheral, flutter-plugin, web, mobile, desktop

## 简介

A maintained Flutter BLE peripheral and GATT server plugin for Android, iOS, macOS, and Windows, based on ble_peripheral.
