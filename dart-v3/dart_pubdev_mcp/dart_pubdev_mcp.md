# dart_pubdev_mcp

**Tag**: mcp, pub-dev, flutter, dart, ai, web, mobile

## 简介

Model Context Protocol (MCP) server for pub.dev, Dart SDK, and Flutter. Gives AI agents live package search, API docs, AST source slices, and breaking change diffs.
