# seasonal_app_icon

**Tag**: app-icon, dynamic-icon, seasonal, flutter-plugin, mobile

## 简介

A Flutter plugin for dynamically changing app icons based on seasonal events (Christmas, Black Friday, etc.). Supports light/dark mode variants.
