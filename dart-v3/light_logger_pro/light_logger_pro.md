# light_logger_pro

**Tag**: logging, dart, flutter, performance, encryption, mobile, security

## 简介

A high-performance binary logging package for Dart & Flutter that writes compressed logs instead of plain text, dramatically reducing file size while offering encryption, auto-rotation, real-time monitoring, and fast querying.
