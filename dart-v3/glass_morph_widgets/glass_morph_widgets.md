# glass_morph_widgets

**Tag**: ui, widgets, glassmorphism, animation, flutter, web, mobile, desktop

## 简介

A pure-Dart Flutter package providing animated glass-morphism widgets with zero native code. Supports mobile, web, and desktop platforms.
