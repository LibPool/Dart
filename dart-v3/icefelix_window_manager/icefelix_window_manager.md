# icefelix_window_manager

**Tag**: window, desktop, multi-monitor, ui, platform-integration, mobile, state-management

## 简介

Cross-platform window management for Flutter desktop. Size, position, state, multi-monitor, frameless, events. macOS, Windows, and Linux in one package.
