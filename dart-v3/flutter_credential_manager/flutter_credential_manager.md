# flutter_credential_manager

**Tag**: web, mobile, security

## 简介

A **fork** of the original Credential Manager plugin, featuring a **critical fix for iOS (Swift)**. 
This version ensures correct **Base64URL handling** for challenges and IDs, enhancing WebAuthn/Passkey compliance and one-tap login functionality. Supports Google Credential Manager (Android) and Keychain (iOS).
