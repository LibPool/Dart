# olu

**Tag**: rtl, arabic, typography, bento, carousel, mobile, ui

## 简介

RTL-first Flutter UI kit with zero dependencies — Arabic typography (kashida, tajweed, bidi), responsive Bento grids, and RTL-aware carousels.
