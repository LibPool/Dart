# oka_play

**Tag**: build-system, cli, flutter, google-play, web, mobile, ui, serialization, security, tooling

## 简介

Google Play publish target for oka (ADR-0014): PlayPublishTarget composes the Play Publisher API upload tail (service-account JSON by path, JWT → OAuth token exchange, Edits API flow) onto any oka Android AAB build.
