# siprix_voip_sdk

**Tag**: sip, voip, call, mobile

## 简介

Siprix VoIP SDK plugin for embedding voice-over-IP (VoIP) audio/video calls based on SIP/RTP protocols into Flutter applications.

## 官网

- 主页: https://siprix-voip.com
- 源码仓库: https://github.com/siprix/FlutterPluginFederated/tree/main/siprix_voip_sdk
- 文档: https://docs.siprix-voip.com
- pub.dev: https://pub.dev/packages/siprix_voip_sdk
