# neuro_realm

**Tag**: mobile, ui, database, tooling

## 简介

The very-unofficial Realm SDK for Flutter. Realm is a mobile database - an alternative to SQLite and key-value stores. This variant uses named parameters for required fields, and generates a builder class for each RealmObject.
