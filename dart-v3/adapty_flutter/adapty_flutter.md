# adapty_flutter

**Tag**: mobile

## 简介

Adapty SDK is an open-source framework that makes implementing in-app subscriptions in Flutter applications fast and easy. It’s 100% open-source and lightweight.

## 官网

- 主页: https://adapty.io/
- 源码仓库: https://github.com/adaptyteam/AdaptySDK-Flutter
- 问题追踪: https://github.com/adaptyteam/AdaptySDK-Flutter/issues
- 文档: https://adapty.io/docs/flutter-sdk-overview
- pub.dev: https://pub.dev/packages/adapty_flutter
