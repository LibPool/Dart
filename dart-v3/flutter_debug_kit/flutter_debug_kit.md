# flutter_debug_kit

**Tag**: web, mobile, desktop, networking

## 简介

Reads the system HTTP proxy at launch and routes all dart:io HTTP/WebSocket traffic through it. Enables Charles/Fiddler packet capture on Android, iOS, macOS and Windows.
