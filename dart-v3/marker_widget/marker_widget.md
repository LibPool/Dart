# marker_widget

**Tag**: google-maps, google-maps-flutter, map, marker, widget, web, mobile, ui

## 简介

Render Flutter widgets into google_maps_flutter bitmaps, glyphs, markers, and ground overlays with caching and modern Flutter View APIs.
