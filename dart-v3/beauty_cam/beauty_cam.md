# beauty_cam

**Tag**: library

## 简介

beauty_cam is a plugin that allows you to set beauty and filters, and it supports remote download of filters as well as custom filters（是一个可以设置美颜和滤镜的插件，它支持远程下载滤镜以及自定义滤镜）
