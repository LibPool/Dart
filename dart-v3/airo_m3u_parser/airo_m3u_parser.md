# airo_m3u_parser

**Tag**: m3u, m3u8, iptv, playlist, parser, web, mobile

## 简介

High-performance streaming M3U & M3U8 playlist parser for Flutter — Rust-accelerated on native platforms with an identical pure-Dart fallback (including web).
