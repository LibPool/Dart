# flutter_ml_helper

**Tag**: flutter, machine-learning, tensorflow-lite, ml-kit, cross-platform, mobile

## 简介

Easy integration with TensorFlow Lite and ML Kit for Flutter applications. Supports all 6 platforms with WASM compatibility.
