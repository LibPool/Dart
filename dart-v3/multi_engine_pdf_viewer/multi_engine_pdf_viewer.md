# multi_engine_pdf_viewer

**Tag**: pdf, pdf-viewer, pdfium, pdfjs, mobile

## 简介

An engine-independent PDF viewer for Android and iOS with PDFKit, PDF.js, EmbedPDF and native PDFium, search, outlines, links, and named actions.
