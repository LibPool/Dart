# flutter_perf_guard

**Tag**: mobile, ui, networking, tooling

## 简介

Enterprise-grade Flutter performance analysis, debugging, profiling, and  optimization toolkit for production-scale applications. Includes frame  analysis, jank detection, memory leak detection, rebuild tracking,  Image cache analyzing, Network request profiling,  real-time dashboards, and exportable profiling reports.
