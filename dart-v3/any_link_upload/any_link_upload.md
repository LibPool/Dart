# any_link_upload

**Tag**: upload, file-upload, multipart, progress, http, web, networking

## 简介

Upload manager for any_link. Real progress tracking through 8 phases: validate, compress, hash, chunk, upload, server-processing, retry, complete. Zero extra dependencies.
