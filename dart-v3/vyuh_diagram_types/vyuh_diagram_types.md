# vyuh_diagram_types

**Tag**: diagram, data-model, geometry, flowchart, immutable, web, mobile, tooling

## 简介

Immutable document model, shapes, text and geometry for Vyuh Diagram. Pure Dart with no Flutter dependency, so it runs on servers, CLIs and agents.
