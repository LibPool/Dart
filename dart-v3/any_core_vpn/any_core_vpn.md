# any_core_vpn

**Tag**: vpn, singbox, xray, proxy, networking, web, mobile, desktop, serialization

## 简介

Flutter VPN plugin with a unified Dart API for sing-box (singbox) and Xray-core on Android, Windows (in full version) and macOS.  Supports share links, JSON configs and routing.
