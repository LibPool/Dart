# temporal

**Tag**: date, time, temporal, datetime, calendar, web

## 简介

TC39 Temporal date/time API for Dart. Automatically delegates to the JS Temporal API on web and to temporal_rs (Rust FFI) on native platforms. Provides Calendar, TimeZone, Instant, PlainDate, PlainTime, PlainDateTime, ZonedDateTime, TemporalDuration, PlainYearMonth, and PlainMonthDay.
