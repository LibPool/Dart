# face_liveness_check

**Tag**: liveness, face-detection, mlkit, camera, biometric, mobile

## 简介

A customizable Flutter package for on-device real-time facial liveness detection using Google ML Kit and Camera. Features configurable challenges, localization, and guaranteed frontal photo capture.
