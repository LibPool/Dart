# pos_printer_d

**Tag**: printer, pos, thermal-printer, bluetooth, esc-pos, web, mobile, networking

## 简介

A clean Flutter plugin for POS thermal printers. Supports Bluetooth, USB, and Network (TCP) connections with a simple unified API.
