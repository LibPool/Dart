# blifi

**Tag**: bluetooth, ble, esp32, wifi, provisioning, security

## 简介

BLE-based Wi-Fi provisioning for ESP32: send Wi-Fi credentials over an encrypted (X25519 + AES-256-GCM) Bluetooth Low Energy session, no hotspot.
