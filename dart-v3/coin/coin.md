# coin

**Tag**: cryptocurrency, blockchain, monero, bitcoin, ethereum, security, state-management

## 简介

Cross-platform multi-coin cryptocurrency toolkit: Monero, Bitcoin, EVM. BIP-32/39/44 HD keys, Schnorr/ECDSA signing, PSBT, BIP-47, MuSig2, ABI codec, native secp256k1 FFI with pure-Dart fallback.
