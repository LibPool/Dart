# ultimate_grid

**Tag**: grid, table, datagrid, spreadsheet, timesheet, mobile

## 简介

Scalable, themable 2D data-grid for Flutter — 9-region freeze, canvas-paint body, merges, async data, selection, sort, filter, search.
