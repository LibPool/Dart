# appstream_dart

**Tag**: appstream, flathub, linux, ffi, sqlite, desktop, database, serialization

## 简介

High-performance AppStream XML parser with C++23 FFI bridge. Streams catalog metadata into SQLite with Drift ORM and FTS5 search.
