# tseries

**Tag**: time-series, forecasting, arima, sarimax, ffi

## 简介

Time-series analysis for Dart: ARIMA, SARIMA and SARIMAX on the ctsa C library via FFI, automatic order selection (autoArima) and pure-Dart forecasting primitives.
