# nucleus_flutter_toolkit

**Tag**: ui, desktop, design-system, animation, mobile, state-management

## 简介

A desktop-grade application toolkit for Flutter: frameless window shell, design system, motion primitives, overlays, routing, hotkeys and state utilities for Windows, macOS, Linux, Android and iOS.
