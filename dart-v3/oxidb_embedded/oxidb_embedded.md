# oxidb_embedded

**Tag**: web, mobile, database, security

## 简介

OxiDB embedded for Flutter/Dart — the full in-process document database (queries, indexes incl. geo, aggregation, full-text search, transactions, blob storage, SQL, AES-256-GCM encryption at rest) over dart:ffi. A local database in the Hive/Isar weight class, with a server-grade engine.
