# glint_network

**Tag**: mcp, flutter, devtools, debugging, http, web, mobile, networking, tooling

## 简介

The glint network toolset. An MCP server that gives AI agents a running Flutter app's HTTP, WebSocket and log traffic through the Dart VM service.
