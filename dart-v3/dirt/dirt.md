# dirt

**Tag**: library

## 简介

The compiler of Dirt, the clean language inspired by Kotlin that transpiles to Dart.

## 官网

- 主页: https://dirtlang.org
- 源码仓库: https://github.com/dirtlang/dirt
- 问题追踪: https://github.com/dirtlang/dirt/issues
- pub.dev: https://pub.dev/packages/dirt
