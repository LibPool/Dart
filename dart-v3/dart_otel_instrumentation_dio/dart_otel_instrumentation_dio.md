# dart_otel_instrumentation_dio

**Tag**: web, mobile, networking, tooling

## 简介

Dio HTTP client instrumentation for flutter_otel: an Interceptor that emits a log record per request/response/error via an injected Logger. First of the dart_otel_instrumentation_<target> family.
