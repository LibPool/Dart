# antinvestor_ui_loans

**Tag**: flutter, ui, loans, antinvestor, fintech, web, mobile

## 简介

Loan management UI library for Antinvestor. Embeddable screens and widgets for loan products, requests, accounts, disbursements, repayments, penalties, schedules, restructuring, portfolio reporting, and dashboard.
