# firebase_remote_update

**Tag**: mobile, ui, tooling

## 简介

Reusable force/optional update gate for Flutter apps, backed by Firebase Remote Config and guarded by a real store-availability check (Play In-App Update on Android, iTunes lookup on iOS) so users are never locked out of a build that is not actually live.
