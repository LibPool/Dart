# zv_player

**Tag**: video, video-player, hls, dash, youtube, web, mobile, ui

## 简介

A cinematic, capability-driven video player for Flutter. MP4, HLS, DASH and local files play natively (Media3 on Android, AVPlayer on iOS); YouTube plays through the official IFrame API under the same player UI.
