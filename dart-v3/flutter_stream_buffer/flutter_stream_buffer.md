# flutter_stream_buffer

**Tag**: streaming, ai, performance, widgets, chat, mobile, ui, tooling

## 简介

Frame-batched text streaming for Flutter AI responses, live captions, and logs. Includes cancellation, bounded accumulation, and a lifecycle-aware builder.
