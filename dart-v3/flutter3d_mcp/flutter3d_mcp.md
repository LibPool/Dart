# flutter3d_mcp

**Tag**: mcp, level-editor, modelling, tooling, ai, web, mobile, ui

## 简介

MCP servers for flutter3d over stdio: a level editor and a model editor an agent can drive, the project server, and the kit every flutter3d server is built on.
