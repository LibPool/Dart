# scroll_edge_blur

**Tag**: blur, shader, ui, effects, glassmorphism, mobile

## 简介

Progressive blur for Flutter: iOS style edge blur for scroll views, toolbars and headers. A GPU shader on the backdrop, no snapshots, cheap while scrolling.
