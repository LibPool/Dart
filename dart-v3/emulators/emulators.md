# emulators

**Tag**: mobile, tooling

## 简介

A utility library to automate mobile emulators. Wraps `xcrun` for iOS and the Android CLI tools.

## 官网

- 源码仓库: https://github.com/tim-smart/dart_emulators.git
- pub.dev: https://pub.dev/packages/emulators
