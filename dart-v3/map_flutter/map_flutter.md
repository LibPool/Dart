# map_flutter

**Tag**: map, google-maps, openstreetmap, routing, location, mobile

## 简介

A Flutter package for interactive maps with trip planning, routing, dynamic markers and filtering. Supports Google Maps & OpenStreetMap (OSM) via OpenRouteService.
