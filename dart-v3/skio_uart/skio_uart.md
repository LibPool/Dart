# skio_uart

**Tag**: serial-port, uart, rs485, embedded, hardware, mobile, desktop, ui, tooling

## 简介

Serial ports by path for Flutter and Dart: UART, RS-232 and RS-485 on Android panels (/dev/ttyS*), Linux, Jetson, Windows (COM3) and macOS. Pure Dart FFI, nothing native to build.
