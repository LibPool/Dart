# unified_ads

**Tag**: ads, admob, monetization, advertising, mediation, web, networking

## 简介

One unified Dart API for banner, interstitial and rewarded ads across AdMob, Unity, AppLovin MAX, LevelPlay, Facebook Audience Network, Start.io and InMobi.
