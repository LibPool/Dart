# flutter_perf_lints

**Tag**: lints, analyzer, flutter, performance, mobile, ui, tooling

## 简介

Analyzer plugin that flags Flutter performance problems: undisposed controllers, full-size image decodes, eager lists, animated Opacity and heavy build work.
