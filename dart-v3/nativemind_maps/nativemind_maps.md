# nativemind_maps

**Tag**: maps, offline-maps, map, geolocation, travel, web, mobile

## 简介

The native map engine of maps.nativemind.net for HolySpots and LienDeed: offline raster maps, layers, two-language labels, external map links. Android, iOS, web.
