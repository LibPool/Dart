# misardev_flutter

**Tag**: ai, app-builder, api-client, sse, secure-storage, web, mobile, desktop, ui, tooling

## 简介

Build, deploy and chat with your apps from Flutter: the MisarDev API with secure key storage, typed plan-limit errors, retries and SSE streaming on iOS, Android, macOS and web.
