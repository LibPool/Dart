# dartway_lints

**Tag**: dartway, lints, linter, flutter, mobile, ui, testing, state-management, tooling

## 简介

DartWay's convention rules as an analyzer plugin: the UI kit as the single source of styles, relative imports kept short, and ProviderScope left to the app bootstrap and tests. Shown in the IDE, dart analyze and flutter analyze.
