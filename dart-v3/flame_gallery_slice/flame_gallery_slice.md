# flame_gallery_slice

**Tag**: flame, game, minigame, gamification, arcade, ui

## 简介

Fruit Slice: a swipe-to-slice Flame mini game for Flame Gallery. Brandable sprites, colors and texts, with timer, lives and bombs.
