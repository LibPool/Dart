# design_system_widgets

**Tag**: mobile, ui

## 简介

This repository contains a collection of reusable Flutter widgets built to align with the design system of our application. These widgets have been crafted to ensure consistency in UI elements such as buttons, text fields, cards, and more, adhering to the defined styles, spacing, and component behavior. Designed for scalability and flexibility, these widgets help maintain a uniform look and feel across different projects, while also simplifying the development process by providing ready-to-use components.
