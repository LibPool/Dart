# google_analystic_charts

**Tag**: web, mobile, desktop

## 简介

Plugin Flutter para exibir Google Charts (gráficos do Google) em Android, iOS, macOS e Web, ideal para dados do Google Analytics (GA4) vindos do seu backend.
