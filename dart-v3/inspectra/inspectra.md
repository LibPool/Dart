# inspectra

**Tag**: security, supply-chain, coverage, secret-scanning, api-surface, web, mobile, tooling

## 简介

Enterprise software assurance and supply-chain security for Dart and Flutter: OSV.dev audit, package source inspection, trust and typosquat analysis, safe dependency installation, Git hooks, Trivy scans with automatic provisioning, format and lint gates, public API dumps and coverage.
