# fpack

**Tag**: flutter, build, packaging, cli, release, web, mobile, ui, tooling

## 简介

Package Flutter apps into release artifacts for every platform (apk, aab, ipa, dmg, exe, msix, deb, rpm, AppImage, web) with one command. Native Go core, thin Dart launcher.
