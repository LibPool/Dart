# knex_dart_duckdb

**Tag**: sql, query-builder, database, duckdb, knex, ui, tooling

## 简介

DuckDB driver for knex_dart — execute analytical SQL queries against DuckDB using the knex_dart query builder and the dart_duckdb FFI package.
