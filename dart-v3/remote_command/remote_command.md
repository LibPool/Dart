# remote_command

**Tag**: mobile, ui

## 简介

A Flutter native plugin for iOS, designed for audio playback apps. It allows developers to easily integrate with the iOS lock screen and Control Center, enabling remote control features such as play, pause, next/previous track, and progress dragging.
