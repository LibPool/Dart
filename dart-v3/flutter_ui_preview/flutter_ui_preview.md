# flutter_ui_preview

**Tag**: ui, preview, device, developer-tools, testing, web, mobile

## 简介

An in-app, non-intrusive UI preview overlay for Flutter. Preview any screen or widget in isolation on simulated device frames — without altering app logic or navigating away from your current view. Perfect for rapid UI iteration during development.
