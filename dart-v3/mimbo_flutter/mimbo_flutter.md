# mimbo_flutter

**Tag**: game-engine, rive, flutter, game-development, mobile

## 简介

The mimbo game engine in Flutter. A Rive GPU stage that draws mimbo worlds in 3D, a fixed-step clock, and a player that runs a world game on it.
