# prism_pagination

**Tag**: pagination, infinite-scroll, list, widget, ui, mobile, state-management

## 简介

Infinite-scroll pagination for Flutter — automatic load-more, retryable errors, empty and end-of-list states, with a pluggable page loader. Part of the Prism package family.
