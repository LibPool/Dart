# skribble_icons_cib

**Tag**: ui, icons, hand-drawn, design-system, sketch, networking

## 简介

CoreUI Brands icon set for skribble, rendered as precomputed hand-drawn
geometry. CoreUI brand marks: 830 logos for products, platforms, and social networks.
