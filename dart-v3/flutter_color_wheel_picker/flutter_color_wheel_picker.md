# flutter_color_wheel_picker

**Tag**: color-picker, hsv, hex, opacity, widgets, mobile, ui

## 简介

Flutter HSV color picker with a hue wheel, opacity slider, HEX RGB/ARGB input, preset swatches, callbacks and a color stream. Flutter SDK only.
