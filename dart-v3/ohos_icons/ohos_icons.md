# ohos_icons

**Tag**: icons, harmonyos, ohos, openharmony, symbol, mobile

## 简介

HarmonyOS Symbol (HM Symbol) icons for Flutter, in the style of cupertino_icons. Ships the official HarmonyOS icon font plus 534 named IconData constants and rich metadata (Chinese labels, categories, minimum HarmonyOS version). Works on the HarmonyOS Flutter fork (CPF-Flutter/flutter_flutter) and standard Flutter.
