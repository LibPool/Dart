# flutter3d_hub

**Tag**: game-development, game-engine, graphics, web, mobile, ui, tooling

## 简介

The model hub's client contract for flutter3d: the reference format `<uuid>@<n>`, the refusals, the cache policy and the versioned server protocol. Plain Dart with no engine behind it.
