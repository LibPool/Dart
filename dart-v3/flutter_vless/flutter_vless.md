# flutter_vless

**Tag**: vpn, vless, v2ray, xray, wireguard, web, mobile, desktop, networking

## 简介

Xray/V2Ray Flutter VPN plugin: VLESS Reality/XHTTP, VMess, Trojan, Shadowsocks, Hysteria2 and WireGuard config import for Android, iOS, macOS and Windows.
