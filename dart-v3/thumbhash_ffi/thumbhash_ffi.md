# thumbhash_ffi

**Tag**: thumbhash, ffi, image, placeholder, blurhash, web, mobile, ui, tooling

## 简介

Fast ThumbHash image placeholder encoder and decoder for Flutter, written in C and bound with dart:ffi through build hooks. Pure Dart fallback on the web.
