# dart_husky

**Tag**: git-hooks, husky, cli, developer-tools, git, mobile, tooling

## 简介

A pure-Dart CLI tool to manage Git hooks (pre-commit, commit-msg, pre-push) in any Dart or Flutter project. Similar to husky and lefthook.
