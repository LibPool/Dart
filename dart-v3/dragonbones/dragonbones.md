# dragonbones

**Tag**: dragonbones, skeletal-animation, animation, gamedev, ui

## 简介

Pure-Dart runtime for the DragonBones 5.x skeletal animation format: parses DragonBones Pro exports and evaluates armature, bone, mesh and IK timelines. Zero dependencies.
