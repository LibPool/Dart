# byok_llm

**Tag**: llm, ai, gemini, openai, anthropic, web, serialization

## 简介

Typed JSON replies from Gemini, Claude, OpenAI and any OpenAI-compatible service with the user's own API key, falling back across models when one is rate limited, busy or retired.
