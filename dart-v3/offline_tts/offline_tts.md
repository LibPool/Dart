# offline_tts

**Tag**: tts, text-to-speech, offline, speech, android, web, mobile

## 简介

Offline on-device text-to-speech Flutter plugin (does not use system TTS). Encapsulates Sherpa-ONNX + voice models + AudioTrack behind a stable Dart API.
