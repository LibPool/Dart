# haptic_flow

**Tag**: haptics, vibration, gestures, tactile, animation, mobile, ui

## 简介

A declarative haptic choreography engine for Flutter. Compose rhythmic tactile sequences, dynamic gesture/scroll feedback, and realistic physical presets.
