# smf_material_theme

**Tag**: flutter, theme, material-design, dark-mode, template, mobile, ui

## 简介

The SMF module of the Material 3 theme for the Flutter app that SMF generates. It gives the app a light and a dark theme with a palette and a bundled font, in a file that you edit.
