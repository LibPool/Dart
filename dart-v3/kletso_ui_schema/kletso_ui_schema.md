# kletso_ui_schema

**Tag**: ai, chat, chatbot, sdk, generative-ui, ui, serialization

## 简介

Protocol package for Kletso: JSON Schemas, hand-written Dart models and conformance fixtures for kletso.ui/v1 surfaces, kletso.events/v1 and the realtime frames.
