# llm_tool_calling_generator

**Tag**: llm, tool-calling, function-calling, ai-agents, codegen, serialization, tooling

## 简介

Code generator for llm_tool_calling. Turns @Tool-annotated Dart functions into LLM tools for OpenAI, Gemini and Claude, with JSON schemas and validation.
