# universal_driver_macos

**Tag**: macos, accessibility, automation, mobile, desktop, ui, tooling

## 简介

macOS accessibility driver for the universal automation family: semantic snapshot and element-at-position over AXUIElement, input synthesis over CGEvent. Pure Dart through native-assets build hooks (swiftc-compiled code asset, @Native bindings). No Flutter, no plugin surface.
