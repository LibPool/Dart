# renpy_flutter

**Tag**: visual-novel, renpy, game, flutter, mobile, ui

## 简介

Flutter widgets and UI adapters for Ren'Py-compatible visual novels: dialogue, menus, image/audio layers, ATL animation, screen-language, and transitions.
