# lumide_status_bar_stats

**Tag**: lumide-utils, lumide-plugin, system-monitor, desktop, networking

## 简介

Lumide IDE plugin that shows CPU, memory, disk, network, battery and CPU temperature in the status bar, with a live dashboard. Linux, macOS, Windows.
