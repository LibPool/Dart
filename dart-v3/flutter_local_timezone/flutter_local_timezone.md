# flutter_local_timezone

**Tag**: timezone, datetime, intl, web, mobile, desktop

## 简介

Synchronously read the device's IANA timezone identifier, such as Asia/Kolkata, and be notified when it changes. Android, iOS, macOS, Windows, Linux and the web.
