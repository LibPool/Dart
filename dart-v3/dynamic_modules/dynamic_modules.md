# dynamic_modules

**Tag**: code-push, dart-vm, mobile, ui

## 简介

Minimal wrapper over the Dart VM's dynamic-module loader. Requires a Flutter engine built with --dart-dynamic-modules; it will not compile against a stock SDK, by design.
