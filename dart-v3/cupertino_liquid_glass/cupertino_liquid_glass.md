# cupertino_liquid_glass

**Tag**: ui, cupertino, blur, glass, ios, mobile

## 简介

Flutter widgets replicating Apple's iOS Liquid Glass visual style. BackdropFilter blur, specular highlights, spring tab bar. A visual approximation — not a native UIKit bridge.
