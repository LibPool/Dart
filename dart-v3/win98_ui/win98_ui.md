# win98_ui

**Tag**: ui, widget, retro, windows, theme, mobile, desktop

## 简介

A Windows 98 look-and-feel widget kit for Flutter: draggable windows, menus, toolbars, lists, trees, dialogs, desktop icons, a taskbar and more. No Material.
