# emaki

**Tag**: video-generation, seedance, ai, text-to-video, image-to-video, web, tooling

## 简介

Official SDK for emaki (emaki.ai), the Japanese-language AI video generator for Seedance 2.5 and Seedance 2.0. Text-to-video, image-to-video and images with one API key.
