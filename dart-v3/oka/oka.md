# oka

**Tag**: flutter, android, build-system, cli, gradle, mobile, ui, tooling

## 简介

No-Gradle build system for Flutter Android. Runs `flutter assemble` with direct Android SDK tools (aapt2, d8, apksigner) — no Gradle daemon — with plugin packaging, AAB support, and dependency recovery.
