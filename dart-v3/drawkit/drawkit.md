# drawkit

**Tag**: ui, hand-drawn, animation, widgets, mobile

## 简介

Animated hand-drawn UI for Flutter: real widgets on top, seeded pen strokes behind, one shared boil clock — the Dart port of drawably with zero dependencies beyond the Flutter SDK.
