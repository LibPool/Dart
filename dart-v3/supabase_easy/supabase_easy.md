# supabase_easy

**Tag**: supabase, authentication, database, storage, realtime, mobile, security

## 简介

Supabase wrapper for Flutter that cuts Auth, CRUD, real-time, and Storage boilerplate by 60–70%. Type-safe, zero config, single import.
