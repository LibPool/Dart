# welvet_android

**Tag**: mobile

## 简介

Android (arm64-v8a + x86_64) native libraries for welvet — Loom Welvet C-ABI FFI. Add via `welvet` on pub.dev; do not depend on this package directly unless you know you need Android-only artifacts.
