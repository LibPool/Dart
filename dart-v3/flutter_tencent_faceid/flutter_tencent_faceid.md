# flutter_tencent_faceid

**Tag**: tencent-cloud, face-verification, ocr, kyc, identity-verification, mobile, ui, tooling

## 简介

Tencent Cloud FaceID Flutter plugin wrapping the native Android and iOS SDKs, providing ID-card OCR and liveness face verification with automatic SDK installation at build time.
