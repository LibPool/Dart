# flutter_pcm_sound_spm

**Tag**: audio, pcm, sound, web, mobile, desktop

## 简介

Send real-time PCM audio (16-bit integer) to the device speakers on Android, iOS, macOS and web. Swift Package Manager compatible fork of flutter_pcm_sound.
