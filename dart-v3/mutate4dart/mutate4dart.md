# mutate4dart

**Tag**: testing, mutation-testing, code-quality, coverage, mobile

## 简介

Mutation testing for Dart and Flutter projects. Mutates covered code with package:analyzer, runs only the tests that import it, and reports a mutation score per method next to its CRAP score (sibling of crap_dart).
