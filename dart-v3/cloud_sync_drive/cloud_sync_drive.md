# cloud_sync_drive

**Tag**: google-drive, sync, backup, tooling

## 简介

Google Drive adapter for the cloud_sync family. Supports drive, drive.file, and drive.appdata scopes. Implements StorageAdapter so it plugs directly into SyncClient.
