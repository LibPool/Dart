# unfold

**Tag**: foldable, iphone-duo, adaptive, layout, responsive, web, mobile, ui

## 简介

iPhone Duo and foldable layouts for Flutter, from UIKit's own APIs: reserved regions, vertical bars, size classes and UIHinge. Android foldables work too.
