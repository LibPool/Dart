# flutter_charset_savanitdev

**Tag**: mobile, desktop

## 简介

Charset encoding and decoding Library, include iso-(2-15), windows series, gbk, euc-jp, euc-kr, shift-jis. And supportted charset detect, canEncode, canDecode.
