# device_unique_id

**Tag**: device, device-id, unique-id, platform-channel, mobile, ui, security

## 简介

Get a reliable device identifier on Android and iOS — Android ID, iOS identifierForVendor, and a Keychain/EncryptedSharedPreferences-backed persistent UUID that survives reinstall.
