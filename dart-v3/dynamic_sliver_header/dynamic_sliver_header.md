# dynamic_sliver_header

**Tag**: web, ui, state-management, tooling

## 简介

A fully dynamic animated SliverPersistentHeader package. Builder API, animation timing ranges, parallax, collapsed child replacement, sticky tabs, state callbacks, and theme-based presets.
