# groundcover_rum

**Tag**: monitoring, observability, rum, tracing, mobile, networking

## 简介

groundcover Real User Monitoring (RUM) for Flutter on iOS and Android: sessions, network and tracing, screens, taps, errors, logs, native crashes, hangs, app start, frame vitals.
