# bloom_server

**Tag**: bloom, server, http, ssr, web, mobile, networking

## 简介

Flutter-free Dart web server for full-stack apps — HTTP APIs, routing, middleware, SSR, SSG/ISR delivery, env config, and DI. Pairs with bloom_js_native.
