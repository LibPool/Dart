# val_latex_flutter

**Tag**: katex, latex, math, streaming, mathematics, mobile, ui

## 简介

Render LaTeX math in Flutter: formula widgets, math inside text and Markdown, line wrapping, selection, screen readers, theming and streaming LLM output.
