# firebase_auth_kit

**Tag**: mobile, ui, security

## 简介

Ready-to-use Firebase authentication UI for Flutter. Drop-in login & signup screens with email/password, Google Sign-In, and phone OTP. Fully customizable via AuthUIConfig.
