# flutter_gl_flutterflow

**Tag**: web, mobile, ui

## 简介

Cross-platform OpenGL API for Flutter through dart:ffi. Fixed platformViewRegistry deprecation for Flutter 3.32.4+. 3D programming with Texture Widget support.
