# gsd_restapi

**Tag**: rest-api, http-client, session-management, encryption, authentication, web, mobile, networking, security, tooling

## 简介

DOCUframe REST API client for Flutter with encrypted login, session recovery, native V1/V3 endpoints, batching, uploads, and telemetry.
