# rishvi_zebra_scanner

**Tag**: web, mobile

## 简介

A Flutter plugin for Zebra Technologies barcode scanner devices (TC-series, MC-series, EC-series). Uses the DataWedge API to deliver scan results via a reactive stream. Developed by Rishvi for use with Zebra Android hardware.
