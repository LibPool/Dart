# dnd_kit

**Tag**: drag-and-drop, dnd, geometry, sortable, mobile

## 简介

Pure Dart core engine for the dnd_kit drag-and-drop family. Flutter apps use dnd_kit_flutter; Jaspr apps use dnd_kit_jaspr.
