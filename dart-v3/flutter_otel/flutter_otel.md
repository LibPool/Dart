# flutter_otel

**Tag**: web, mobile, ui, networking

## 简介

Batteries-included OpenTelemetry SDK for Flutter apps: the logs signal, optional session tracking, and an OTLP/HTTP exporter today, with traces and metrics designed to slot in later. This is the package apps depend on.
