# checked_exceptions

**Tag**: analyzer-plugin, lints, static-analysis, exceptions, tooling

## 简介

Checked exceptions for Dart, as an analyzer plugin. A call to a @Throws-annotated function must be caught or propagated, and a catch clause must not silently swallow it.
