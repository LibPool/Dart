# topwisemp35p_horizonpay

**Tag**: pos, topwise, horizonpay, payment, terminal, mobile

## 简介

Flutter SDK plugin for Topwise MP35P and HorizonPay smart POS terminals. Supports card processing, EMV transactions, PIN entry, hardware keyboard handling, and receipt printing.
