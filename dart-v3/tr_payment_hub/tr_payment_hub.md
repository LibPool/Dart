# tr_payment_hub

**Tag**: payment, iyzico, paytr, turkey, e-commerce, mobile

## 简介

Turkish payment gateway integration (iyzico, PayTR, Param, Sipay). Supports proxy mode (Flutter + any backend) and direct mode (Dart backend).
