# litertlm_dart

**Tag**: llm, ffi, on-device, litert, gemma, mobile

## 简介

Pure Dart runtime for Google's LiteRT-LM: FFI bindings, engine/conversation lifecycle, and streaming on-device LLM inference. No Flutter dependency.
