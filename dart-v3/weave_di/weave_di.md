# weave_di

**Tag**: dependency-injection, routing, navigation, modular, guards, mobile

## 简介

Dependency injection and typed routing for Flutter in one package. Scopes, parameterized factories, circular-dependency detection, route guards, middleware and transitions. No code generation.
