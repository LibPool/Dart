# relax_storage

**Tag**: storage, encryption, security, local-storage, aes, mobile, ui

## 简介

A secure Flutter storage package with AES-CBC encryption. Provides encrypted key-value storage built on top of GetStorage with SHA-256 key derivation and random IV generation.
