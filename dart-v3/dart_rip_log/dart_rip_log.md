# dart_rip_log

**Tag**: cd, audio, parser, ripping, accuraterip, serialization

## 简介

Parses CD rip log files from EAC, XLD, and other rippers into structured, JSON-serialisable quality data (AccurateRip, CRCs, peaks, errors).
