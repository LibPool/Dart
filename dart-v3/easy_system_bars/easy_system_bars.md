# easy_system_bars

**Tag**: status-bar, navigation-bar, edge-to-edge, system-ui, mobile, ui

## 简介

Fix the status bar and navigation bar of a whole Flutter app with one line. Always-readable status bar icons and three navigation bar modes, no SafeArea.
