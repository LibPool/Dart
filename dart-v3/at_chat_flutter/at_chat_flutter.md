# at_chat_flutter

**Tag**: mobile, ui

## 简介

A Flutter plugin project to provide a chat feature between atSigns built on the atPlatform to any Flutter application.

## 官网

- 主页: https://atsign.com
- 源码仓库: https://github.com/atsign-foundation/at_client_sdk/tree/trunk/packages/at_chat_flutter
- 文档: https://docs.atsign.com/
