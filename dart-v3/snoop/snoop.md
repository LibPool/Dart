# snoop

**Tag**: debugging, devtools, inspector, network, state-management, web, mobile, networking, tooling

## 简介

In-app debug inspector for Flutter. Inspect network calls, live state, logs and navigation in a floating dev-tools overlay. Add an adapter for your HTTP client and state library.
