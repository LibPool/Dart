# markdown_forge

**Tag**: markdown, editor, gfm, mermaid, katex, mobile

## 简介

GitHub-Flavored Markdown renderer and live-syntax source editor for Flutter: tables, task lists, footnotes, KaTeX math, Mermaid and an outline.
