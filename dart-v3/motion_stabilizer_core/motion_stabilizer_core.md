# motion_stabilizer_core

**Tag**: mobile

## 简介

Motion-sickness mitigation toolkit for Flutter. Sensor-driven "vehicle motion cues" (animated dots), an artificial horizon and a fixation dot, plus an Android system overlay that floats the cues over any app.
