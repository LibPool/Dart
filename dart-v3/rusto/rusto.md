# rusto

**Tag**: web, mobile

## 简介

Pure Rust OCR library bindings for Dart and Flutter based on RapidOCR and PaddleOCR.

## 官网

- 主页: https://github.com/byrizki/rusto-rs
- pub.dev: https://pub.dev/packages/rusto

## 历史版本号

- 0.3.2 (2026-10-25)

## 获取地址

- pub.dev: https://pub.dev/packages/rusto
- pub 安装: `dart pub add rusto`
- Flutter 安装: `flutter pub add rusto`
- 最新版本: 0.3.2
- 最新版归档: https://pub.dev/api/archives/rusto-0.3.2.tar.gz
