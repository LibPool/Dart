# vyuh_diagram_core

**Tag**: diagram, flowchart, editor, undo-redo, headless, mobile

## 简介

Headless diagram engine for Dart: create shapes and connectors, edit through transactions with undo and redo, and extend with plugins. No Flutter needed.
