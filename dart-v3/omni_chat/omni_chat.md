# omni_chat

**Tag**: chat, messaging, ui, widgets, media, mobile

## 简介

A professional, feature-rich Flutter chat UI package. Supports 17+ message types including text, image, video, audio waveform, sticker, GIF, document, location, contact, link preview, poll, profile card, ephemeral media, and custom messages. Includes swipe-to-reply, emoji reactions, message editing, built-in media viewers, screenshot protection, full theme customisation, and built-in localisation via OmniChatStrings.
