# virtual_keypad

**Tag**: keyboard, virtual-keyboard, onscreen-keyboard, multilingual-keyboard, text-input, mobile, desktop, ui

## 简介

On-screen virtual keyboard widget and keypad for Flutter kiosk, POS, TV, desktop and touchscreen apps. Numeric, numpad, PIN, emoji, floating and custom layouts in 16 languages.
