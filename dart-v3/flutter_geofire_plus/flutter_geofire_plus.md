# flutter_geofire_plus

**Tag**: geolocation, geofire, firebase, maps, location, web, mobile, database

## 简介

A Flutter plugin for realtime geospatial proximity queries with multi-backend support (Firebase, Firestore, Supabase, Postgres, MySQL), typed APIs, ride-dispatch helpers, and native background location tracking.
