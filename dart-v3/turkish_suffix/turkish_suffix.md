# turkish_suffix

**Tag**: mobile, ui

## 简介

A Dart package for handling Turkish suffixes. This package provides a set of extensions and widgets for adding various grammatical suffixes to Turkish words, making it easier to work with Turkish language rules in your Dart and Flutter applications.
