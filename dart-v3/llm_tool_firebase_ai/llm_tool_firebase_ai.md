# llm_tool_firebase_ai

**Tag**: llm, tool-calling, function-calling, firebase, gemini

## 简介

Use llm_tool with Firebase AI Logic (firebase_ai). Turns your @LlmTool functions into Gemini function declarations and runs the whole tool loop.
