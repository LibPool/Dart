# dot_shorthand

**Tag**: lint, analyzer-plugin, codemod, dot-shorthands, flutter, mobile, ui, tooling

## 简介

Migrate Dart code to dot shorthands (Color.red -> .red). CLI batch rewrite plus an analyzer plugin with a quick fix.
