# datecs_sk1_21

**Tag**: printer, fiscal, pos, thermal-printer, datecs, desktop

## 简介

Complete Dart SDK for the Datecs SK1-21 fiscal thermal printer: fiscal receipts, reports, PLU items, VAT, electronic journal, fiscal memory and display via DUDE COM on Windows.
