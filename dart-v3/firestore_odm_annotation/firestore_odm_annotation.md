# firestore_odm_annotation

**Tag**: firestore, odm, annotations, code-generation, flutter, web, mobile

## 简介

Annotations for firestore_odm, the type-safe Firestore ODM for Flutter and Dart. Declare collections, subcollections and document ID fields.
