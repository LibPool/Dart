# mpv_kit_libs

**Tag**: mpv, video, ffi, native-assets, desktop, ui, tooling

## 简介

Prebuilt LGPL libmpv (mpv 0.41 with the mpv_kit Vulkan render patch, FFmpeg 8.1) for mpv_kit, delivered through a Dart build hook with sha256 verification. Windows, Linux and macOS on x64 and arm64.
