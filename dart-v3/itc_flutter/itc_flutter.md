# itc_flutter

**Tag**: mobile, tooling

## 简介

The itc_flutter CLI tool simplifies the setup of new Flutter projects by automatically generating a well-structured folder and file layout,currently tailored for personal use. Suggestions are welcomed to improve this tool making it more valuable for broader audience
