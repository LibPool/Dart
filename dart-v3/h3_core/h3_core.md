# h3_core

**Tag**: h3, geospatial, ffi, mapping, hexagonal, web, mobile

## 简介

Dart/Flutter bindings for Uber's H3 hexagonal geospatial indexing library. Uses dart:ffi on native platforms and h3-js on web — same API everywhere.
