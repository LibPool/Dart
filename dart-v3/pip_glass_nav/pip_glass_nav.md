# pip_glass_nav

**Tag**: navigation, bottom-navigation-bar, glassmorphism, liquid-glass, mobile, ui

## 简介

Customizable glass bottom navigation for Flutter with an animated selection bubble, paired icons, badges, SVG widgets and RTL support.
