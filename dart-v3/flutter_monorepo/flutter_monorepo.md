# flutter_monorepo

**Tag**: web, mobile, networking, state-management, tooling

## 简介

Bootstrap a production-ready Flutter monorepo in one command. Choose state management (GetX/Riverpod/Bloc/Cubit), HTTP client, locales, and platforms.
