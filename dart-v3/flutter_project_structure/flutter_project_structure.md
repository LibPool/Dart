# flutter_project_structure

**Tag**: flutter, dart, ai, code-analysis, mcp, web, mobile

## 简介

Make a Flutter/Dart codebase AI-ready: API skeletons, an import graph, CLAUDE.md and an MCP server give agents full project context cheaply.
