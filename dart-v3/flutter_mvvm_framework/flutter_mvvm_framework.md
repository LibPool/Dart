# flutter_mvvm_framework

**Tag**: mvvm, state-management, reactive, rest-api, architecture, web, mobile, security, tooling

## 简介

A modular, robust, and batteries-included Model-View-ViewModel (MVVM) framework for Flutter with reactive properties, commands, REST client, auth, and pagination.
