# loro_crdt

**Tag**: crdt, local-first, collaboration, ffi, wasm, web, mobile, desktop

## 简介

Dart bindings for Loro, a high-performance CRDT library for local-first, collaborative apps. Runs on Android, iOS, macOS, Windows, Linux and the web.
