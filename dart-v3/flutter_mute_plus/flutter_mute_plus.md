# flutter_mute_plus

**Tag**: mute, ringer, silent-mode, vibrate, mobile

## 简介

Check or toggle the device ringer mode (normal, silent, vibrate). A maintained fork of flutter_mute with AGP 8/9, Xcode 16 and Swift Package Manager support.
