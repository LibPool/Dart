# custom_container_package_1001

**Tag**: mobile, ui

## 简介

The `custom_container` package provides a highly customizable container widget for Flutter. It allows you to easily create containers with customizable border radius, border color, border width, and background color, giving you the flexibility to design beautiful UIs effortlessly.
