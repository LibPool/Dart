# youtube_extractor_muzo

**Tag**: mobile, testing

## 简介

A highly robust, sandboxed Dart/Flutter library for YouTube Music stream extraction, supporting Signature Cipher, N-Throttle parameter bypass, and Botguard PoToken attestation.
