# traffic_cop

**Tag**: networking, logging, debugging, dio, http, web, mobile, ui, tooling

## 简介

A client-agnostic HTTP/Realtime network auditor for Flutter. Collapse concurrent duplicate requests, track payload sizes and latency, and monitor/debug logs securely with a built-in dashboard.
