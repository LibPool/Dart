# flutter_mautic

**Tag**: web, mobile

## 简介

Flutter Mautic provides seamless integration with the Mautic API, allowing Flutter developers to easily manage contacts, campaigns, and custom fields within their apps. This package simplifies operations such as adding or removing contacts from campaigns, updating contact fields, and retrieving Mautic data, offering a convenient, secure way to interact with Mautic's CRM functionalities directly from Flutter.
