# qt_common_web

**Tag**: analytics, tracking, quick-tracking, aliyun, web, mobile, ui

## 简介

Quick Tracking 统计基础库 Web 端 Flutter 插件，基于官方 QuickTracking Web SDK（qt_web.js），API 与 qt_common_sdk 原生插件保持一致。
