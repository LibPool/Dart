# mermaid_erdiagram

**Tag**: mermaid, erd, diagram, database, visualization, web, mobile, ui

## 简介

Native Mermaid entity relationship diagram (erDiagram) rendering for Flutter, no WebView: attribute tables with keys and comments, crow's foot markers, subgraphs and light/dark themes.
