# omnyshell_web

**Tag**: terminal, ssh, web, pwa, ui, tooling

## 简介

A browser client for OmnyShell — connect to a Hub, discover nodes, run interactive sessions — and the reusable library behind it: embed a real remote shell terminal, or its UI kit, in any Dart web app.
