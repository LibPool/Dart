# flutter_table_layout

**Tag**: table, datatable, data-grid, responsive, export, web, mobile, desktop

## 简介

Responsive data table for Flutter with frozen columns, sorting, filtering, grouping, editing, and Excel/PDF export for mobile, web, and desktop.
