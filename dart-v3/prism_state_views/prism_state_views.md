# prism_state_views

**Tag**: state, empty, loading, error, widget, mobile, ui, state-management

## 简介

One widget for empty, loading, error, and success states in Flutter — with retry callbacks, custom icons, and Dart 3 sealed view-state classes. Pure Flutter, works on all six platforms.
