# japanese_snow_vocabulary

**Tag**: navigation, safety, automotive, snow, japan

## 简介

Pure Dart JP-domestic snow vocabulary — six enum cases (アイスバーン / ブラックアイスバーン / 雪道 / 圧雪 / シャーベット / 凍結) with verbatim JAF citations.
