# leonard_host

**Tag**: mobile, tooling

## 简介

Pure-Dart VM-service host for Leonard — exposes a set of LeonardExtensions over `ext.leonard.*` so a non-Flutter Dart program can be driven live by leonard_cli / leonard_drive.
