# flutter_otel_native

**Tag**: mobile, desktop, state-management

## 简介

Native (Swift) telemetry foundation for flutter_otel on iOS/macOS: an on-disk queue that lets native code record finished spans/log records before or without a running Dart isolate, plus a MethodChannel bridge that drains it into the existing TracerProvider/LoggerProvider pipeline.
