# shtoone_push

**Tag**: push-notifications, android, huawei, xiaomi, vivo, mobile

## 简介

Flutter plugin that integrates Chinese Android push services (Huawei, Xiaomi, Honor, vivo, OPPO) to provide offline push notifications.
