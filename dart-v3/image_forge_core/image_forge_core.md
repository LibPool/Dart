# image_forge_core

**Tag**: image, image-processing, gpu, ffi, flutter, mobile, ui

## 简介

Lightweight Rust image processing engine for Flutter. Core operations: resize, crop, rotate, compress, thumbnails, EXIF, blurhash, basic filters, GPU compute, and RGBA buffer pipeline. Headless engine — no UI widgets. No face beauty or preset filters.
