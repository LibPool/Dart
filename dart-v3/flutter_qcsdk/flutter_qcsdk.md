# flutter_qcsdk

**Tag**: mobile

## 简介

A Flutter plugin for Oudmon / HeyCyan smart glasses and wearables. Enables BLE device scanning, connection management, battery monitoring, media file synchronization, AI chat integration (text, voice, image), and Wi-Fi OTA firmware upgrades.
