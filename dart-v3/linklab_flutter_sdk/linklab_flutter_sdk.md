# linklab_flutter_sdk

**Tag**: deep-linking, deferred-deep-link, dynamic-links, universal-links, app-links, mobile

## 简介

Flutter plugin for Linklab dynamic links: Android App Links / iOS universal links, deferred deep links (Play Install Referrer, pasteboard, IP attribution) and short-link resolution.
