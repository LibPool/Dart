# eureel_flutter

**Tag**: onboarding, video, tutorial, widget, mobile, ui

## 简介

Per-screen tutorial videos for Flutter apps — the Eureel SDK. Upload and map videos in the Eureel dashboard; this package shows them as a corner bubble with a full player.
