# jet_cad_floor_plan

**Tag**: cad, floor-plan, restaurant, point-of-sale, web, mobile

## 简介

An embeddable parametric floor planner for Flutter: walls, openings, rooms, dimensions and furniture symbols, with a host API for tables.
