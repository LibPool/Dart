# arcane_jaspr_kb

**Tag**: web, ui, tooling

## 简介

Knowledge-base (docs) chrome renderers for the Arcane Jaspr theme packages. Opt-in: this package pulls in arcane_lexicon (a server-side, dart:io docs package), so it is kept OUT of the theme packages to keep them web-safe for client apps. Docs sites depend on this package directly.
