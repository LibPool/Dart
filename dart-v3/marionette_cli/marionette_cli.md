# marionette_cli

**Tag**: mcp, ai, claude, agent, copilot, mobile, tooling

## 简介

CLI that lets AI agents (Claude, Copilot, Cursor) inspect and interact with running Flutter apps — tap, scroll, type, and screenshot.
