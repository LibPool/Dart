# isar_sync_flutter

**Tag**: isar, sync, offline-first, google-sign-in, icloud, mobile

## 简介

Flutter companion for isar_sync: wire Google Sign-In (Drive) and the icloud_storage plugin into isar_sync's cloud sync adapters.
