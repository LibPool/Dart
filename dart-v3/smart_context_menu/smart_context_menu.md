# smart_context_menu

**Tag**: context-menu, menu, popup, overlay, chat-context-menu, mobile, ui

## 简介

A powerful, customizable iOS-style context menu: smart positioning, fluid animations, drag-to-select, submenus (async, paginated), and widgets above the preview (e.g. reactions).
