# scan_tally

**Tag**: barcode, scanner, inventory, gs1, keyboard

## 简介

Continuous barcode scanning for stock counts: duplicate filtering, tally sessions with undo, keyboard wedge scanners, GS1 parsing, check digits and feedback.
