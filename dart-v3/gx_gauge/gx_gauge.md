# gx_gauge

**Tag**: gauge, chart, progress-indicator, stepper, widget, mobile, ui

## 简介

Customizable Flutter gauges: linear progress, stepper, scale and bar gauges plus radial gauges with ranges, ticks, labels, needles and animation (formerly girix_code_gauge).
