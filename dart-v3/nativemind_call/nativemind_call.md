# nativemind_call

**Tag**: web, mobile, tooling

## 简介

Native media layer of NativeMind calls on Andrey Bekhtold's handmade WebRTC code (Android PeerConnectionClient, iOS WebRTCManager, the WebRTCClientType configuration, Debug.swift): video through Flutter textures, hardware codecs, a Pigeon API after WebRTCManagerDelegate, and NmNativeCallPort — the NmCallPort of nativemind_deals.
