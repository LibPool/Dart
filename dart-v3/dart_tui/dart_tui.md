# dart_tui

**Tag**: terminal, tui, cli, elm, bubbletea, ui, tooling

## 简介

Elm-style terminal UI framework for Dart — Model–Update–View, async commands, 27+ components, Lipgloss-inspired styling, spring animation, and gum-style helpers.
