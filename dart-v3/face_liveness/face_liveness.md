# face_liveness

**Tag**: liveness, anti-spoofing, face-detection, ffi, camera, mobile, ui

## 简介

On-device face liveness (anti-spoofing) detection for Flutter: a camera widget that tells real faces from photos, screens and masks. Uses dart:ffi and ncnn.
