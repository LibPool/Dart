# neomorphic_spend_card

**Tag**: ui, fintech, card, neumorphism, animation, mobile

## 简介

A beautiful, animated neumorphic spend overview card for Flutter fintech apps. Features an animated arc budget ring, live spend ticker, category breakdown chips, shimmer pulse, and full dark/light mode support.
