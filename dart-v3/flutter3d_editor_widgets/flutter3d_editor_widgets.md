# flutter3d_editor_widgets

**Tag**: game-development, game-engine, tooling, mobile, ui

## 简介

Shared editor controls — a number field, a colour field, a section label, a range slider, an enum dropdown, a texture slot row, a texture path field, a colour swatch field and the FieldRow they assemble into, so far — over EditorWidgetsTheme, so the modeller and the level editor stop keeping their own copies.
