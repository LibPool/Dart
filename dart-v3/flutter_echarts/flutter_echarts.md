# flutter_echarts

**Tag**: web, mobile, ui, tooling

## 简介

A data visualization charts library, based on Apache ECharts, able to build advanced charts like WebGL 3D, GIS map, etc.

## 官网

- 主页: https://github.com/entronad/flutter_echarts
- pub.dev: https://pub.dev/packages/flutter_echarts
