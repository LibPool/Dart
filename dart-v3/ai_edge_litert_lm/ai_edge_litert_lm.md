# ai_edge_litert_lm

**Tag**: web, mobile

## 简介

A Flutter plugin for on-device LLM inference using Google's LiteRT-LM framework. Provides a high-level Conversation API with support for text, multimodal (image/audio) inputs, and tool calling. Android is fully supported via the official Kotlin SDK. iOS support will be added when the Swift SDK is available.
