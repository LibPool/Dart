# flutter_scene_ode_core

**Tag**: physics, ode, flutter-scene, simulation, web, mobile

## 简介

Pure-Dart core of flutter_scene_ode: the ODE (Open Dynamics Engine) physics simulation, its FFI and WebAssembly bindings and the library loader. Runs without Flutter, e.g. in a `dart compile exe` headless program.
