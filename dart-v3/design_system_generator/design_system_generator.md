# design_system_generator

**Tag**: design-system, flutter, code-generation, theming, build-runner, mobile, ui, serialization, tooling

## 简介

A generator for design system tokens, build from a json configuration for dart/flutter.
Generates colors, spatials, breakpoints, and other useful elements from a configuration.
