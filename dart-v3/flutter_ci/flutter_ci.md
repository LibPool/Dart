# flutter_ci

**Tag**: cli, flutter, ci, cd, automation, mobile, ui, tooling

## 简介

CLI tool for Flutter CI/CD: bumps pubspec versions, builds Android and iOS artifacts, stores them in versioned folders, tags releases and distributes builds.
