# object_detection

**Tag**: litert, tflite, object-detection, computer-vision, on-device-ml, web

## 简介

On-device object detection using MediaPipe EfficientDet-Lite models in LiteRT (formerly TensorFlow Lite) format. 80 COCO classes, fully offline.
