# flutter_db_inspector_core

**Tag**: database, devtools, debugging, inspector, mobile

## 简介

Runtime core of Flutter DB Inspector: DbInspector, registry, router, VM service extension and the generic SQL, document and key-value engines. Apps normally depend on `flutter_db_inspector`, which includes this.
