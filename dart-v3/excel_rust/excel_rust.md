# excel_rust

**Tag**: mobile, ui

## 简介

Read large excel files iteratively with ease using the excel_rust package.
This package provides efficient methods to handle large Excel files without
loading the entire file into memory, making it suitable for processing
large datasets. It leverages Rust for performance and integrates seamlessly
with Flutter.
