# liquid2d

**Tag**: mobile, ui

## 简介

Dart/Flutter binding for Chipmunk2D physics engine. This uses Chipmunk2D version 7.0.3.

## 官网

- 主页: https://github.com/liquid-physics/liquid2d
- pub.dev: https://pub.dev/packages/liquid2d

## 历史版本号

- 0.0.3 (2024-11-23)
- 0.0.2 (2024-02-27)
- 0.0.1 (2024-02-22)
