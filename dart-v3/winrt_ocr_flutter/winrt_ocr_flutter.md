# winrt_ocr_flutter

**Tag**: mobile, desktop, ui

## 简介

On-device Windows OCR for Flutter. Wraps Windows.Media.Ocr via C++/WinRT behind a single recognizeText(imagePath) method channel call. Windows-only — designed to slot behind a per-platform OCR dispatch abstraction in a consuming app, alongside mobile OCR engines for Android/iOS.
