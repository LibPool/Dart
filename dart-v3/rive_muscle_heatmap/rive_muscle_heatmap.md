# rive_muscle_heatmap

**Tag**: rive, fitness, anatomy, animation, health, mobile, ui

## 简介

Drop-in interactive human muscle heatmap widget for Flutter, powered by Rive. Highlight any set of muscles with one widget. Free anatomy asset included.
