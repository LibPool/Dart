# arch_guard_lint

**Tag**: clean-architecture, static-analysis, lints, ui, tooling

## 简介

Analyzer plugin that shows arch_guard layer violations, forbidden package imports and circular dependencies as warnings in your IDE and in dart analyze, with quick fixes.
