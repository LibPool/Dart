# crypto_wallet_core

**Tag**: crypto, bitcoin, ethereum, wallet, secp256k1, security

## 简介

Small, auditable pure-Dart wallet core. BIP-39, BIP-32, Bitcoin addresses, secp256k1 signing, Keccak, RLP and Ethereum transaction signing.
