# typed_socket

**Tag**: websocket, realtime, networking, reconnect, web, mobile, serialization, tooling

## 简介

A typed, resilient WebSocket client for Dart and Flutter: automatic reconnect with jittered backoff, heartbeats, offline buffering, and typed JSON channels.
