# hud_radial_menu

**Tag**: ui, menu, animation, widget, mobile, state-management

## 简介

A high-fidelity, interactive HUD radial menu for Flutter. Supports 5 petal styles (glassmorphism, neon glow, neumorphic, solid, wireframe) and 5 petal shapes, with smooth animations, hover/tap states, and full theming support.
