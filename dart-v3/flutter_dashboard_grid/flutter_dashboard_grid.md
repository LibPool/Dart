# flutter_dashboard_grid

**Tag**: dashboard, grid, layout, drag-and-drop, widget, mobile, ui

## 简介

Dashboard grid your users lay out themselves: resize, move, column sections, a phone and tablet section carousel and edit-mode handles. A fork of the dashboard package.
