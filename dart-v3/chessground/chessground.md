# chessground

**Tag**: ui

## 简介

Chess board UI developed for lichess.org. It has no chess logic inside so it can be used for chess variants.

## 官网

- 源码仓库: https://github.com/lichess-org/flutter-chessground
- pub.dev: https://pub.dev/packages/chessground
