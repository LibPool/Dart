# mockk_http

**Tag**: web, mobile, networking, testing, tooling

## 简介

In-app HTTP interceptor for Flutter: sends dio, HttpClient and package:http traffic to t he MockkHttp IDE plugin to record, debug and mock responses, also from AI agents over MCP.
