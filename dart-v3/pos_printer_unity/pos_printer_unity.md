# pos_printer_unity

**Tag**: printer, pos, thermal-printer, android, web, mobile

## 简介

A unified Flutter plugin for POS terminal printers. Supports Positivo (L3, L400), PAX, Gertec, Ingenico and more through a single, clean API.
