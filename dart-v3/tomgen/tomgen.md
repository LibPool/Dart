# tomgen

**Tag**: toml, code-generation, build-runner, configuration, ui, serialization, tooling

## 简介

TOML-first CLI and build_runner generator for dart-tomg: generates typed model libraries and compiles build-input TOML into const Dart registries, including optional field obfuscation. A dev_dependency in consuming packages.
