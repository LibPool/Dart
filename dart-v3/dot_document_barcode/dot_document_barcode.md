# dot_document_barcode

**Tag**: innovatrics, digital-onboarding, remote-identity-verification, document-detection, mobile

## 简介

A Flutter plugin, as a part of Innovatrics IDV Flutter SDK, that provides document barcode scanning for a Flutter project.
