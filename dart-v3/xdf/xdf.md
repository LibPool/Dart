# xdf

**Tag**: web

## 简介

Read and write XDF (Extensible Data Format) recordings, as made by LabRecorder: whole files in memory like pyxdf (clock synchronisation, dejittering), or large files indexed for fast viewing. Pure Dart, web-safe.
