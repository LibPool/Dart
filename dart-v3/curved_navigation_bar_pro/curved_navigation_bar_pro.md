# curved_navigation_bar_pro

**Tag**: navigation, ui, animation, widgets, material-design, mobile

## 简介

A beautiful Flutter curved bottom navigation bar with an animated curved notch FAB, smooth elastic bubble animation, badge support, and fully customisable theming.
