# cherrypick_lint

**Tag**: lint, di, ioc, dependency-injection, static-analysis, web, tooling

## 简介

Analyzer plugin that catches CherryPick DI API misuse right in the IDE and in dart analyze: missing await on scope disposal, misused annotations, and runtime traps.
