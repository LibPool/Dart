# knex_dart

**Tag**: sql, query-builder, database, orm, knex, ui, tooling

## 简介

A Dart SQL query builder inspired by Knex.js. Use driver packages (knex_dart_postgres, knex_dart_mysql, knex_dart_sqlite) to connect to databases.
