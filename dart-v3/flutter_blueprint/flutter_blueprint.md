# flutter_blueprint

**Tag**: cli, scaffolding, code-generation, flutter, architecture, web, mobile, security, state-management, tooling

## 简介

Enterprise Flutter CLI generator for clean architecture apps with Provider/Riverpod/BLoC/GetX, API presets, security guardrails, CI templates, and release-readiness scaffolding.
