# fast_dev

**Tag**: flutter, cli, assets, code-generation, build-runner, mobile, ui, tooling

## 简介

写在 dev_dependencies 的 Flutter 开发期工具：根据 flutter.assets 生成类型安全路径。CLI 和 build_runner 同一套结果。
