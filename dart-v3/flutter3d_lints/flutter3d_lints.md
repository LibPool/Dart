# flutter3d_lints

**Tag**: game-development, lints, analyzer, determinism, mobile, tooling

## 简介

Analyzer rules for code inside a flutter3d fixed step: no wall clock, no unseeded Random, no dart:math transcendental where Portable gives one answer everywhere.
