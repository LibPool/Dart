# universal_capture_flutter

**Tag**: flutter, screencast, frames, automation, mobile

## 简介

FrameSource over a running Flutter app's MCP toolkit screenshots: paced polling of `ext.mcp.toolkit.view_screenshots` through the Dart VM service, feeding the universal_screencast pipeline.
