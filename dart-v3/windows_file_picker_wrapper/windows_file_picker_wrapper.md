# windows_file_picker_wrapper

**Tag**: mobile, desktop

## 简介

A rock-solid, deadlock-free native Windows 10/11 File and Folder Picker for Flutter desktop. Uses isolated STA processes to eliminate COM deadlocks and Z-order focus freezes.
