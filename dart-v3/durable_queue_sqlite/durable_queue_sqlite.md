# durable_queue_sqlite

**Tag**: queue, sqlite, persistence, offline, retry, web, mobile, desktop, database

## 简介

SQLite storage for durable_queue on mobile, desktop, and web. Persists tasks across app restarts with indexed, transactional queries.
