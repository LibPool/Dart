# generate_assets

**Tag**: flutter, assets, codegen, cli, mobile, serialization, tooling

## 简介

A CLI tool that generates Dart asset constants from your Flutter project's pubspec.yaml. Supports unused asset detection and batch deletion of unused files including 2x/3x resolution variants.
