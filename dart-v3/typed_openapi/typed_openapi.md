# typed_openapi

**Tag**: openapi, swagger, code-generation, api-client, cli, web, tooling

## 简介

OpenAPI 3.x to Dart client generator for imperfect, code-first specs: named normalizer rules, diagnostics with stable codes, overrides, open enums, unions with an unknown variant and typed errors.
