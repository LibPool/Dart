# sql_server_wrapper

**Tag**: web, mobile, desktop, database

## 简介

Fork of mssql_connection. Cross-platform Dart FFI plugin for Microsoft SQL Server databases using FreeTDS. Supports Windows, Android, iOS, macOS, and Linux natively.
