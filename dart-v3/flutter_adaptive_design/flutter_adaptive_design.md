# flutter_adaptive_design

**Tag**: adaptive, cupertino, material3, design-system, responsive, mobile, ui

## 简介

Platform-adaptive Flutter design system automatically dispatching native iOS (Cupertino HIG) and Android (Material 3) UI from a single codebase.
