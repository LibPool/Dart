# goaffpro_attribution

**Tag**: attribution, affiliate, analytics, referral, deep-linking, mobile

## 简介

Affiliate attribution for Flutter apps. Tracks which affiliate referred each install and each conversion, using the platform install referrer with a probabilistic fallback.
