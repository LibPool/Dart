# bug_capsule

**Tag**: web, mobile, networking, state-management, tooling

## 简介

BugCapsule for Flutter — records the context around a failure into a portable .bugcapsule capsule, replays it locally, and ships every integration (BLoC, Riverpod, Provider, GetX, MobX, Dio, http, GoRouter, SharedPreferences) and the bugcapsule CLI in one package.
