# flutter_roomplan

**Tag**: roomplan, arkit, lidar, usdz, multi-room, web, mobile, ui, serialization

## 简介

A powerful Flutter plugin for Apple's RoomPlan API enabling 3D room scanning, multi-room merge, object detection, and export to USDZ/JSON formats. Perfect for AR measurement, smart home, and interior design apps on iOS 16.0+ devices with LiDAR support.
