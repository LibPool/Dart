# hesab_pay

**Tag**: payments, payment-gateway, fintech, sdk, web, mobile, security

## 简介

A production-grade Flutter/Dart SDK for the HesabPay payment gateway API. Create payment sessions, distribute multi-vendor payments, verify webhook signatures, encrypt PINs, and parse redirect callbacks.
