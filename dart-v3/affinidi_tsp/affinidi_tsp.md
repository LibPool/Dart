# affinidi_tsp

**Tag**: tsp, cryptography, did, ssi, messaging, security

## 简介

Trust Spanning Protocol (TSP) Rev 3 for Dart: CESR framing, HPKE-Base, sealed box, signed-only messages, relationship control and ssi-integrated DID-based VIDs.
