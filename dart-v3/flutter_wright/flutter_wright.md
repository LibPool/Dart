# flutter_wright

**Tag**: testing, automation, integration-testing, e2e, ai, web, mobile, networking

## 简介

Playwright-style control of a running Flutter app — snapshot, tap, type, waitFor, network capture — for AI-driven and automated end-to-end testing. Debug-only in-app HTTP server.
