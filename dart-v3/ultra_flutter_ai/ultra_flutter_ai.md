# ultra_flutter_ai

**Tag**: ai, llm, rag, embeddings, flutter, mobile, ui, state-management

## 简介

Production-grade AI toolkit for Flutter & Dart. Embeddings, LLM inference, vector search, RAG pipelines, prompt orchestration, AI agents (ReAct), streaming, tool calling, multi-provider plugin architecture, and ready-made chat UI widgets.
