# dropfind

**Tag**: mobile, ui

## 简介

'DropFind is a customizable and user-friendly dropdown search widget for Flutter, designed to help users quickly find and select items from large lists with ease. It supports filtering, theming, and responsive layouts out of the box.
Maintained by gnovation.com.'
