# feature_sliced_lints

**Tag**: lints, analyzer, architecture, web, mobile, ui, tooling

## 简介

Analyzer plugin that enforces Feature-Sliced Design (layers, slices, public APIs and a pure domain) in Dart and Flutter projects.
