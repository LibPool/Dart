# otp_animated_fields

**Tag**: otp, pin, input, animation, verification, ui

## 简介

A one-time-code (OTP) input whose boxes become the loading indicator: on submit they fly from the row onto a circle and orbit it until verification resolves, then land as a check mark or shake back into place.
