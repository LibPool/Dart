# adaptive_image_picker

**Tag**: image-picker, image-cropper, image-compression, camera, photopicker, mobile

## 简介

A production-grade, zero-permission adaptive image picker for Flutter with pure-Dart cropping, binary-search compression, and native PhotoPicker integration.
