# universal_driver_windows

**Tag**: automation, windows, accessibility, uia, desktop, ui

## 简介

Windows accessibility driver for the universal automation family: a UI Automation (UIA) driver over a Rust sidecar, mapping the Windows control tree onto the family's semantic snapshot model.
