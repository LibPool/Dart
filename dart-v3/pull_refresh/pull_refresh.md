# pull_refresh

**Tag**: refresh, pagination, infinite-scroll, listview, widget, mobile, ui

## 简介

Maintained pull-to-refresh and load-more for any Flutter ScrollView, with bouncing and clamping physics, localised RTL indicators and semantics.
