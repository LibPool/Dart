# zebridge

**Tag**: postgresql, nats, offline-first, sqlite, ffi, mobile, desktop, ui, database, tooling

## 简介

ZeBridge client for Dart and Flutter: an offline-first local replica of PostgreSQL tables, kept in sync over NATS, with libzb built in for Android, iOS, macOS and Linux.
