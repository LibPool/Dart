# vio

**Tag**: backend, framework, http, websocket, server, web, ui, database, networking, security, state-management, tooling

## 简介

A lightweight modular Dart backend framework: plugin lifecycle, single-port HTTP + WebSocket, a multi-transport handler gateway, JWT auth, config, scheduler, SQLite, and reverse-proxy building blocks.
