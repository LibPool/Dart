# structured_log_remote_sync

**Tag**: logging, remote-logging, log-shipping, observability, structured-logging, web, networking

## 简介

RemoteSyncLogOutput — a batching, retrying structured_log sink that ships log entries to a structured_log_server instance over HTTP.
