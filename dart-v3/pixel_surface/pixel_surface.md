# pixel_surface

**Tag**: gpu, texture, ffi, cvpixelbuffer, surface-texture, mobile

## 简介

Flutter GPU texture runtime — TextureRegistry bridge, CVPixelBuffer / SurfaceTexture upload, and GpuTextureView. No editor, filters, or beauty.
