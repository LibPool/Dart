# native_toolchain_rust_mirror

**Tag**: mobile, ui, tooling

## 简介

Library to interact with rustup and cargo when building Dart and Flutter native assets written in Rust.  Mirrored by sneurlax from irondash for downstream package-publishing purposes until irondash incorporates library names; use the versions from irondash in production. This crate will be unpublished/deleted as soon as possible.
