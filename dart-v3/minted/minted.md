# minted

**Tag**: validation, type-safety, domain-driven-design, standards, ui

## 简介

The shared vocabulary of the minted family: the ParseOutcome and MintedFailure types a parse hands back. The value types themselves live in the minted_* domain packages. Pure Dart.
