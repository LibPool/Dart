# flutter_crop_image

**Tag**: image, cropper, crop-image, image-cropper, document-scanner, mobile, ui

## 简介

A production-ready, highly extensible Flutter image cropper package with headless engine support, customizable overlays, themes, gestures, shapes, and GPU-accelerated export.
