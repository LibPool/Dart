# rebi_vin_decoder

**Tag**: library

## 简介

Dart library for working with Vehicle Identification Numbers (VINs) based on ISO 3779:2009 and   World Manufacturer Identifiers (WMIs) based on ISO 3780:2009, enriched by NHTSA data.
