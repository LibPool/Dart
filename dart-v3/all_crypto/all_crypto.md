# all_crypto

**Tag**: cryptography, encryption, hashing, aes, chacha20, serialization, security

## 简介

Authenticated encryption in pure Dart with versioned envelopes that never serialize keys, ChaCha20-Poly1305, AES-GCM, SHA-256, and HMAC.
