# carp_movesense_package

**Tag**: mobile-sensing, mobile-health, sensors, digital-phenotyping, mobile

## 简介

The CARP Movesense sampling package. Samples sensor data from the Movesense MD and ACTIVE (HR+, HR2) devices.
