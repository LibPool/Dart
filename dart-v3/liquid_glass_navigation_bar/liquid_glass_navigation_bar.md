# liquid_glass_navigation_bar

**Tag**: navigation, bottom-navigation-bar, glassmorphism, ui, widget, mobile

## 简介

A glassmorphism bottom navigation bar for Flutter inspired by iOS 26 liquid glass, with light/dark themes, badges, a sliding indicator and an action chip.
