# silon

**Tag**: messaging, sms, whatsapp, notifications, api, web, mobile, desktop

## 简介

Official Dart SDK for the Silon messaging API. Pure Dart, Flutter-compatible (mobile, desktop, and web). Send messages on any channel, manage broadcasts, OTP, CRM, bulk sends, and verify webhook signatures.
