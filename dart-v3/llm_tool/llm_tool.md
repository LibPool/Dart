# llm_tool

**Tag**: llm, tool-calling, function-calling, ai-agents, on-device-ai, serialization

## 简介

Turn Dart functions into LLM tools for OpenAI, Gemini, Claude, MCP and on-device models. Annotate with @LlmTool to generate the JSON schema, argument validation and typed calls.
