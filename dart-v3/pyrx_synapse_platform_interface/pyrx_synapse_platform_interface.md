# pyrx_synapse_platform_interface

**Tag**: pyrx, synapse, platform-interface, push-notifications, mobile, tooling

## 简介

Platform-interface contract for the PYRX Synapse Flutter SDK. Defines the abstract Dart surface that platform implementations (`pyrx_synapse_ios`, `pyrx_synapse_android`) extend, plus the Pigeon spec that codegens the type-safe MethodChannel + EventChannel layer between Dart and the iOS / Android native SDKs.
