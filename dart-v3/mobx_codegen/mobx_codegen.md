# mobx_codegen

**Tag**: reactive-programming, state-management, codegen, tooling

## 简介

Code generator for MobX that adds support for annotating your code with @observable, @computed, @action and also creating Store classes.

## 官网

- 主页: https://mobx.netlify.app
- 源码仓库: https://github.com/mobxjs/mobx.dart
- 问题追踪: https://github.com/mobxjs/mobx.dart/issues
- pub.dev: https://pub.dev/packages/mobx_codegen
