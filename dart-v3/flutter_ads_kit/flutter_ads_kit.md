# flutter_ads_kit

**Tag**: ads, admob, google-mobile-ads, advertising, monetization, mobile, ui

## 简介

Production-ready Google AdMob for Flutter. Zero-config widgets for Banner, Native, Interstitial, Rewarded, Rewarded Interstitial, and App Open ads. Built-in iOS ATT and GDPR/UMP consent. Handles all edge cases automatically.
