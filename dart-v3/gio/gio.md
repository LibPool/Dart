# gio

**Tag**: http, http-client, rest-api, networking, flutter, web, mobile, testing, tooling

## 简介

A powerful and flexible HTTP client library for Dart and Flutter.  Features include interceptors, request/response transformation,  file upload/download, mock server support, and cross-platform compatibility.
