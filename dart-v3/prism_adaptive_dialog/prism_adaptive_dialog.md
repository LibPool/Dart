# prism_adaptive_dialog

**Tag**: dialog, bottom-sheet, adaptive, responsive, widget, mobile, desktop, ui

## 简介

Adaptive dialogs for Flutter — bottom sheets on phones, centered dialogs on desktop, from one call. The companion to prism_adaptive_scaffold. Pure Flutter, works on all six platforms.
