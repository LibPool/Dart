# rg_bridge

**Tag**: mobile, ui, testing

## 简介

Hardware test bridge: device info + 14 headless test controllers + touchscreen widget. Native Android ships in-package (button interception, screen events, bluetooth/wifi, permissions); iOS is a neutral stub.
