# srik_cli

**Tag**: flutter, cli, scaffolding, clean-architecture, riverpod, mobile, ui, state-management, tooling

## 简介

Flutter project scaffolder. Choose architecture (Clean, MVVM, Feature-first, Simple) and a generated design system (Material through Spatial UI). Generate projects and add features.
