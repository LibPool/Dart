# hubsight_sdk

**Tag**: cctv, webrtc, camera, surveillance, nvr, web, mobile

## 简介

Standard Flutter SDK for HubSight CCTV Surveillance Platform. Provides Zero-Config enrollment (.hscfg), Atomic 401 token refresh, Multi-View WebRTC batching, and Real-time Thumbnails.
