# facebetter_flutter

**Tag**: beauty, camera, video, image-processing, mobile

## 简介

Real-time beauty effect engine for Flutter. Supports smoothing, whitening, face reshape, makeup, filters, stickers, chroma key, and virtual background on iOS and Android.
