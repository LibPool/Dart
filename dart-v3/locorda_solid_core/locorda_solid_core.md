# locorda_solid_core

**Tag**: rdf, linked-data, semantic-web, crdt, solid, web, networking

## 简介

Solid Pod backend implementation for Locorda — internal HTTP layer and types used by locorda_solid. One of multiple BYOB backends alongside Google Drive.
