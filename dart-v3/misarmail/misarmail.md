# misarmail

**Tag**: email, transactional-email, marketing, api-client, webhooks, web, tooling

## 简介

Send transactional email and run marketing campaigns from Dart: MisarMail's API for sends, campaigns, contacts, templates, domains, validation, analytics, webhooks and SSE.
