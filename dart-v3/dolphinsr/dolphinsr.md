# dolphinsr

**Tag**: spaced-repetition, flashcards, anki, srs, web, mobile, ui, tooling

## 简介

A spaced-repetition scheduling algorithm for Dart, based on Anki's SM-2 variant. Build flashcard and review systems for Flutter, web, or server.
