# db_dsl

**Tag**: database, query-builder, orm, lmdb, offline-first, ui, tooling

## 简介

A Diesel-style query language for Dart: typed tables, filters, joins, aggregates and transactions sent as a documented protocol to any engine (native LMDB, in memory, or your own).
