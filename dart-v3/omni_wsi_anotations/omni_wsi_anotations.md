# omni_wsi_anotations

**Tag**: serialization

## 简介

A pure Dart package for WSI (Whole Slide Imaging) vector annotation manipulation, validation, calibration, import and export (Aperio XML, Hamamatsu NDPA, QuPath GeoJSON).
