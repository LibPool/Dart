# schema_build

**Tag**: web, mobile, ui, serialization, tooling

## 简介

A professional Server-Driven UI (SDUI) engine and visual builder for Flutter. Create, manage, and update dynamic layouts in real-time via JSON with zero-rebuild reactivity.
