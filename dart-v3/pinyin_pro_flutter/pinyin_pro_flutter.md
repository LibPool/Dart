# pinyin_pro_flutter

**Tag**: pinyin, chinese, i18n, localization, text, mobile

## 简介

A professional Chinese pinyin conversion library for Flutter/Dart. Supports tone marks, multiple readings, text matching, HTML generation, and custom dictionaries.
