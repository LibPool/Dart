# flutter_translation_sync

**Tag**: localization, i18n, translation, cli, flutter, mobile, tooling

## 简介

A Dart CLI tool and library to sync, validate, and auto-translate Flutter localization files. Supports all Google Translate languages, auto-creates missing language files, and integrates into any Flutter project.
