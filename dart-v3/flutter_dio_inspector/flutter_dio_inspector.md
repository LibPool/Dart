# flutter_dio_inspector

**Tag**: dio, network, debugging, http, inspector, web, mobile, networking

## 简介

An in-app network panel for Dio: a draggable floating ball with an unread badge, and a full-screen inspector for requests, responses, headers, bodies and cURL.
