# sngnav_road_friction_ipc

**Tag**: desktop, tooling

## 简介

Host Linux x86_64 only. Receives road-friction samples over Eclipse iceoryx™ (iceoryx2™) shared memory and classifies them with the RoadFriction rule from kuksa_dart_sdk.
