# ollama_dart

**Tag**: nlp, gen-ai, llms, ollama, web, tooling

## 简介

Dart client for the Ollama API to run LLMs locally (OpenAI gpt-oss, DeepSeek-R1, Gemma 3, Llama 4, and more).
