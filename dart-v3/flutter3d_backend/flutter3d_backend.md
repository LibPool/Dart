# flutter3d_backend

**Tag**: graphics, gpu, rendering, web, mobile, desktop, ui, tooling

## 简介

Picks the graphics backend a build draws through: Impeller on a desktop, WebGL2 in a browser, and a software rasteriser at runtime if Impeller will not start.
