# fingerprint_sdk

**Tag**: fingerprint, biometrics, plugin, q818, flutter, mobile

## 简介

A Flutter plugin for Q818 fingerprint hardware integration. Capture images, generate ISO/ANSI templates, and compare fingerprints.
