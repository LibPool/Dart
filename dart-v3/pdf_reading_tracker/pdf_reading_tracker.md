# pdf_reading_tracker

**Tag**: pdf, pdf-viewer, annotations, bookmarks, sqlite, mobile, ui, database

## 简介

Flutter PDF reader with reading progress, bookmarks, annotations, notes, search, host toolbar integration, offline SQLite persistence,  and PDF merge/split, built on Syncfusion PDF Viewer.
