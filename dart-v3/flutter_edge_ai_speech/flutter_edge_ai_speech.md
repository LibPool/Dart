# flutter_edge_ai_speech

**Tag**: speech, stt, gemma, litert, on-device, web, mobile, state-management

## 简介

On-device speech (STT + TTS) for flutter_edge_ai via the LiteRT C API + dart:ffi. Opt-in Stt/TtsBackendProvider.
