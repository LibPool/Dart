# dart_otel_instrumentation_http

**Tag**: web, networking, tooling

## 简介

package:http client instrumentation for dart_otel: a BaseClient wrapper that starts a CLIENT span per request, propagates it via W3C traceparent, and captures request/response headers as semantic-convention attributes.
