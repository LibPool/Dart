# flutter_db_inspector

**Tag**: database, sqlite, devtools, debugging, inspector, mobile

## 简介

Inspect, query and edit your Flutter app's local databases from DevTools, VS Code and Android Studio while it runs. Runtime, wire protocol and the DevTools extension in one package; add a connector per database you use.
