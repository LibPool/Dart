# amwal_ecr

**Tag**: payments, pos, ecr, terminal, web, mobile, desktop, ui

## 简介

Drive an Amwal POS terminal from Flutter. One Dart API over native Android and iOS ECR SDKs (Wi‑Fi, USB, Web Service, and Android app-to-app), plus a pure-Dart Windows host (LAN TCP + Web Service): sale, void, refund, inquiry and e-receipt, with typed outcomes that keep an unknown result apart from a refusal.
