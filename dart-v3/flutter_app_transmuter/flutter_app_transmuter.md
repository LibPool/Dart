# flutter_app_transmuter

**Tag**: web, mobile, serialization

## 简介

Transmute your Flutter application using one command from terminal.  Facilitates many types of application changes such as rebranding, changing package and bundle ids, changing API keys in AndroidManifest.xml or AppDelegate.swift, swapping resources and icons, swapping out source files, etc.
