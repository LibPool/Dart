# redact

**Tag**: privacy, security, llm, pii, redaction, web, mobile

## 简介

On-device, precision-first PII redaction for Dart and Flutter. Scrub emails, phones, cards, SSNs and more from text before it reaches any LLM, then restore the model's reply.
