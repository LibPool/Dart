# html_editor_enhanced_flutterflow

**Tag**: web, mobile, ui

## 简介

HTML rich text editor for Android, iOS, and Web, using the Summernote library. Enhanced with highly customizable widget-based controls, bug fixes, callbacks, dark mode, and more. FlutterFlow compatible version with updated dependencies.
