# supafreeze

**Tag**: supabase, freezed, dart-mappable, code-generation, build-runner, ui, database, tooling

## 简介

Generate Freezed or dart_mappable models from Supabase database schema automatically. Supports incremental generation, smart caching, and build_runner integration.
