# cellar

**Tag**: storage, cache, files, encryption, cross-platform, web, mobile, security

## 简介

Cross-platform file and data storage for Dart and Flutter. Save, read, stream, and cache with one API on every platform — auto-cleanup, encryption, custom backends.
