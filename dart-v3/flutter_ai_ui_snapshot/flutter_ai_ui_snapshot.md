# flutter_ai_ui_snapshot

**Tag**: cli, ai, codegen, testing, developer-tools, mobile, ui, tooling

## 简介

Generate AI-ready Markdown context for a Flutter screen: a static UI tree from source analysis plus a headless-rendered PNG, in one CLI command. No simulator required.
