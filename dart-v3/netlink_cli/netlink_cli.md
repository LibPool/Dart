# netlink_cli

**Tag**: mobile, ui, networking, tooling

## 简介

Companion CLI for the netlink package: adds the dependency, wires NetworkConfigScreen as the default route, and writes the required Android & iOS (Bonjour) permissions into a Flutter app.
