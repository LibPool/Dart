# docx_to_markdown

**Tag**: docx, markdown, ooxml, word, documents, serialization

## 简介

Convert Word .docx (OOXML) files to GitHub-Flavored or CommonMark Markdown in pure Dart, with images, tables, lists, footnotes, math, and extensible hooks.
