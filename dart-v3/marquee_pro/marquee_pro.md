# marquee_pro

**Tag**: marquee, animation, text, ticker, widget, mobile, ui

## 简介

Marquee Text is a Flutter widget for smooth, infinitely scrolling text, rich content, and custom widgets with flexible controls for direction, speed, fading edges, pauses, and animated colors.
