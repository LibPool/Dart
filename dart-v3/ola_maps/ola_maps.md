# ola_maps

**Tag**: maps, ola-maps, navigation, geolocation, markers, web, mobile

## 简介

Ola Maps Flutter plugin (Android, iOS, and Web SDK map views) plus Places / Geocoder helpers. Vendored from ola_maps_flutter 0.2.0.
