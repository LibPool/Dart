# music_feature_analyzer

**Tag**: audio, metadata, music, music-player, song, mobile

## 简介

Flutter package to extract song metadata and AI-powered music features from audio files. Get title, artist, album, duration, bitrate, album art, genre, and more on Android & iOS.
