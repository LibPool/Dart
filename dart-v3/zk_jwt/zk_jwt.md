# zk_jwt

**Tag**: jwt, sd-jwt, zero-knowledge, poseidon, credentials, ui, security

## 简介

Selective Disclosure JWT with a ZK-friendly Poseidon hash, backed by prebuilt Rust native binaries. No Rust toolchain required to consume it.
