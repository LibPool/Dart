# quickpatch_build_trace

**Tag**: mobile, ui, tooling

## 简介

Chrome Trace Event Format producer used by QuickPatch's build-trace plumbing across flutter_tools, dart-sdk's aot_tools, and quickpatch_cli. Not intended for consumption outside of those projects.
