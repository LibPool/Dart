# lkcn_ui

**Tag**: ui, components, design-system, luckin, material, mobile

## 简介

瑞幸风格 Flutter 组件库 · Luckin Coffee Style Flutter UI Kit. 22 个基于 Material 设计的组件，覆盖按钮、商品卡、价格、会员卡等 O2O 业务场景，与 npm 包 lkcn-ui（微信小程序版）双端对齐。
