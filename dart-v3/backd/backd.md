# backd

**Tag**: api-client, backend, web, mobile, tooling

## 简介

The pure-Dart client for backd: sign-in and sessions, collections and the query language, files, function jobs, realtime live views and generated realm types. Works in Flutter apps and standalone Dart programs alike.
