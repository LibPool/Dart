# adaptive_image_picker_ohos

**Tag**: image-picker, image-cropper, image-compression, camera, photopicker, mobile

## 简介

OpenHarmony adaptation of adaptive_image_picker: a production-grade, zero-permission adaptive image picker for Flutter with pure-Dart cropping, binary-search compression, and native PhotoPicker integration.
