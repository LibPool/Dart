# e2ee_vault

**Tag**: encryption, cryptography, password, security, e2ee

## 简介

Auditable zero-knowledge vault crypto: Argon2id key hierarchy, XChaCha20-Poly1305 records, truncation-proof streaming files, blind index, password tools, HIBP.
