# naeileun_pin_input

**Tag**: flutter, ui, bottom-sheet, pin, security, mobile

## 简介

6자리 PIN(간편 비밀번호) 입력용 모달 바텀시트 위젯. 입력 완료 후 외부 검증 → controller로 success/error/close 제어.
