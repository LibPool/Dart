# silon_sms_autofill

**Tag**: otp, sms, autofill, android, authentication, web, mobile, security

## 简介

Optional Android zero-tap SMS OTP autofill for the Silon SDK. Wraps Google's SMS Retriever API (zero-tap) with a User Consent (one-tap) fallback; no-ops cleanly off Android. Pairs with silon's otp.send(appHash: ...).
