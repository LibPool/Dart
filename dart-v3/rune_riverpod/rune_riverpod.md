# rune_riverpod

**Tag**: rune, bridge, riverpod, state-management, reactive, ui

## 简介

Riverpod 2.x bridge for the rune package. Registers ProviderScope root + RiverpodConsumer widget for consuming providers by string name inside Rune source.
