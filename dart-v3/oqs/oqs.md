# oqs

**Tag**: cryptography, post-quantum, kem, pqc, liboqs, security

## 简介

Dart FFI bindings for liboqs — high-performance post-quantum cryptography (PQC) with ML-KEM, ML-DSA, Falcon for key encapsulation and signatures.
