# vertically_scrollable_bar

**Tag**: mobile, ui, networking, tooling

## 简介

The VerticallyScrollableBar is a customizable Flutter widget for creating a vertical, scrollable navigation menu. It offers flexible styling options including gradients, icons, text colors, and image handling (icons, assets, network images, SVGs). Perfect for building side menus with dynamic user interaction and smooth visual feedback.
