# flutter3d_pointer_lock

**Tag**: input, mouse, pointer-lock, game-development, web, mobile, desktop

## 简介

Locks the mouse pointer and reports its motion as relative deltas, which Flutter offers on no desktop platform and does not surface in a browser. Formerly pointer_lock.
