# flutter_esc_pos_bluetooth_universal

**Tag**: bluetooth, printer, thermal-printer, esc-pos, pos, web, mobile, desktop

## 简介

Print receipts on ESC/POS thermal Bluetooth printers (BLE and Classic SPP) from Android, iOS, macOS, Windows, Linux and Flutter Web, with one API.
