# flutter_probe_gen

**Tag**: testing, e2e, flutter, codegen, build-runner, mobile, ui, tooling

## 简介

build_runner code generator for FlutterProbe — reads flutter_probe_annotation decorators on Flutter classes and emits .probe test files into tests/generated/. Pair with flutter_probe_agent and the probe CLI to run the generated end-to-end tests.
