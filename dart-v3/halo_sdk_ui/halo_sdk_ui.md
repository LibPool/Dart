# halo_sdk_ui

**Tag**: payments, nfc, android, point-of-sale, mobile, ui

## 简介

Halo Dot tap-on-phone payments for Flutter. Wraps the native sdk_ui library behind one Dart class, so an app can take a card payment on the phone itself. Android only.
