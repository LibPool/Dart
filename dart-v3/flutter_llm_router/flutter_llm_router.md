# flutter_llm_router

**Tag**: ai, llm, flutter-ai-toolkit, cost-tracking, failover, mobile, state-management

## 简介

A resilient multi-provider LLM router for Flutter AI Toolkit featuring transparent failover, token cost tracking, and attempt logging.
