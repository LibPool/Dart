# flutter_rust_3d

**Tag**: web, mobile

## 简介

GPU 3D engine for Flutter. Rust + wgpu + Rapier3D, rendered into irondash native texture.

## 官网

- 源码仓库: https://github.com/IILLUMINATION/flutter_3d_engine
- pub.dev: https://pub.dev/packages/flutter_rust_3d

## 历史版本号

- 0.1.0 (2026-07-13)

## 获取地址

- pub.dev: https://pub.dev/packages/flutter_rust_3d
- pub 安装: `dart pub add flutter_rust_3d`
- Flutter 安装: `flutter pub add flutter_rust_3d`
