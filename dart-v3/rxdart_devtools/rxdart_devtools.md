# rxdart_devtools

**Tag**: rxdart, devtools, streams, debugging, flutter, mobile

## 简介

A Dart & Flutter DevTools extension for inspecting RxDart Subjects and Dart Streams. Simple SDK to set up for value/error introspection and injection.
