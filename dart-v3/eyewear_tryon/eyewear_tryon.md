# eyewear_tryon

**Tag**: virtual-try-on, eyewear, face-tracking, augmented-reality, glasses, mobile

## 简介

Virtual glasses try-on for Flutter with real-world sizing: PD measurement, frames drawn at true size from measurements, photos or 3D models, and a fit score.
