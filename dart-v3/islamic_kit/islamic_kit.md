# islamic_kit

**Tag**: islamic, qibla, prayer-times, hijri, zakat, mobile, ui

## 简介

Comprehensive Islamic toolkit for Flutter: prayer times, Qibla compass, Hijri calendar, Zakat calculator & Islamic events widgets.
