# webtransport

**Tag**: webtransport, quic, http3, ffi, networking, web, mobile, ui, tooling

## 简介

WebTransport (HTTP/3 over QUIC) for Dart and Flutter: one browser-shaped client API, backed by the browser on the web and by a bundled Rust implementation elsewhere.
