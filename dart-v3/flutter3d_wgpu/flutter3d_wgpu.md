# flutter3d_wgpu

**Tag**: gpu, compute, ffi, graphics, mobile

## 简介

The compute sidecar for flutter3d: a compute-only GraphicsDevice over wgpu-native through dart:ffi, so compute steps run on the GPU when the drawing device has none.
