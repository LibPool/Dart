# jackdaw_a2ui

**Tag**: ai, llm, a2ui, generative-ui, ui, tooling

## 简介

A2UI renderers for jackdaw agents. Sends the UI a jackdaw agent builds to an a2ui_core message processor, so any renderer built on a2ui_core can draw it, and turns its actions back into messages for the agent.
