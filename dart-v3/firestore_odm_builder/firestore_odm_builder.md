# firestore_odm_builder

**Tag**: firestore, odm, code-generation, build-runner, flutter, web, mobile, ui, tooling

## 简介

Code generator for firestore_odm, the type-safe Firestore ODM for Flutter and Dart. Generates typed queries, patches, aggregates and converters with build_runner.
