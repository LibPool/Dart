# fast_package

**Tag**: flutter, widget, ui, utilities, toast, mobile

## 简介

A lightweight Flutter toolkit with debounce/throttle, async queue, extensions, and UI widgets (Toast, Loading, Shimmer, Refresh, Slidable, animated list, gradient borders). Depends only on the Flutter SDK.
