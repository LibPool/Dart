# amani_auth_sdk

**Tag**: web, mobile, security

## 简介

AmaniQuery Auth Intelligence Flutter SDK. Device signal collection, risk assessment, passkey (FIDO2/WebAuthn) authentication, biometric authentication, social sign-in, consent and DSR APIs for the AmaniQuery gateway.
