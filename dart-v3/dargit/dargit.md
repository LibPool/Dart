# dargit

**Tag**: git, vcs, version-control, ssh, flutter, web, mobile, networking

## 简介

Git in pure Dart with an API that mirrors git commands: commit, status, log, clone, fetch, push and rebase over local, HTTPS and SSH remotes; SHA-1 and SHA-256.
