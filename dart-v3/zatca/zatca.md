# zatca

**Tag**: zatca, qr, einvoice, fatoora, phase2, mobile, serialization, security

## 简介

A Flutter package for generating ZATCA (Saudi Arabia's Zakat, Tax and Customs Authority) compliant invoice XML and QR codes.
