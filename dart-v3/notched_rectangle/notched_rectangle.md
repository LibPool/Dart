# notched_rectangle

**Tag**: mobile, ui, tooling

## 简介

NotchedRectangle shape for Flutter. Create modern UI designs with customizable corner notches/cutouts. Compatible with ClipPath, and in the future ShapeBorder, and Container decorations.
