# aws_iot_core

**Tag**: aws, iot, mqtt, shadow, cognito, web, mobile, networking, tooling

## 简介

AWS IoT Core MQTT client for Dart and Flutter: SigV4 WebSockets with Cognito credentials, re-signing on reconnect, wildcard topics and Device Shadow.
