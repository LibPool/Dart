# simosec

**Tag**: security, fintech, middleware, authentication, api, web

## 简介

Modular security engine for APIs and fintech apps. A pluggable, middleware-based pipeline providing HMAC-SHA256 signature verification, input validation, dry-run sandboxing, rate limiting, anomaly detection, authorization, and audit logging.
