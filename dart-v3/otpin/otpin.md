# otpin

**Tag**: otp, widget, animation, input, verification, mobile, ui, state-management

## 简介

A beautifully animated, customizable OTP input widget for Flutter. Ships with Orbital and Cascade visual styles — each with rich animations for empty, typing, verifying, success, and error states. Zero dependencies. Strategy Pattern architecture.
