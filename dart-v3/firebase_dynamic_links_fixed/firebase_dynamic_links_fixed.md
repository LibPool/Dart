# firebase_dynamic_links_fixed

**Tag**: mobile

## 简介

Flutter plugin for Google Dynamic Links for Firebase. Supports firebase_core ^4.4.0, Flutter 3.x, Dart 3, null safety, AGP 8+, and Kotlin 1.9+.
