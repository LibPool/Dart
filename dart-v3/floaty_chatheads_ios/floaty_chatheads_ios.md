# floaty_chatheads_ios

**Tag**: overlay, chathead, floating-window, ios, mobile, ui

## 简介

iOS implementation of floaty_chatheads with UIWindow-based PiP overlay, snap-to-edge physics, theming, and VoiceOver accessibility.
