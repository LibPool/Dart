# snappy_snag

**Tag**: bug-reporting, feedback, developer-tools, screenshot, ai, mobile

## 简介

An easy-to-use in-app bug reporting and user feedback SDK for Flutter, allowing users to send screenshots, device info, and custom logs seamlessly.
