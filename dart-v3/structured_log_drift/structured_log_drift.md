# structured_log_drift

**Tag**: logging, drift, database, structured-logging, debugging

## 简介

StructuredLogDriftInterceptor — a drift QueryInterceptor that logs every query, batch, failure and transaction end as a structured_log entry, with its duration and slow queries flagged; argument values stay out by default.
