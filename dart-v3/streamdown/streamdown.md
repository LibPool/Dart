# streamdown

**Tag**: ai, markdown, streaming, llm, openai, mobile

## 简介

Flicker-free streaming markdown renderer for Flutter AI apps. Drop-in replacement for flutter_markdown with no flash on partial code fences, tables, or LaTeX.
