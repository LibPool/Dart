# bluetooth_thermal_printer_pro

**Tag**: mobile

## 简介

A Flutter plugin to connect and print text/images to Bluetooth thermal printers.Updated Bluetooth thermal printer plugin (Android) for modern Flutter/Kotlin/AGP.
