# flutter_watch_link

**Tag**: watchos, ffi, companion, watchconnectivity, web, mobile

## 简介

WatchConnectivity for Flutter companion apps: one Dart API for iPhone-to-Apple-Watch messaging, application context, and guaranteed background transfers.
