# logo_motion

**Tag**: loading, animation, svg, logo, mobile, ui

## 简介

A customizable SVG logo loading animation widget for Flutter. Pass any SVG logo and get a beautiful stroke-trace, fill-reveal, and fade-out animation cycle.
