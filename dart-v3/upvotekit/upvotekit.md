# upvotekit

**Tag**: feedback, webview, roadmap, changelog, widget, web, mobile, ui

## 简介

First-party Flutter SDK for UpvoteKit — a thin webview wrapper around the hosted embed pages for feedback boards, roadmaps, and changelogs.
