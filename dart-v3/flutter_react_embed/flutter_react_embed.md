# flutter_react_embed

**Tag**: react, webview, react-native, micro-frontends, platform-views, web, mobile, serialization

## 简介

Embed React web apps and React Native apps in Flutter as native platform views on Android and iOS, with a typed JSON-RPC bridge between Dart and JavaScript.
