# phoenixdb

**Tag**: database, key-value, ffi, vector-search, sql, mobile

## 简介

ACID-compliant embedded database for Dart and Flutter, written in Rust with dart:ffi: MVCC key/value storage, SQL, HNSW vector search, hybrid document search and RAG.
