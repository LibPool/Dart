# l10n_health

**Tag**: l10n, i18n, localization, arb, static-analysis, mobile, ui, serialization

## 简介

Health check for the translation layer of Dart and Flutter apps. Finds unused and missing ARB keys, placeholder mismatches, duplicate and untranslated values, hardcoded UI strings and invisible Unicode, with a safe prune mode and HTML, Markdown and JSON reports.
