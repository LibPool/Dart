# scroll_number

**Tag**: mobile, ui

## 简介

A beautiful, customizable scrollable number picker widget for Flutter. Built with ListWheelScrollView with smooth drum-roll scrolling, top/bottom fade gradients, and a sleek dark highlight for the selected item.
