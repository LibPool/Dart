# easyi18n

**Tag**: i18n, l10n, translation, flutter, arb, mobile, ui

## 简介

Runtime SDK for easyi18n: resolve UI strings with source-as-key tr(), with an offline floor (baked assets) and live hot-update from a delivery manifest/CDN.
