# onnx_runtime_dart

**Tag**: onnx, inference, machine-learning, transformer, web, mobile

## 简介

A pure-Dart ONNX inference runtime for transformer, vision, audio, and generative models. No FFI; runs on web, WebAssembly, Flutter, and Dart.
