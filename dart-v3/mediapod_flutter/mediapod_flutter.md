# mediapod_flutter

**Tag**: media, upload, image, video, widget, mobile, ui

## 简介

Flutter widgets for Mediapod - a self-hosted media service. Upload, display, and manage media assets with imgproxy optimization and HLS video streaming. Deploy the backend with Docker, integrate seamlessly with Flutter.
