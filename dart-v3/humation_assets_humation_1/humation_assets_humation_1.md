# humation_assets_humation_1

**Tag**: avatar, svg, assets, web

## 简介

The humation-1 asset pack (86 hand-drawn SVG parts plus manifest) for the humation avatar engine. Embedded as pure Dart, so it works on the server and the web with no asset loading.
