# safe_loading

**Tag**: ui

## 简介

This package provides a simple and effective way to manage loading indicators, ensuring a smooth user experience during asynchronous operations. And then, SafeLoaderWidget, SafeErrorWidget, SafeEmptyWidget are also provided.
