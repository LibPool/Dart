# omni_doc_scan

**Tag**: document-scanner, mlkit, visionkit, camera, web, mobile

## 简介

Scanner de documento pelo SDK do sistema: ML Kit Document Scanner no Android, VNDocumentCameraViewController (VisionKit) no iOS. Expõe todo o parâmetro nativo configurável dos dois SDKs por uma API Dart única.
