# livekit_beauty_bridge

**Tag**: tooling

## 简介

Native frame-processing bridge for livekit_client's TrackProcessor: intercepts local camera frames before publish, hands them to a registered Dart callback (I420 in/out, with NV21/RGBA conversion helpers), and reconstructs the returned frame for encoding.
