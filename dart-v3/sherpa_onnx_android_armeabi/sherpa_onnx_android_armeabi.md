# sherpa_onnx_android_armeabi

**Tag**: speech-recognition, speech-synthesis, speaker-identification, audio-tagging, voice-activity-detection, mobile

## 简介

Speech recognition, speech synthesis, and speaker recognition using next-gen Kaldi with onnxruntime without Internet connection. Android armeabi-v7a native libraries.
