# sql_formatter

**Tag**: sql, formatting, database, postgresql, parser

## 简介

A pure-Dart SQL pretty-printer supporting standard SQL, PostgreSQL, MySQL and SQLite dialects. A faithful port of the JS sql-formatter library.
