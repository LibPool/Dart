# flutter_on_device_rag

**Tag**: rag, llm, ai, embeddings, on-device, mobile, ui, tooling

## 简介

Pure-Dart on-device RAG for Flutter and Dart. Chunk, embed and search text, then build grounded LLM prompts, fully offline.
