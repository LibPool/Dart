# voo_watch_ui

**Tag**: flutter, watch, watchos, wear-os, sdui, mobile, ui

## 简介

Cross-platform UI DSL for smartwatches. Define your watch UI in Dart and render it identically on Apple Watch (native SwiftUI) and Wear OS (Flutter).
