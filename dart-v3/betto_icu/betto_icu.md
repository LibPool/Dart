# betto_icu

**Tag**: text, unicode, nlp, tokenizer, icu

## 简介

Unicode text tokenization for Dart — Tokenizer interface, IcuTokenizer (system ICU FFI, UAX #29), and RegExpTokenizer (pure Dart, Latin fallback).
