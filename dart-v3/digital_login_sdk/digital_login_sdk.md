# digital_login_sdk

**Tag**: oauth2, authentication, login, azerbaijan, openid, mobile, security, state-management

## 简介

Unofficial Flutter SDK for Azerbaijan DigitalLogin (login.gov.az). Secure OAuth 2.0 authorization code flow with state validation and optional PKCE in a single call.
