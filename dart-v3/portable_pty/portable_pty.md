# portable_pty

**Tag**: terminal, pty, ffi, shell, process, web, mobile, desktop, ui, networking, tooling

## 简介

Cross-platform pseudo-terminal (PTY) for Dart. Spawns shell subprocesses on Linux, macOS, Windows, and Android, links native assets into supported iOS builds, and connects through WebSocket or WebTransport to a remote PTY server on web.
