# mpg_pendant

**Tag**: library

## 简介

Cross-platform USB HID driver for XHC xHB04B-family CNC pendants (LHB04B-4, LHB04B-6, WHB04B-4, WHB04B-6). Decodes button, jog wheel, and selector events; encodes display updates.
