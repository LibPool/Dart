# prism_master_detail

**Tag**: master-detail, adaptive, responsive, layout, widget, mobile, desktop, ui

## 简介

Adaptive master-detail layouts for Flutter — side-by-side panes on tablets/desktop, stacked navigation on phones, from one widget. Companion to prism_adaptive_scaffold. Pure Flutter, all six platforms.
