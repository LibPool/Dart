# qnox_pdf_text

**Tag**: pdf, text-extraction, plugin, flutter-plugin, mobile

## 简介

Fast text extraction from PDFs for Flutter (Android via pdfbox-android, iOS via PDFKit). Also supports URLs (download then parse).
