# imaji_rebuild_budget

**Tag**: flutter, testing, performance, widget-test, rebuild, mobile, ui, tooling

## 简介

Catch unnecessary widget rebuilds in Flutter: a Dart test helper that fails widget tests over a measured rebuild budget. Headless, no device, no probes.
