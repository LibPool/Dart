# nitro_server

**Tag**: http, server, network, ffi, nitro, web, mobile, networking

## 简介

Fast HTTP/1.1 and WebSocket server for Dart and Flutter, backed by a native multithreaded C++ engine over Nitro FFI, with trie routing and per-route timeouts.
