# flutter3d_conformance

**Tag**: graphics, gpu, testing, conformance, mobile

## 简介

The behaviour a flutter3d_hardware backend has to have, as tests it can run against itself. Flat: no Flutter import of its own, and flutter3d_shaders (its one dependency that used to carry the SDK in) no longer does either.
