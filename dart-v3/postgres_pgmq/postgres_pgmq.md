# postgres_pgmq

**Tag**: postgres, pgmq, queue, messaging, web, database, tooling

## 简介

Idiomatic Dart client for Postgres Message Queue (PGMQ) on package:postgres. Wraps any Session (Connection, Pool, TxSession) with the full PGMQ SQL API.
