# tll_monitor_flutter_sdk

**Tag**: monitoring, exception-handling, mqtt, flutter, web, mobile, networking

## 简介

TLL Flutter 纯 Dart 异常监控采集 SDK。支持 MQTT 优先上报、HTTP 兜底、 慢请求/失败请求采集，对接 tll-monitor-serve 接入协议。
