# flutter_mcp_harness

**Tag**: flutter, testing, e2e, mcp, automation, mobile, ui, tooling

## 简介

Programmatic E2E harness for Flutter apps: build and launch a debug binary, attach to its Dart VM service, drive widgets through the MCP toolkit service extensions, and assert with composable scenarios.
