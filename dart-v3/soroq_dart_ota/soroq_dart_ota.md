# soroq_dart_ota

**Tag**: flutter, ota, ios, code-push, mobile, ui

## 简介

iOS dart_eval patch-point OTA for Soroq. Runs SIGNED downloaded Dart bytecode at designated patch points via a bundled dart_eval Runtime. Companion to soroq_flutter; designated points only (not arbitrary Dart).
