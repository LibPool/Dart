# native_video_toolkit

**Tag**: video, ffi, jni, avfoundation, mediacodec, mobile, desktop

## 简介

Compress, merge, mute, and reverse video with zero bundled native dependencies — bound directly to AVFoundation (iOS/macOS, via ffigen + package:objective_c) and android.media (Android, via jni/jnigen). No MethodChannel, no hand-written native glue.
