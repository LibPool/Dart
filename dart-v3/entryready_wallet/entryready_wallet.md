# entryready_wallet

**Tag**: apple-wallet, google-wallet, passkit, wallet, access-control, mobile

## 简介

Add EntryReady mobile keys to Apple Wallet and Google Wallet. Presents the platform's provisioning flow and reports what is already in the wallet.
