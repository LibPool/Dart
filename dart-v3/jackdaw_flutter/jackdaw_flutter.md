# jackdaw_flutter

**Tag**: ai, llm, flutter, chat, agents, mobile, ui

## 简介

Flutter widgets for jackdaw agents. A chat controller with streaming text merged to one update per frame, tool approval cards and a composer, built so that inference never costs the UI thread a frame.
