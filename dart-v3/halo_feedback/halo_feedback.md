# halo_feedback

**Tag**: mobile, desktop, security

## 简介

Cross-platform MDM (Mobile Device Management) feedback plugin for Flutter. Enables device authentication and configuration retrieval for Android, iOS, macOS, and Windows platforms with callback-based navigation support.
