# anka_super_loading_package

**Tag**: animation, flutter, loading, widget, mobile, ui

## 简介

Five curated indeterminate loading animations for Flutter (pulse dots, ring, shimmer bar, segment spinner, wave dots) behind one AnkaSuperLoading widget.
