# uikit_tab_bar

**Tag**: tab-bar, ios, liquid-glass, cupertino, navigation, mobile, ui

## 简介

Native iOS 26+ tab bar (UITabBarController, Liquid Glass) for Flutter with minimize on scroll, accessory and search tab; CupertinoTabBar fallback elsewhere.
