# label_ocr

**Tag**: ocr, text-recognition, ml-kit, label, mobile, ui, tooling

## 简介

On-device text recognition for labels and packaging. Returns lines with bounding boxes and rebuilds table rows. Android and iOS, Latin text, ML Kit.
