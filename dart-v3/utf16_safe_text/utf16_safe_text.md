# utf16_safe_text

**Tag**: unicode, utf16, string, emoji, text, mobile

## 简介

Truncate and sanitize Dart strings without splitting UTF-16 surrogate pairs. Prevents the not-well-formed-UTF-16 crash in Flutter text rendering.
