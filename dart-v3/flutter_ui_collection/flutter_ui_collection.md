# flutter_ui_collection

**Tag**: ui, design-system, widgets, neon, theming, mobile, security

## 简介

A complete Flutter UI framework — 89 core components + 6 enhanced modules (Auth, Chat/WhatsApp-level, Dashboard/Charts, E-Commerce/Cart+Checkout, Social, Settings). 192 files, ~35K LOC. Material-free.
