# mcp_datastore

**Tag**: mcp, datastore, filesystem, database, capability, ui

## 简介

Policy-gated data-interface layer for the MCP ecosystem — a unified capability surface over persistent, addressable data stores. Filesystem (fs.*) is built in; relational / document databases (db.*) plug in as sibling adapter packages. Deny-by-default policy, plan-commit for destructive ops, path-jailed filesystem access.
