# slint_skia

**Tag**: mobile, tooling

## 简介

Slint runtime for Flutter via Rust FFI — slint-interpreter + i-slint-renderer-skia (GPU) rendered into a Flutter external texture. Bindings generated with cbindgen and ffigen.
