# flutter_face_liveness

**Tag**: mobile

## 简介

Production-ready Flutter SDK for face detection, liveness verification, and anti-spoof protection using ML Kit, TensorFlow Lite, and optional YOLOv8n-face / SCRFD-2.5G-KPS backends.
