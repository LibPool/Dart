# flutter_offline_cache_sync

**Tag**: offline-first, cache, sync, offline, repository, web, mobile

## 简介

Offline-first data engine for Dart and Flutter: a durable outbox plus a stale-while-revalidate cache. Pending edits survive restarts, eviction and retries.
