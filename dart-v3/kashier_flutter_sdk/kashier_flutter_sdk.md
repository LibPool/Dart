# kashier_flutter_sdk

**Tag**: payments, payment-gateway, apple-pay, wallet, egypt, mobile, ui

## 简介

Kashier payment SDK for Flutter. Accept Card, Apple Pay, and mobile wallet payments in Egypt with a prebuilt, localized (EN/AR) payment sheet.
