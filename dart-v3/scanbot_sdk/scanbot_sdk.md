# scanbot_sdk

**Tag**: mobile

## 简介

Flutter plugin of the Scanbot Scanner SDK for Android and iOS. Provides functionality like Document Scanning, QR and Barcode Scanning, PDF Creation, TIFF, OCR, etc.
