# arabic_text

**Tag**: arabic, normalization, search, flutter, rtl, mobile

## 简介

Arabic text normalization — tashkeel, alef, hamza, ya, ta marbouta, search keys, sort keys. Zero dependencies. Conformant with devsamhan-arabic spec v1.0.0.
