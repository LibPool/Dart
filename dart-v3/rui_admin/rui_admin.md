# rui_admin

**Tag**: web, mobile, desktop, ui

## 简介

A flutter UI, for crossing platform APP, supporting mobile and windows, macos, web. 主要特点：admin布局，左侧菜单栏可展开收起，在宽度太小时自动切换为drawer。
