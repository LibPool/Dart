# testibnu

**Tag**: mobile, testing

## 简介

Package sederhana buatan Ibnu untuk mempelajari cara membuat dan mempublikasikan plugin Flutter ke pub.dev. Berisi contoh fungsi-fungsi matematika dasar seperti menghitung luas dan keliling bangun datar.
