# flutter_microfrontend

**Tag**: mobile, ui, tooling

## 简介

A powerful, production-ready Flutter package for building large-scale applications using micro-frontend architecture. Enables true module independence with lazy loading, dynamic module registration, scoped dependency injection, a typed event bus, and a robust plugin system.
