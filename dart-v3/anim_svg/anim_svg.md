# anim_svg

**Tag**: svg, animation, lottie, thorvg, smil, mobile, ui, serialization

## 简介

Flutter widget for animated SVG. Transpiles SMIL, CSS @keyframes, and Svgator animations to Lottie JSON, rendered by the native thorvg engine.
