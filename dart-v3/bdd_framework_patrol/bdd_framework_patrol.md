# bdd_framework_patrol

**Tag**: bdd, behavior-driven-development, test, patrol, integration-test, mobile, testing, tooling

## 简介

Patrol integration for bdd_framework. Lets you write BDD scenarios that run as Patrol integration tests, with access to the PatrolIntegrationTester in every step.
