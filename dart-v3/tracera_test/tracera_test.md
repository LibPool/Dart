# tracera_test

**Tag**: tracera, autotest, test, test-reporting, testops, web, testing

## 简介

Tracera Autotest adapter for the Dart `test` package: bind, steps, lifecycle sections and attachments from stock `test` / `group` / `setUp` APIs.
