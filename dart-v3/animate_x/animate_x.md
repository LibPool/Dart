# animate_x

**Tag**: animation, ui, widgets, mobile

## 简介

One Flutter SDK for 58+ ready-made animations. Wrap any widget (Text, Image, ListView items, Container, anything) in AnimateX, pass an animation name, and it plays. Includes staggered list animations, swipe, and drag & drop helpers.
