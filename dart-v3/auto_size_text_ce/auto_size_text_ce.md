# auto_size_text_ce

**Tag**: text, font, responsive, typography, widget, mobile, ui

## 简介

Maintained community edition of auto_size_text. Auto-sizing Flutter text with rich text, grouping, app-wide defaults, TextScaler, intrinsic sizing, and WidgetSpan support.
