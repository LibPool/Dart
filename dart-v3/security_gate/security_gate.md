# security_gate

**Tag**: mobile, security

## 简介

A pluggable, callback-driven device-security-check pipeline for Flutter. Run ordered security checks (jailbreak, root, Play Integrity, proxy, VPN, keyboard, Wi-Fi) at app startup or anywhere — get a simple pass/fail result and handle it with your own custom code.
