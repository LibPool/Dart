# agent_gate_bloc

**Tag**: navigation, bloc, ai, agent, mobile, testing, state-management, tooling

## 简介

Bloc / Cubit integration for agent_gate — AI-agnostic behavioural routing middleware for Flutter. Adds GateCubit, GateBloc, typed GateState and a GateBlocListener that performs navigation.
