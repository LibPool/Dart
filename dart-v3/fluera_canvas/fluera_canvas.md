# fluera_canvas

**Tag**: canvas, whiteboard, infinite-canvas, notes, graphics, mobile

## 简介

Document-grade infinite-canvas SDK for Flutter — layered scene graph, selection + transform, lasso, image annotations, text, keyboard shortcuts.
