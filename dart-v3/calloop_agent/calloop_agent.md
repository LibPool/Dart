# calloop_agent

**Tag**: webrtc, voip, calling, call-center, callkit, web, mobile, ui

## 简介

Calloop agent SDK for Flutter: take calls routed by Calloop (WhatsApp, SIP) over WebRTC — availability, devices, transfer, supervisor board and monitoring, native call UI.
