# internet_connection_monitor

**Tag**: connectivity, internet, network, mobile, networking

## 简介

Una librería para apps Dart y Flutter que comprueba si hay Internet y avisa cuando la conexión se pierde o vuelve, con revisiones periódicas y reintentos.
