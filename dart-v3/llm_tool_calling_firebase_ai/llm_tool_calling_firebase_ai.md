# llm_tool_calling_firebase_ai

**Tag**: llm, tool-calling, function-calling, firebase, gemini

## 简介

Use llm_tool_calling tools with Firebase AI Logic (firebase_ai). Turns generated tools into Gemini function declarations and runs the whole tool loop.
