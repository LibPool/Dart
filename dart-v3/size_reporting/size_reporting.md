# size_reporting

**Tag**: widget, layout, ui

## 简介

A tiny widget that reports its child's laid-out size after layout, delivered via a post-frame callback. Shared by immersive_scaffold, resonance_sheet, and liquid_buttons_kit so there is a single implementation of the primitive.
