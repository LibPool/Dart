# layrz_wifi

**Tag**: wifi, network, scan, ssid, flutter-plugin, web, mobile, desktop, networking

## 简介

Flutter plugin to scan nearby WiFi networks and read the current SSID on Android, iOS, macOS, Windows, Linux, and Web.
