# whisper_kit

**Tag**: audio, speech, transcription, ai-tools, whisper, mobile

## 简介

On-device speech-to-text for Flutter using OpenAI Whisper. Supports offline transcription, 99 languages, export to SRT/VTT, batch processing, and more.
