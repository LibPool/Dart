# guji_diff

**Tag**: chinese, text-comparison, collation, ancient-texts, opencc, web

## 简介

A robust collation engine for ancient and modern Chinese texts, supporting verbatim and structural comparison, variant character normalization, and statistical analysis. Platform-adaptive with native OpenCC FFI and Web OpenCC-JS support.
