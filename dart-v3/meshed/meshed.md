# meshed

**Tag**: networking, bluetooth, mesh, p2p, ble, web, mobile

## 简介

A Flutter plugin for peer-to-peer mesh networking. Supports BLE, Wi-Fi Direct, and platform-specific transports for decentralized communication without servers.
