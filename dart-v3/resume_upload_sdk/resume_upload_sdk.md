# resume_upload_sdk

**Tag**: upload, file-upload, resumable, chunk-upload, mobile

## 简介

A Flutter SDK for resumable file uploads with chunk-based upload and automatic resume support. Supports pause, resume, cancel, and progress tracking across all platforms.
