# pina_amm

**Tag**: solana, amm, defi, blockchain, mobile, ui, state-management, tooling

## 简介

Dart and Flutter client for the Pina AMM on Solana: instruction builders, account decoders, PDAs, events, and errors generated from the program IDL.
