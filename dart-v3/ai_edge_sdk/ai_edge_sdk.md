# ai_edge_sdk

**Tag**: artificial-intelligence, machine-learning, gemini, on-device-ai, text-generation, mobile

## 简介

Flutter plugin for Google's AI Edge SDK, enabling on-device generative AI with Gemini Nano on Android devices.
