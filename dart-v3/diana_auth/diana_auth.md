# diana_auth

**Tag**: authentication, authorization, jwt, security, web, networking

## 简介

Authentication and authorization for the Diana backend framework: pluggable authenticator strategies (JWT, HTTP Basic, API key), Spring-style @Secured/@RolesAllowed guards and principal binding.
