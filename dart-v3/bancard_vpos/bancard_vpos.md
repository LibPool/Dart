# bancard_vpos

**Tag**: payments, bancard, vpos, paraguay, ecommerce, mobile, ui

## 简介

Flutter package for Bancard VPOS 2.0 payments (Paraguay). Supports single buy and recurring payments with native card management. No backend required.
