# wio_terminal

**Tag**: embedded, tinygo, microcontroller, wioterminal

## 简介

dart2tinygo binding for the Seeed Wio Terminal (LCD text). The Dart side is @GoImport / @GoName / @GoType annotations only; the TinyGo runtime package ships in go/ and is wired up by the generated go.mod.
