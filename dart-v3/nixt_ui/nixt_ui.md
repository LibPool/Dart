# nixt_ui

**Tag**: ui, design-system, widgets, theme, components, mobile

## 简介

Nixt UI — a faithful Flutter port of the Nuxt UI v4 mobile design system. Signature green, 7 semantic color roles, switchable neutral palettes, light/dark via ThemeExtension, Lucide icons, Poppins type. Zero third-party deps.
