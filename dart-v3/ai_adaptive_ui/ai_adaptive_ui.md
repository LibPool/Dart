# ai_adaptive_ui

**Tag**: flutter, adaptive, responsive, layout, ai, mobile, ui

## 简介

Una librería Flutter moderna para construir interfaces adaptativas que responden automáticamente a diferentes tamaños de pantalla, orientaciones, idiomas y densidades de píxeles. Incluye widgets inteligentes como AdaptiveLayout, AdaptiveCard, y preparado para integración con IA.
