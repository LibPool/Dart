# flutter_native_oss_licenses

**Tag**: license, oss, open-source, compliance, legal, mobile

## 简介

Collects Flutter/Dart and native dependency licenses in one list: Android Gradle, CocoaPods, and remote SwiftPM, with all Flutter platforms supported.
