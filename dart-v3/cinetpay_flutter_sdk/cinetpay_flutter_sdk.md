# cinetpay_flutter_sdk

**Tag**: web, mobile

## 简介

Flutter SDK for CinetPay payments. Opens the CinetPay checkout page in a WebView and reports the payment result back to your app. The payment must be initialized on your backend first — this SDK only handles the frontend flow.
