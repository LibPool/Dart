# payubiz_cb_flutter

**Tag**: web, mobile

## 简介

The PayU Custom Browser for Flutter provides a optimized solution for Flutter App to open bank pages, Otp Auto read and submit. The PayU Custom Browser allows you to integrate with the PayU PG with minimal integration effort to accept faster payments. This will support both iOS and Android.
