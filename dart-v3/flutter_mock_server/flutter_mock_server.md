# flutter_mock_server

**Tag**: flutter, mock-server, api-mocking, testing, cli, web, mobile, serialization, state-management, tooling

## 简介

A local mock API server for Flutter and Dart with YAML config, static/stateful routes, CRUD simulation, deterministic seeded data, and hot reload.
