# opentelemetry_flutter

**Tag**: web, mobile, networking

## 简介

PLACEHOLDER. OpenTelemetry SDK for Flutter. Distributed tracing, metrics, OTLP exporters (gRPC/HTTP), and context propagation for observability backends.
