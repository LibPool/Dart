# spring_boot_starter_feign

**Tag**: http, rest, spring, web, serialization, networking, tooling

## 简介

Feign clients for spring_boot_dart: annotate an interface with @FeignClient and @GetMapping, inject it as a bean; JSON via ObjectMapper, interceptors, retries, fallbacks.
