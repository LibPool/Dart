# obd2_kit

**Tag**: obd, elm327, automotive, diagnostics, bluetooth

## 简介

OBD-II and ELM327 protocol library over any byte transport: SAE J1979 PIDs, DTCs, VIN, ISO-TP reassembly, multi-ECU frames and a live polling scheduler.
