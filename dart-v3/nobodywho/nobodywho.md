# nobodywho

**Tag**: ai, llm, stt, tts, local-ai, mobile, desktop

## 简介

On-device AI for mobile & desktop: text, vision, embeddings, RAG, tool calling, STT, TTS & VAD. Run GGUF models with Metal/Vulkan acceleration. Free for commercial use.
