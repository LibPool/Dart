# dart_pdf_editor_assets

**Tag**: pdf, pdf-editor, fonts, assets, web, ui

## 简介

Optional bundled assets for dart_pdf_editor - the six editor fonts, the metric-compatible faces the renderer substitutes into unembedded text (TeX Gyre for the standard 14, Carlito for Calibri), and the prebuilt web render worker. Depend on it (and call registerBundledEditorAssets) for the full-featured editor; omit it for a size-minimal viewer that ships none of them.
