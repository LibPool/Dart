# persian_calendar_kit

**Tag**: calendar, date-picker, jalali, persian, shamsi, mobile

## 简介

Persian (Jalali / Shamsi) calendar toolkit for Flutter: date conversion, formatting, Iranian holidays, Hijri dates and customizable date pickers.
