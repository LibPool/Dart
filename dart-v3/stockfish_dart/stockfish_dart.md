# stockfish_dart

**Tag**: chess, stockfish, uci, engine, ffi, web, mobile, desktop, ui

## 简介

Stockfish 19 chess engine for Dart on macOS, Windows and Linux, embedded through FFI with a typed, documented API covering every UCI command and option. No Flutter required.
