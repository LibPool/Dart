# traput_dynamic_linking

**Tag**: web, mobile, ui

## 简介

Traput Dynamic Linking SDK for Flutter. Handles Universal Links (iOS), App Links (Android), and deferred deep links via a single API (Traput.onLink()). Logic-only, no UI.
