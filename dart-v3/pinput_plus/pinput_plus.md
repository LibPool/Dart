# pinput_plus

**Tag**: pin, otp, input, flutter, web, mobile, desktop, ui

## 简介

Flexible, customizable PIN/OTP input for Flutter with themes, masking, and validation—ideal for login, 2FA, and verification flows on mobile, desktop and web.
