# kaderkita_ocr

**Tag**: ocr, ktp, kk, indonesia, mlkit, mobile

## 简介

On-device Flutter OCR for Indonesian KTP and Kartu Keluarga (KK). Camera scanners with optional debug pipeline / ROI inspection.
