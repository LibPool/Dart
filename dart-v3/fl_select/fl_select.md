# fl_select

**Tag**: select, multiselect, dropdown, cascade, widget, mobile, ui, tooling

## 简介

A Flutter package for building selection UIs (e.g. filter bar) on a composable architecture of entry points, delegates and layouts, A2UI-ready, with search, theming, and i18n.
