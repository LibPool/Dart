# sms_composer_sheet

**Tag**: sms, messaging, flutter-plugin, native, composer, mobile, ui

## 简介

A Flutter plugin for native SMS composer with beautiful bottom sheet UI. Supports iOS and Android with haptic feedback and error handling.
