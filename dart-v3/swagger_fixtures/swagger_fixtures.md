# swagger_fixtures

**Tag**: testing, openapi, swagger, fixtures, codegen, web, ui, serialization, tooling

## 简介

Test fixtures from a Swagger/OpenAPI spec — one JSON file per documented response, built from its examples, plus a Dart file that names and parses them.
