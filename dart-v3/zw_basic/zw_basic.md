# zw_basic

**Tag**: mobile, ui

## 简介

Flutter基于Getx的框架库,包含路由管理 状态控制 网络请求 网络请求不同状态Ui展示 失败重试 日志打印 刷新组件 屏幕适配 吐司提示 等
