# saymaker

**Tag**: video-generation, image-generation, ai, text-to-video, text-to-image, web, mobile

## 简介

Generate images and video from Dart and Flutter on SayMaker. One API key runs Veo 3.1, Kling 3.0, Seedance 2.0, Nano Banana 2, GPT Image 2.5 and more.
