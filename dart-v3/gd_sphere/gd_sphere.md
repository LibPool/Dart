# gd_sphere

**Tag**: web, mobile, desktop, ui, testing

## 简介

Sphere is a highly customizable 3D globe widget written using a custom RenderObject. It positions child widgets on a virtual sphere using Fibonacci distribution and renders them with depth-based scaling, alpha, and hit-testing.
This widget works on all Flutter platforms, including web, mobile, and desktop.
