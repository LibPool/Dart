# datajack

**Tag**: cli, agent-skills, cyberware, macss, tooling

## 简介

The command-line surface of the skillwire package: a `skill` module of five routes that any modular_cli_sdk CLI mounts to deploy agent skills into AI coding hosts. The port a person plugs into; skillwire is the wire.
