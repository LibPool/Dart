# internxt_client

**Tag**: web, security, state-management, tooling

## 简介

Internxt cloud storage client + CLI for Dart. Pure-Dart port of the Python internxt-cli. Provides login/auth, drive operations (list/move/rename/copy/trash), encrypted upload/download with resumable batch state, parallel-worker pool, memory-gated concurrency, and a WebDAV server bridging Internxt to standard file-system clients.
