# cera_ffi_flutter

**Tag**: llm, inference, ffi, gguf, ai, mobile, desktop, ui

## 简介

Flutter FFI plugin for the Cera on-device inference engine. Ships prebuilt native libraries for Android, iOS, macOS, Linux and Windows.
