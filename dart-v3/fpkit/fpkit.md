# fpkit

**Tag**: functional, fp, monad, either, option, mobile, ui, state-management

## 简介

Ultimate functional programming toolkit for Dart 3+ & Flutter. Option, Either, Result, Validation, IO, Task, TaskEither, Reader, Writer, State, function combinators and immutable helpers. A modern successor to dartz / fpdart built on sealed classes and pattern matching.
