# fugue

**Tag**: icons, fugue, pixel-art, flutter-icons, mobile

## 简介

The complete Fugue icon set by Yusuke Kamiyamane (3,571 glyphs, 16/32/48 px, shadow and shadowless) for Flutter. Unofficial repackage maintained by NativeMind.
