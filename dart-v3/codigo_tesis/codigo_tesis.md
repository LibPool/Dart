# codigo_tesis

**Tag**: web, mobile, networking

## 简介

Una aplicación Flutter diseñada para controlar un dispositivo ESP32 a través de una conexión HTTP. Esta aplicación permite monitorear distancias de sensores y ejecutar rutas predefinidas.
