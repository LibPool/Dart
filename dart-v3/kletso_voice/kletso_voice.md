# kletso_voice

**Tag**: ai, voice, speech, chatbot, sdk, web, mobile, desktop

## 简介

Microphone and speaker for Kletso voice sessions: PCM capture on mobile, desktop and web (Wasm-safe) plus low-latency playback, installed in one line.
