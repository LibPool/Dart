# universal_automation_toolkit

**Tag**: automation, browser, cli, mcp, web, mobile, tooling

## 简介

Agent-facing surface for the universal automation family: declarative plans with a fail-closed runner, an observe/act/verify CLI, and an MCP stdio server. One binary, two faces. No Flutter, no process lifecycle.
