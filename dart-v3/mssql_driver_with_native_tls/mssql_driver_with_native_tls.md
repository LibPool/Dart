# mssql_driver_with_native_tls

**Tag**: sql-server, mssql, database, tds, flutter, web, mobile

## 简介

Dart TDS 7.4 Microsoft SQL Server driver with pooling, transactions, Bulk Load, NTLM/Azure AD, and a small native OpenSSL TLS helper.
