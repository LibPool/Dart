# batik

**Tag**: web, mobile, ui, networking, state-management

## 简介

A model-agnostic Flutter framework for agent-driven UI generation with streaming, Riverpod state management, diff/patch rendering, tool-use agents, animations, offline cache, schema validation, virtualization, and multi-agent orchestration. Integrates with Wayang Assistant WebSocket Chat API.
