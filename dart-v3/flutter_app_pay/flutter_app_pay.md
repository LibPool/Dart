# flutter_app_pay

**Tag**: in-app-purchase, subscriptions, payments, google-play, app-store, web, mobile, ui, state-management

## 简介

Modular in-app purchase SDK for Flutter. Provides a unified API for Google Play, App Store, and RuStore billing through separate provider plugins. Includes entitlement management, server-side receipt verification hooks, and a simple extensible design.
