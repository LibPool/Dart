# rxdart

**Tag**: rxdart, reactive-programming, streams, observables, rx, web

## 简介

RxDart is an implementation of the popular ReactiveX api for asynchronous programming, leveraging the native Dart Streams api.

## 官网

- 源码仓库: https://github.com/ReactiveX/rxdart
- pub.dev: https://pub.dev/packages/rxdart
