# openui_mcp

**Tag**: mobile, ui, state-management, tooling

## 简介

MCP `ToolProvider` for OpenUI Flutter. Wraps `mcp_dart`'s `McpClient` with the JS-reference-compatible `extractToolResult` envelope unwrap.
