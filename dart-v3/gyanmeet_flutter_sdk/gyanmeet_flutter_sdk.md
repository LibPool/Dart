# gyanmeet_flutter_sdk

**Tag**: mobile, ui

## 简介

Gyanmeet meeting SDK for Flutter — a self-contained video meeting widget with host controls, chat, polls, batch exams, certificate verification, and optional on-device AI proctoring.
