# netlens_http_client

**Tag**: http, inspector, netlens, interceptor, web, networking, tooling

## 简介

NetLens adapter for dart:io HttpClient. Catches HttpClient calls for the NetLens in-app HTTP inspector and lets NetLens resend them.
