# netoscope

**Tag**: debugging, network, logging, http, dio, web, mobile, networking

## 简介

Network logger and HTTP inspector for Flutter. Logs Dio, http, GraphQL, WebSocket, SSE and gRPC traffic with an in-app inspector, secret redaction, timeline and N+1 detection.
