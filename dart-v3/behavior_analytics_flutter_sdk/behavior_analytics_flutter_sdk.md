# behavior_analytics_flutter_sdk

**Tag**: mobile

## 简介

O plugin FingerPrint para Flutter é uma poderosa ferramenta anti-fraude, que realiza a identificação de dispositivos, respeitando as políticas de privacidade do usuário.
