# socrits_express

**Tag**: video, voip, webrtc, web, ui, tooling

## 简介

Socrits Express — low-level voice & video media engine (LiveKit) for Socrits. Mint a room token on your backend, join the room, publish/subscribe. No UI and no call invitations — you build those (use the socrits UIKit package if you want them included).
