# flitware_base

**Tag**: backend, api, realtime, database, web, mobile, tooling

## 简介

Flitware Base SDK for Dart — multi-platform Dart/Flutter client for the Flitware Base realtime backend API. Derived from the PocketBase Dart SDK with full protocol compatibility.
