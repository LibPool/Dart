# flutter_sms_actual_kotlin

**Tag**: mobile, testing

## 简介

A Flutter plugin to Send SMS and MMS on iOS and Android. If iMessage is enabled it will send as iMessage on iOS. This plugin must be tested on a real device on iOS.
