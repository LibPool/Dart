# flutter_security_kit

**Tag**: security, encryption, privacy, anti-tamper, cybersecurity, mobile

## 简介

All-in-one Flutter security toolkit with military-grade AES-256-GCM data encryption, secure vault, root/jailbreak detection, anti-Frida, debugger shield, and screen privacy.
