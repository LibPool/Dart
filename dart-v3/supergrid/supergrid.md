# supergrid

**Tag**: mobile, ui

## 简介

A customizable Flutter package for displaying grid views of sections.Includes three main widgets SimpleGridView A basic grid view with simple customization options. FlatGridView A grid view with more advanced configuration options. SectionGridView A grid view with support for sections and additional styling options.
