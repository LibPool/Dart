# rtlsdr

**Tag**: sdr, ffi

## 简介

FFI bindings to access librtlsdr and read Software-Defined Radio signals using Dart streams.

## 官网

- 主页: https://github.com/renggli/dart-rtlsdr
- pub.dev: https://pub.dev/packages/rtlsdr
