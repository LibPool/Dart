# flutter_example_template

**Tag**: example, gallery, showcase, preview, responsive, mobile

## 简介

An example-app shell for Flutter packages: a preview stage at three widths or at 1:1, a device wall, a code pane and a settings panel, driven through ports so it names no subject.
