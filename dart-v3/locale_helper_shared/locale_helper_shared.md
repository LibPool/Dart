# locale_helper_shared

**Tag**: flutter, localization, i18n, arb, mobile, tooling

## 简介

Shared data models and ARB/ICU/CLDR helpers used by the locale_helper CLI and the locale.ly review backend. Pure Dart, no platform dependencies.
