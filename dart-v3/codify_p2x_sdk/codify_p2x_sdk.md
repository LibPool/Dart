# codify_p2x_sdk

**Tag**: api, sdk, p2x, codify, rest-client, web, mobile, tooling

## 简介

Dart/Flutter SDK for the Project20X (P2X) API. Companion of the TypeScript wizard-api-client. Used by Codify, IBD, PHM, and DietManager Flutter apps.
