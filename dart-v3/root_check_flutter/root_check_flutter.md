# root_check_flutter

**Tag**: mobile, security

## 简介

A comprehensive Flutter plugin to detect security-compromised environments including:
- Rooted Android devices
- Jailbroken iOS devices
- Developer mode status
- Virtual/emulated devices
Provides multiple detection methods for robust security checks.
