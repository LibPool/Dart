# reaxdb_dart

**Tag**: database, nosql, offline-first, storage, cache, security

## 简介

Embedded NoSQL database for Dart. LSM storage with a write-ahead log, ACID transactions, secondary indexes, AES-256-GCM encryption, TTL and change streams. No native dependencies.
