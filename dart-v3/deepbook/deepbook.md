# deepbook

**Tag**: sui, blockchain, deepbook, defi, web3, web, ui, state-management

## 简介

Dart SDK for DeepBook V3, the decentralized central limit order book on Sui. Aligned with the official @mysten/deepbook-v3 TypeScript SDK.
