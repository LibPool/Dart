# typed_openapi_core

**Tag**: openapi, swagger, parser, linter, diagnostics, web, ui, tooling

## 简介

The engine of typed_openapi: reads OpenAPI 3.x specs, normalizes their defects with named rules, checks them with stable diagnostic codes and builds the semantic IR that the Dart client generator writes from.
