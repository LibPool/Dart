# cnativeapi

**Tag**: web, ui, tooling

## 简介

Raw Dart FFI bindings to the nativeapi C API. The native library is built from source by a build hook.

## 官网

- 主页: https://github.com/libnativeapi/nativeapi
- 源码仓库: https://github.com/libnativeapi/nativeapi/tree/main/bindings/dart/cnativeapi
- pub.dev: https://pub.dev/packages/cnativeapi
