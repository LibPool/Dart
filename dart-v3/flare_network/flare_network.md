# flare_network

**Tag**: flare, blockchain, ethereum, oracle, serialization, networking, state-management, tooling

## 简介

Dart client for Flare Network. Read FTSOv2 price feeds, resolve contracts via the Contract Registry, and call any Flare contract over JSON-RPC. Pure Dart.
