# flutter_feedback_kit

**Tag**: feedback, user-feedback, widget, form, offline, web, mobile, ui

## 简介

In-app user feedback for Flutter — customisable form widget, voice input, offline queue, screenshot capture, and pluggable backends (webhook, Firebase, etc.).
