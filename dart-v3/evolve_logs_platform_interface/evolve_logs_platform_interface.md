# evolve_logs_platform_interface

**Tag**: web, mobile, tooling

## 简介

The platform interface for the evolve_logs federated plugin. Defines the method-channel contract between the Dart side of the e-volv Observer and Launch Flutter SDK and the native Android (io.e-volv:logs-android) and iOS (EvolveLogs) clients, which own the disk queue, retry schedule and flush.
