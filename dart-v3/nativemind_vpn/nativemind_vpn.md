# nativemind_vpn

**Tag**: widgets, vpn, design-system, web, ui, tooling

## 简介

VPN client widgets made by hand: Gleb Sosnin's connect button, stat tiles, location card, server and app lists, search sheet and tab bar, Wishyut's settings widgets, the VPN editions (Pink / Orange / Green / Blue / Red / Blue-GOST) as data, country flags and app marks.
