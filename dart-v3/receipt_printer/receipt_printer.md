# receipt_printer

**Tag**: receipt, printer, flutter-ui, pos, thermal-printer, mobile, ui

## 简介

Flutter receipt, ticket and coupon UI with printer presets, shaped paper, pull-to-tear motion, QR codes and PNG capture. Not a hardware driver.
