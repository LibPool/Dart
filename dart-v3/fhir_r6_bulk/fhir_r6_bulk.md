# fhir_r6_bulk

**Tag**: fhir, hl7, healthcare, bulk-data, ndjson, web, serialization, networking

## 简介

Library to support the FHIR Bulk Data Access API (https://www.hl7.org/fhir/uv/bulkdata/index.html) for FHIR R6 resources.
