# codepush_ios

**Tag**: code-push, ios, hot-update, mobile, ui

## 简介

iOS bytecode patch applier for CodePush. Add this only if you patch iOS; it requires a Flutter engine built with --dart-dynamic-modules and will not compile against a stock SDK.
