# apexcharts_flutter

**Tag**: charts, visualization, graph, custompainter, widgets, web, mobile, ui

## 简介

Native Flutter port of ApexCharts v4.7.0 (MIT): 13 chart types rendered on CustomPainter, no WebView, works on every Flutter platform.
