# offline_fetch

**Tag**: http, offline, network, cache, retry, web, mobile, networking, tooling

## 简介

Offline-first HTTP client for Dart and Flutter. Retries with backoff, serves cached GETs when offline, and queues POST/PUT/PATCH/DELETE until back online.
