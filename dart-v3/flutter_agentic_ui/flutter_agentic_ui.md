# flutter_agentic_ui

**Tag**: flutter, ai, chat, ui, agent, mobile

## 简介

Drop-in chat UI for Flutter AI agents — chat view, streaming bubbles, ReAct step visualizer, and typing indicator, wired to flutter_agentic.
