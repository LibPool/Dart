# local_timezone

**Tag**: timezone, datetime, intl, ffi, web, mobile, desktop

## 简介

Synchronously read the device's IANA timezone identifier, such as Asia/Kolkata, in pure Dart. Works on Android, iOS, macOS, Windows, Linux and the web, with no plugin and no dependencies.
