# henry_catraca

**Tag**: mobile

## 简介

Biblioteca Dart/Flutter para comunicação com catracas e relógios de acesso Henry® via protocolo TCP/IP. Suporta os modelos Prime Acesso 8X, Prime Acesso SF e Henry Argos.
