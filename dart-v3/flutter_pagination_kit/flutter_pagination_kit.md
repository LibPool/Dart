# flutter_pagination_kit

**Tag**: pagination, sliver, listview, gridview, infinite-scroll, mobile

## 简介

A clean, reusable, generic pagination toolkit that solves real-world pagination problems. Supports lists, grids, slivers, infinite scroll, and pull-to-refresh.
