# sharara_usb

**Tag**: mobile, ui

## 简介

a high-performance Flutter plugin designed for direct hardware interaction with USB peripherals. Engineered specifically for POS systems and thermal printers, it provides a unified, low-latency interface for device discovery and raw data transmission
