# puml_canvas

**Tag**: plantuml, uml, diagram, rendering, canvas, web, mobile

## 简介

A native PlantUML-compatible diagram renderer for Flutter. Parses PUML in Dart and paints directly onto a Canvas — no server, no WebView.
