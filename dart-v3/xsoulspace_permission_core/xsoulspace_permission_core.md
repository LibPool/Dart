# xsoulspace_permission_core

**Tag**: ui

## 简介

Composable permission contract shared across products: typed request kinds, decisions (allow / deny / escalate), policy composition, grant stores and the gate runner. Transport-free by design — ACP, doc routers and OS dialogs stay product-side.
