# zebchat_flutter

**Tag**: chat, live-chat, customer-support, messaging, push-notifications, mobile

## 简介

ZebChat live chat for Flutter apps: in-app chat, user identity, screen views, unread count and push notifications. Wraps the native ZebChat Android and iOS SDKs.
