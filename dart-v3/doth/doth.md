# doth

**Tag**: web, security, state-management

## 简介

A multi-provider OAuth2 authentication library for Dart backends. Inspired by markbates/goth for Go — write once, plug in any provider. Compatible with shelf, dart_frog, alfred, and raw dart:io servers.
