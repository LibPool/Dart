# flutter_alone

**Tag**: mobile, desktop, ui

## 简介

A robust Flutter plugin designed to ensure only a single instance of your desktop application runs at a time, offering customizable messages, cross-user detection, and enhanced window management for Windows, macOS, and Linux.
