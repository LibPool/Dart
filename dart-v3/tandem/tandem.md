# tandem

**Tag**: ai, agent, llm, ag-ui, generative-ai, mobile, ui, state-management

## 简介

Makes an existing Flutter screen agent-aware over AG-UI. The agent sees what its state class lists and calls its methods; important actions wait for approval.
