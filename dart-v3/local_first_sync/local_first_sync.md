# local_first_sync

**Tag**: offline-first, local-first, sync, offline, storage, mobile

## 简介

Local-first sync for Dart and Flutter: offline writes, a crash-safe queue, dependency-ordered operations, temp-id rewriting, and pluggable conflict resolution.
