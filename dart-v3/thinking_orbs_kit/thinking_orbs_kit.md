# thinking_orbs_kit

**Tag**: loading, ai, agent, animation, progress-indicator, mobile, ui

## 简介

Dotted, genuinely 3D loading indicators for AI and agent interfaces in Flutter. Nine hand-tuned designs, two purpose-tuned sizes, one line to drop in.
