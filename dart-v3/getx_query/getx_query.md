# getx_query

**Tag**: getx, query, state-management, cache, http, web, mobile, ui, networking

## 简介

TanStack-Query-style data fetching for GetX: Rx-backed useQuery/useMutation over flutter_query — no HookWidget, render with Obx — plus auto-disposing view models.
