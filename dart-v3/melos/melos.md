# melos

**Tag**: monorepo, cli, release, versioning, changelog, mobile, tooling

## 简介

A tool for managing Dart & Flutter projects with one or many packages (monorepo). Supports automated versioning via Conventional Commits. Inspired by JavaScripts Lerna package.

## 官网

- 主页: https://melos.invertase.dev/~melos-latest
- 源码仓库: https://github.com/invertase/melos/tree/main/packages/melos
- 问题追踪: https://github.com/invertase/melos/issues
- pub.dev: https://pub.dev/packages/melos
