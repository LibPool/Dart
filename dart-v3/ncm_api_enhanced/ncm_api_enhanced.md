# ncm_api_enhanced

**Tag**: web, mobile, desktop

## 简介

Unofficial Netease Cloud Music API for Flutter, backed by an embedded Node.js v26.9.0 runtime. Exposes all 439 upstream module functions as a Dart facade; runs on Linux/macOS/Windows (via the system `node` binary), Android (via libnode.so loaded by the native bridge), and iOS (via NodeMobile.xcframework embedded in the .app bundle).
