# apptracer_flutter_ios

**Tag**: crash-reporting, error-monitoring, observability, tracer, mobile

## 简介

iOS implementation of apptracer_flutter, the unofficial Flutter integration with Tracer (apptracer.ru). Forwards Dart errors to the OKTracer iOS SDK.
