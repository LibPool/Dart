# lightweight_rich_editor

**Tag**: editor, rich-text, text, notebook, performance, mobile, state-management

## 简介

A rich-text editor for Flutter that draws notes on ruled paper. Lists, code blocks, pictures, links, find and replace, HTML and Markdown paste.
