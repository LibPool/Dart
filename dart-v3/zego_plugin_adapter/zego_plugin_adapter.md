# zego_plugin_adapter

**Tag**: ui

## 简介

ZegoCloud's plugin adapter, which a wraper for `zego_uikit` to use plugins, such as `zego_uikit_beauty_plugin` and `zego_uikit_signaling_plugin`

## 官网

- 主页: https://www.zegocloud.com/
- pub.dev: https://pub.dev/packages/zego_plugin_adapter
