# flutter_code_query

**Tag**: flutter, go-router, navigation, static-analysis, cli, mobile, serialization, tooling

## 简介

Fast static navigation queries and checks for Flutter apps using go_router. Parses lib/ without type resolution and prints JSON for coding agents.
