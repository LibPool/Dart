# bottom_shelfer

**Tag**: mobile

## 简介

A customizable slide-up bottom sheet presentation for Flutter. Supports arbitrary height detents, a draggable grabber, optional dimming scrim, keyboard avoidance, rotation, scroll coordination, and full layout-metric overrides.
