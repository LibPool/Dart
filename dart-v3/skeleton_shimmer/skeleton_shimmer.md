# skeleton_shimmer

**Tag**: shimmer, skeleton, loading, placeholder, animation, web, mobile, ui

## 简介

Shimmer loading effect and skeleton loaders for Flutter. One sweep shared across every placeholder, API-compatible with the shimmer package, and reduced-motion aware.
