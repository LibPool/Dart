# activeledger_falcon

**Tag**: activeledger, falcon, post-quantum, cryptography, ui, security

## 简介

Falcon-512 (FN-DSA) post-quantum keys for the Activeledger Dart SDK, backed by liboqs with prebuilt native libraries.
