# root_toast

**Tag**: toast, snackbar, overlay, notification, widget, ui

## 简介

Toasts drawn in the root Overlay so modal sheets, dialogs and the keyboard never hide them. Queue, stack or replace, swipe to dismiss, theming, RTL and accessibility.
