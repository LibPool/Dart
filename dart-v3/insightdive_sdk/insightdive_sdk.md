# insightdive_sdk

**Tag**: feedback, survey, nps, csat, webview, web, mobile, ui

## 简介

Flutter SDK for Insightdive in-app surveys. Modal bottom-sheet or inline widget — embed anywhere, stream lifecycle events, zero user identifiers.
