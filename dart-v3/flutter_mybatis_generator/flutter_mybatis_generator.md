# flutter_mybatis_generator

**Tag**: build-runner, codegen, mybatis, sql, database, mobile, ui, serialization, state-management, tooling

## 简介

Code generator for flutter_mybatis. Generates Mapper implementations from annotated abstract classes, and validates statement ids against the mapper XML at build time.
