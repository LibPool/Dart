# legichain_sdk

**Tag**: kyc, aml, sanctions, identity, compliance, web, mobile, state-management

## 简介

Official Legichain SDK for Flutter — KYC identity verification, AML sanctions screening, and address verification. One API key wraps every /v1 endpoint plus a stateful KYC flow controller (polling, SSE, retry, NFC chip-read interface, image-quality gating).
