# vector_map_tiles_mbtiles

**Tag**: flutter-map, vector-map-tiles, map, mbtiles, mobile, state-management

## 简介

Mapbox MBTiles vector tile provider for vector_map_files / flutter_map that can be used for a 100% offline map.
