# flutter_otel_device_info

**Tag**: mobile

## 简介

Coarse, non-identifying device attributes (OS, hardware model, form factor) for OpenTelemetry resources in Flutter apps, drawn from an explicit allowlist that never includes device names, hardware IDs or locale.
