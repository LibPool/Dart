# mpv_kit_video

**Tag**: mpv, video, vulkan, player, mobile, desktop

## 简介

Flutter video output for mpv_kit: zero-copy Vulkan rendering into Flutter textures (D3D11 shared textures on Windows, GL memory objects on Linux, IOSurface on macOS) with a software fallback.
