# google_maps_cluster

**Tag**: google-maps, google-maps-flutter, map, cluster, markers, mobile, ui, tooling

## 简介

Fast marker clustering for google_maps_flutter: a precomputed index per zoom level and a widget that builds cached cluster markers for the visible area.
