# flux_http

**Tag**: http, networking, dio, either, clean-architecture, web, mobile, ui, tooling

## 简介

A configurable, multi-environment, multi-backend HTTP client for Dart and Flutter. Returns Either<FluxFailure, T> without boilerplate. No codegen required.
