# scientific_input

**Tag**: scientific, parser, formatter, input, scientific-notation, mobile, ui

## 简介

Flutter widgets and utilities for parsing, validating, formatting, and displaying scientific notation such as 1.2e-3 and 1.2 × 10⁻³.
