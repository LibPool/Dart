# j1939

**Tag**: can-bus, j1939, nmea2000, socketcan, ffi, desktop, networking

## 简介

SAE J1939 on Linux SocketCAN via Dart FFI. Address claiming, BAM/RTS-CTS transport, DM1 diagnostics, NMEA 2000 Fast Packet, and zero-copy frames.
