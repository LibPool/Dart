# smf_shared_preferences

**Tag**: flutter, preferences, settings, shared-preferences, persistence, mobile, ui

## 简介

The SMF module of preferences with shared_preferences for the Flutter app that SMF generates. It remembers the settings of the app that are no secret, such as the theme mode.
