# ispect_layout

**Tag**: inspector, ispect, debug, layout, widget-inspector, mobile, ui

## 简介

Visual layout inspector for Flutter - inspect sizes, paddings, decorations, transforms, text styles, and compare widgets side-by-side at runtime.
