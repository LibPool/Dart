# ohlom_login

**Tag**: mobile, security, tooling

## 简介

Login with Ohlom — OAuth2 Authorization Code + PKCE (public client) for Flutter apps. Opens the Ohlom consent page, exchanges the code for tokens, and exposes the signed-in session (access/refresh + user). No client secret in the app.
