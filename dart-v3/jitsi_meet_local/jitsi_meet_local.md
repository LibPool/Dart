# jitsi_meet_local

**Tag**: web, mobile, networking

## 简介

Jitsi Meet Local Plugin - A plugin for integrating open source Jitsi Meet API in flutter. Jitsi Meet is secure, fully featured and allows completely free video conferencing made with https://jitsi.org, a collection of open source projects
