# swrly_hooks

**Tag**: swrly, flutter-hooks, state-management, cache, mobile, ui

## 简介

Flutter Hooks bindings for swrly — `useSwrlyQuery` and `useSwrlyMutation` for consuming a swrly cache from HookWidget-based screens.
