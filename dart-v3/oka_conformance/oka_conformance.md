# oka_conformance

**Tag**: build-system, cli, testing, conformance, web, ui, networking, state-management, tooling

## 简介

Shared publish-target conformance suite for oka (ADR-0014): the three publishing laws (dry-run without credentials, no stdin, no secret values in state) as a reusable test harness, plus redaction and plan-shape assertion helpers and a scripted fake HTTP transport for offline tests.
