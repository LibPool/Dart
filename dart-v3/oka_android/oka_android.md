# oka_android

**Tag**: aab, android, apk, build-system, flutter, mobile, ui, tooling

## 简介

Android platform pipelines for oka: no-Gradle Flutter APK/AAB build steps, plugin packaging, direct Android SDK toolchain (aapt2, d8, apksigner), and typed manifest/spec values.
