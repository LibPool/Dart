# stripe_client

**Tag**: stripe, payments, billing, api, web, mobile, tooling

## 简介

Pure Dart client for the Stripe API: typed resources, webhook signature verification, automatic retries and idempotency keys. Runs on Dart servers, CLIs and Flutter apps.
