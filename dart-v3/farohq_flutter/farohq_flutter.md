# farohq_flutter

**Tag**: monitoring, crash-reporting, error-tracking, observability, logging, web, mobile, networking

## 简介

Error monitoring for Flutter apps (Android and iOS) with FaroHQ. Captures crashes with screens, HTTP calls and breadcrumbs, grouped with the root cause.
