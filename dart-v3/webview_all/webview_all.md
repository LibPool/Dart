# webview_all

**Tag**: webview, webview-flutter, html, javascript, browser, web, mobile, desktop

## 简介

A WebView plugin supporting Android, iOS, macOS, Windows, Linux, Web, and OpenHarmony, with an API compatible with webview_flutter.
