# cf_lite

**Tag**: web, mobile, serialization

## 简介

Config Box Lite is a lightweight, JSON-based persistent key-value storage solution for Dart and Flutter applications. It provides a simple, asynchronous API to store, retrieve, and listen to data changes with robust type-casting support for primitives, Lists, and Maps.
