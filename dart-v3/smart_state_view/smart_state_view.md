# smart_state_view

**Tag**: state-management, async, loading, error-handling, widget, mobile, ui

## 简介

A production-ready Flutter async state management widget by GreeLogix for loading, success, empty, error, and idle screens with animations, overlay loading, pull-to-refresh, skeleton/shimmer loaders, and full customization.
