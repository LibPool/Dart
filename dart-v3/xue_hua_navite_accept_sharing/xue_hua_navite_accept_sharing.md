# xue_hua_navite_accept_sharing

**Tag**: sharing, share-extension, share-target, file-sharing, multiplatform, web, mobile, desktop

## 简介

A cross-platform Flutter plugin for receiving shared text, URLs, images, videos, and arbitrary files across Android, iOS, macOS, Windows, Linux, and Web.
