# hubspot_mobile_chat

**Tag**: hubspot, chat, customer-support, messaging, flutter-plugin, mobile

## 简介

A Flutter wrapper around the HubSpot Mobile Chat SDKs for Android and iOS — configure, identify visitors, open live chat, and receive push notifications.
