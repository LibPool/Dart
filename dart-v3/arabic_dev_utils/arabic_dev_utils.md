# arabic_dev_utils

**Tag**: mobile, ui, tooling

## 简介

Utilities for developers building Arabic and RTL Flutter/Dart applications: text normalization, invisible-character cleanup, Arabic-aware search, digit conversion, and RTL direction helpers.
