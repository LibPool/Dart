# qlaya

**Tag**: machine-learning, onnx, ai, inference, classification, web, networking, tooling

## 简介

QLaya — fast, local, on-device decision engine with calibrated probabilities and user-selectable quantized model variants. Dart client for the QLaya HTTP server or direct ONNX inference.
