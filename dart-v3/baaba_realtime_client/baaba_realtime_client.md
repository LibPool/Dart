# baaba_realtime_client

**Tag**: realtime, websocket, signalr, chat, webrtc, web, mobile, ui, networking, testing, tooling

## 简介

A customizable, production-grade Real-Time client for Flutter (SignalR & WebSockets). Features Either-based error handling, auto-reconnection with jitter, dead-connection detection, offline queueing, room subscriptions, chat & video call signaling helpers, and built-in test doubles.
