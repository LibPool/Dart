# fluent_2

**Tag**: fluent, design-system, ui, widgets, charts, web, mobile, desktop

## 简介

Microsoft Fluent 2 components for Flutter web and desktop: 90+ widgets, 20 chart types, tokens, theming, a11y and 135 locales. No Material.
