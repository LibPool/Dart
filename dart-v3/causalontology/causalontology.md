# causalontology

**Tag**: library

## 简介

The Dart binding of the Causalontology standard - a verb-first noun-hosting ontology; a programming-language-neutral standard and shared commons for reified causation. Zero dependencies: RFC 8785 canonicalization, SHA-256 identity, pure-Dart SHA-2 and Ed25519 (RFC 8032), schema and semantics validation, and an in-memory conformant store.
