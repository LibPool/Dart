# netra_flutter

**Tag**: web, mobile, ui, networking

## 简介

A Flutter networking plugin with offline queueing, slow network strategies, smart caching, circuit breaker, multipart uploads, and event-driven observability. Built on top of OkHttp via a native Android bridge.
