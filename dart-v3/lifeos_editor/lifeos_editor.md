# lifeos_editor

**Tag**: mobile, ui, serialization, state-management, tooling

## 简介

A rich text editor for Flutter with a TipTap-like extension system, slash commands, bubble menu, and markdown serialization. Build editors with pluggable block types, inline marks, keyboard shortcuts, and input rules.
