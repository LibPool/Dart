# openinstall_flutter_global

**Tag**: mobile

## 简介

openinstall_flutter_global is a Flutter plugin based on openinstall, and with null safety support.

## 官网

- 主页: https://www.openinstallglobal.com/
- pub.dev: https://pub.dev/packages/openinstall_flutter_global
