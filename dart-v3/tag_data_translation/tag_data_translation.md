# tag_data_translation

**Tag**: rfid, gs1, epc, barcode, mobile

## 简介

GS1 EPC Tag Data Translation for Flutter and RAIN (UHF) RFID. Encode and decode SGTIN, SSCC, SGLN, GRAI, and all EPC schemes on Android and iOS.
