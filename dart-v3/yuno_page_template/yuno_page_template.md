# yuno_page_template

**Tag**: web, mobile, ui

## 简介

Flutter UI kit for Yuno Learning: responsive course, batch, and instructor widgets; V4 + legacy API models/adapters; share widgets; and ready-to-use pages for web, iOS, and Android.
