# flutter_call_manager

**Tag**: mobile, ui, state-management

## 简介

Flutter plugin to manage incoming and outgoing calls (SIM and VoIP) across Android and iOS. Supports native call handling, call states, custom UI, and integrates with TelecomManager and CallKit.
