# nav2_safety_layer

**Tag**: ros2, nav2, safety, winter-driving, state-management

## 简介

Pure-Dart bridge composing navigation_safety_core primitives over ROS 2 Navigation Stack (nav2) Collision Monitor / Detector state messages.
