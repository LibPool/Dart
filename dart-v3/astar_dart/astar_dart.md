# astar_dart

**Tag**: astar, pathfinder, manhattan, euclidean, hex, testing, tooling

## 简介

A pathfinder implementation in Dart. Efficiently finds shortest paths on grids, supporting barriers and weights. Manhattan, Euclidean, Hex
