# ypay_inventory

**Tag**: mobile

## 简介

YPay inventory Flutter Plugin для библиотеки YPay Flutter позволяет интегрировать встроенные бейджи и виджеты YandexPaySDK в ваши проекты. Инвентарь — это набор визуальных элементов с брендированными продуктами Яндекса.
