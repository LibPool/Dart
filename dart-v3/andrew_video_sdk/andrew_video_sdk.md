# andrew_video_sdk

**Tag**: video, editor, ffmpeg, ai, sdk, mobile

## 简介

Video editing SDK for Flutter — timeline, multi-track, transitions, effects, filters, AI subtitle, smart cut, screen recording. Layer 1 core with SPI architecture.
