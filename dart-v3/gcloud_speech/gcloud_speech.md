# gcloud_speech

**Tag**: mobile

## 简介

A comprehensive Flutter package for Google Cloud Speech-to-Text. Supports audio recording (start / pause / resume / stop), real-time streaming transcription, and post-recording batch transcription with extensive configuration options.
