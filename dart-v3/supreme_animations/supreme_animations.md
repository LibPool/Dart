# supreme_animations

**Tag**: animation, timeline, physics, transitions, flutter, mobile, ui

## 简介

A high-performance animation library for Flutter featuring Tweens, Timelines, ScrollTrigger, FLIP layout morphs, Staggers, and Physics Easings.
