# jet_cad_2d_kit_architecture

**Tag**: cad, floor-plan, architecture, desktop

## 简介

The architecture kit for jet_cad_2d plans: walls, doors, windows, gaps, room separators, rooms, dimensions, boxes, a furniture library and wall attachment.
