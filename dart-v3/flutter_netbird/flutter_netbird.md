# flutter_netbird

**Tag**: web, mobile, desktop, networking

## 简介

A Flutter FFI plugin for NetBird mesh VPN, providing secure peer-to-peer connectivity, DNS resolution, and HTTP proxy across Android, iOS, macOS, Windows, and Linux.
