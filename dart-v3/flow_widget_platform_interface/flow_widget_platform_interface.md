# flow_widget_platform_interface

**Tag**: widget, home-widget, platform-interface, web, mobile, ui

## 简介

A common platform interface for the flow_widget plugin. Separates app-facing APIs from platform implementations following Flutter's federated plugin architecture recommendations.
