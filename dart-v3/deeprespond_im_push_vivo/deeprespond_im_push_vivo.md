# deeprespond_im_push_vivo

**Tag**: mobile

## 简介

深应智能 IM 的 vivo 推送通道（只有 Android，vivo、iQOO）：判断能否使用、取得令牌、令牌刷新。vivo 推送 SDK 由 App 放入。
