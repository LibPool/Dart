# meanvc2_onnx

**Tag**: voice-conversion, onnx, audio, speech, mobile

## 简介

Streaming MeanVC2 zero-shot voice conversion (160 ms chunks) on ONNX Runtime for Flutter, with the speaker encoder for registering a reference voice.
