# rudderstack_api

**Tag**: rudderstack, analytics, tracking, server, web, mobile, tooling

## 简介

Pure Dart RudderStack server-side SDK: identify, track, page, screen, group and alias, sent in gzip batches with retries. Runs on Dart servers, CLIs and Flutter apps.
