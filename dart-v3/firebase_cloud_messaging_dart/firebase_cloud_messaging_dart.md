# firebase_cloud_messaging_dart

**Tag**: web, mobile, networking, tooling

## 简介

A pure Dart server-side client for sending Firebase Cloud Messages through the FCM HTTP v1 API. It does not implement native Flutter registration or receive handlers. Includes service-account and Application Default Credentials support.
