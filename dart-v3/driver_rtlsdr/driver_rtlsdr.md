# driver_rtlsdr

**Tag**: android, usb, ffi, radio, sdr, mobile, ui, testing

## 简介

Full RTL-SDR (RTL2832U) stack for Flutter/Android in one package: native USB/FFI driver (tuning, IQ streaming, WFM/NFM/AM/SSB demodulation, stereo, RDS, spectrum, recording, gain), a testable ChangeNotifier radio engine (controllers, presets), and a gqrx-inspired widget library (scope, waterfall, tuner, panels, screens). Reusable native core (C, GPLv2). Merged from driver_rtlsdr + core_rtlsdr + widget_rtlsdr.
