# biometric_storage_plus_new

**Tag**: biometrics, encryption, storage, security, secure-storage, web, mobile, desktop, ui

## 简介

Secure Storage: Encrypted data store optionally secured by biometric lock with support
for iOS, Android, MacOS. Partial support for Linux, Windows and web (localStorage) (refork from codeux.design).
