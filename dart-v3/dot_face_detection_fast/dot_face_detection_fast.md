# dot_face_detection_fast

**Tag**: innovatrics, digital-onboarding, remote-identity-verification, face-detection, video-injection-prevention, mobile

## 简介

A Flutter plugin, as a part of Innovatrics IDV Flutter SDK, that provides fast face detection feature for a Flutter project.
