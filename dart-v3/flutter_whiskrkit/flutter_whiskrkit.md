# flutter_whiskrkit

**Tag**: mobile, ui

## 简介

Flutter wrapper for the WhiskrKit in-app survey SDK. Surveys render as fully native UI; this plugin only triggers presentation.

## 官网

- 主页: https://whiskrkit.eu
- 源码仓库: https://github.com/WhiskrKit/whiskrkit-flutter
- pub.dev: https://pub.dev/packages/flutter_whiskrkit
