# dart_vector_index

**Tag**: ai, vector-search, rag, embeddings, hnsw, tooling

## 简介

Fast, pure-Dart vector search & HNSW index for on-device RAG, semantic search, and embeddings with Cosine, Euclidean, SQ8 quantization, and metadata filtering.
