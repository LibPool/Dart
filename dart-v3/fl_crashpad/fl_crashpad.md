# fl_crashpad

**Tag**: crash-reporting, crashpad, minidump, ffi, privacy, mobile, desktop

## 简介

Native crash reporting for Flutter with Google Crashpad: sanitised minidumps of crashes the Dart VM never sees, on desktop, Android and iOS, for any minidump backend.
