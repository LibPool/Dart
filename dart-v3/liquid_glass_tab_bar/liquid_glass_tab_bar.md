# liquid_glass_tab_bar

**Tag**: bottom-navigation, navigation-bar, tab-bar, liquid-glass, glassmorphism, mobile, ui

## 简介

iOS 26 liquid glass bottom navigation bar (tab bar, nav bar) for Flutter with a real refracting glass droplet, drag to select and light/dark mode.
