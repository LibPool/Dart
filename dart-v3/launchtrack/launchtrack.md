# launchtrack

**Tag**: web, mobile, tooling

## 简介

A Flutter plugin for deferred deep linking. Wraps the LaunchTrack Android (Install Referrer + Fingerprint API) and iOS (Clipboard + Fingerprint API) SDKs. Works out-of-the-box with minimal client integration.
