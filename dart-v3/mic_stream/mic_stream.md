# mic_stream

**Tag**: ui

## 简介

A plugin to receive raw byte streams from a device's microphone. Audio is returned as `Stream<Uint8list>`.

## 官网

- 主页: https://github.com/anarchuser/mic_stream
- pub.dev: https://pub.dev/packages/mic_stream
