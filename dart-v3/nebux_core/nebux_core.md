# nebux_core

**Tag**: sdk, nebux, api, auth, crm, web, mobile, networking, security, tooling

## 简介

Core foundation library for Nebux Flutter SDK containing HTTP client, HMAC-SHA256 signing, daily handshake, and customer identity resolution.
