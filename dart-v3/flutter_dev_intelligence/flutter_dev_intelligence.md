# flutter_dev_intelligence

**Tag**: flutter, developer-tools, debugging, build-diagnostics, cli, mobile, ui, tooling

## 简介

Offline-first diagnostic toolkit that analyzes Flutter and Dart build logs, identifies root causes, separates cascading failures, and generates evidence-backed debugging reports.
