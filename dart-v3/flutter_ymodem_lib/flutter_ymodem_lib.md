# flutter_ymodem_lib

**Tag**: ymodem, ble, bluetooth, ota, firmware, mobile, desktop

## 简介

A pure Dart YModem file transfer protocol for Flutter: zero native code on Android, iOS, Windows, macOS and Linux. Perfect for BLE OTA firmware upgrades.
