# nepali_input_formatters

**Tag**: nepal, nepali, input-formatter, validator, currency, mobile

## 简介

A collection of Flutter TextInputFormatters, validators, and utilities tailored for Nepali data formats (phone numbers, citizenship, and Lakhs/Crores currency).
