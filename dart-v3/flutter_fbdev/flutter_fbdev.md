# flutter_fbdev

**Tag**: embedded, handheld, framebuffer, gamepad, flutter-pi, mobile

## 简介

Run Flutter on no-DRM framebuffer handhelds: a software-rendered /dev/fb0 embedder with gamepad/evdev input and an on-screen button-mapping overlay.
