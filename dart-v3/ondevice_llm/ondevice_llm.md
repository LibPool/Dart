# ondevice_llm

**Tag**: library

## 简介

Headless on-device LLM lifecycle management: verified downloads with resume, developer-recommended model catalogs, user-consented updates and model switching, coexisting versions with rollback, and cold-start reactivation. Pure Dart core; engine adapters ship separately.
