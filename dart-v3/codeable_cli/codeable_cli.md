# codeable_cli

**Tag**: mobile, ui, state-management, tooling

## 简介

A CLI tool that scaffolds production-ready Flutter projects with Clean Architecture, BLoC/Cubit, Dio, Hive, GoRouter, multi-flavor builds, and Firebase integration.
