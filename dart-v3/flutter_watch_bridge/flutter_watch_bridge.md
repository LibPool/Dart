# flutter_watch_bridge

**Tag**: watch, wear-os, watchos, wearable, connectivity, web, mobile, state-management

## 简介

One API for messages, state sync and file transfer between a Flutter phone app and its paired Apple Watch or Wear OS watch, with pairing and reachability streams.
