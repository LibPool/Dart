# simple_sms_native

**Tag**: sms, mms, messaging, android, mobile

## 简介

A modern MMS / SMS plugin for Android with typed inbound/outbound messaging, lookup service, and conversation enrichment. Runtime permissions + default-SMS-app role management are delegated to simple_permissions_native.
