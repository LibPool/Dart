# audios_resolver

**Tag**: mobile, tooling

## 简介

Cross-platform audio URL resolver for YouTube/YTMusic via InnerTube Android clients. Resolves direct streaming URLs with codec, bitrate, and expiry metadata. Supports single and batch resolution.
