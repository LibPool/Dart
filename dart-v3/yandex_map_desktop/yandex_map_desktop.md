# yandex_map_desktop

**Tag**: map, yandex, windows, macos, webview, web, mobile, desktop

## 简介

Yandex Maps JS API 2.1 for Flutter desktop via WebView. Windows (Edge WebView2) and macOS (WKWebView) support.
