# flutter_workoutkit

**Tag**: workoutkit, apple-watch, healthkit, fitness, workouts, mobile

## 简介

A Flutter plugin that leverages Apple's WorkoutKit SDK to create, preview, and sync custom workouts with the Apple Watch Workout app.
