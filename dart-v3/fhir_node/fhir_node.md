# fhir_node

**Tag**: fhir, fhirpath, hl7, healthcare, interoperability

## 简介

Minimal model-reflection interface (FhirNode) letting model-independent FHIRPath/CQL engines navigate FHIR data of any version (R4/R5/R6).
