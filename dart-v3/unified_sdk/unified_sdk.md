# unified_sdk

**Tag**: consent, gdpr, cmp, tcf, privacy, mobile

## 简介

GDPR consent management platform (CMP) by SFBX AppConsent: show the consent notice and read IAB TCF v2 and Google Consent Mode v2 consent on Android and iOS.
