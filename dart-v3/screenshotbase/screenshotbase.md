# screenshotbase

**Tag**: web, networking, tooling

## 简介

Dart client for Screenshotbase API to render website screenshots and PDFs. See https://screenshotbase.com

## 官网

- 主页: https://screenshotbase.com
- 源码仓库: https://github.com/martechdev/screenshotbase-dart
- pub.dev: https://pub.dev/packages/screenshotbase
