# bifold

**Tag**: foldable, ios, android, adaptive-layout, hinge, mobile, ui, testing

## 简介

Fold awareness for the foldable iPhone and Android foldables: hinge angle and pose, fold regions, fold-aware layout widgets, a debug overlay and test fakes.
