# zegoweb_prebuilt

**Tag**: web, mobile, ui

## 简介

Unofficial Flutter web plugin wrapping ZEGOCLOUD's @zegocloud/zego-uikit-prebuilt JavaScript UIKit via dart:js_interop. Drop-in pre-built call UI. Not affiliated with or endorsed by ZEGOCLOUD.
