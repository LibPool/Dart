# polly_flutter

**Tag**: resilience, retry, circuit-breaker, networking, widgets, mobile, ui, tooling

## 简介

Flutter-first resilience widgets built on polly_dart. Provides drop-in replacements for FutureBuilder, StreamBuilder, network images, buttons, forms, and lists — all with automatic retry, circuit breaker, caching, rate limiting, and connectivity awareness baked in.
