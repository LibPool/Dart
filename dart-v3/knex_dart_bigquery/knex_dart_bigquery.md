# knex_dart_bigquery

**Tag**: sql, query-builder, database, bigquery, knex, web, ui, tooling

## 简介

Google BigQuery driver for knex_dart — execute queries against Google BigQuery via the BigQuery REST API using the knex_dart query builder.
