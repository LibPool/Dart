# pqtransport

**Tag**: cryptography, tls, quic, network, flutter, web, mobile, ui, networking, security

## 简介

Pure-Dart post-quantum transport: UDP, TLS 1.3 hybrid (X25519MLKEM768 / SecP256r1MLKEM768 / SecP384r1MLKEM1024), DNS/DoH/DoT, mDNS, QUIC, HTTP/1.1–3.
