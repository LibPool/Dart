# rune_provider

**Tag**: rune, bridge, provider, state-management, reactive, ui

## 简介

Provider (provider package) bridge for the rune package; registers ChangeNotifierProvider, Consumer, and Selector widgets on a RuneConfig for reactive state in source strings.
