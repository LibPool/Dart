# unity_ads_plugin

**Tag**: mobile

## 简介

Unity Ads plugin for Flutter Applications. This plugin is able to display Unity Banner Ads and Unity Video Ads.

## 官网

- 主页: https://github.com/pavelzaichyk/flutter_unity_ads
