# flutter_clean_arch_scaffold_cli

**Tag**: cli, flutter, code-generation, mason, architecture, mobile, tooling

## 简介

CLI tool to initialize Flutter projects with clean architecture and generate feature modules (data, domain, presentation) using Mason templates.
