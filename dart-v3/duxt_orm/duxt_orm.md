# duxt_orm

**Tag**: orm, database, postgresql, mysql, sqlite, ui, tooling

## 简介

ActiveRecord-style ORM for Dart. Supports PostgreSQL, MySQL, and SQLite with auto-migrations, query builder, and schema definitions.
