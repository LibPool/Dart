# bluetooth_print_plus

**Tag**: mobile

## 简介

bluetooth_print_plus is a flutter plugin for bluetooth thermal printer, support Android & iOS, supports tspl/tsc、cpcl、esc pos.

- 主页: https://github.com/amoLink/bluetooth_print_plus
