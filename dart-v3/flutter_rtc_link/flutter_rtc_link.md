# flutter_rtc_link

**Tag**: webrtc, rtc, streaming, iot, robot, web, mobile

## 简介

Flutter plugin for real-time audio/video (WebRTC WHIP/WHEP + LiveKit) and IoT device management: publish, subscribe, live relay, robot teleoperation, provisioning and OTA.
