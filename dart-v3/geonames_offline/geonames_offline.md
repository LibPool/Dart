# geonames_offline

**Tag**: geocoding, reverse-geocoding, geonames, offline, geolocation, web, networking

## 简介

Coordinates in, nearest populated place out, resolved offline against an embedded GeoNames dataset. Pure Dart, no network at resolution time.
