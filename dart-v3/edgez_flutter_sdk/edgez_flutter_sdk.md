# edgez_flutter_sdk

**Tag**: wifi, mesh, halow, iot, mobile, security

## 简介

Android Flutter SDK for EdgeZ HaLow mesh devices, Wi-Fi transport, encrypted messaging, voice calls, provisioning, and OTA updates.
