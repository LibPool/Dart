# clicklens

**Tag**: analytics, events, tracking, mixpanel, web, mobile, desktop, tooling

## 简介

ClickLens product analytics for Flutter apps on Android, iOS, web, macOS, Windows and Linux. Batched, retried, offline-safe event tracking.
