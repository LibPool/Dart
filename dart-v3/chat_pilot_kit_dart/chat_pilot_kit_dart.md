# chat_pilot_kit_dart

**Tag**: chat, ai, sdk, streaming, mobile

## 简介

Headless chat SDK for AI-powered conversation apps. Pure Dart, no Flutter dependency. Supports streaming, plugins, and multiple transport layers.
