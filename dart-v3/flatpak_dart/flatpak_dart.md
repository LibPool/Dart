# flatpak_dart

**Tag**: linux, flatpak, desktop, ffi, libflatpak, web

## 简介

Typed Dart API for managing Flatpak applications on Linux. Drives libflatpak via a C++23 FFI bridge: list, install, update, uninstall, remotes and permissions.
