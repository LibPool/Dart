# openui_flutter

**Tag**: generative-ui, ai, llm, widgets, chat, mobile, ui

## 简介

Render OpenUI Lang, the streaming generative UI language, as native Flutter widgets: layouts, tables, charts, forms, cards and icons, plus custom components.
