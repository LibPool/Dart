# ethiopic_typography

**Tag**: ethiopia, amharic, typography, theme, fonts, mobile, ui

## 简介

Drop-in bilingual Flutter theming with Manrope + Noto Sans Ethiopic font pairing. Latin text uses Manrope; Ge'ez falls back to Noto Sans Ethiopic.
