# confeature

**Tag**: mobile, tooling

## 简介

Confeature SDK for Dart / Flutter — drop-in compatible with ConfigCat's `configcat_client` package. Edge-cached feature flag evaluations from Cloudflare Workers; pure-Dart with optional Flutter integration.
