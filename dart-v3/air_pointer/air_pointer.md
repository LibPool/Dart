# air_pointer

**Tag**: canvas, gestures, hand-tracking, mediapipe, web, mobile

## 简介

Platform-agnostic canvas input for Flutter. Unifies mouse, trackpad, and MediaPipe hand-gesture events behind a single CanvasInputController.
