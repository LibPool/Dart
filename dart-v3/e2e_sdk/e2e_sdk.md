# e2e_sdk

**Tag**: mobile, testing

## 简介

e2e-test 环境切换 SDK(Flutter / 纯 Dart):按平台下发的描述符切 baseUrl/Host、 应用变量与开关,回传就绪。只切环境、不做登录;正式包默认惰性。
