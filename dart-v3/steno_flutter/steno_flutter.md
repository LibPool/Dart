# steno_flutter

**Tag**: logging, logger, flutter, observability, crash, web, mobile

## 简介

Flutter integration for the steno structured logger: FlutterError capture, PlatformDispatcher error capture, dart:developer sink, device/app enrichers, route scope observer, and a runZoned bootstrap helper.
