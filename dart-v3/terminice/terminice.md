# terminice

**Tag**: terminal, cli, prompt, terminal-interface, terminal-ui, ui, testing, tooling

## 简介

A robust terminal UI toolkit for Dart CLI apps. 30+ ready-to-use components, 11 built-in style presets, display modes, fallback policies, testing utilities, and zero boilerplate.
