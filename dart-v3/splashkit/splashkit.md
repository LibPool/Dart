# splashkit

**Tag**: mobile, tooling

## 简介

A CLI tool to add Android native splash screen using AVD in Flutter apps.

- 主页: https://github.com/mohammed-jasir-7/splashkit
- pub.dev: https://pub.dev/packages/splashkit
