# lowcoai_api

**Tag**: lowco, pdf, ocr, invoice, sdk, web, mobile, tooling

## 简介

Official Dart and Flutter client for the Lowco API — PDF, render, OCR, Document AI, QR and barcodes, with jobs, file inputs, webhooks and typed errors.
