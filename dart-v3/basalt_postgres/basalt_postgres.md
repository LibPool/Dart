# basalt_postgres

**Tag**: orm, database, postgres, sql, ui, serialization

## 简介

Postgres backend for the Basalt Dart ORM — a driver-backed Connection + SqlDialect on package:postgres, with introspection and json/uuid/numeric/array codecs.
