# sumsub_flutter_web

**Tag**: sumsub, kyc, identity-verification, web, mobile, ui

## 简介

Sumsub identity verification (KYC) for Flutter Web, built on the Sumsub WebSDK 2.0 with the same API as flutter_idensic_mobile_sdk_plugin.
