# android_telecom

**Tag**: telephony, dialer, android, calls, plugin, mobile, ui, state-management, tooling

## 简介

Build a full default Phone (dialer) app on Android with Flutter via RoleManager, InCallService, CallScreeningService and the CallLog provider.
