# drift_studio

**Tag**: drift, sqlite, database, debugging, devtools

## 简介

A professional, in-app database studio for Drift (SQLite) databases. Searchable table explorer, filterable and sortable data grid, schema inspector, and a SQL console with autocomplete, snippets and saved queries.
