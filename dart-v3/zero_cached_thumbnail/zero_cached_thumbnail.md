# zero_cached_thumbnail

**Tag**: video, thumbnail, cache, media, web, mobile

## 简介

Cross-platform video-thumbnail Flutter plugin. Native APIs only (MediaMetadataRetriever / AVFoundation / Media Foundation). On-disk JPEG cache with LRU eviction and concurrent decode dedup.
