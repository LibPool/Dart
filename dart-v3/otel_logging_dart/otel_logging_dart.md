# otel_logging_dart

**Tag**: opentelemetry, logging, observability, otlp, telemetry, web, mobile, networking

## 简介

Send Dart and Flutter application logs to an OpenTelemetry collector over the OTLP/HTTP protocol, with package:logging integration and trace correlation.
