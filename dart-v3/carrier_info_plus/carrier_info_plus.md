# carrier_info_plus

**Tag**: carrier, sim, telephony, cellular, network, mobile, networking

## 简介

Cellular carrier, SIM and network info for Flutter. Swift Package Manager ready, dual-SIM aware, and explicit about what modern iOS no longer reports.
