# vie_revenue_cat

**Tag**: mobile, ui, state-management

## 简介

A production-grade, highly extensible RevenueCat & Hybrid In-App Purchase Manager for Flutter. Effortlessly handles Native RevenueCat Paywalls (purchases_ui_flutter), custom local Flutter paywalls, dynamic Firebase Remote Config routing, reactive entitlement state management, and seamless feature gating.
