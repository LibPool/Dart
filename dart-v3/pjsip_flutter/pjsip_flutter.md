# pjsip_flutter

**Tag**: sip, voip, pjsip, telephony, ffi, mobile, ui, tooling

## 简介

A Flutter/Dart FFI plugin that embeds the PJSIP (PJSUA) SIP stack for VoIP calling on Android and iOS, built with modern native-assets build hooks.
