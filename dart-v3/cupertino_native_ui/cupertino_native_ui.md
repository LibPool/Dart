# cupertino_native_ui

**Tag**: liquid-glass, cupertino, ios, swiftui, native-widgets, mobile, ui

## 简介

Native iOS 26 Liquid Glass widgets for Flutter, backed by SwiftUI: glass effects, tab bar, toolbar, sheets, menus, lists and scroll edge effects.
