# log_bundle

**Tag**: logging, bug-report, diagnostics, debugging, ui, serialization, tooling

## 简介

Collect app logs and build a ready-to-attach bug report bundle — a redacted, bounded txt/json/zip file. The payload a shake-to-report SDK sends, without the vendor.
