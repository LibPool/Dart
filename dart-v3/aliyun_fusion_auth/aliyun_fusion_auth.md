# aliyun_fusion_auth

**Tag**: aliyun, authentication, phone, sms, web, mobile, security

## 简介

An independent Flutter plugin for Alibaba Cloud Fusion Authentication on Android and iOS, with explicit consent and server-verifiable tokens.
