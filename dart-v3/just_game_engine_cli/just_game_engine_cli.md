# just_game_engine_cli

**Tag**: cli, gamedev, game-engine, flutter, mobile, ui, tooling

## 简介

The Just Game Engine's commands for `just` (just_core_cli): run and build games, check releases hold no editor, manage scenes and migrate saved files.
