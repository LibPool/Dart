# misarseo_flutter

**Tag**: seo, keyword-research, rank-tracking, api-client, secure-storage, web, mobile, desktop, tooling

## 简介

MisarSEO's API from Flutter apps: keyword research, site audits, rank tracking, backlinks and AI search visibility, with secure key storage, retries, typed plan-limit errors and SSE on iOS, Android, macOS and web.
