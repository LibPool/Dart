# objectbox_mesh_sync

**Tag**: mobile, desktop, database, networking

## 简介

Fast Flutter database for persisting Dart objects. This package adds the Mesh Sync (peer-to-peer) network transport for ObjectBox Sync on Android, iOS and macOS.
