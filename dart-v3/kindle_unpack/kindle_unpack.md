# kindle_unpack

**Tag**: mobi, azw3, kf8, epub, ebook

## 简介

Pure-Dart library for reading Amazon Kindle ebook files (MOBI / AZW / AZW3 / KF8) and re-emitting them as EPUB 3. No DRM removal.
