# loro_crdt_flutter

**Tag**: crdt, local-first, collaboration, flutter, sync, web, mobile, ui, tooling

## 简介

Flutter integration for loro_crdt (Loro CRDTs): bundles the web build and provides a TextEditingController bound to a collaborative LoroText.
