# jackdaw_cli

**Tag**: ai, llm, cli, agents, serialization, tooling

## 简介

Command line tools for jackdaw. Inspect session journals and traces, compile JSON Schemas to the GBNF grammars used for constrained output, and validate JSON against a schema.
