# pulse_dev

**Tag**: monitoring, error-reporting, observability, analytics, sdk, mobile, ui

## 简介

Pure Dart core for the Pulse Developer Intelligence SDK. Provides event models, the event pipeline, transport and storage interfaces, privacy sanitization, breadcrumb buffering, performance instrumentation, offline queueing, and configuration. Flutter-free — suitable for any Dart project.
