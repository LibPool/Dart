# weklem_web_youtube_player

**Tag**: web, mobile, ui

## 简介

A Flutter web package developed by WeKlem to seamlessly embed and play YouTube videos. Designed with performance and simplicity in mind, this widget provides an easy interface for incorporating YouTube content into web applications.
