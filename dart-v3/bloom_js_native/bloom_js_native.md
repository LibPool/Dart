# bloom_js_native

**Tag**: bloom, web, dom, signals, ssr, mobile

## 简介

Reactive Dart web framework for real DOM apps — SSR, SSG, ISR-friendly rendering, signals, SEO, and browser APIs. Not Flutter web.
