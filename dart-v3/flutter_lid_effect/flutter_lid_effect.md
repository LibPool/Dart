# flutter_lid_effect

**Tag**: macos, animation, sensor, blur, lid-angle, mobile, desktop, ui

## 简介

A Flutter plugin for macOS that reads MacBook lid angles and adds smooth perspective, blur animation and gradient dimming to your app.
