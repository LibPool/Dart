# mysql_dart

**Tag**: database, serialization, tooling

## 简介

Native MySQL client written in Dart. Supports TLS, MySQL 9/9.7 caching_sha2_password, JSON columns, MariaDB 10/11, and Percona/MySQL 5.7/8.
