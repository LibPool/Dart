# flutter_edge

**Tag**: web, mobile, desktop

## 简介

On-device AI for Flutter — run LLMs, embeddings and RAG locally across Android, iOS, web and desktop, model-agnostic (Gemma, Qwen, Phi and more). Name reserved; first release coming soon.
