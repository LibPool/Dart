# floating_snackbar

**Tag**: snackbar, toast, notification, overlay, ui, mobile

## 简介

Customizable floating snackbars/toasts for Flutter: success, error, warning & info variants, top/bottom positioning, global theming, actions, progress, and a context-free overlay mode. Pure Dart, all platforms.
