# flutter_riglogic

**Tag**: ffi, riglogic, metahuman, facial-animation, game-dev, mobile, ui

## 简介

Dart FFI bindings for Epic Games' OpenRigLogic: read MetaHuman DNA files and evaluate facial rigs (joints, blend shapes, animated maps) in real time.
