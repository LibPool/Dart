# tricoredb

**Tag**: database, sql, client, driver, web, tooling

## 简介

Dart driver for TriCoreDB's native tricore protocol: SQL with server-side parameters, transactions, documents, vectors, graphs, cache and LLM context, over TCP or TLS, with no dependencies.
