# yandex_pay_core

**Tag**: yandex, payments, fintech, sdk, mobile, ui, security

## 简介

Core SDK for Yandex Pay Flutter modular architecture. Provides YPay initialization, deeplinks, and the module registry used by yandex_pay_quickpay and yandex_pay_auth.
