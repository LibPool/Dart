# card_fan_spread

**Tag**: cards, card-fan, cardistry, animation, magic, mobile, ui

## 简介

A Flutter card component that reproduces magician deck spreads: table spread, fan, reverse fan, the cardistry S fan and the two-hand fan, with an optional double-tier offset (giant fan) and a movable fan pivot, all with per-card cascading animation.
