# paystation_flutter

**Tag**: payments, payment-gateway, webview, bangladesh, web, mobile

## 简介

Flutter SDK for the PayStation payment gateway. Talks only to your own backend (never PayStation directly, never holds credentials) to start payments, show a hosted checkout WebView, and verify final status.
