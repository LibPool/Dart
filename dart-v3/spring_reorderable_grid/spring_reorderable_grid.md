# spring_reorderable_grid

**Tag**: library

## 简介

A drag-to-reorder grid where tiles are real mass-spring-damper bodies, not tweened positions. Dragging one tile shoves its neighbors with an actual simulated force, so they carry velocity, overshoot, and settle with a configurable, physically believable wobble.
