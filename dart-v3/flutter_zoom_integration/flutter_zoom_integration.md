# flutter_zoom_integration

**Tag**: mobile, desktop, security

## 简介

Flutter plugin integrating the Zoom Meeting SDK on macOS and iOS via Swift MethodChannel. Supports join/start/leave meetings, JWT auth, and audio/video.
