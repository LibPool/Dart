# product_pilot_sdk

**Tag**: analytics, product-analytics, tracking, observability, mobile

## 简介

Flutter SDK for ProductPilot — product analytics with AI-driven event recommendations. Auto-captures screen views, lifecycle, Dio and go_router navigation. Privacy-first: never collects bodies, headers, or source code.
