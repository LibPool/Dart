# llm_tool_generator

**Tag**: llm, tool-calling, function-calling, ai-agents, codegen, serialization, tooling

## 简介

Code generator for llm_tool. Turns @LlmTool-annotated Dart functions into LLM tools for OpenAI, Gemini, Claude, MCP and on-device models, with JSON schemas and validation.
