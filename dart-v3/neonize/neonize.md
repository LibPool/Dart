# neonize

**Tag**: whatsapp, whatsapp-bot, automation, whatsmeow, websocket, web, mobile, networking, security

## 简介

A Dart/Flutter library for WhatsApp automation and bot development, providing a high-level interface to interact with WhatsApp Web protocol through the Neonize Go library. Features include message handling, media support, QR code authentication, and comprehensive WhatsApp API integration.
