# nativemind_copilot

**Tag**: ai, agent, copilot, chat, mcp, mobile, security, tooling

## 简介

The NativeMind copilot for Flutter: agent conversation panel, decisions and spending policy, voice and attachments, the copilot protocol client, OAuth / MCP connect screens and a prototype engine.
