# glassmorphic_ui

**Tag**: glassmorphism, ui, widgets, animation, material-design, mobile

## 简介

iOS 26-inspired Liquid Glass design system for Flutter. Glassmorphism widgets with real-time backdrop blur, specular borders, and customizable tint overlays — containers, cards, buttons, app bars, bottom navs, sheets, dialogs, and more.
