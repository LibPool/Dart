# flutter_bio_auth

**Tag**: mobile, security

## 简介

On-device face detection, tracking, active liveness challenges, and an injectable 1:1 face-recognition / anti-spoof pipeline for Flutter. Detection/tracking/liveness work with zero bundled AI models (native ML Kit on Android, Vision framework on iOS). Recognition and passive anti-spoofing are model-driven and loaded from a developer-supplied asset path at initialize() time.
