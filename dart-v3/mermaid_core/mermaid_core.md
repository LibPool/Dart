# mermaid_core

**Tag**: mermaid, diagram, svg, visualization, mobile, tooling

## 简介

Pure Dart port of mermaid.js: detect, parse and lay out 28 diagram types into a backend-agnostic scene, with an SVG renderer and a CLI. No Flutter.
