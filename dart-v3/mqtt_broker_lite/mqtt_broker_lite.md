# mqtt_broker_lite

**Tag**: mqtt, broker, iot, pubsub, networking, web, security

## 简介

A pure-Dart MQTT 3.1.1 broker. Supports wildcards, retained messages, QoS 0/1/2, will messages, authentication, TLS, and WebSocket transport.
