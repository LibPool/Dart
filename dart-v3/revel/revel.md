# revel

**Tag**: mobile, security

## 简介

Flutter SDK for revel-backend — Firebase-backed auth via custom token exchange. Supports email/password, Google, and Apple sign-in. Drop-in for any app that authenticates against revel-backend's /sessions/* endpoints.
