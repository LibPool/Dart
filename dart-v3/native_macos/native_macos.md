# native_macos

**Tag**: macos, liquid-glass, appkit, native, widget, mobile, desktop, ui

## 简介

Real AppKit controls and Liquid Glass for Flutter on macOS: a native toolbar, sidebar, glass groups, popovers, date pickers, and menus drawn by the OS.
