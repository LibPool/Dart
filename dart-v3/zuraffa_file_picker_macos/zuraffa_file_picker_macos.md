# zuraffa_file_picker_macos

**Tag**: file-picker, macos, zuraffa, desktop

## 简介

The macOS implementation of zuraffa_file_picker (NSOpenPanel / NSSavePanel): pick files, save documents and pick directories via the native open and save panels.
