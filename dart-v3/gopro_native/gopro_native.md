# gopro_native

**Tag**: gopro, usb, linux, ffi, web, desktop, networking

## 简介

Linux-first GoPro camera control for Dart: USB discovery, BLE, HTTP, COHN, Wi-Fi and livestreaming. Enumerate-only over USB, never claiming CDC-NCM.
