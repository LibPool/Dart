# mcp_server

**Tag**: web, networking, security

## 简介

Dart implementation of Model Context Protocol (MCP) server. Supports protocol revisions 2024-11-05 / 2025-03-26 / 2025-06-18 / 2025-11-25 with per-version capability gating, OAuth 2.1 (RFC 9728), and stdio / SSE / Streamable HTTP transports.
