# professional_toast

**Tag**: toast, notification, snackbar, ui, overlay, mobile

## 简介

A highly customizable, animated toast/snackbar-style notification package for Flutter with support for icons, colors, positions, stacking, actions, progress bars, RTL, and queuing.
