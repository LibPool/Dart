# android_desktop_mode

**Tag**: android, desktop-mode, samsung-dex, chromeos, multi-window, mobile, desktop

## 简介

Detects whether an Android device is running in desktop mode - Samsung DeX, ChromeOS, Android desktop windowing or a vendor PC mode - with the raw signals behind the verdict and a stream of changes.
