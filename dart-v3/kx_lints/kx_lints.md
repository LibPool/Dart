# kx_lints

**Tag**: lints, flutter, custom-lint, static-analysis, code-quality, mobile, ui, tooling

## 简介

Opinionated Flutter lint rules that catch real bugs via custom_lint — file length, widget structure, theme access, magic numbers, hardcoded strings, and more. Configurable per-rule thresholds, quick-fixes included.
