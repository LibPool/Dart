# val_highlight_flutter

**Tag**: syntax-highlighting, code-editor, code, highlight, highlighter, mobile, ui

## 简介

Flutter widgets for syntax-highlighted code: CodeView for display and CodeField for editing, with 55 languages, themes and smooth large files.
