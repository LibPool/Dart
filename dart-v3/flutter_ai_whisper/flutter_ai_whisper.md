# flutter_ai_whisper

**Tag**: mcp, flutter, developer-tools, vm-service, debugging, web, mobile, state-management

## 简介

MCP server that inspects and injects state in a running Flutter app over the Dart VM Service, supporting route navigation and Riverpod, Bloc and GetX.
