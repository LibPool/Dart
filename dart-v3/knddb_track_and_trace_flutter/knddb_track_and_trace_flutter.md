# knddb_track_and_trace_flutter

**Tag**: api, sdk, medicine, track-and-trace, knmdb, web, mobile, security

## 简介

Интеграция Dart/Flutter SDK KNMDB Track and Trace с Flutter: сохранение входа в защищённом хранилище платформы (Keychain, EncryptedSharedPreferences, libsecret) и восстановление сессии при запуске приложения.
