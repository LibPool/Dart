# sileo_flutter

**Tag**: web, mobile, desktop, ui

## 简介

An opinionated toast notification library for Flutter, ported from sileo-vue. Pure Dart/Flutter UI, no platform channels — works on Android, iOS, web, Windows, macOS and Linux.
