# pip_webrtc

**Tag**: web, mobile

## 简介

A fork of pip plugin for Picture in Picture, tuned for WebRTC iOS video calls. Uses the video call PiP approach (initWithActiveVideoCallSourceView) compatible with .playAndRecord audio session.
