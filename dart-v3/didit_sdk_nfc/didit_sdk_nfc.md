# didit_sdk_nfc

**Tag**: web, mobile

## 简介

Didit Identity Verification SDK for Flutter, pinned to the nfc native SDK variant (NFC passport reading without automatic capture). Same Dart API as didit_sdk - depend on exactly one of the didit_sdk packages. Generated from didit_sdk - do not edit by hand.
