# sinhala_unicode_converter

**Tag**: mobile

## 简介

A comprehensive Flutter/Dart package for converting legacy Sinhala fonts (FM Abhaya, FM Bamini, DL Manel, Kaputa) and Singlish text to Unicode. Features auto-detection capabilities and supports multiple Sinhala font formats for seamless text conversion in Sri Lankan applications.
