# dir_picker

**Tag**: dir-picker, directory, picker, ffi, jni, web, mobile, desktop

## 简介

A Flutter plugin for picking directories and listing file system entries, supporting Android, iOS, macOS, Windows, Linux, and Web via FFI and JNI.
