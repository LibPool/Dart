# nativemind_core

**Tag**: web, ui

## 简介

The light base of the NativeMind widgets: design tokens, theme, editions from configuration, primitives (with the handmade DealApp button family and dialogs), the PIN keypad, composites, navigation, charts, localization infrastructure and the icon API, with the essential Fugue icons. No plugins.
