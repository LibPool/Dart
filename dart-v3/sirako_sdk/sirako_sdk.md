# sirako_sdk

**Tag**: web, mobile, networking, security, tooling

## 简介

Sirako Merchant SDK — Official Dart/Flutter client for the Sirako payment API (https://dev-sirako.fidelity-market.com). Authenticate every request with your X-API-Key.
