# direct_pay_core

**Tag**: payments, payment-gateway, three-d-secure, web, mobile

## 简介

Core payment engine for Direct Pay (S2S) — server-to-server payment SDK for Flutter with SHA-512 hashing, 3D Secure WebView, and structured logging.
