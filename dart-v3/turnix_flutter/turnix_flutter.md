# turnix_flutter

**Tag**: web, mobile, tooling

## 简介

A Flutter plugin for fetching WebRTC ICE (STUN/TURN) credentials from the Turnix.io API, with support for advanced options like regions, TTL, client IP, and per-call parameters.
