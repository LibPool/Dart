# smart_emv

**Tag**: nfc, emv, payments, credit-card, mobile

## 简介

A pure Dart EMV NFC Reader library that supports reading payment cards (Visa, Mastercard, Amex, Discover, etc.) on Android & iOS using NFC ISO-7816 / APDU commands.
