# pulse_dio

**Tag**: monitoring, networking, observability, dio, sdk, web

## 简介

Dio interceptor for the Pulse Developer Intelligence SDK. Automatically captures HTTP request/response metrics from package:dio and forwards them to the Pulse event pipeline.
