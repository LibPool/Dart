# printing_ohos

**Tag**: mobile

## 简介

Plugin that allows Flutter apps to generate and print documents to compatible printers on ohos print.

## 官网

- 源码仓库: https://gitee.com/openharmony-sig/fluttertpc_printing
- pub.dev: https://pub.dev/packages/printing_ohos
