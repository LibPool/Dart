# utopia_cms

**Tag**: cms, admin, dashboard, crud, database, mobile

## 简介

Flutter CMS and admin panel toolkit - sortable, filterable CRUD tables and per-row actions over Firebase, Supabase, Hasura or any GraphQL backend.
