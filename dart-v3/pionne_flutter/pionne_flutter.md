# pionne_flutter

**Tag**: error-monitoring, crash-reporting, observability, pionne, mobile

## 简介

Error monitoring SDK for Flutter — Pionne. Auto-captures Flutter framework errors, unhandled async errors, AND native crashes (NSException, signals, ANR, NDK, OOM) via MetricKit (iOS 14+) and ApplicationExitInfo (Android 11+). Ships rich runtime context (Dart version, OS, device, locale) and tracks Release Health (crash-free user rate per release).
