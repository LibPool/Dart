# ag_flow

**Tag**: mobile, networking, state-management

## 简介

An opinionated Flutter framework: typed page-state, paginated list controllers, a type-keyed DI locator, guard-based routing over go_router, and a centralized networking layer — zero third-party state-management dependency.
