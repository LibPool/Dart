# milsat_dropdown_textfield

**Tag**: ui

## 简介

A DropdownTextfield is a material design TextField. The DropDownButton is a widget that we can use to select one unique value or multivalue from a set of values. This is Milsat's fork of dropdown_textfield, with search added to multi-select.
