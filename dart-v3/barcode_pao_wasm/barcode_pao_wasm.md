# barcode_pao_wasm

**Tag**: web, mobile

## 简介

Cross-platform barcode generation library for Flutter Web (WASM version). Supports 18 barcode types including QR, Code128, JAN, GS1, PDF417, DataMatrix and more. Powered by C++ WASM engine.
