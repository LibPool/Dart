# native_pdf_engine

**Tag**: pdf, html-to-pdf, webview, ffi, jni, web, mobile, desktop

## 简介

A high-performance, FFI-based Flutter package to convert HTML and URLs to PDF using native OS webviews (Android, iOS, macOS).
