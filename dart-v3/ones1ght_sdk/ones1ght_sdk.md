# ones1ght_sdk

**Tag**: indoor-positioning, uwb, location, geofencing, mobile

## 简介

OneS1ght indoor positioning SDK for Flutter. Wraps the OneS1ght iOS and Android SDKs: UWB positioning, zone enter / exit / dwell events and upload.
