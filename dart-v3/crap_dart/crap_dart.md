# crap_dart

**Tag**: code-quality, metrics, testing, coverage, lint, web, mobile, tooling

## 简介

CRAP metric analyzer and configurable quality gates for Dart and Flutter projects. Combines cyclomatic complexity with test coverage, enforces file size, golden test, l10n, accessibility and API documentation gates.
