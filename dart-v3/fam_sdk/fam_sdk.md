# fam_sdk

**Tag**: payment, sdk, api, subscription, mangopay, web, mobile

## 简介

Official Flutter/Dart SDK for FAM API - Type-safe payment and subscription integrations with zero third-party dependencies. Production-ready with automatic retries, comprehensive error handling, and webhook support.
