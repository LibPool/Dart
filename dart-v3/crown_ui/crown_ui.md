# crown_ui

**Tag**: ui, design-system, components, theme, responsive, web, mobile, desktop

## 简介

A comprehensive, CSS-like UI framework for Flutter with 60+ pre-built components, design tokens, themes, and multi-platform support. Inspired by web development and Kivy, Crown UI provides a modern alternative to Material Design with seamless support for iOS, Android, Windows, macOS, and Web.
