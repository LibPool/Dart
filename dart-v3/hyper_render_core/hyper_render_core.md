# hyper_render_core

**Tag**: flutter, html, rendering, richtext, css, mobile

## 简介

Core engine for HyperRender. Universal Document Tree, single-RenderObject layout with CSS float, Flexbox, Grid, CJK typography, AI streaming, and crash-free text selection.
