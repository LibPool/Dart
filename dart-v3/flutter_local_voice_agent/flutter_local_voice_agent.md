# flutter_local_voice_agent

**Tag**: speech-to-text, text-to-speech, speech-recognition, offline, voice, mobile

## 简介

Complete on-device speech-to-text and text-to-speech for Flutter. One local voice agent handles microphone, recognition, reply, and playback.
