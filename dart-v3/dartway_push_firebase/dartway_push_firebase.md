# dartway_push_firebase

**Tag**: dartway, push, notifications, firebase, fcm, web, mobile, tooling

## 简介

Firebase Cloud Messaging transport for DartWay push on Android, iOS and web — tokens, permission, opened notifications, and a web service worker whose click opens the notification's link.
