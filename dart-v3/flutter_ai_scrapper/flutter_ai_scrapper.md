# flutter_ai_scrapper

**Tag**: scraping, html, ai, on-device, gemma, web, mobile, serialization, state-management

## 简介

On-device AI web scraping for Flutter. Parses real HTML with a DOM, harvests JSON-LD and OpenGraph for free, and falls back to a local Gemma model or any OpenAI/Claude-compatible provider for schema-typed extraction.
