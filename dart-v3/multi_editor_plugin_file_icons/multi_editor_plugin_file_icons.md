# multi_editor_plugin_file_icons

**Tag**: editor, plugin, file-icons, icons, flutter, mobile

## 简介

File icons plugin for MultiEditor - provides beautiful colorful icons for 150+ file types via Devicon CDN with lazy SVG loading and LRU caching.
