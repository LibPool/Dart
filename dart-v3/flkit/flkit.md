# flkit

**Tag**: mobile, tooling

## 简介

FlKit is a CLI tool to export Flutter projects as zip files. More features like code optimization coming soon!

- 源码仓库: https://github.com/mubashardev/flkit.git
- pub.dev: https://pub.dev/packages/flkit

- pub.dev: https://pub.dev/packages/flkit
