# gemini_tts_wrapper

**Tag**: tts, gemini, audio, google, flutter, web, mobile, ui, tooling

## 简介

One-shot Gemini TTS REST client for Flutter that returns audio bytes (Uint8List) and includes an in-memory just_audio source.
