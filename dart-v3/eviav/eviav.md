# eviav

**Tag**: web, mobile

## 简介

SDK oficial de Eviav para Dart y Flutter. Wrapper tipado de la API REST de mapas (api.eviav.com): geocoding, ruteo, places, isócronas, fleet y mas.

## 官网

- 主页: https://eviav.com
- 源码仓库: https://github.com/eviav-platform/eviav-dart
- 文档: https://eviav.com/docs
- pub.dev: https://pub.dev/packages/eviav
