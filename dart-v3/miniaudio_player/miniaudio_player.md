# miniaudio_player

**Tag**: audio, miniaudio, sound, player

## 简介

Ultra-low-resource cross-platform audio player and DSP engine using miniaudio. Features equalizer, reverb, limiter, crossfeed, pitch, rate, and real-time visualizer.
