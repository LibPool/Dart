# natlas

**Tag**: nlp, llm, nigeria, translation, chatbot, mobile

## 简介

Dart and Flutter SDK for N-ATLAS, Nigeria's multilingual language model for English, Hausa, Igbo and Yoruba. Chat, streaming, translation and summaries.
