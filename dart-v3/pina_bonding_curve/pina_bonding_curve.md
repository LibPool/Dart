# pina_bonding_curve

**Tag**: solana, launchpad, bonding-curve, blockchain, mobile, ui, state-management, tooling

## 简介

Dart and Flutter client for the Pina Bonding Curve launchpad on Solana: instruction builders, account decoders, PDAs, events, and errors generated from the program IDL.
