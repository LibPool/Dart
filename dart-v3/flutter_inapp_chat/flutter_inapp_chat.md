# flutter_inapp_chat

**Tag**: chat, firebase, firestore, supabase, appwrite, web, mobile, ui

## 简介

A simple, complete chat system for Flutter with ready-to-use UI, image sharing, and view models, backed by Cloud Firestore, Appwrite, or Supabase.
