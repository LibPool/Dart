# csp_amap_flutter_map

**Tag**: web, mobile, ui

## 简介

A Flutter plugin for AMap (Gaode Map) SDK with support for Android and iOS platforms.
This is the pub.dev compatible version. For full HarmonyOS support, please visit our Gitee repository.
Features include map display, markers, polylines, polygons, location services, POI search, API key
management, privacy compliance, and custom styling. The base library (csp_amap_flutter_base) is
bundled into this package (lib/base/), so no extra dependency is required.
