# polaris_xlog

**Tag**: logging, xlog, mars, ffi, flutter-plugin, mobile, security

## 简介

Flutter plugin for Tencent mars-xlog: high-performance daily-rotated local logs with optional encryption, pure-Dart decoding, and FFI hot-path logging.
