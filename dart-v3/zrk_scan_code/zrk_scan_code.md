# zrk_scan_code

**Tag**: mobile

## 简介

行业最强扫码体验 —— 一维码/二维码秒识，弱光、模糊、倾斜也能稳稳扫出。Android 用 CameraX + ML Kit，iOS 用 AVFoundation + Vision。iOS 同时支持 CocoaPods 与 SPM（Swift Package Manager）依赖管理。
