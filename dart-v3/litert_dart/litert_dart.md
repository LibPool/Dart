# litert_dart

**Tag**: llm, ffi, gemma, on-device, ai, mobile

## 简介

On-device LiteRT-LM (.litertlm) LLM inference for pure Dart via dart:ffi. No Flutter. Load a model (Gemma, Qwen, DeepSeek…) and generate text locally.
