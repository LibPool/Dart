# dotdart

**Tag**: flutter, assets, codegen, lottie, svg, web, mobile, desktop, ui, tooling

## 简介

Build-time Flutter asset compiler that generates typed, optimized widgets from SVG, Lottie, images, and GIFs for mobile, web, and desktop.
