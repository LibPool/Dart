# hallmark_tokens

**Tag**: design-system, design-tokens, theme, oklch, accessibility, web, mobile, ui, security

## 简介

Design tokens for Hallmark-Flutter. Five themes that refuse to look AI-generated, expressed as a Flutter ThemeExtension. Colour tokens are authored in OKLCH and gamut-mapped to sRGB at parse time, so Flutter output matches what a browser renders for the same token.
