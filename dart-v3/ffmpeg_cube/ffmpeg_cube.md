# ffmpeg_cube

**Tag**: video, audio, ffmpeg, media, transcoding, mobile

## 简介

Cross-platform audio/video processing and playback SDK for Flutter. 跨平台影音處理與播放 SDK，支援轉檔、裁剪、縮圖、合併、混音、字幕、播放等功能。
