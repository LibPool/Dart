# flutter_tca_generator

**Tag**: mobile, state-management, tooling

## 简介

A Flutter library that provides a simple and efficient way to implement The Composable Architecture (TCA)-like architecture in Flutter apps.
This package simplifies state management by using a declarative and modular approach, inspired by TCA from Swift.
