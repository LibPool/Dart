# xue_hua_animated_svg

**Tag**: svg, animation, flutter, smil, vector-graphics, mobile, ui

## 简介

Pure Dart animated SVG for Flutter: SMIL/CSS precompiled to a typed AST, 60/120fps paint with static subtree Picture caching, zero native deps.
