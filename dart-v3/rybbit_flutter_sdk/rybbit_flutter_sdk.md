# rybbit_flutter_sdk

**Tag**: analytics, rybbit, tracking, privacy, events, mobile

## 简介

Flutter SDK for Rybbit Analytics. Track screen views, events, errors, and user identification with offline queue, GA4 events, and multi-platform support.
