# lightening_wallet

**Tag**: bitcoin, lightning, wallet, payments, ffi, mobile, networking

## 简介

High-performance Lightning wallet for Flutter using Rust FFI with LDK-node. Supports Bitcoin on-chain and Lightning Network payments.
