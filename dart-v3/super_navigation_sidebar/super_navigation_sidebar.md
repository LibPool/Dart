# super_navigation_sidebar

**Tag**: mobile, ui, state-management

## 简介

A themeable, responsive navigation sidebar for Flutter with expanded, rail, and drawer modes, typed NavNode<T> trees, search, favorites, recents, state persistence, localization, RTL support, and a reusable NavigationSearchView that opens as a dialog or modal bottom sheet.
