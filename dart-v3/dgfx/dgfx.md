# dgfx

**Tag**: graphics, rasterizer, vector, canvas, opentype, tooling

## 简介

A 2D graphics engine in pure Dart: analytic anti-aliased rasterization, gradients, patterns, stroking, clipping and OpenType text. No dependencies.
