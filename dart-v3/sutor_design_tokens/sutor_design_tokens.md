# sutor_design_tokens

**Tag**: design-tokens, design-system, theming, mobile, ui

## 简介

Sutor Design Tokens — Flutter constants for colors, spacing, typography, motion, elevation, and other design primitives across light, dark, and high-contrast themes. Generated from the DTCG source of truth via Style Dictionary.
