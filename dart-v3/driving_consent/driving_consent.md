# driving_consent

**Tag**: consent, privacy, gdpr, automotive, navigation, state-management

## 简介

Privacy-first per-purpose, jurisdiction-aware consent state machine where UNKNOWN equals DENIED. Jidoka gates, pluggable storage. Pure Dart.
