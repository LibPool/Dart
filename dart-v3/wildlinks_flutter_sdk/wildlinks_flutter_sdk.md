# wildlinks_flutter_sdk

**Tag**: deep-linking, universal-links, app-links, url-shortener, mobile, ui

## 简介

Flutter SDK for the WildLinks smart link platform - Universal Link / App Link resolution and deferred deep link matching for apps built with Flutter.
