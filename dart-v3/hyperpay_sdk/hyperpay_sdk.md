# hyperpay_sdk

**Tag**: payment, hyperpay, oppwa, mada, mobile, ui

## 简介

Flutter plugin for HyperPay (OPPWA) Mobile SDK v7.11.0. ReadyUI, CustomUI, Apple Pay, Google Pay, MADA, tokenization, and 3DS2.
