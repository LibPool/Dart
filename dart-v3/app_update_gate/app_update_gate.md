# app_update_gate

**Tag**: web, mobile, ui, tooling

## 简介

Source-agnostic force/optional update gate for Flutter. Bring your own update policy source (REST API or any backend), guarded by a real store-availability check (Play In-App Update on Android, iTunes lookup on iOS) so users are never locked out of a build that is not actually live.
