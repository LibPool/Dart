# fluid_island_hud

**Tag**: dynamic-island, hud, notification, animation, ui, mobile, state-management

## 简介

A fluid morphing Dynamic Island and floating pill notification HUD for Flutter apps. Features spring physics, swipe-to-dismiss, and compact/expanded states.
