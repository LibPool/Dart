# material_glimmer_ui

**Tag**: glimmer, design-system, ui, theme, widgets, mobile

## 简介

A Flutter UI kit of glass surfaces and lit edges. An app widget, a theme, a full token set and a widget library. Inspired by Jetpack Compose Glimmer and Material Design.
