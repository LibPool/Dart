# flutter_xprinter_sdk

**Tag**: printer, thermal, esc-pos, xprinter, bluetooth, mobile

## 简介

Flutter plugin for XPrinter thermal receipt printers. Cyrillic-safe text, Floyd-Steinberg image dithering, BLE / Classic Bluetooth / USB / TCP transports.
