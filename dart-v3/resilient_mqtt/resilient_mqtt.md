# resilient_mqtt

**Tag**: mqtt, iot, reconnect, networking, state-management, tooling

## 简介

A resilience layer for mqtt_client: exponential backoff with jitter, connection state as a Stream, automatic re-subscribe and typed decoders. Pure Dart.
