# spigcow_doctor

**Tag**: mobile, ui, serialization, tooling

## 简介

Analyzes Flutter projects for memory leaks, missing const, heavy build() work and architecture issues — a "React Doctor" for Flutter with a health score, baselines and CI-ready reports (SARIF, JSON, HTML).
