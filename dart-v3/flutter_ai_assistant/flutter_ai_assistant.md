# flutter_ai_assistant

**Tag**: ai, assistant, agent, voice, llm, mobile, ui

## 简介

Drop-in AI assistant for Flutter apps. Reads UI via Semantics tree, executes multi-step tasks autonomously, and supports Gemini (Firebase AI Logic), Claude, and OpenAI.
