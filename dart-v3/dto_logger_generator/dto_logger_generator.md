# dto_logger_generator

**Tag**: json, codegen, build-runner, dto, logging, ui, serialization, tooling

## 简介

build_runner code generator for dto_logger's @DtoLog annotation. Generates fromJson, toJson, copyWith and equality that log nulls, missing keys and type mismatches in debug builds.
