# filemaker_odata_api

**Tag**: filemaker, claris, odata, rest, database, web, ui, tooling

## 简介

A typed Dart client for the Claris FileMaker OData v4 API, with a fluent query builder for $filter, $select, $orderby, $top and $skip.
