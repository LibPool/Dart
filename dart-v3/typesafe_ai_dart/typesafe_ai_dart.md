# typesafe_ai_dart

**Tag**: ai, typesafe, jev-ai, sdk, http, web, ui, networking

## 简介

Unofficial Dart SDK for the TypeSafe AI System One API (Jev). Typed questions and answers, retries, timeouts and typed events, built for servers.
