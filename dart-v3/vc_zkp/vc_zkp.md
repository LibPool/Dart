# vc_zkp

**Tag**: dart, mobile, desktop, ui

## 简介

VCs for ZKPs — Dart. Native Poseidon/EdDSA via prebuilt Rust binaries (macOS, iOS, Android, Linux, Windows). App developers do not need Rust installed.
