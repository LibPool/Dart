# material_async_button

**Tag**: button, loading, async, material, widget, ui, state-management

## 简介

Drop-in loading state for Elevated, Filled, Outlined, Text, Icon and FloatingAction Material buttons — spinner while onPressed runs, AsyncButtonTheme, AsyncButtonController.
