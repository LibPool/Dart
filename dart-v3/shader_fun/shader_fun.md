# shader_fun

**Tag**: shaders, shadertoy, mobile, ui

## 简介

Run and experiment with Shadertoy GLSL shaders in Flutter. Features multi-pass ping-pong buffers, audio/mic reactive visualizers, and live interactive widget textures.
