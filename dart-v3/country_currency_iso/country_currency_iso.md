# country_currency_iso

**Tag**: web, ui

## 简介

Pure Dart ISO 3166 country ↔ ISO 4217 currency mapper. Africa-first tables (OHADA / WAEMU / CEMAC + common corridors), suitable for PoS defaults, billing, and web forms.
