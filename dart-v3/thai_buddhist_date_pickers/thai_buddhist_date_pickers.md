# thai_buddhist_date_pickers

**Tag**: mobile, ui

## 简介

Flutter calendar and pickers (dialog/fullscreen, range, multi) for Thai Buddhist (พ.ศ.) and Gregorian (ค.ศ.), built on thai_buddhist_date.
