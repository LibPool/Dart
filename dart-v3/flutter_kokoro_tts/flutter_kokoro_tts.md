# flutter_kokoro_tts

**Tag**: text-to-speech, tts, kokoro, onnx, speech-synthesis, web, mobile, ui

## 简介

On-device Kokoro TTS for Flutter — high-quality text-to-speech using ONNX and espeak-ng, with multiple voices. No cloud API required.
