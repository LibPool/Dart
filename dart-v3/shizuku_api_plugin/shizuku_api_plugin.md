# shizuku_api_plugin

**Tag**: shizuku-api, adb, shell, root, system, web, ui

## 简介

Shizuku API is the API provided by Shizuku and Sui. With Shizuku API, you can call your Java/JNI code with root/shell (ADB) identity.
