# stun

**Tag**: networking, nat, stun, webrtc, p2p, web

## 简介

Complete STUN (RFC 5389/5780) implementation for NAT traversal, public IP discovery, and NAT type detection. Supports IPv4/IPv6 dual-stack, P2P applications, and WebRTC.
