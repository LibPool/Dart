# simple_native_vision

**Tag**: vision, ai, camera, tflite, onnx, web, mobile

## 简介

Computer vision & on-device AI extension for Flutter, providing MediaPipe face landmark detection, ONNX Runtime corner detection, TFLite object detection, and active liveness analysis.
