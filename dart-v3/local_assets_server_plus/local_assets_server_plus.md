# local_assets_server_plus

**Tag**: web, ui, networking, testing

## 简介

HTTP Server which serves local assets as URL link. Usecase - simplify workflow with mock data. Instead of creating dedicated logic/intercepters/UI workarounds, it creates a server, which returns an actual path to an asset, which works great with CachedNetworkImage/Image.network and etc.
