# ios26_bottom_navigationbar

**Tag**: navigation, bottom-navigation, ios, glassmorphism, widget, mobile, ui

## 简介

A customizable iOS 26 frosted glass floating bottom navigation bar for Flutter with gliding pill indicator, ambient fade, and full theme reactivity.
