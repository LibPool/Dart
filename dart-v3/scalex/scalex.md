# scalex

**Tag**: web, mobile, desktop

## 简介

Simple responsive sizing for Flutter with syntax like 4.w, 4.h, 4.sp. Smart scaling on mobile/tablet, fixed sizes on desktop. Works seamlessly across web, mobile, and desktop platforms.
