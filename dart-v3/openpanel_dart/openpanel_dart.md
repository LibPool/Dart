# openpanel_dart

**Tag**: analytics, openpanel, web, mobile, networking, tooling

## 简介

Pure Dart analytics client for OpenPanel. Track events, identify users and manage groups via the HTTP API. Works on Flutter as well as plain Dart (CLI, server, web).
