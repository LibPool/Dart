# bd_map

**Tag**: map, bangladesh, widget, geo, visualization, web, mobile, ui, serialization

## 简介

Interactive drill-down maps of Bangladesh for Flutter, from division to union, with a geography API and data coloring from JSON or an API. Pure Dart, no assets or dependencies.
