# malipopay_checkout

**Tag**: payments, checkout, mobile-money, tanzania, fintech, web, mobile

## 简介

Malipopay hosted checkout for Flutter. Opens the merchant's branded Malipopay payment page (card and mobile money) in a WebView and returns the result.
