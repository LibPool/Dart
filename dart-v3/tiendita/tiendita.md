# tiendita

**Tag**: web, mobile, ui, networking, tooling

## 简介

A Flutter package for building modern e-commerce applications with seamless API integration. Tiendita provides reusable widgets, data models, and networking utilities specifically designed for marketplace and shopping features. Built with Dio for efficient HTTP communication and structured to support scalable Flutter mobile projects.
