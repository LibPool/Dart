# cux_buildnumber

**Tag**: git, release, ci, ui, tooling

## 简介

Monotonic build numbers shared through git refs — a Dart port of git-buildnumber.sh v1.3. A library plus a bin/ entrypoint; the only runtime dependency is git on PATH.
