# kata_chat_core

**Tag**: chat, chatbot, sdk, mqtt, web, mobile, ui, tooling

## 简介

Headless Kata Platform chat client for Flutter — iOS, Android and Web. Send messages to a Kata Platform bot and receive its replies over MQTT, with no UI attached.
