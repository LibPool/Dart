# gshock_api_dart

**Tag**: web, mobile, desktop, testing

## 简介

Cross-platform Dart & Flutter library for Casio G-Shock Bluetooth watches. Pure-Dart core with swappable BLE transports (Flutter, Linux BlueZ, and Mock).
