# liquid_glass_ui_kit

**Tag**: ui, theme, glassmorphism, ios, cupertino, web, mobile, desktop

## 简介

An accessible, customizable Liquid Glass design system for Flutter with translucent themes and ready-made widgets for mobile, web, and desktop.
