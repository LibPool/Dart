# livqeno_rtc

**Tag**: webrtc, video-call, video, realtime, web, mobile

## 简介

Livqeno SDK for Flutter — join a room, publish camera and microphone, render participants. Hides WebRTC, SDP, ICE, STUN, TURN and the media server behind a small typed API.
