# dox_mysql_native

**Tag**: database, state-management, tooling

## 简介

Fast native MySQL and MariaDB client for Dart, the default MySQL driver of the Dox ORM. Rust (mysql_async) runs the pool and a prepared statement cache. Dart gets typed rows.
