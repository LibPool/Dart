# ousi_ui

**Tag**: ui, widgets, design-system, components, theme, mobile

## 简介

A beautiful, production-ready Flutter UI library with 35+ components, smooth micro-interactions, OKLCH colors, and full dark mode. Inspired by HeroUI.
