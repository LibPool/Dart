# aud_midi

**Tag**: midi, audio, music, web, mobile, desktop, networking

## 简介

MIDI for Dart and Flutter apps on iOS, macOS, Android, Windows, Linux and the web: USB, Bluetooth LE, virtual and network MIDI in a MIDI isolate
