# skio_usb_serial

**Tag**: usb, serial-port, esp32, web-serial, android, web, mobile, ui

## 简介

USB serial for Flutter on Android (USB OTG) and web (Web Serial): talk to ESP32, Arduino, STM32 and CH340, CP210x, FTDI adapters. JNI, no platform channels.
