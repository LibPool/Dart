# keybay

**Tag**: security, secrets, keychain, keystore, credentials, mobile

## 简介

Cross-platform secret storage for Dart without Flutter: native Data Protection Keychain items on Apple platforms where available, or an authenticated encrypted file with an OS-protected key.
