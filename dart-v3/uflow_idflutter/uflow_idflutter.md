# uflow_idflutter

**Tag**: authentication, subscription, supabase, uflow, otp, web, mobile, ui, security

## 简介

Flutter SDK for UFlow ID (id.uflow.uz) - email OTP auth without redirects, server-side subscriptions, and UFlow branded widgets.
