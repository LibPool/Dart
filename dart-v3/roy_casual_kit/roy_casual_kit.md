# roy_casual_kit

**Tag**: widgets, game, ui, flame, casual-game, mobile

## 简介

A casual/idle-game SDK for Flutter (GetX + Flame): storage, i18n, audio, haptics, reminders, economy/progression, live-ops tooling, and a candy-styled widget kit.
