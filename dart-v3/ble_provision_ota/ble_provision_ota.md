# ble_provision_ota

**Tag**: bluetooth, ble, provisioning, ota, firmware-update, mobile

## 简介

Cross-platform Flutter plugin for parameterized BLE Wi-Fi provisioning, resilient framed transport, resumable OTA, and Android SPP fallback.
