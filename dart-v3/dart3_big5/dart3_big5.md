# dart3_big5

**Tag**: web, mobile, desktop

## 简介

A Dart 3+ compatible package providing encode and decode methods for Big5 character encoding. Supports null safety and works on all Dart platforms (web, server, desktop, mobile). Perfect for working with traditional Chinese text and legacy systems using Big5 encoding.
