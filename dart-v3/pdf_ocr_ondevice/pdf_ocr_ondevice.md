# pdf_ocr_ondevice

**Tag**: pdf, ocr, text-recognition, on-device, scanned-documents

## 简介

On-device OCR engine for dart_pdf_editor that adds a selectable, searchable text layer to scanned PDFs with a downloadable PP-OCR ONNX model.
