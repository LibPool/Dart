# health_forge_strava

**Tag**: health, strava, fitness, workout, rest-api, web, security

## 简介

Strava REST API adapter for health_forge — fetches workouts, heart rate, calories, distance, and elevation via OAuth 2.0 PKCE with rate limiting.
