# fluttersdk_dusk

**Tag**: mcp-server, e2e-testing, ai-agents, testing, flutter, web, mobile, tooling

## 简介

Flutter E2E driver for LLM agents and CI. 36 CLI commands and 35 MCP tools drive a running app over VM Service extensions; no flutter_test harness needed.
