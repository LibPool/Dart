# medplat_core

**Tag**: flutter, utilities, networking, database, mobile, state-management

## 简介

Flutter infrastructure library providing DI, networking (Dio/Retrofit), SQLite, BLoC base classes, analytics contracts, geo-location, and PDF/Excel export utilities.
