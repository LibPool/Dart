# netshake

**Tag**: network, debugging, devtools, testing, http, web, ui, networking, tooling

## 简介

Shake your phone to open an in-app network debugger. Throttle latency and bandwidth, simulate slow 3G and offline, inject HTTP errors, inspect every request. Debug builds only.
