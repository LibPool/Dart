# cobalt_bloc

**Tag**: dependency-injection, di, bloc, state-management, ui

## 简介

Lets an Cobalt scope close the blocs it built — a mixin that bridges bloc's close() to Cobalt's AsyncDisposable, and the function to name where a mixin will not reach.
