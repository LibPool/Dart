# flutter_ffmpeg_sw_player

**Tag**: mobile, desktop

## 简介

一个基于 FFmpeg 管道输出的 Flutter 视频软渲染插件，专为解决 Linux 平台下视频播放的稳定性与依赖痛点而设计。
