# tinygo_machine

**Tag**: embedded, tinygo, microcontroller

## 简介

Board-agnostic dart2tinygo bindings for TinyGo's common machine package: GPIO and ADC implemented (#21); PWM not yet (see docs/writing_bindings.md).
