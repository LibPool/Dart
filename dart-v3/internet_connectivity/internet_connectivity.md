# internet_connectivity

**Tag**: mobile, networking

## 简介

A comprehensive Flutter plugin for getting the update on network or internet connectivity status changed it has basically four variables CONNECTED , DISCONNECTED,AIRPLANE_MODE_ON,AIRPLANE_MODE_OFF
