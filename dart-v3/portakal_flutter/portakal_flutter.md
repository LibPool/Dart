# portakal_flutter

**Tag**: printer, thermal-printer, flutter, label, esc-pos, mobile, ui

## 简介

Universal printer SDK for Flutter — Widgets and preview renderers for TSC, ZPL, EPL, ESC/POS, CPCL, DPL, IPL, SBPL, and Star PRNT.
