# ops_calendar

**Tag**: calendar, widget, event, appointment, month-view, mobile, ui, state-management

## 简介

Ribbon-based multi-day event calendar for Flutter. Month view with swipeable navigation. State-management agnostic — works with BLoC, Riverpod, Provider.
