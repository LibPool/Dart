# gt4_web

**Tag**: geetest, captcha, gt4, web, verification, mobile, ui, testing

## 简介

GeeTest CAPTCHA v4 (gt4) for Flutter Web, built on the official gt4.js with an API compatible with the official gt4_flutter_plugin.
