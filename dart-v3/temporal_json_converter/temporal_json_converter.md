# temporal_json_converter

**Tag**: date, time, temporal, datetime, json, serialization

## 简介

JSON converters for the Temporal date/time types. Provides a TemporalJsonConverter class with static const converters for use with json_serializable (@TemporalJsonConverter.plainDate, etc.).
