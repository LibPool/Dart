# zegoweb_ui

**Tag**: web, mobile, ui

## 简介

Flutter-native call UI built on zegoweb core. Drop-in ZegoCallScreen widget with composable layouts, controls, and ThemeExtension theming. Not affiliated with or endorsed by ZEGOCLOUD.
