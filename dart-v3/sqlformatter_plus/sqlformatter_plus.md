# sqlformatter_plus

**Tag**: mobile, database

## 简介

A lightweight Flutter package that formats raw SQL queries into human-readable, properly indented output. Supports SELECT, JOIN, WHERE, GROUP BY, ORDER BY, HAVING, LIMIT, UNION, INSERT, UPDATE and more.
