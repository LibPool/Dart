# openpay_bbva

**Tag**: web, mobile, desktop, networking

## 简介

A Flutter plugin for iOS and Android that tokenizes payments via the Openpay BBVA platform. Supports Web, Windows, macOS, and Linux for card tokenization via HTTP.
