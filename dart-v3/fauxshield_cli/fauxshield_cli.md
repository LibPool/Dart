# fauxshield_cli

**Tag**: web, serialization, tooling

## 简介

Command line client for the FauxShield anti-counterfeit platform. Drive the whole API from a terminal or a script: products, batches, serialized units, verifications, fraud alerts, recalls, webhooks, simulations, and the audit log.
