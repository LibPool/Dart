# mcp_datastore_sqlite

**Tag**: mcp, datastore, sqlite, database, adapter, tooling

## 简介

SQLite DbAdapter for mcp_datastore — drives the db.* verbs (query / exec / tx) against a SQLite database via package:sqlite3. Sibling adapter package; mcp_datastore core stays DB-client-free.
