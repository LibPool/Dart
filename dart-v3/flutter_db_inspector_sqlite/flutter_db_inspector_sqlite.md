# flutter_db_inspector_sqlite

**Tag**: sqlite, sqflite, database, inspector, debugging, mobile

## 简介

SQLite adapter for Flutter DB Inspector. Works with sqflite, sqflite_common_ffi, Floor and any SQLite executor; also powers the Drift adapter.
