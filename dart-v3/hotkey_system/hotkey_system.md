# hotkey_system

**Tag**: hotkey, shortcuts, keyboard, macos-shortcuts, hardware-keyboard, mobile, desktop

## 简介

This plugin allows Flutter desktop apps to defines system/inapp wide hotkey (i.e. shortcut).
