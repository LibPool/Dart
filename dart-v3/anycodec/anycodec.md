# anycodec

**Tag**: codec, video, audio, ffi, rust, web, mobile

## 简介

Cross-platform audio/video codec engine for Dart and Flutter: platform-native codecs first (MediaCodec, Media Foundation, VideoToolbox, GStreamer, WebCodecs) with an always-available software fallback.
