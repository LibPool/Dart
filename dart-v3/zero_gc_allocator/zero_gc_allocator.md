# zero_gc_allocator

**Tag**: ffi, memory, performance, native, allocator, mobile

## 简介

Ultra-high-performance manual memory management for Dart/Flutter using FFI, offering arena, pool, and slab allocators outside the Dart GC for zero GC pressure and deterministic O(1) allocation latency in latency-critical systems.
