# grimoire

**Tag**: ebook, reader, epub, viewer, mobile, ui

## 简介

Calibre-style Flutter ebook reader built on Unseal, with paginated or scrolling layouts, navigation, search, bookmarks, highlights, themes, and text selection hooks.
