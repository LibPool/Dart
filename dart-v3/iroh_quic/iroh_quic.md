# iroh_quic

**Tag**: iroh, p2p, networking, quic, ffi, mobile, ui, tooling

## 简介

Pure-Dart binding for iroh 1.0 - peer-to-peer QUIC networking with endpoints, connections, streams, relays, and address lookup over the Rust core. No Flutter: load a signed prebuilt native library via `dart run iroh_quic:setup` (or build it with cargo), loaded over dart:ffi (flutter_rust_bridge runtime).
