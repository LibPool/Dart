# lexical_flutter

**Tag**: mobile, ui, state-management, tooling

## 简介

Flutter rendering, selection and input layer for lexical_core: a dirty-set reconciler, one render object per block, InlineSpan building with a bidirectional offset map, theming and IME integration.
