# zkfinger10_16kb

**Tag**: fingerprint, zkteco, biometrics, android, page-size-16kb, mobile

## 简介

ZKTeco fingerprint scanner plugin (enroll, identify, verify) for Android, patched to run on 16 KB page size devices. Fork of zkfinger10.
