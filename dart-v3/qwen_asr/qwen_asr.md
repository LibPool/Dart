# qwen_asr

**Tag**: speech-recognition, asr, machine-learning, audio, web, mobile

## 简介

On-device Qwen3-ASR speech-to-text for Flutter: offline and live-streaming transcription powered by a pure Rust engine. No cloud, no server.
