# apollovm_wasm

**Tag**: vm, wasm, webassembly, compiler, web

## 简介

Native (Dart VM) WebAssembly execution for ApolloVM: the wasm_run-backed WasmRuntime, kept out of the core package so apollovm stays FFI-free.
