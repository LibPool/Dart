# eid_icao

**Tag**: eid, icao, passport, mrz, smartcard, security

## 简介

Reads ICAO 9303 passports and identity cards over any eid transport: BAC and PACE, MRZ, face image and data groups, with Passive, Chip and Active Authentication.
