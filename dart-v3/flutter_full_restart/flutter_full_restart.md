# flutter_full_restart

**Tag**: restart, relaunch, app-lifecycle, swift-package-manager, web, mobile, desktop

## 简介

Fully restart a Flutter app: kill the process and cold-start it. Android, iOS, macOS, Web, Windows, Linux. Swift Package Manager ready.
