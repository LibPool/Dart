# trace_agent_timeline

**Tag**: ai, agent, timeline, streaming, widget, mobile, ui

## 简介

An agent run timeline for Flutter: streaming reasoning, tool calls, parallel steps and retries, with adapters for OpenAI, Anthropic and the Vercel AI SDK.
