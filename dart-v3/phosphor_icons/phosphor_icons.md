# phosphor_icons

**Tag**: icons, phosphor, ui, flutter, mobile

## 简介

Implementation of Phosphor Icons for Flutter. 1500+ icons in Thin, Light, Regular, Bold, Fill, and Duotone. Compatible with Flutter 3.43+.
