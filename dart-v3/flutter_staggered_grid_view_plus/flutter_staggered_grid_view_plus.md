# flutter_staggered_grid_view_plus

**Tag**: staggered-grid, masonry, grid, layout, widgets, mobile, ui

## 简介

A maintained successor and migration of flutter_staggered_grid_view providing a collection of Flutter grid layouts (staggered, masonry, quilted, woven, etc.) for current Flutter versions.
