# byte_track_dart

**Tag**: ui

## 简介

A pure-Dart, detector-agnostic multi-object tracking framework with a pluggable algorithm architecture. Ships with ByteTrack, DeepSORT, and OC-SORT built in, and lets you add BoT-SORT, StrongSORT, or your own algorithm via a simple strategy interface. Feed it bounding boxes from any YOLO model -- v5 through YOLO26, or any detector at all -- and get back stable object IDs across frames.
