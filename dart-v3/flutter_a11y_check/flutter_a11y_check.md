# flutter_a11y_check

**Tag**: accessibility, a11y, testing, widget-test, wcag, mobile, ui

## 简介

One-line accessibility audit for Flutter widget tests: tap targets, labels, contrast, images, 200% text, duplicate labels and focus order, in a readable report.
