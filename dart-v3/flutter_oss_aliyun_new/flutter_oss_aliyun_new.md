# flutter_oss_aliyun_new

**Tag**: mobile

## 简介

Flutter plugin for Alibaba Cloud OSS: direct upload, multipart/resumable upload, auto mode (size-based routing), concurrent queue, STS auto-refresh, real-time progress, pause/resume/cancel, and cross-bucket copy/move.
