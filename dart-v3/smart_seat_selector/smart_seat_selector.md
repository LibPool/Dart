# smart_seat_selector

**Tag**: booking, cinema, widget, seat-selector, seat-picker, mobile, ui

## 简介

A universal grid-based seat selection widget for Flutter supporting Cinemas, Buses, Flights, and Event halls with zoom and pan interaction.
