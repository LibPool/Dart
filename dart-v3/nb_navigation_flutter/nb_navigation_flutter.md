# nb_navigation_flutter

**Tag**: mobile

## 简介

A Flutter plugin for Nextbillion.ai Navigation SDK, providing turn-by-turn navigation.

## 官网

- 源码仓库: https://github.com/nextbillion-ai/nextbillion-navigation-flutter
