# dragonbones_flutter

**Tag**: dragonbones, skeletal-animation, gamedev, canvas, mobile, ui

## 简介

Draw DragonBones skeletal animations on a Flutter Canvas: update(dt) + render(Canvas), plus a ready-made widget and no game engine dependency.
