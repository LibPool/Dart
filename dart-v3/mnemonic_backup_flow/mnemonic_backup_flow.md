# mnemonic_backup_flow

**Tag**: wallet, bip39, mnemonic, security, rwa, mobile, tooling

## 简介

Recovery-phrase reveal, verification and import screens for Flutter wallets, with a PIN gate, screenshot-protection hooks, random-word checks and clipboard clearing.
