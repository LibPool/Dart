# flutter_n8n_chat_ui

**Tag**: web, mobile, ui

## 简介

A comprehensive Flutter chat UI package designed for seamless n8n webhook integrations. Features real-time messaging with text, audio recording, image sharing, message caching, pagination, custom theming, and multilingual support across all platforms.
