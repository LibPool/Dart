# super_tree_field

**Tag**: flutter, widgets, treeview, hierarchy, accessibility, mobile, ui

## 简介

Super Tree — a GeniusLink design-system Flutter package providing a recursive, generic, keyboard-first hierarchy component for arbitrary typed data. Supports search, expansion, selection, inline editing, drag-and-drop, custom cells, scrolling, LTR/RTL, and light/dark themes.
