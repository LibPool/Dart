# android_otp_kit

**Tag**: otp, sms, autofill, authentication, android, mobile, security, tooling

## 简介

Android OTP login in one package: Phone Number Hint, SMS Retriever (zero-tap), SMS User Consent fallback, app hash helper + CLI, and a self-filling OTP field.
