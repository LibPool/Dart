# spotlight_tour_kit

**Tag**: mobile, ui

## 简介

A zero-dependency, native Flutter spotlight tour: dim scrim, highlighted cutout, and step-by-step tooltips that require a real tap on the highlighted widget to advance, game-tutorial style.
