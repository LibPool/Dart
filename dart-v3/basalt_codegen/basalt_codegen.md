# basalt_codegen

**Tag**: orm, code-generation, build-runner, database, ui, tooling

## 简介

build_runner code generator for the Basalt Dart ORM — derives row readers and INSERT/UPDATE builders from @Queryable, @Insertable, and @AsChangeset.
