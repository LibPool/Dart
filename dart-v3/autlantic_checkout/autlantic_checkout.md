# autlantic_checkout

**Tag**: payments, checkout, billing, usdc, autlantic, web, mobile, security

## 简介

Autlantic Billing mobile Checkout presenter for Flutter. Opens hosted checkoutUrl via ASWebAuthenticationSession (iOS) and Chrome Custom Tabs (Android). Never accepts API keys.
