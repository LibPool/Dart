# sqlite_ultra

**Tag**: sqlite, database, orm, reactive, flutter, mobile

## 简介

A type-safe SQLite wrapper for Flutter with auto migrations, reactive tables, smart caching, typed queries, and isolate-based background execution for fast and safe app development.
