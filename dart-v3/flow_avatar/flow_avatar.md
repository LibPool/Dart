# flow_avatar

**Tag**: avatar, animation, ui, flutter, generative, mobile, state-management

## 简介

Deterministic animated multi-pattern avatars for Flutter. Stable visual identity from any string seed, with mesh, dither, plasma, ribbon, and noise patterns plus conversational states and no image assets.
