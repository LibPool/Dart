# lava_flutter

**Tag**: animation, icons, openlava, micro-interactions, widgets, mobile, ui

## 简介

Tile-based OpenLava micro-animation engine for Flutter. 3D icons with native alpha, interactive tilt and drag-to-rotate, at 60/120 fps.
