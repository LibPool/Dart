# drawerbehavior

**Tag**: library

## 简介

Drawer behavior is a library that provide an extra behavior on drawer, such as, move view or scaling view's height while drawer on slide..

## 官网

- 主页: https://github.com/shiburagi/Drawer-Behavior-Flutter
