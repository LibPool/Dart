# flutter_frappe_chat

**Tag**: frappe, erpnext, chat, websocket, realtime, web, mobile, ui, networking

## 简介

Frappe Chat for Flutter. Realtime messaging over Socket.IO, attachments, voice notes, typing indicators and a themeable chat screen for Frappe/ERPNext sites.
