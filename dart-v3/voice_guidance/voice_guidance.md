# voice_guidance

**Tag**: tts, voice, navigation, accessibility, flutter, mobile, desktop, ui

## 简介

Platform-agnostic voice guidance for navigation apps. Works on mobile (flutter_tts), Linux (spd-say), and silently in CI.
