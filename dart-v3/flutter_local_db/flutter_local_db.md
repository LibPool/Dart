# flutter_local_db

**Tag**: nosql, ffi, rust, storage, lmdb, web, mobile, database

## 简介

A high-performance cross-platform local database for Dart. Native platforms use Rust+LMDB via FFI, optimized for both Dart APIs and Flutter apps.
