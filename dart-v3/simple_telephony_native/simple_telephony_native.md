# simple_telephony_native

**Tag**: telephony, phone, android, calling, mobile

## 简介

Android telephony plugin for Flutter. Receive and control phone calls via InCallService when registered as the default dialer. Supports foreground event streaming and background delivery with at-least-once guarantees.
