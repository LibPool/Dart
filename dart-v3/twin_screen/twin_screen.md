# twin_screen

**Tag**: foldable, dual-screen, adaptive, responsive, layout, web, mobile

## 简介

Fold-aware and dual-screen layouts for Flutter: iPhone Duo, Android foldables and flip phones, and web, plus window size classes and a fold simulator.
