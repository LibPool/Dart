# ares_edge

**Tag**: document-scanner, edge-detection, scanner, camera, image-processing, mobile

## 简介

Commercial Flutter document scanner with real-time edge detection, automatic capture, perspective correction and image cropping. Offline Android and iOS camera SDK.
