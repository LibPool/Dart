# ffr_crypto

**Tag**: cryptography, security, ffi, rust, encryption, mobile

## 简介

A Flutter-first, Rust-powered cryptography package with native RSA, AEAD, hashing, KDF, ECC, compatibility primitives, and typed workflows.
