# indian_input_formatter

**Tag**: mobile

## 简介

Production-grade Indian input formatters for Flutter: Aadhaar, PAN, GSTIN, IFSC, UPI, +91 phone, and INR currency with lakh/crore formatting. Cursor-safe and composable.
