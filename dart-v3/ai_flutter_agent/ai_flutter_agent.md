# ai_flutter_agent

**Tag**: ai, llm, semantics, accessibility, agent, mobile, ui

## 简介

A Flutter package that lets LLMs operate app UIs via the Semantics tree. Perceive → Plan → Execute → Verify loop with built-in safety features.
