# local_auth_ohos

**Tag**: authentication, biometrics, harmonyos, ohos, security

## 简介

HarmonyOS local authentication (fingerprint / face / device PIN) implementation for local_auth, backed by the UserIAM userAuth kit (@ohos.userIAM.userAuth).
