# flutter_unified_map

**Tag**: map, google-maps, mapkit, flutter-plugin, web, mobile, desktop

## 简介

Native maps for Flutter with a flutter_map-style API - Google Maps on Android, Apple MapKit on iOS and macOS, flutter_map on web and desktop. Markers, polylines, polygons, tiles.
