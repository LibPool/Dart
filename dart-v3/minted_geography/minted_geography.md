# minted_geography

**Tag**: validation, type-safety, geography, domain-driven-design, standards, ui

## 简介

Well-modelled Dart value types for geography: GeoCoordinate (ISO 6709 in all three field widths) and Geohash (base32 cells that decode). Part of the minted family.
