# flutter_dynamic_routing

**Tag**: mobile, state-management

## 简介

A Flutter package for enabling dynamic routing based on user choices or app states. Easily define custom workflows with flexible screen sequences to create adaptive navigation flows tailored to user actions. Perfect for apps with complex branching paths or multi-step processes.
