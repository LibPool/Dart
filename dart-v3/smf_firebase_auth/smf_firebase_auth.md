# smf_firebase_auth

**Tag**: flutter, firebase, authentication, sign-in, mobile, security

## 简介

The SMF module of Firebase Authentication for the Flutter app that SMF generates. Users sign in with an email address and a password, anonymously, or with Google and Apple.
