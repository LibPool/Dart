# eccentric_khqr

**Tag**: khqr, khqr-sdk, khqr-code, bakong-khqr, bakong, mobile

## 简介

KHQR Plugin for Flutter. This plugin provides a simple way to generate and scan KHQR codes, including support for Bakong KHQR codes.
