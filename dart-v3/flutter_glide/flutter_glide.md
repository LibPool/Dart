# flutter_glide

**Tag**: mobile, ui, networking

## 简介

Flutter image loading inspired by Glide & Picasso. Auto-detects network, asset, SVG, and file sources. Ships GlideImage, GlideCircle, GlideBanner, and GlideGrid with shimmer placeholders, initials avatars, rounded corners, colour tints, tap callbacks, and memory-cache hints — zero config required.
