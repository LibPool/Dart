# chopper_utils

**Tag**: chopper, rest-api, authentication, token-refresh, interceptors, web, networking, security, tooling

## 简介

Authentication utilities for Chopper-generated OpenAPI clients, with common request headers, coordinated access-token refresh, automatic 401 retries, and optional HTTP logging.
