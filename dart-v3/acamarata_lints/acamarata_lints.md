# acamarata_lints

**Tag**: lints, analysis, flutter, dart, style, mobile, tooling

## 简介

Shared Dart and Flutter lint rules for acamarata packages. Extends flutter_lints with strict acamarata-specific overrides for consistent code style across all packages.
