# jpeg_turbo_resizer

**Tag**: mobile, desktop

## 简介

A custom Flutter plugin for Windows that enables fast and efficient image resizing using the libjpeg-turbo library. This initial release focuses on resizing JPEG images with high performance. More features, such as additional image processing capabilities, will be added in future updates.
