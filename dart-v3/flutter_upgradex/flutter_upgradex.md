# flutter_upgradex

**Tag**: cli, flutter, developer-tools, dependencies, upgrade, mobile, tooling

## 简介

Upgrade Flutter dependencies one by one — safely. Runs flutter analyze after each upgrade and auto-rolls back anything that breaks.
