# offline_stt

**Tag**: speech-to-text, stt, offline, transcription, on-device, web, mobile, desktop, ui, networking

## 简介

Transcribe audio files offline using only the speech recognition built into the OS. Nothing is sent over the network. Android, iOS, macOS and Web.
