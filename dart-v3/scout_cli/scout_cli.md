# scout_cli

**Tag**: scout, capability-intelligence, flutter, cli, mobile, ui, serialization, tooling

## 简介

Scout CLI — query, validate, and serve capability manifests generated by scout_builder. All commands read scout.manifest.json; no Dart analyzer dependency required at runtime.
