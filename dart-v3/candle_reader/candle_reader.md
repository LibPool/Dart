# candle_reader

**Tag**: widget, animation, reading, candle, spotlight, mobile, ui

## 简介

An interactive candle reading-light widget for Flutter. Spring-follow flame, warm spotlight, pinch-to-resize, pinch-to-extinguish with rising smoke, and tap-to-relight. Works over any child — text, images, PageView, PDFs.
