# prism_settings

**Tag**: settings, preferences, widget, ui, mobile, desktop

## 简介

Ready-made adaptive settings screens for Flutter — tiles, toggles, sliders, dropdowns, and sections with built-in search. Two-pane on wide windows. Part of the Prism package family.
