# ssl_pinning_manager

**Tag**: web, mobile, networking

## 简介

A reusable, dynamic, and backend-driven Flutter package for managing SSL certificate pinning. Enforce secure HTTPS connections by dynamically rotating between pre-bundled SSL certificates via backend configuration.
