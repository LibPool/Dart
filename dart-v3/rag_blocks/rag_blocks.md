# rag_blocks

**Tag**: rag, ollama, llm, embeddings, ai, ui, state-management, tooling

## 简介

Building blocks for local RAG pipelines in pure Dart: text splitting, CSV-to-prose, exact table maths, query rewriting, similarity ranking and an Ollama client.
