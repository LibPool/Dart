# decoupage_administratif_senegal

**Tag**: mobile, database

## 简介

Un package Flutter pour le découpage administratif du Sénégal, fournissant une base de données SQLite des régions, départements et communes du Sénégal. Ce package permet d'accéder aux informations administratives du pays à travers des requêtes SQL locales.
