# rosbridge_dart_client

**Tag**: ros2, rosbridge, websocket, nav2, automotive, web, ui, serialization, networking, tooling

## 简介

Subscribe-only Dart client for rosbridge_suite — ROS 2 topic JSON streams over WebSocket. Pure Dart, no transport-layer lock-in.
