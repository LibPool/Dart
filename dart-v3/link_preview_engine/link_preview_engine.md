# link_preview_engine

**Tag**: mobile, serialization

## 简介

A Flutter link preview engine with OpenGraph/Twitter Card extraction, intelligent image ranking, URL normalization, typed JSON-LD structured data (Article/Product/Recipe/VideoObject), and a pluggable cache layer.
