# flutter_glass_ui_kit

**Tag**: mobile, ui

## 简介

A complete Glassmorphism / Frosted UI system for Flutter. Includes GlassContainer, GlassCard, GlassButton, GlassBottomSheet, GlassAppBar, and more.
