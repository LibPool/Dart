# zaim_api

**Tag**: zaim, oauth1, household-accounting, api-client, finance, web, security, tooling

## 简介

Dart client for the Zaim REST API v2.1.0. OAuth 1.0a authentication, money record CRUD, categories, genres, accounts and the public master data endpoints, with no code generation.
