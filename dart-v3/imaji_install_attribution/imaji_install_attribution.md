# imaji_install_attribution

**Tag**: flutter, android, ios, deep-linking, attribution, mobile

## 简介

Flutter plugin: Play Install Referrer (Android) and Apple AdServices (iOS) for install attribution and deferred deep links. Typed results, no Kotlin Gradle Plugin.
