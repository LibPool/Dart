# dart2wgsl

**Tag**: web

## 简介

A tool to transpile a restricted subset of Dart to WGSL (WebGPU Shading Language).

## 官网

- 主页: https://github.com/sanjayc77/dart2wgsl
- pub.dev: https://pub.dev/packages/dart2wgsl
