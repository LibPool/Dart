# ianvs_acp_runtime

**Tag**: acp, agent, ffi, rust, macos, desktop, ui, tooling

## 简介

Shared Rust stdio ACP runtime and Dart C FFI bindings for macOS agent hosts, with streaming sessions, permissions, cancellation and native build tooling.
