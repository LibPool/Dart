# prism_form

**Tag**: form, validation, widget, ui, mobile, state-management

## 简介

Declarative forms for Flutter — typed fields, composable validators, sealed submit states, inline errors, and a headless controller. Pure Flutter, all platforms. Part of the Prism package family.
