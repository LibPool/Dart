# scribble_with_timestamp

**Tag**: mobile

## 简介

Scribble is a lightweight library for freehand drawing in Flutter supporting pressure, variable line width and more along with these features I have added timestamp to each point drawn on the canvas so more functionality could be derived from it like writing speed.
