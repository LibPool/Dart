# dart_cpp_bridge

**Tag**: ffi, native, interop, cpp, mobile, desktop, ui, tooling

## 简介

Dart ↔ C++20 bridge (FRB-like). Dart FFI session layer; Native Assets build hooks for Android, iOS, Linux, macOS, and Windows.
