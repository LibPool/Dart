# dart_pdf_editor

**Tag**: pdf, pdf-viewer, pdf-editor, annotations, forms, mobile

## 简介

Flutter PDF editor and viewer for Dart: native rendering, text selection, search, annotations, forms, signatures, page editing, and document comparison.
