# pikafish

**Tag**: mobile

## 简介

The Flutter plugin for PIKAFISH (base on Stockfish), A well-known Chinese chess open source engine.

## 官网

- 主页: https://mdevs.cn
- 源码仓库: https://github.com/hezhaoyun/flutter_pikafish
- pub.dev: https://pub.dev/packages/pikafish
