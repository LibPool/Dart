# tracera

**Tag**: tracera, autotest, test-reporting, testops, web, ui, networking, testing, tooling

## 简介

Tracera Autotest adapter core for Dart: bind, steps, comments, errors, attachments and context pinning, plus the HTTP / flush / log / dotenv / Env runtime the runner packages build on.
