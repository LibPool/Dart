# indonesia_regions

**Tag**: web, mobile, ui, networking, tooling

## 简介

Offline static data of all Indonesian provinces (provinsi), regencies (kota/kabupaten) and districts (kecamatan) with a simple query API. No network required. Pure Dart, works in Flutter, server, CLI.
