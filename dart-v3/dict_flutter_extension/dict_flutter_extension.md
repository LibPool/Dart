# dict_flutter_extension

**Tag**: mobile, ui

## 简介

为 Flutter Widget 提供常用扩展方法（点击、内边距、居中、尺寸、可见性等），并封装文件操作、页面导航、Widget 构建等工具类，内部项目通用的 Flutter 语法糖工具库。
