# counter_animation_enhanced

**Tag**: counter, animation, numbers, odometer, formatting, mobile, ui

## 简介

A rolling-digit counter for Flutter. Numbers count up and down on slot-machine wheels with spring motion, digit grouping, decimals and reduce-motion support.
