# ola_map_flutter

**Tag**: web, mobile, ui

## 简介

A Flutter plugin for integrating the official Ola Map SDK. This plugin provides access to map functionalities including adding markers, showing and hiding current location, and initializing the map with your API key. Designed to be used in Flutter applications for seamless integration with Ola Maps.
