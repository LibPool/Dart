# data_tree

**Tag**: mobile, ui, tooling

## 简介

A powerful CLI tool that automatically reads Flutter app storage using ADB  and prints GetStorage, SharedPreferences, and app data files as a clean  ASCII tree in the terminal. Designed for debugging Flutter apps without  exporting manual files. Supports Android auto-detection, key-based filtering,  and full tree visualization.
