# lerix_messaging

**Tag**: push-notifications, fcm, apns, web-push, web, mobile, desktop

## 简介

Push notifications for the Lerix Flutter SDK (lerix_flutter): FCM on Android, APNs on iOS and macOS, WNS on Windows and Web Push on the web, with topics, tap callbacks and unsend.
