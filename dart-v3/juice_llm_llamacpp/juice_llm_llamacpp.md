# juice_llm_llamacpp

**Tag**: llm, on-device, llama-cpp, ai, juice, ui, state-management

## 简介

Embedded on-device LLM runtime for juice_llm — an LlamaCppProvider backed by llama.cpp (GGUF, Metal) via llama_cpp_dart.
