# flutter_monaco

**Tag**: vscode, monaco, editor, markdown, ide, web, mobile, ui

## 简介

Integrate Monaco Editor (VS Code's editor) in Flutter apps. Features 100+ languages, syntax highlighting, themes, and full API.
