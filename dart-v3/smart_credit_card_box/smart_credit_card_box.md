# smart_credit_card_box

**Tag**: credit-card, banking, payment, card-flip, ui, mobile

## 简介

An interactive 3D flipping credit card widget for Flutter with real-time brand detection, CVV auto-flip, holographic sheen, and vector chip/logos.
