# swift_image

**Tag**: mobile, ui, networking

## 简介

Flutter image loading inspired by Glide & Picasso. Auto-detects network, asset, SVG, and file sources. Ships SwiftImage, SwiftImageCircle, SwiftImageBanner, and SwiftImageGrid with shimmer placeholders, initials avatars, rounded corners, colour tints, tap callbacks, and memory-cache hints — zero config required.
