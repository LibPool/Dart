# mock_api_interceptor

**Tag**: web, mobile, ui, serialization, networking, testing

## 简介

A Dio interceptor with UI for mocking API responses in Flutter apps. Intercept HTTP requests, select mock responses from a bottom sheet, edit JSON bodies, and toggle mock mode with a floating button.
