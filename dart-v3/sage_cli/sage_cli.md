# sage_cli

**Tag**: mobile, ui, tooling

## 简介

Sage CLI is a simple command-line tool to quickly set up new Flutter projects from a template. It automates the process of cloning a starter repo, cleaning up unnecessary files, and updating project-specific configurations like the project name and package.
