# spring_boot_starter_scheduling

**Tag**: scheduling, cron, spring

## 简介

Scheduling starter for spring_boot_dart: @Scheduled methods with fixed rate, fixed delay or cron expressions, a TaskScheduler bean, stopped with the context.
