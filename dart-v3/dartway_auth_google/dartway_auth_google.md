# dartway_auth_google

**Tag**: dartway, auth, google, sign-in, flutter, web, mobile, security

## 简介

Sign in with Google for a DartWay app, reached as dw.signInWithGoogle(): the SDK initialised with a nonce the server checks, and the ID token sent as the sign-in command.
