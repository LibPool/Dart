# advertising_id_flutter

**Tag**: mobile, desktop

## 简介

A Flutter plugin to access advertising ID.Wraps ASIdentifierManager.advertisingIdentifier (on iOS&macOS) advertising ID (on Android), and OAID (on HarmonyOS).
