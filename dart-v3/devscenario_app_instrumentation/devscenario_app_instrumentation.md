# devscenario_app_instrumentation

**Tag**: web, mobile, desktop, ui, networking

## 简介

In-app automation driver for Flutter apps — the Dev Tool "F2 in-app SDK" for Flutter. Hosts the same on-device WebSocket (Android) / HTTP (iOS) protocol the desktop driver already speaks, but walks Flutter's own widget tree and dispatches gestures through Flutter's binding, so the desktop Inspector and flows can drive a Flutter app the native View/UIView walkers can't see.
