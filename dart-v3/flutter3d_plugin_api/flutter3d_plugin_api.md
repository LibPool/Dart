# flutter3d_plugin_api

**Tag**: game-development, game-engine, plugins, web, mobile

## 简介

The interfaces a flutter3d plugin is written against: the manifest, the host and its registries, the loop's phases and the event bus. Plain Dart over flutter3d_foundation.
