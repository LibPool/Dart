# pollar_flutter

**Tag**: stellar, payments, blockchain, wallet, web3, web, mobile, networking, state-management

## 简介

Unofficial Flutter SDK for Pollar (https://pollar.xyz) — wallet onboarding and USDC/Stellar payments via a WebView bridge to @pollar/react, since Pollar's SDK is currently JS/TS-only.
