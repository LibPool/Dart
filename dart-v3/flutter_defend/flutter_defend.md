# flutter_defend

**Tag**: security, encryption, sql-injection, jailbreak, secure-storage, mobile, database

## 简介

FlutterDefend 是一个轻量级的 Flutter 安全工具包，提供 SQL 注入检测、本地加密存储、安全输入框封装、越狱/root 检测等功能。
