# any_link_connect

**Tag**: connectivity, offline, network, captive-portal, sync, mobile, networking

## 简介

Two-layer connectivity monitor for Flutter. Detects captive portals, measures connection quality, queues offline requests. Fixes connectivity_plus#3440.
