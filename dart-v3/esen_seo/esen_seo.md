# esen_seo

**Tag**: seo, ssr, html, meta-tags, web, mobile, ui, serialization

## 简介

Real semantic HTML for Flutter Web — SEO widget extensions, meta tags, OpenGraph, JSON-LD and a bot-aware SSR server. No Puppeteer, pure Dart.
