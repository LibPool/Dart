# syncache_drift

**Tag**: cache, offline-first, drift, sqlite, persistence, database

## 简介

Drift (SQLite) storage backend for Syncache. Provides durable persistent caching with full support for tag-based invalidation, pattern matching, and a mutation outbox sharing one SQL connection with the cache.
