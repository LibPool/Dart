# connect_database

**Tag**: web, mobile, database

## 简介

A Flutter package for ODBC database connectivity with support for SQL Server, PostgreSQL, and Sybase Anywhere. Features connection pooling, bulk operations, query metrics, and automatic SELECT interception with CAST.
