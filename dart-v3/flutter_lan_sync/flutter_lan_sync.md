# flutter_lan_sync

**Tag**: mobile, serialization, security

## 简介

Production-grade offline LAN sync for Flutter apps. Peer-to-peer transfer of any JSON-serialisable data over Wi-Fi using X25519 ECDH + AES-256-GCM encryption, HMAC app-identity verification, UDP broadcast discovery, and a CRDT Last-Write-Wins merge strategy.
