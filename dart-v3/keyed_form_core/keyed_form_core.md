# keyed_form_core

**Tag**: library

## 简介

Shared vocabulary for the keyed_form family: FieldRef / StrictFieldRef / VariantRef field references over keyed_lens optics, DelegatingFieldRef, FieldErrors, and the @keyedSchema annotation.
