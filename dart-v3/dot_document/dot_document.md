# dot_document

**Tag**: innovatrics, digital-onboarding, remote-identity-verification, document-detection, machine-readable-zone, mobile

## 简介

A Flutter plugin, as a part of Innovatrics IDV Flutter SDK, that provides components for document capture and related functionalities for a Flutter project.
