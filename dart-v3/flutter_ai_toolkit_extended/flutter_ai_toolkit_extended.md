# flutter_ai_toolkit_extended

**Tag**: ai, chat, gemini, web, mobile, desktop

## 简介

A fork of flutter_ai_toolkit (BSD-3, Google LLC) with an additional maxWidth constraint on user message bubbles, allowing user chat bubbles to be capped at a configurable fraction of the screen width. Supports mobile, desktop, and web.
