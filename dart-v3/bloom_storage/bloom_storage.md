# bloom_storage

**Tag**: bloom, storage, s3, web

## 简介

Flexible, swappable file storage abstraction for Bloom server applications (Local Disk and S3-compatible backends like AWS S3, Cloudflare R2, MinIO, and Supabase Storage).
