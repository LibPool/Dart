# oicana

**Tag**: pdf, typst, templating, document, oicana, web, mobile, desktop

## 简介

Generate typeset PDFs in Dart and Flutter from Typst templates. Runs in process on Android, iOS, Linux, macOS and Windows, and as WebAssembly on the web.
