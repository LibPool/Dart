# rune_http

**Tag**: rune, bridge, http, server-driven-ui, cache, web, ui, networking

## 简介

HTTP source-fetching bridge for the rune package. RuneHttpView fetches Rune source strings from a URL, caches them in memory, and renders through RuneView with offline-first fallbacks.
