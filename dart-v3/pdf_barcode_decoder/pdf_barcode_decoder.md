# pdf_barcode_decoder

**Tag**: pdf, barcode, qr-code, barcode-scanner, decoder, mobile

## 简介

A fast, lightweight Flutter plugin to decode barcodes (QR, PDF417, Aztec, DataMatrix, Code128, etc.) directly from PDF files and bytes.
