# tessera_pdf

**Tag**: pivot-table, pdf, export, report, ui

## 简介

PDF export for the tessera pivot-table engine: paginated pages with repeated headers, fit-to-width or tiling, themed with CubeExportTheme. Pure Dart, built on package:pdf.
