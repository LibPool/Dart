# mbaudience

**Tag**: library

## 简介

MBAudience is a plugin libary for MBurger, that lets you track user data and behavior inside your and to target messages only to specific users or groups of users.

## 官网

- 主页: https://web.mburger.cloud/engagement-platform
- 源码仓库: https://github.com/Mumble-SRL/MBAudience-Flutter
- pub.dev: https://pub.dev/packages/mbaudience
