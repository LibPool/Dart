# custom_cursor_with_icon

**Tag**: textfield, cursor, widget, input, ui, mobile

## 简介

A Flutter TextField widget with an animated cursor that displays a customizable icon below the caret. Fully configurable cursor appearance, blinking behavior, and icon placement.
