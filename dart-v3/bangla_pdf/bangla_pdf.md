# bangla_pdf

**Tag**: pdf, bangla, unicode, typography, text-shaping, web

## 简介

Correct Bangla (Bengali) text in PDFs: real OpenType shaping for conjuncts, reph and vowel signs, with text that copies back out as clean Unicode.
