# sip_ua_webrtc_fixed

**Tag**: web, mobile, desktop

## 简介

Fork of sip_ua with WebRTC fixes for Web platform. A SIP UA stack for Flutter/Dart, based on flutter-webrtc, support iOS/Android/Desktop/Web.
