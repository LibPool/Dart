# rtc_rnnoise

**Tag**: webrtc, audio, noise-reduction, ai, native-ffi, web, mobile

## 简介

A high-performance AI noise reduction plugin for Flutter WebRTC, based on RNNoise. Features real-time VAD and zero-latency native audio processing via pre-compiled binaries.
