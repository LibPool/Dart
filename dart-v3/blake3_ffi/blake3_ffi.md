# blake3_ffi

**Tag**: blake3, hashing, cryptography, ffi, performance, ui, security, tooling

## 简介

BLAKE3 hashing for Dart over native FFI: 22x the throughput of the pure-Dart path on bulk data. One-shot, streaming, keyed (MAC), key derivation. C compiled at build.
