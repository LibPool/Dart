# zanbug_flutter

**Tag**: crash-reporting, error-reporting, monitoring, performance, flutter, mobile

## 简介

Zanbug crash reporting and performance monitoring for Flutter — Flutter errors, real screenshots, an offline queue and start-up / screen-load timing.
