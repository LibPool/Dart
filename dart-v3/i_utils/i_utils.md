# i_utils

**Tag**: utilities, http, storage, i18n, responsive, web, mobile, ui, networking

## 简介

Mobile-first Flutter utility toolkit: HTTP (Dio), secure/prefs storage, reactive theme & locale, overlay toasts, loader, dialogs, navigation helpers, validators, date, connectivity, responsive sizing.
