# dot_matrix_loader

**Tag**: flutter, animation, loading, ui, widgets, web, mobile, tooling

## 简介

A zero-dependency Flutter package for premium dot-matrix loading animations. Render animated NxM dot grids with 61 built-in presets, a custom builder API, and a sequence API.
