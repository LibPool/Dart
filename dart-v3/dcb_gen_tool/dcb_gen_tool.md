# dcb_gen_tool

**Tag**: ui, tooling

## 简介

Code generation CLI for dart_cpp_bridge. Downloads a pinned Python toolchain (python-build-standalone + libclang-ng), parses C++ headers via libclang, and generates Dart/C++ bridge code.
