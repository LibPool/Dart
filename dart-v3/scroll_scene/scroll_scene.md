# scroll_scene

**Tag**: scroll, animation, scrolltrigger, parallax, sliver, mobile, ui

## 简介

GSAP ScrollTrigger for Flutter: pin sections, scrub timelines by scroll progress, keyframes, stagger, snap points and debug markers. Pure Flutter.
