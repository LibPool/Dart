# eli_ble_gatt_server

**Tag**: web, mobile, ui

## 简介

Flutter plugin to turn a device into a BLE GATT Server peripheral (Android & iOS). Supports advertising, custom UUIDs, READ/WRITE/NOTIFY, and real-time event streaming.
