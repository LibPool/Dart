# self_swagger

**Tag**: web, ui, serialization, tooling

## 简介

self_swagger generates an OpenAPI 3.0 specification from your shelf_router routes.
Annotate routes with simple // @openapi: key=value comments, configure route
mounts and API metadata in openapi.yaml, and get a complete openapi.json.
Works as a build_runner builder for incremental generation or as a standalone CLI.
