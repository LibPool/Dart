# facial_liveness_detection_flutter_plugin

**Tag**: mobile

## 简介

人脸活体检测，支持静默，炫彩，眨眼，张嘴，摇头，点头，远近及随意动作组合，支持Android,IOS, HMOS, H5,小程序等
