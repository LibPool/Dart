# fluid_bottom_sheet_x

**Tag**: bottom-sheet, modal, gesture, snap, ui, mobile

## 简介

An elastic multi-snap bottom sheet for Flutter inspired by Apple Maps and Spotify with rubber-band physics, frosted glass, and nested scroll gestures.
