# call_kit_for_zego

**Tag**: zegocloud, calling, callkit, video-call, voip, web, mobile, ui

## 简介

Real-time audio/video calling for Flutter, powered by ZEGOCLOUD, with native CallKit and Android ConnectionService incoming-call UI. Includes a demo signaling server.
