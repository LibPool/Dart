# appspro_sdk

**Tag**: subscriptions, payments, carrier-billing, otp, mobile, ui, tooling

## 简介

Native Flutter widgets and a typed client for AppsPro carrier-billed subscriptions (BDApps DCB, Robi/Airtel) — phone, OTP, status and cancel.
