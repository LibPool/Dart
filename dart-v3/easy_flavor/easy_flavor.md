# easy_flavor

**Tag**: flutter, flavors, cli, firebase, build-variants, mobile, ui, tooling

## 简介

A CLI that sets up Flutter flavors (dev, staging, prod, ...) for Android and iOS in new or existing projects, with optional Firebase integration.
