# secploy

**Tag**: monitoring, crash-reporting, observability, logging, privacy, mobile, security

## 简介

Error monitoring and security telemetry for Dart. Credential scrubbing, actor-bucketed sampling and a bounded delivery queue, shared with the Flutter SDK.
