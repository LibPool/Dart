# lerix_app_update

**Tag**: app-update, in-app-update, google-play, mobile, ui

## 简介

Google Play in-app updates for the Lerix Flutter SDK (lerix_flutter): a required update from Lerix release control runs Play's IMMEDIATE update flow instead of opening the store page.
