# dicom_viewer

**Tag**: dicom, medical-imaging, radiology, viewer, flutter, web, mobile, desktop

## 简介

A pure-Dart DICOM viewer for Flutter. Parses uncompressed, RLE, and JPEG DICOM files, applies VOI windowing and PALETTE LUTs, and renders images across Web, Desktop, and Mobile.
