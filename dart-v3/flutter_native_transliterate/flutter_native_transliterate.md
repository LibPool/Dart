# flutter_native_transliterate

**Tag**: web, mobile, networking

## 简介

On-device script transliteration using the OS-native ICU engine (Android android.icu.text.Transliterator, iOS CFStringTransform). No network, no API key - e.g. Latin->Devanagari/Tamil/Kannada. Returns input unchanged on unsupported OS so it is always safe to call.
