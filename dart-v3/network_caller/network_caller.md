# network_caller

**Tag**: web, mobile, serialization, networking, security

## 简介

A lightweight and easy-to-use Dart/Flutter package to simplify making network API calls. It supports all CRUD operations (Create, Read, Update, Delete) with customizable headers, request bodies, and token-based authentication
Features Perform GET, POST, PUT, PATCH, and DELETE requests with a clean and consistent API.
Support for passing custom headers including authorization tokens.
Handles JSON encoding/decoding automatically.
