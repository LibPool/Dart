# adaptive_layout_kit

**Tag**: responsive, adaptive, layout, slivers, desktop, mobile, state-management

## 简介

Responsive box and sliver layouts, scoped breakpoints, resizable panes with state retention, and foldable display-region geometry for Flutter.
