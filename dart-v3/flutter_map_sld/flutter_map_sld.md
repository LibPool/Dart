# flutter_map_sld

**Tag**: gis, sld, ogc, geospatial, mapping, mobile

## 简介

Parse, validate, and use OGC Styled Layer Descriptor (SLD) and Symbology Encoding (SE) styles in Dart. Raster-first, pure Dart, no Flutter dependency.
