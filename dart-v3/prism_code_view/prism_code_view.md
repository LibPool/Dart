# prism_code_view

**Tag**: code, syntax-highlighting, widget, text, mobile, ui, serialization

## 简介

A syntax-highlighted code viewer widget for Flutter. Built-in Dart and JSON tokenizer, copy button, line numbers, and word-wrap. Pure Flutter — no platform channels, works on all six platforms.
