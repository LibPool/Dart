# statkit

**Tag**: statistics, statistics-analysis, math, data-science, hypothesis-testing, mobile, testing

## 简介

Pure Dart statistics kernel: descriptives, hypothesis tests (t, ANOVA, chi-square), correlation, regression, nonparametric tests, reliability, clustering, ROC, PCA and logistic regression. Zero Flutter dependency.
