# nativemind_deals

**Tag**: web, ui

## 简介

Handmade UI of the DealApp (Dilap) marketplace by Eugene Tretiakov: onboarding, phone / OTP / PIN screens, interest and location selectors, category and action tiles, the pulse avatar, read-more, reviews, the specialist swiper and cards, call screens and charts. Services sit behind nine ports; LiveKit bindings live in `livekit.dart`.
