# jackdaw_mcp

**Tag**: ai, llm, mcp, agents, web, networking, tooling

## 简介

MCP client for jackdaw. Turns the tools of Model Context Protocol servers into jackdaw tools, with servers treated as untrusted. Ships its own client over Streamable HTTP and stdio, and an adapter for dart_mcp.
