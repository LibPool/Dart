# fluttorch_gen

**Tag**: pytorch, code-generation, build-runner, on-device, web, ui, tooling

## 简介

Generates a typed Dart API from a Fluttorch model manifest, so shapes, dtypes and preprocessing cannot drift from the training pipeline.
