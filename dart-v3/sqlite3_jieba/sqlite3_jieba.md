# sqlite3_jieba

**Tag**: sqlite, fts5, full-text-search, chinese, tokenizer, database

## 简介

A jieba-backed FTS5 tokenizer for SQLite, shipped as a native asset. Adds a `jieba` tokenizer and a `jieba_cut()` function to package:sqlite3.
