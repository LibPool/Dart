# flutter2figma

**Tag**: figma, design, design-system, cli, codegen, mobile, ui, tooling

## 简介

(Beta) Convert an existing Flutter UI into an editable Figma design: auto-layout frames or an exact runtime capture, text styles, color variables with light/dark modes, and components.
