# android_build_doctor

**Tag**: android, gradle, cli, build, kotlin, mobile, ui, state-management, tooling

## 简介

Flutter Android build doctor: checks Java/Gradle/AGP/Kotlin compatibility, audits every plugin for AGP 9 blockers, explains Gradle errors, applies safe fixes.
