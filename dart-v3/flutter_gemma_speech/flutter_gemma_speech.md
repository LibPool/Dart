# flutter_gemma_speech

**Tag**: speech, stt, gemma, litert, on-device, web, mobile, state-management

## 简介

On-device speech (STT + TTS) for flutter_gemma via the LiteRT C API + dart:ffi. Opt-in Stt/TtsBackendProvider.
