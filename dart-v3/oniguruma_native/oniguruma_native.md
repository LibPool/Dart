# oniguruma_native

**Tag**: oniguruma, regex, regexp, unicode, textmate, web

## 简介

Oniguruma regex bindings for Dart on every platform: native dart:ffi on IO, WebAssembly on web, behind one vscode-oniguruma-compatible OnigScanner API.
