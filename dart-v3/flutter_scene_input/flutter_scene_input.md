# flutter_scene_input

**Tag**: input, gamepad, gamedev, pointer-lock, mobile

## 简介

Rebindable input actions for Flutter Scene games. Keyboard, mouse, gamepads, and pointer lock, with contexts, rebinding, and scene drivers.
