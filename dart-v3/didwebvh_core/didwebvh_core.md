# didwebvh_core

**Tag**: did, didwebvh, ssi, identity, cryptography, web, security

## 简介

Spec-aligned did:webvh v1.0 core: log entries, JCS/multihash/multikey primitives, SCID & entry-hash generation, signing, creation, resolution and validation. A faithful Dart port of didwebvh-java's didwebvh-core module.
