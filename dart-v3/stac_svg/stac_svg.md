# stac_svg

**Tag**: ui, widget, server-driven-ui, dynamic-widgets, flutter-svg, web, mobile

## 简介

A Stac widget parser for rendering SVG images in Flutter using the flutter_svg package, enabling server-driven SVG layouts.
