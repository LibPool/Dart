# pdfme_flutter

**Tag**: pdf, pdfme, generator, offline, flutter-plugin, web, mobile, ui, serialization, tooling

## 简介

Generate PDFs on-device from pdfme Designer templates. Pass template JSON and inputs, get PDF bytes — no server required.
