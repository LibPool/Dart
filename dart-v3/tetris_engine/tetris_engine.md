# tetris_engine

**Tag**: tetris, game, puzzle, game-engine, widget, web, mobile, ui

## 简介

A complete, customizable Tetris engine for Flutter: Guideline rules (SRS, 7-bag, hold, lock delay, T-Spins), themes, touch and keyboard controls, replays and save/restore.
