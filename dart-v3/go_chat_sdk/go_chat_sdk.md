# go_chat_sdk

**Tag**: im, chat, websocket, flutter, sdk, web, mobile, desktop, networking

## 简介

Flutter IM SDK for go-chat / LumenIM. OpenIM-style API with WebSocket messaging, Local-First cache, AES envelopes, and AI streaming. Supports Android, iOS, macOS, Windows, Linux, and Web (in-app WebView on Android/iOS/macOS; otherwise url_launcher).
