# sensitive_content_analysis

**Tag**: nsfw, nsfw-detection, content-moderation, sensitive-content, sensitive-content-analysis, mobile

## 简介

Flutter package for detecting and alerting users to nudity in images and videos before displaying them, utilizing the SensitiveContentAnalysis Framework by Apple.
