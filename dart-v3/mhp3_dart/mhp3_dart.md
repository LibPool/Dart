# mhp3_dart

**Tag**: security, state-management

## 简介

A comprehensive Dart SDK for the MHP3 protocol, providing reliable message delivery, end-to-end encryption (E2EE) via OpenMLS, and efficient state synchronization using G-PTS/C-PTS.
