# easy_mock_channel

**Tag**: mobile, testing

## 简介

Fluent MethodChannel mocking for Flutter tests. Stub platform-channel calls with when, match arguments by deep equality, and assert with verify — the mock handler installs immediately and is removed on teardown. Also ships a guard that fails a test when the app calls an unmocked platform channel, naming the channel, method, and call site instead of hanging.
