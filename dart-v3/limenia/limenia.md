# limenia

**Tag**: moderation, content-moderation, trust-and-safety, dsa, reporting, mobile, ui

## 简介

Flutter package for apps that use the Limenia moderation service: send reports, complaints and reviews reliably, read decisions, plus ready-made widgets.
