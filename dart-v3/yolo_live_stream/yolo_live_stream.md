# yolo_live_stream

**Tag**: web, mobile

## 简介

같은 Wi-Fi의 두 기기를 WebRTC로 직접 연결해 영상을 실시간 송수신하고, 수신 영상에 YOLO 객체 탐지 오버레이를 얹는 Flutter 플러그인입니다.
