# sqlite3_vec

**Tag**: sqlite, vector-search, embeddings, knn, rag, ui, database, tooling

## 简介

Vector search for SQLite, backed by sqlite-vec v0.1.9. Adds the vec0 virtual table and vec_*() functions to package:sqlite3, compiled from bundled C by a build hook.
