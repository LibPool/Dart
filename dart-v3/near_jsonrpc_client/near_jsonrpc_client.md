# near_jsonrpc_client

**Tag**: near, blockchain, rpc, openapi, web3, web, serialization, state-management, tooling

## 简介

Type-safe NEAR Protocol JSON-RPC client for Dart, generated from the official nearcore OpenAPI spec. Runs identically on native (AOT) and web (JS).
