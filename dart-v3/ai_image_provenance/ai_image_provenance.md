# ai_image_provenance

**Tag**: c2pa, content-authenticity, provenance, ai, metadata, security

## 简介

Inspects encoded image bytes for AI-generation and AI-editing evidence via validated C2PA Content Credentials, IPTC/XMP digital source type metadata, and pluggable watermark detectors.
