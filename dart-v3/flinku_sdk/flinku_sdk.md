# flinku_sdk

**Tag**: deep-linking, firebase, deferred-deep-linking, dynamic-links, referral, mobile

## 简介

Official Flutter SDK for Flinku — deferred deep linking for iOS and Android. A practical alternative and replacement for Firebase Dynamic Links after the shutdown.
