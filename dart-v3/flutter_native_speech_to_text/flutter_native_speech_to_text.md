# flutter_native_speech_to_text

**Tag**: speech-to-text, android, ios, web, desktop, mobile

## 简介

Speech-to-text for Flutter by zakaria5729. Uses Android RecognizerIntent, Apple Speech, Windows, Vosk on Linux and the Web Speech API.
