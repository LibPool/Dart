# pakdatakit_flutter

**Tag**: pakistan, validation, forms, input-formatter, qr, mobile, ui

## 简介

Flutter widgets for Pakistani data: CNIC, phone and IBAN fields that format as you type, form validators, and a Raast payment QR code widget.
