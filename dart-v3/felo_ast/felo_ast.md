# felo_ast

**Tag**: speech-translation, realtime, interpreter, doubao, subtitles, mobile, ui, state-management

## 简介

Realtime simultaneous speech translation for Flutter: streams 16kHz PCM audio to bilingual subtitles with optional TTS. Pluggable providers, Doubao AST built in.
