# custom_floating_action_button_location

**Tag**: mobile, ui

## 简介

A Flutter package to set a custom location for the Floating Action Button (FAB) on your app's screen. This package allows developers to position the FAB precisely, providing flexibility for creating unique and intuitive user interfaces.
