# glass_ui

**Tag**: mobile, ui, tooling

## 简介

glass_ui is a Flutter package that brings stunning, fully customizable glassmorphism components to your app. With sleek blur effects, vibrant gradients, and flexible styling options, glass_ui makes it easy to create modern, elegant UIs that stand out. Whether you're building cards, buttons, containers, or full layouts, this package helps you achieve a polished glass aesthetic with minimal effort.
