# segmented_ring_painter

**Tag**: chart, progress, activity-rings, fitness, custom-painter, mobile, ui, testing

## 简介

High-performance segmented circular progress and concentric activity ring widget for Flutter with gradient arcs, rounded caps, gap math, and tap hit-testing.
