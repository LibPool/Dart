# miniav_recorder

**Tag**: ui

## 简介

High-level multi-source A/V recorder built on miniav + miniav_tools. Sync screen/camera/mic/loopback into MP4/MKV files or chunked streams.

## 官网

- 源码仓库: https://github.com/PracticalXR/miniAV/tree/master/miniav_tools/miniav_recorder
- pub.dev: https://pub.dev/packages/miniav_recorder
