# k_html_dark_mode

**Tag**: html, dark-mode, webview, accessibility, theme, web, ui

## 简介

Standalone dark mode for HTML shown in a web view. Pass any HTML and get back a document that themes itself, keeping text at WCAG AA and brand colours intact.
