# super_naviagtion_page

**Tag**: ui

## 简介

SuperNaviagtionPage — a GeniusLink package providing NavigationPage, an independent in-widget navigation container. Views open parent-bounded popups/overlays with a private stack, back/back-to-root, data passing, typed results, unlimited nesting, and modes: bottom sheet, drawer, full-screen overlay, or dialog. Multiple containers work independently; system back targets the active one. Retention can preserve, suspend, recreate, or dispose stacks. Supports light/dark and LTR/RTL.
