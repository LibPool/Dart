# flutter_launcher_icons_flavors

**Tag**: icons, flutter, launcher, flavors, cli, web, mobile, desktop, serialization, tooling

## 简介

Flavor-aware fork of flutter_launcher_icons. Generates Android, iOS, macOS, Web, and Windows icons from one consolidated YAML config.
