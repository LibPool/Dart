# buoy_network

**Tag**: web, mobile, desktop, networking

## 简介

Buoy network inspector for Flutter — captures all dart:io HTTP traffic via HttpOverrides (package:http, dio, images) with an in-app panel and live streaming to Buoy Desktop.
