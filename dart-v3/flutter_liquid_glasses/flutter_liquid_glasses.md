# flutter_liquid_glasses

**Tag**: liquid-glass, glassmorphism, impeller, shaders, material, mobile, ui

## 简介

Kyant-faithful liquid glass for Flutter on Impeller: SDF refraction, 7-path chromatic dispersion, hue-blend tint, pointer glow, damped springs.
