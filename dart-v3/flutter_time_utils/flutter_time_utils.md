# flutter_time_utils

**Tag**: date, time, datetime, duration, utilities, mobile

## 简介

A lightweight Flutter package providing Duration extensions (5.seconds, 2.hours), DateTime helpers (isToday, format, timeAgo), a zero-dependency date formatter, relative time strings, and compact duration formatting.
