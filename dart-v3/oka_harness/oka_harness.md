# oka_harness

**Tag**: build-system, cli, testing, e2e, mobile, ui, tooling

## 简介

Device E2E targets over oka's owning dev sessions (ADR-0026): launch an Android app via `oka dev`, pick the forwarded VM service URI up from the runner-session contract, and drive/assert it with the flutter_mcp_harness scenario core.
