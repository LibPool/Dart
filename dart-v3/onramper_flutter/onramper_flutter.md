# onramper_flutter

**Tag**: mobile, ui, testing, security

## 简介

Official Flutter plugin for the Onramper crypto on-ramp. Configures, initializes, and embeds a native SwiftUI checkout button. iOS-only, requires iOS 16+ and App Attest.
