# rune_lint

**Tag**: rune, lint, validation, testing, diagnostics, ui, tooling

## 简介

Validation helpers for rune source strings. Catches unregistered widgets, missing constants, parse errors, and other common mistakes at test time instead of at runtime in front of users.
