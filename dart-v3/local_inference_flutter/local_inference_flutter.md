# local_inference_flutter

**Tag**: llm, ai, chat, agents, on-device, mobile, ui

## 简介

On-device AI chat and agents for Flutter: a drop-in customizable chat UI, tool calling, background model downloads, GGUF models via llama.cpp. Offline and private.
