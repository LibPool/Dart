# pcloud_flutter

**Tag**: web, mobile

## 简介

A pub.dev-conformant Flutter/Dart wrapper for the pCloud REST API — folders, files, sharing, public links, trash, thumbnails, revisions and archives.

## 官网

- 主页: https://gitlab.com/traubch/pcloud_flutter
- pub.dev: https://pub.dev/packages/pcloud_flutter
