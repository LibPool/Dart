# paste_anything_editor

**Tag**: editor, clipboard, html, quill, math, web, mobile, ui, tooling

## 简介

Rich text editor for Flutter web that pastes and copies Word, Excel, Google Docs, Markdown, HTML, tables, math formulas and images with formatting kept.
