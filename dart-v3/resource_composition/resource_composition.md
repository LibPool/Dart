# resource_composition

**Tag**: lifecycle, processes, composition, testing, state-management

## 简介

Declarative resource composition contracts (ADR-0026): typed immutable component graphs validated before side effects, first-class readiness declarations, typed output promises, lifecycle events with terminal causes, and replaceable resource providers. Zero dependencies; no daemon, no runtime lock-in. Probe mechanics stay in providers.
