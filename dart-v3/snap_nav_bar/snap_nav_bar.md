# snap_nav_bar

**Tag**: navigation, bottom-navigation, page-view, gestures, ui

## 简介

A frosted, gesture-driven bottom navigation bar with loose swipe-to-preview paging, snap-on-release physics, tap-to-centre and haptic feedback.
