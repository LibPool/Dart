# ds_i18n

**Tag**: i18n, l10n, localization, internationalization, translation, mobile, serialization, tooling

## 简介

Lightweight, JSON-based localization for Flutter. Drop translation files into assets/i18n/, call I18n.t('key'), switch languages at runtime. No codegen.
