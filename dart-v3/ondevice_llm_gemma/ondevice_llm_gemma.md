# ondevice_llm_gemma

**Tag**: mobile, ui, serialization

## 简介

flutter_gemma engine adapter for ondevice_llm: model activation with coexisting versions, tiered GPU-to-CPU session acquisition with a single serialization gate, and Flutter adapters (SharedPreferences store, connectivity policy, default model directory).
