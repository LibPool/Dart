# s_metar

**Tag**: aviation, weather, metar, taf, meteorology, web

## 简介

Parse/decode METAR/TAF aeronautical weather reports (wind, visibility, weather, clouds...). Fetch live/past METAR/TAF data from aviationweather.gov API.
