# openvino_genai_windows

**Tag**: desktop

## 简介

Windows x64 implementation of openvino_genai. Downloads the pinned Intel OpenVINO GenAI runtime (SHA-256 verified), compiles the LLM and VLM C bridges and bundles the DLLs.
