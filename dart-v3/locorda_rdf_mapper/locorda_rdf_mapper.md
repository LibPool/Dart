# locorda_rdf_mapper

**Tag**: rdf, orm, linked-data, semantic-web, knowledge-graph, web

## 简介

ORM-like mapping between Dart classes and RDF graphs. Declarative object-to-RDF mapping for linked data and knowledge graph applications.
