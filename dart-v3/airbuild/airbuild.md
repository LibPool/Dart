# airbuild

**Tag**: app-distribution, ota-updates, codepush, beta-testing, install-links, mobile, ui, testing, tooling

## 简介

AirBuild Distribution SDK for Flutter. Check for new binary builds from AirBuild install links and prompt testers to install them, plus an optional CodePush module for OTA Dart patches.
