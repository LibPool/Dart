# iroh_dart

**Tag**: iroh, p2p, networking, quic, ffi, mobile, ui

## 简介

Dart/Flutter binding for iroh 1.0 - peer-to-peer QUIC networking (endpoints, connections, streams, relays, address lookup) over the shared Rust core. Wraps iroh; does not re-port it.
