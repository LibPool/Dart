# carp_aware_package

**Tag**: mobile-sensing, mobile-health, sensors, digital-phenotyping, mobile

## 简介

The CARP AWARE sampling package. Samples passive sensor data from an Apple Watch (watchOS) using the AWARE watchOS sensing framework.
