# imaji_binary_sdk

**Tag**: swift-package-manager, xcframework, gradle, code-generation, flutter-plugin, mobile, ui, tooling

## 简介

Generate a Flutter plugin or a native SwiftPM + Gradle wrapper for a closed-source binary SDK (xcframework, aar), with the vendor binary optional at build time.
