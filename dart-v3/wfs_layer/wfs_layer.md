# wfs_layer

**Tag**: web, mobile

## 简介

A Flutter package to load and display Web Feature Service (WFS) layers on a flutter_map map. Supports points, lines, polygons, marker clustering, bbox filtering, caching, retries, and full customisation. Works on Android, iOS, and Web.
