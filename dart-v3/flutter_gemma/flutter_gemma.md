# flutter_gemma

**Tag**: gemma, llm, ai, on-device, multimodal, web, mobile, desktop

## 简介

Run Gemma and other LLMs on-device in Flutter (Android, iOS, Web, Desktop). Multimodal vision/audio, function calling, thinking mode, GPU, embeddings, RAG.
