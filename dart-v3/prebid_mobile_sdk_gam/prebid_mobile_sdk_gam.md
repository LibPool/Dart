# prebid_mobile_sdk_gam

**Tag**: ads, prebid, gam, google-ad-manager, header-bidding, mobile

## 简介

Unofficial Google Ad Manager (GAM) rendering for prebid_mobile_sdk, via Prebid's GAM event handlers. Optional companion package.
