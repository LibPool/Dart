# security_doctor

**Tag**: security, static-analysis, cli, ci, code-quality, mobile, ui, tooling

## 简介

Security audit for Flutter and Dart apps: OWASP MASVS and CWE mapped checks for Dart code, configs and native manifests. Built for CI.
