# nexo_cli

**Tag**: cli, codegen, flutter, architecture, mobile, testing, state-management, tooling

## 简介

CLI generator for Nexo-based Clean Architecture in Flutter apps. Scaffolds feature folders with Bloc or Cubit, data/domain layers, and tests.
