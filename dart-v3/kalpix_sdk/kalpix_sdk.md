# kalpix_sdk

**Tag**: web, mobile, networking, security

## 简介

Official Flutter SDK for the Kalpix backend. Provides typed APIs for authentication, real-time chat, social graph, store/economy, game matchmaking, and avatar management over HTTP and WebSocket.
