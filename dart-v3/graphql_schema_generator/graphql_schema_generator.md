# graphql_schema_generator

**Tag**: graphql, sdl, schema, codegen, server, web, tooling

## 简介

Generates a GraphQL SDL schema from plain Dart classes and enums. Reads the code, not a running server: no endpoint, no introspection query, and no credentials to hold.
