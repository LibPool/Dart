# single_word_clickable_text

**Tag**: mobile, ui, tooling

## 简介

A Flutter package that provides a customizable widget for displaying text where each word is individually clickable. Ideal for applications that require interactive text, such as chat applications or tutorials. Supports customizing text style, alignment, and handling click events on each word.
