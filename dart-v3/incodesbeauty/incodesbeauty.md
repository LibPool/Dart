# incodesbeauty

**Tag**: mobile, ui

## 简介

Real-time face beauty (smoothing, whitening, reshape, makeup, LUT looks) for Flutter live-streaming apps with Agora RTC. Requires a license key; runs unlicensed with a watermark.
