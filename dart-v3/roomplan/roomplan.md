# roomplan

**Tag**: roomplan, ar, lidar, scanning, ios, mobile, desktop, ui

## 简介

Scan a room with Apple's RoomPlan and get walls, doors, windows and furniture with real dimensions, a USDZ model, and a floor-plan widget.
