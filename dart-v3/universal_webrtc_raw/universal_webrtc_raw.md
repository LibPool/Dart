# universal_webrtc_raw

**Tag**: webrtc, sidecar, rust, web, serialization, tooling

## 简介

Raw client for the xs-webrtc-sidecar/1 wire protocol: process supervision, JSON-lines request correlation, and event stream for the webrtc-rs engine sidecar.
