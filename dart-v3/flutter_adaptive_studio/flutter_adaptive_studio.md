# flutter_adaptive_studio

**Tag**: icons, launcher-icons, splash-screen, adaptive-icons, app-icon, mobile, ui, tooling

## 简介

Flutter launcher icon and splash screen generator: adaptive app icons, native animated splash, and iOS launch screen from one SVG. Android + iOS, themed, mask-correct, per flavor.
