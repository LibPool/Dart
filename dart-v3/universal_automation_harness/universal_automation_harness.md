# universal_automation_harness

**Tag**: automation, composition, mcp, ui

## 简介

Composition-root SDK over the universal automation toolkit: flows and versioned commands that compile to AutomationPlan, budgets as enforceable components, and a rule/guide envelope whose content stays world data.
