# ekyc_vn_flutter_sdk

**Tag**: ekyc, liveness, face-detection, identity-verification, camera, mobile, ui

## 简介

On-device eKYC capture for Flutter: guided Vietnamese ID card and passport capture with card liveness, and a face liveness flow (look straight, left, right). Ready-made screens for Android and iOS.
