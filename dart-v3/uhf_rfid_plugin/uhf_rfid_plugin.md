# uhf_rfid_plugin

**Tag**: rfid, uhf, barcode, scanner, pda, mobile

## 简介

Flutter plugin for UHF RFID R2000 SDK and Barcode/QR Scanner. Supports PDA7100, PDA3109 and similar handheld devices.
