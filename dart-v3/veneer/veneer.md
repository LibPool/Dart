# veneer

**Tag**: ios, liquid-glass, uikit, native, ui, mobile

## 简介

Real native iOS 26 UI for Flutter: Liquid Glass, UIKit tab and navigation bars, composers and sheets driven by Flutter layout, with matching Flutter UI on Android.
