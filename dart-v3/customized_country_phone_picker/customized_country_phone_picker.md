# customized_country_phone_picker

**Tag**: phone, country-picker, country-phone-picker, input, widget, mobile, ui

## 简介

Flutter phone input with country picker (sheet/dialog), EN/AR names, inline country prefix, paste-to-detect with smart truncation, optional strict validation, themed search.
