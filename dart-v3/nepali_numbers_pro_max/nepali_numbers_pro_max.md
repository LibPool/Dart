# nepali_numbers_pro_max

**Tag**: nepali, nepali-numbers, currency, devanagari, npr, mobile

## 简介

Production-grade Nepali number / NPR currency library for Dart & Flutter. Devanagari ↔ ASCII digits, Indian-style lakh/crore/arab grouping, NPR formatting, number → words (एक करोड पच्चीस लाख…), words → number, ordinals, fractions, compact form, paisa-safe BigInt math, and percentages. Zero deps.
