# litportnet_free_proxy

**Tag**: proxy, proxies, network, http, socks, web, networking, tooling

## 简介

Dependency-free Dart client for Litport's free-proxy API snapshot of verified HTTP, SOCKS4, and SOCKS5 proxies, with typed filtering.
