# fpjs_pro_plugin

**Tag**: mobile

## 简介

Flutter plugin that can be used in an application to call the native FingerprintJS Pro libraries and identify devices.

## 官网

- 主页: https://fingerprint.com
- 源码仓库: https://github.com/fingerprintjs/fingerprintjs-pro-flutter
- pub.dev: https://pub.dev/packages/fpjs_pro_plugin
