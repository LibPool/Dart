# muzoapi

**Tag**: web

## 简介

A Dart package for extracting audio and video streams from YouTube videos, supporting multi-language audio tracks.

## 官网

- 主页: https://github.com/example/muzoapi
- pub.dev: https://pub.dev/packages/muzoapi
