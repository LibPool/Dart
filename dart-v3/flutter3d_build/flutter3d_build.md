# flutter3d_build

**Tag**: game-development, game-engine, build-hook, mobile, ui, tooling

## 简介

The build hook behind `dart run flutter3d_build:init`: converts model and texture sources into what the engine loads, on every build rather than as a step somebody remembers to run.
