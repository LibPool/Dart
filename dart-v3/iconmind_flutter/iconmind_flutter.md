# iconmind_flutter

**Tag**: mobile, ui

## 简介

5,287 open-source icons for AI-era software — agents, MCP, RAG, prompts — as tree-shakeable Flutter widgets. Outline and duotone, three weights, drawn from the same source of truth as every other IconMind package.
