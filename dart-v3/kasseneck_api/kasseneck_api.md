# kasseneck_api

**Tag**: pos, payments, receipt, thermal-printer, austria, web, mobile

## 简介

Austrian fiscal cash register (RKSV, Registrierkasse) for Flutter: signed receipts, cancellations, hobex and Stripe card payments, ESC/POS receipt printing.
