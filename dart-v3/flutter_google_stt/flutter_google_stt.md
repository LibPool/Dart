# flutter_google_stt

**Tag**: speech-to-text, speech-recognition, google-cloud, grpc, streaming, web, mobile, networking

## 简介

A Flutter plugin for real-time speech-to-text using Google Cloud Speech-to-Text API via gRPC streaming.
