# fddp

**Tag**: flutter, cli, architecture, codegen, mobile, ui, state-management, tooling

## 简介

Flutter CLI to auto-generate clean architecture feature folders with Provider, Bloc, Cubit, or Riverpod. One command builds your full data/domain/presentation structure.
