# flutter_local_device_discovery

**Tag**: device-discovery, local-network, mdns, ssdp, upnp, mobile, desktop, networking

## 简介

Local-network device and service discovery for Flutter using native mDNS/DNS-SD, Bonjour, SSDP, WS-Discovery, and secure UPnP metadata on Android, iOS, macOS, Windows, and Linux.
