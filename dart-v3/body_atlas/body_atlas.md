# body_atlas

**Tag**: anatomy, fitness, health, education, web, mobile, ui, tooling

## 简介

Pure Dart data for flutter_body_atlas: stable muscle ids, groups, display names and search.
Use it on a server or CLI that needs the same ids as the Flutter widget, without depending on Flutter.
