# dartframe

**Tag**: dataframe, datacube, series, ndrrray, scaler, serialization

## 简介

DartFrame is a Dart library inspired by Pandas and NumPy, simplifying structured data handling (tables, CSVs, JSON) with function tools for filtering, transforming, and analysis.
