# payv

**Tag**: pdf, opentype, text-shaping, arabic, kurdish, web

## 简介

Pure-Dart OpenType shaping and vector PDF generation. Renders Kurdish Sorani, Arabic, Persian and Urdu by executing the font's own GSUB/GPOS tables. No FFI, no dependencies.
