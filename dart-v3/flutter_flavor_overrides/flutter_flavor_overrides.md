# flutter_flavor_overrides

**Tag**: flutter, flavors, cli, dependencies, pubspec, mobile, serialization, tooling

## 简介

CLI that swaps dependencies per Flutter flavor by generating pubspec_overrides.yaml, so a plugin's native code stays out of flavors that don't need it.
