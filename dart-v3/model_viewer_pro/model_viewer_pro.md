# model_viewer_pro

**Tag**: model-viewer, glb, gltf, avatar, three-js, mobile, ui

## 简介

Display & control interactive 3D models (GLB/GLTF) in Flutter. Change mesh colors, toggle visibility, control camera, lighting, & grounded scenes. Built on model_viewer_plus.
