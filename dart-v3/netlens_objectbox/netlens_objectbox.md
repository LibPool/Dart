# netlens_objectbox

**Tag**: http, inspector, netlens, interceptor, objectbox, web, database, networking

## 简介

ObjectBox storage for NetLens. Keeps calls caught by the NetLens in-app HTTP inspector in an ObjectBox database across app restarts.
