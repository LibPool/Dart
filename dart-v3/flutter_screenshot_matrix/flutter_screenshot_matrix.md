# flutter_screenshot_matrix

**Tag**: testing, screenshots, golden, localization, accessibility, mobile, ui

## 简介

Screenshot every screen across devices, locales, themes and text scales in plain flutter test, with real fonts, overflow detection and an HTML gallery.
