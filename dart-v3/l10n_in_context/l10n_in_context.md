# l10n_in_context

**Tag**: localization, l10n, i18n, translation, arb, mobile

## 简介

In-context translation editor for Flutter localization (gen-l10n, ARB). Tap any string in the running app, edit it live and publish over-the-air through Firebase, Supabase or your own backend.
