# live_activity_kit

**Tag**: live-activities, dynamic-island, activitykit, ios, android, mobile, ui, tooling

## 简介

Build iOS Live Activities and Dynamic Island widgets, plus Android Live Updates / ongoing notifications, from Dart. Component DSL, SwiftUI renderer, ActivityKit, App Groups and APNs push updates — no Swift code.
