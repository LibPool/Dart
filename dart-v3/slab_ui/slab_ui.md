# slab_ui

**Tag**: neobrutalism, neubrutalism, brutalism, ui, widget, mobile

## 简介

Neobrutalism (neubrutalism) UI kit for Flutter. 50+ widgets with thick borders, hard shadows, bold type, light/dark theming and accessibility.
