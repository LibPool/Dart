# skribble

**Tag**: ui, widgets, hand-drawn, design-system, sketch, web, mobile

## 简介

Hand-drawn UI components for Flutter. 80+ sketchy widgets with familiar Material and Cupertino APIs — buttons, inputs, navigation, dialogs, and more, all with a hand-drawn aesthetic.
