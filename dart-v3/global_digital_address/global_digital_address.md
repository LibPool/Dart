# global_digital_address

**Tag**: geospatial, geohash, mercator, gis, digital-address, web

## 简介

Square-cell Web Mercator encoder/decoder for globally unique grid codes (“DigiPin”) with lossless roundtrip helpers and approximate cell sizing.
