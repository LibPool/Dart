# tailwind_ui_flutter

**Tag**: flutter, dart, tailwindcss, tailwind, ui, mobile

## 简介

Tailwind CSS-inspired utility-first styling for Flutter with chainable widget extensions, Tailwind v4 colors, reusable styles, dark mode support, and zero dependencies.
