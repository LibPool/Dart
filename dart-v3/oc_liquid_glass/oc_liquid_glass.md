# oc_liquid_glass

**Tag**: effects, shader, visual-effects, liquid-glass, apple, mobile, ui

## 简介

A Flutter package for creating realistic liquid glass droplet effects with GPU-accelerated shaders featuring refraction, blur, and lighting.
