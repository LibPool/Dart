# mux_api

**Tag**: mux, video, api, client, web, mobile, security, tooling

## 简介

Pure Dart client for the Mux API: video, data and system resources, JWT playback-token signing, and webhook verification. Runs on Dart servers, CLIs and Flutter apps.
