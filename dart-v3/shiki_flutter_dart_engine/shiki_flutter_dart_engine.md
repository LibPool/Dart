# shiki_flutter_dart_engine

**Tag**: web, mobile, ui, tooling

## 简介

Pure-Dart Oniguruma engine backend for shiki_flutter (via oniguruma_dart): no FFI, no native build, runs everywhere including web. shiki_flutter's default engine on native/VM.
