# wave_card_type

**Tag**: mobile, tooling

## 简介

A highly customizable, performant, and animatable wave card clipper package for Flutter. Supports smooth waves, zigzags, blobs, stars, heartbeat pulses, noise, ripple effects, double waves, and custom borders or shadows.
