# simple_parallax

**Tag**: parallax, animation, scrolling, ui, sliver, mobile

## 简介

Parallax widgets for Flutter, in pure Dart with no dependencies. A container mode and a per-item mode, either axis, with a drift, a zoom, a blur and an overlay set on their own.
