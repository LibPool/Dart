# magic_js_types

**Tag**: library

## 简介

JavaScript interop numeric types for Dart, including signed and unsigned 8-, 16-, 32-, and 64-bit integers, 32- and 64-bit floating-point values, JavaScript strings, objects, functions, and 32-bit pointers with range validation and BigInt support.
