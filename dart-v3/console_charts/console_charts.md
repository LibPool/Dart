# console_charts

**Tag**: charts, console, terminal, cli, visualization, web, tooling

## 简介

Charts for the console and terminal, rendered as plain text. Sparklines, line and bar charts, gauges, heatmaps and dashboards. No dart:io, so it works on the web too, and no dependencies.
