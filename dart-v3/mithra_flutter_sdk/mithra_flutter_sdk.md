# mithra_flutter_sdk

**Tag**: analytics, push-notifications, notifications, in-app-messaging, marketing, mobile

## 简介

Mithra's Narya SDK for Flutter. A thin bridge over the Narya native SDKs for analytics, push notifications, in-app messages and the mobile inbox.
