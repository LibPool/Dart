# xtask_kit

**Tag**: task-runner, automation, build, desktop, ui, testing, tooling

## 简介

Verbs for xtask that projects otherwise write again each: installing a Linux app, CLI tools or a VS Code extension; publishing to pub; tests per package; scripts under Git's bash.
