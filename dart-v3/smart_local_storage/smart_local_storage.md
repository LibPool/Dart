# smart_local_storage

**Tag**: web, mobile

## 简介

A reusable, production-ready local storage package for Flutter. Pluggable engine (SharedPreferences / SecureStorage / Memory), TTL caching, batch writes, namespaces, typed models, streams, export/import, migration, logging, validators and full null-safety.
