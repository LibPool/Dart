# onepassword_connect

**Tag**: onepassword, secrets, security, api-client, web, mobile, tooling

## 简介

Unofficial pure-Dart client for the 1Password Connect REST API — vaults, item CRUD, files, and op:// secret references on every Dart & Flutter platform.
