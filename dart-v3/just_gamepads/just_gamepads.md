# just_gamepads

**Tag**: gamepad, controller, input, gamedev, game, web, mobile, desktop

## 简介

Gamepad input for Flutter on Android, iOS, macOS, Windows, Linux and the web (WASM too): Xbox, PlayStation, Nintendo and generic controllers in one standard layout.
