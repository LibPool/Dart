# debug_lens_flutter

**Tag**: debug, logging, developer-tools, network, error-handling, mobile, ui, networking

## 简介

A comprehensive custom debugging system for Flutter applications that captures and displays logs from print(), debugPrint(), errors, UI issues, and network requests with a floating overlay button and log viewer panel.
