# super_map

**Tag**: flutter, widgets, diagram, graph, canvas, mobile, ui, serialization

## 简介

GeniusLink design-system Flutter package for pannable, zoomable, draggable node-graph canvases. Includes read/edit modes, ERP workflow metadata, audit locks, node search, auto-layout, validation, minimap, JSON import/export, and PNG, PDF, Word, and CSV export for accounting and process diagrams.
