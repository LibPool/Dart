# imcodec_native

**Tag**: image, codec, native-assets, webassembly, flutter, web, mobile

## 简介

Bundled native and WebAssembly AVIF, HEIF, JPEG XL, WebP, PNG, JPEG, QOI, TIFF and OpenEXR codecs for Imcodec on all Flutter platforms.
