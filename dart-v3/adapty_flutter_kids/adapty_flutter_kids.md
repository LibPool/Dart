# adapty_flutter_kids

**Tag**: web, mobile

## 简介

Kids Mode (COPPA / App Store Kids Category) variant of adapty_flutter. iOS compiles out IDFA / AdSupport via the AdaptySDK-iOS KidsMode trait; same public API.
