# alphabetic_scrollbar

**Tag**: mobile, ui

## 简介

A Flutter package that provides an alphabetic scrollbar widget for easy navigation through lists or grids of items. The scrollbar displays letters of the alphabet, allowing users to quickly jump to specific sections of the list based on the first letter of the items.
