# connectivity_manager_plus

**Tag**: mobile, ui

## 简介

A Flutter utility package to monitor internet connectivity in real-time with customizable Snackbar, Alert Dialog, Full-Screen, or your own custom UI. Built on top of connectivity_plus. Open-source and developer-friendly.
