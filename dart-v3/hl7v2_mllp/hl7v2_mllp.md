# hl7v2_mllp

**Tag**: hl7, hl7v2, mllp, healthcare, tcp, web, tooling

## 简介

MLLP (Minimum Lower Layer Protocol) transport for HL7v2 messages. TCP client and server with TLS support and automatic reconnection.
