# easy_mock_secure_storage

**Tag**: mobile, testing

## 简介

Readable test mock for flutter_secure_storage. Backs the plugin's method channel with an in-memory store you can seed and read back, with no dependency on flutter_secure_storage — it speaks the channel's raw method codes.
