# dart_sei

**Tag**: icons, svg, vector, jaspr, web, tooling

## 简介

Pure Dart library for Sxnnyside Eloquent Icons (SEI). Provides standalone SVG markup, vector paths, and helpers for Jaspr, web, server-side, and CLI Dart.
