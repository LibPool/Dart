# flutter_acp

**Tag**: ai, agent, protocol, llm, coding-assistant, mobile, ui, tooling

## 简介

A Flutter/Dart implementation of the Agent Client Protocol (ACP). Supports both Client and Agent roles for building AI coding assistants.
