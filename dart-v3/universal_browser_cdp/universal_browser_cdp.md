# universal_browser_cdp

**Tag**: web, mobile, serialization, networking, testing, tooling

## 简介

Pure-Dart Chrome DevTools Protocol (CDP) client: discovery, WebSocket JSON-RPC, accessibility snapshots, input synthesis, screenshots, and a fake CDP server for tests. No Flutter, no Node.
