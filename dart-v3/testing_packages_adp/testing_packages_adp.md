# testing_packages_adp

**Tag**: mobile, ui, testing

## 简介

A Flutter plugin for creating and managing dynamic, multi-column tables with customizable features such as dropdowns, validation, read-only cells, and more. Ideal for applications that require interactive table inputs and structured data handling.
