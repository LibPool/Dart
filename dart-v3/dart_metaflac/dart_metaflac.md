# dart_metaflac

**Tag**: flac, metadata, audio, tags, vorbis-comments, web, mobile

## 简介

A pure Dart implementation of metaflac for reading and writing FLAC metadata. No dart:io dependency in core — works with Dart, Flutter, and web applications.
