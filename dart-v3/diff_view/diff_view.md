# diff_view

**Tag**: diff, code, viewer, widget, desktop, mobile, ui

## 简介

A fast side-by-side diff view for Flutter, like JetBrains IDEs' diff viewer, with curved ribbons, synced scrolling, word highlights, folding and line selection.
