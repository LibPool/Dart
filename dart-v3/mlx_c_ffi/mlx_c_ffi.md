# mlx_c_ffi

**Tag**: ffi, mlx, machine-learning, apple-silicon, web

## 简介

Dart FFI bindings for Apple's mlx-c (MLX C API). Includes auto-generated low-level bindings and a high-level Mlx/MlxArray wrapper.
