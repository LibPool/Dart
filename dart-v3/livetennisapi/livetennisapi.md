# livetennisapi

**Tag**: tennis, sports, api, live-scores, client, web, mobile, tooling

## 简介

Dart and Flutter client for the Live Tennis API — real-time tennis scores, players, rankings, history and fixtures for ATP, WTA, Challenger, ITF and juniors over REST.
