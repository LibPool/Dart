# hatang_chat

**Tag**: chat, live-chat, customer-support, messaging, websocket, web, mobile, networking

## 简介

Hatang live chat for Flutter apps: a native customer-support chat screen that talks to your Hatang site over REST and WebSocket, with identity, events, presence and push hooks.
