# imaji_test_hang

**Tag**: testing, flutter, ci, lint, static-analysis, mobile, ui, tooling

## 简介

Fails a Flutter test suite fast on the patterns that deadlock the test isolate, instead of letting the run hang silently for minutes with no file or line named.
