# libriscv

**Tag**: risc-v, emulator, virtual-machine, rv32, rv64, desktop

## 简介

A RISC-V emulator in pure Dart supporting RV32/RV64 with M, A, F, D, C extensions, virtual memory, SBI runtime, and Linux/xv6 boot.
