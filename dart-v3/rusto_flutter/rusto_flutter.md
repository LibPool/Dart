# rusto_flutter

**Tag**: web, mobile

## 简介

Flutter plugin for RustO OCR library based on RapidOCR and PaddleOCR.

## 官网

- 主页: https://github.com/byrizki/rusto-rs
- pub.dev: https://pub.dev/packages/rusto_flutter

## 历史版本号

- 0.3.2 (2026-10-25)

## 获取地址

- pub.dev: https://pub.dev/packages/rusto_flutter
- pub 安装: `dart pub add rusto_flutter`
- Flutter 安装: `flutter pub add rusto_flutter`
- 最新版本: 0.3.2
- 最新版归档: https://pub.dev/api/archives/rusto_flutter-0.3.2.tar.gz
- 版本锁定: `rusto_flutter: ^0.3.2`
- 中央仓库: https://pub.dev/
