# chatified_flutter

**Tag**: chat, support, ai, rag, widget, web, mobile, ui

## 简介

Embeddable AI support messenger for Flutter apps. Wraps the chatified.io messenger in a native modal with identify/track/openMessenger APIs and shared visitor identity across web + app.
