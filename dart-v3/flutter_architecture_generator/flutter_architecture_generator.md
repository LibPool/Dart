# flutter_architecture_generator

**Tag**: cli, clean-architecture, code-generation, scaffolding, flutter, mobile, testing, state-management, tooling

## 简介

A CLI tool to scaffold professional Flutter projects with Clean, MVVM,  BLoC, GetX, or Provider architecture plus DI, routing, and tests.
