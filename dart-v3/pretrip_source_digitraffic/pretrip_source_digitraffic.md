# pretrip_source_digitraffic

**Tag**: pretrip, visibility, digitraffic, finland, winter-driving, web

## 简介

Fintraffic Digitraffic measured road-visibility source for the pretrip_decision_advisor briefing. Fetches the nearest fresh NÄKYVYYS_M road-weather sensor and emits a source-neutral VisibilityObservation. Pure Dart.
