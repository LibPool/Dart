# tray_kit

**Tag**: tray, system-tray, desktop, linux, dbus, mobile

## 简介

A system tray icon with a menu for Flutter on Linux, Windows and macOS. Linux needs no native libraries - it speaks StatusNotifierItem over D-Bus.
