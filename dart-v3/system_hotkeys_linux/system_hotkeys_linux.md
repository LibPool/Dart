# system_hotkeys_linux

**Tag**: hotkeys, shortcuts, linux, wayland, keyboard, desktop

## 简介

The Linux implementation of system_hotkeys, system-wide keyboard shortcuts through the GlobalShortcuts desktop portal. Pure Dart on D-Bus; no key grab, works on Wayland.
