# flutter_dothantech_lpapi_thermal_printer

**Tag**: web, mobile

## 简介

Cross-platform Flutter plugin for Dothantech LPAPI thermal printers. Print text, barcodes, QR codes and images via Bluetooth on Android and iOS.
