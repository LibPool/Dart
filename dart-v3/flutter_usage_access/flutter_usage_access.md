# flutter_usage_access

**Tag**: android, permissions, usage-access, settings, storage, mobile

## 简介

A Flutter plugin for Android Usage Access (PACKAGE_USAGE_STATS) featuring direct-to-app deep linking and Files-by-Google pre-flight UX.
