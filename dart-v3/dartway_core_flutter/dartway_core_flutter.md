# dartway_core_flutter

**Tag**: dartway, flutter, riverpod, fullstack, mobile, ui, state-management

## 简介

The Flutter skeleton of a DartWay app: bootstrap runner, guarded UI actions, the AsyncValue rendering contract, notifications and error reporting. Riverpod-native.
