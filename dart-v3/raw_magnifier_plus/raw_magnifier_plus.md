# raw_magnifier_plus

**Tag**: magnifier, zoom, loupe, image-zoom, raw-magnifier, mobile, ui

## 简介

A powerful, composable Flutter magnifier widget with zero dependencies. Supports custom ShapeBorder for images, videos, and complex UI layouts.
