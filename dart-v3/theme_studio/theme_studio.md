# theme_studio

**Tag**: theming, design-tokens, white-label, material-design, web, mobile, ui

## 简介

Runtime, multi-tenant theming for Flutter. Fetches a fully resolved theme from the Dynamic Theming System API and maps it to ThemeData, a ThemeExtension and adaptive widgets.
