# inject_flutter

**Tag**: flutter, dependency-injection, architecture, state-management, clean-architecture, mobile, ui, tooling

## 简介

Flutter integration for inject_annotation. Provides ViewModelFactory and ViewModelBuilder to inject ViewModels into widgets with automatic lifecycle management, plus SubcomponentBuilder to own a @subcomponent graph's lifecycle from a widget.
