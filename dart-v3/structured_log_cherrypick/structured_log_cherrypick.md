# structured_log_cherrypick

**Tag**: logging, cherrypick, dependency-injection, di, structured-logging, web

## 简介

StructuredLogCherryPickObserver — a CherryPickObserver that logs what the cherrypick DI container does (scopes, modules, cycles, errors) as structured_log entries, without ever printing an instance.
