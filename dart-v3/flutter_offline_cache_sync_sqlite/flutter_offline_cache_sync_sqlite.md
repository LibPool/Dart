# flutter_offline_cache_sync_sqlite

**Tag**: offline-first, sqlite, cache, sync, offline, web, mobile, database, state-management

## 简介

SQLite storage for offline_cache_sync. Keeps records, the outbox and engine state in one database, so queued offline edits survive app restarts.
