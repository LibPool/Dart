# llamadart

**Tag**: llm, ai, on-device, offline, gguf, web, mobile, desktop

## 简介

Cross-platform, on-device LLM inference for Dart and Flutter. Run GGUF (llama.cpp) and LiteRT-LM models locally on Android, iOS, macOS, Windows, Linux and web.
