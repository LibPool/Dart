# spring_boot_starter_cache

**Tag**: cache, caching, spring

## 简介

Cache starter for spring_boot_dart: @Cacheable, @CachePut, @CacheEvict and @Caching on bean methods, SpEL keys, a CacheManager with TTL and size limits.
