# xue_hua_navite_background_downloader

**Tag**: mobile, desktop

## 简介

A native multi-task background downloader plugin for Flutter supporting Android, iOS, macOS, Windows, and Linux with pause/resume, persistent queue, checksum verification, and system notifications.
