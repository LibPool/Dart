# any_image_view

**Tag**: image-viewer, svg, lottie, image, web, mobile, ui, networking

## 简介

A dependency-free Flutter image viewer: PNG, JPG, WebP, GIF, AVIF, HEIC, SVG, Lottie, XFile, local files and disk-cached network images in one widget.
