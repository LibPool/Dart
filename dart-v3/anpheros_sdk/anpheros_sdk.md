# anpheros_sdk

**Tag**: fhir, health, oauth, api-client, web, security, tooling

## 简介

Dart client for Anpheros Platform — a health-data backend with FHIR R4, patient consent (OAuth 2.1 / SMART on FHIR), provenance and an AI context API.
