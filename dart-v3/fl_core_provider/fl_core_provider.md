# fl_core_provider

**Tag**: flutter, state-management, provider, lifecycle, event-bus, mobile, ui

## 简介

A provider-based Flutter state management framework with Controller base class, page/app lifecycle, type-safe event bus, and enum-granularity UI refresh.
