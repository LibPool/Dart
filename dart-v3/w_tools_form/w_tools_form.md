# w_tools_form

**Tag**: flutter, forms, validation, widgets, mobile, ui

## 简介

w_tools 的表单层：提供输入框、下拉、日期、单选复选等字段组件，以及表单构建器、边框、弹窗与字段级校验能力，支持配置化构建。
