# structured_log_bloc

**Tag**: logging, bloc, state-management, structured-logging, debugging, web, mobile

## 简介

StructuredLogBlocObserver — a BlocObserver that turns the lifecycle, events, state changes and errors of every bloc and cubit into structured_log entries. Works with flutter_bloc as is.
