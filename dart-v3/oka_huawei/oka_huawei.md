# oka_huawei

**Tag**: build-system, huawei, appgallery, pipeline, flutter, web, mobile, ui, networking, tooling

## 简介

Huawei AppGallery Connect distribution target for oka (ADR-0014 P2): HuaweiPublishTarget with a dry-run publish plan, AppGallery Connect REST upload tail over an injectable HTTP transport, and a GMS-excluding AndroidBuild variant validated at composition time.
