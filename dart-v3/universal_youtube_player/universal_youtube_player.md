# universal_youtube_player

**Tag**: youtube, video, player, media-kit, desktop, web, mobile

## 简介

Play YouTube videos on Windows, macOS, Linux, ChromeOS, Android, iOS, and web from one codebase, with native libmpv playback and no web view.
