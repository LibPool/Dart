# genkit_flutter_edge_ai

**Tag**: genkit, flutter-edge-ai, llm, on-device-ai, embeddings, mobile, serialization

## 简介

Genkit Dart plugin for flutter_edge_ai: on-device inference with any model a registered engine runs, plus streaming, tool calling, JSON output and embeddings.
