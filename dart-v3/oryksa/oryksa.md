# oryksa

**Tag**: ai, chat, customer-support, voice, sdk, web, mobile, tooling

## 简介

Official Flutter SDK for ORYKSA AI Employees. A ready in-app AI chat and voice (the same as the ORYKSA app), and a client for the ORYKSA API v1.
