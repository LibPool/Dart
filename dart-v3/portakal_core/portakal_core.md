# portakal_core

**Tag**: printer, thermal-printer, esc-pos, zpl, tspl

## 简介

Universal printer language SDK — Pure-Dart protocol engine for TSC, ZPL, EPL, ESC/POS, CPCL, DPL, IPL, SBPL, Star PRNT.
