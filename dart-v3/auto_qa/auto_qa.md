# auto_qa

**Tag**: mcp, testing, flutter-driver, qa, llm, web, mobile, ui

## 简介

An MCP server that lets an LLM drive your live Flutter app — screenshot, tap, type, scroll, and inspect the widget tree — for AI-assisted QA.
