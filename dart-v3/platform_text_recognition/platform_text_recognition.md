# platform_text_recognition

**Tag**: ocr, text-recognition, vision, mlkit, apple-vision, mobile

## 简介

On-device OCR for Flutter. Uses Apple Vision on iOS (no ML Kit / SPM deps) and Google ML Kit Text Recognition on Android.
