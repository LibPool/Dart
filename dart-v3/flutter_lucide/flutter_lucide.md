# flutter_lucide

**Tag**: lucide, lucide-icons, feather, feather-icons, icons, mobile

## 简介

Flutter package for Lucide Icons. Lucide is a free, open-source icon set with 1854+ icons. It's a fork of the popular Feather icon set.
