# ble_proximity_tracker

**Tag**: bluetooth, ble, proximity, radar, airtag, mobile

## 简介

A federated Flutter plugin for high-precision BLE proximity tracking, Sensor Fusion, Kalman signal filtering, and Signal Gradient direction estimation.
