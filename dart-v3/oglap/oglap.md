# oglap

**Tag**: mobile, ui

## 简介

Dart/Flutter SDK for the OGLAP protocol — Offline Grid Location Addressing for the Guinea Grid Profile (GGP). Convert GPS coordinates to compact, deterministic, human-readable LAP codes (e.g. GN-CON-QYTC-B0B1-2282) and back, fully offline.
