# zuraffa_file_picker

**Tag**: file-picker, clean-architecture, zuraffa, state, state-management

## 简介

Typed file picking for the Zuraffa ecosystem: a pure-Dart FilePickerPort (pick, save, pick directory) with an in-memory default adapter and federated platform adapters.
