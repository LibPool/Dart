# easy_monitoring

**Tag**: mobile, desktop

## 简介

Real-time CPU, RAM, GPU, and current process hardware monitoring library for Flutter (Windows, macOS, Linux, Android, iOS) powered by Rust (sysinfo & gfxinfo) and exposed via Dart Streams.
