# ads_kit_levelplay

**Tag**: web, state-management

## 简介

Unity LevelPlay (ironSource) implementation of the ads_kit AdProvider contract. Wraps unity_levelplay_mediation — no ads_kit-facing API here ever leaks a LevelPlay SDK type.
