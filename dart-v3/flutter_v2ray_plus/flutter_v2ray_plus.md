# flutter_v2ray_plus

**Tag**: vpn, vless, v2ray, xray, vmess, mobile

## 简介

Flutter plugin to run VLESS/VMESS as a local proxy and VPN on Android and iOS. V2Ray/Xray core with Shadowsocks, Trojan, and Socks 5 support.
