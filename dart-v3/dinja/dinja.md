# dinja

**Tag**: jinja, template, llm, chat-templates, huggingface, web, testing

## 简介

Jinja engine for Hugging Face and GGUF LLM chat templates: messages, tools, generation prompts. Parity-tested against llama.cpp and Jinja2. All platforms, including web and Wasm.
