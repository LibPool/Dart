# release_to_trigger

**Tag**: gesture-detection, pull-to-refresh, flutter-widgets, animation, secret-access, mobile, ui

## 简介

A general-purpose pull-to-reveal or swipe-to-trigger gesture primitive to reveal hidden content, unlock features, trigger secret vaults, and perform pull-to-refresh actions.
