# figma_sync

**Tag**: figma, design-tokens, codegen, cli, web, mobile, ui, serialization, tooling

## 简介

A command-line tool that generates Flutter colours and text styles from Figma — either from an exported design-token JSON file or straight from the Figma REST API.
