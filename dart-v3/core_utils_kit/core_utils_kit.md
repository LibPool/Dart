# core_utils_kit

**Tag**: utilities, storage, extensions, lifecycle, mobile, state-management

## 简介

Small Flutter utilities: secure key-value storage, date and time formatting, color generation, URL opening, and app lifecycle watching without extra state-management dependencies.
