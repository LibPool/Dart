# wikimedia_dart

**Tag**: wikipedia, wikimedia, mediawiki, rest-api, web, tooling

## 简介

A type-safe Dart client for the Wikimedia REST APIs, covering Wikipedia, Wiktionary, Commons, and other Wikimedia projects.
