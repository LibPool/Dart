# fauxshield_mcp

**Tag**: web, serialization

## 简介

Model Context Protocol server for the FauxShield anti-counterfeit platform. Gives AI agents scoped, auditable access to products, batches, serialized units, fraud alerts, recalls, and the audit trail.
