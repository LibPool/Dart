# flutter_ui_kit_firebase_auth_gate

**Tag**: mobile, ui, security, tooling

## 简介

Firebase Auth 상태(로그인/비로그인)를 분기하는 AuthGate 위젯 패키지. StreamBuilder 기반으로 로딩·에러 상태를 커스터마이즈할 수 있다.
