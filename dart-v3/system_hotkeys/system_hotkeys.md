# system_hotkeys

**Tag**: hotkeys, shortcuts, desktop, keyboard, wayland, web, mobile

## 简介

System-wide keyboard shortcuts for Flutter desktop apps through the operating system's registration APIs and the Linux GlobalShortcuts portal. Conflicts are reported, no Accessibility permission, works sandboxed.
