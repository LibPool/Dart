# seeker

**Tag**: solana, seed-vault, seeker, ffi, mobile, ui, tooling

## 简介

Solana Seed Vault for Flutter. Integrates the seeker_dart package and uses cargokit to build the native Rust (seed_vault_core) library and reach it via FFI.
