# minigpu

**Tag**: web, mobile

## 简介

A library that brings multiplatform GPU compute to Dart and Flutter, using WebGPU directly with a Dawn backend.

## 官网

- 源码仓库: https://github.com/PracticalXR/minigpu/tree/main/minigpu
- pub.dev: https://pub.dev/packages/minigpu
