# ai_assistant_ui

**Tag**: flutter, ai, chatbot, gemini, openai, mobile, ui

## 简介

A customizable, modern AI Chat UI library for Flutter supporting Google Gemini, OpenAI, Claude, Ollama, dynamic light/dark themes, and chat history persistence.
