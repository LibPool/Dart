# flutter_table_plus

**Tag**: table, datatable, data-table, grid, datagrid, mobile, ui

## 简介

A customizable Flutter table widget with synchronized and smooth wheel scrolling, theming, sorting, selection, column reorder and resize, cell editing, and merged rows.
