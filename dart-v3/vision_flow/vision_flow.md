# vision_flow

**Tag**: web, mobile, ui

## 简介

A Flutter plugin for real-time vision tasks, Hands, Face, Pose estimation, and Video Classification. Built on top of MediaPipe, powered by ExecuTorch and TensorFlow Lite.
