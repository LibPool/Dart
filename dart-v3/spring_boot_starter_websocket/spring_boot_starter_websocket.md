# spring_boot_starter_websocket

**Tag**: websocket, realtime, spring, web, serialization, networking, tooling

## 简介

Declarative WebSocket clients for spring_boot_dart: an interface with @WebSocketClient, @OnMessage and @SendMessage becomes a bean; JSON via ObjectMapper, reconnection.
