# mp_flutter_native

**Tag**: wechat, miniprogram, flutter-web, cross-platform, web, mobile, ui

## 简介

Wire MpVideo/MpMap/MpCamera to native <video>/<map>/<camera> in WeChat Mini Programs built by flutter_miniprogram; falls back elsewhere.
