# zuraffa_purchase_platform

**Tag**: purchase, in-app-purchase, zuraffa, web

## 简介

Shared store core for the zuraffa_purchase platform adapters: the StoreApi contract, the in_app_purchase-backed implementation, and the shared purchase/restore flow.
