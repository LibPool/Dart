# svgx

**Tag**: svg, animation, icons, rust, ffi, mobile, ui

## 简介

High-performance static & animated SVG rendering for Flutter. Rust (usvg) parses, Flutter's own GPU pipeline renders — no CPU rasterizer, SMIL animation support.
