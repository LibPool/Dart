# syntax_core

**Tag**: syntax-highlighting, textmate, code, highlighter, mobile, ui

## 简介

TextMate-grammar syntax highlighting in pure Dart. Tokenizes code with VS Code grammars and themes and renders tokens, diffs, HTML, or ANSI. No Flutter required.
