# voxa_beauty

**Tag**: beauty, camera, video, filters, webrtc, web

## 简介

Real-time beauty for VoxaRTC on the camera capture path — skin smoothing, tone, retouch, colour filters, makeup looks, stickers and a cloud catalog, with a ready-made control panel. Needs a Beauty key; the free plan has one.
