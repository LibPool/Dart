# system_hotkeys_macos

**Tag**: hotkeys, shortcuts, macos, keyboard, desktop

## 简介

The macOS implementation of system_hotkeys, system-wide keyboard shortcuts through RegisterEventHotKey. No event tap, no Accessibility permission, works in the App Sandbox.
