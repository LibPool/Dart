# grund_cli

**Tag**: cli, codegen, hot-reload, server, web, tooling

## 简介

Command line tool of grund: generates the code of annotated packages (gen, gen --watch), runs them with hot reload (dev), compiles the browser bundle of client components (bundle) and scaffolds new applications (init).
