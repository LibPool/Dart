# flutter_chat_pro

**Tag**: flutter, chat, messaging, offline, ui, mobile, database

## 简介

Backend-agnostic chat kit for Flutter: typed models, built-in SQLite cache, offline outbox, controllers, and a fully customizable chat room and inbox UI.
