# flutter_fillbars

**Tag**: ui, functionalities, mobile

## 简介

flutter_fillbars is a simple flutter package that allows you to create a container which can fill with or without an animation. Play with the shape of the container to make it more elliptical, or use the preset to make it fully circular. You can apply a static color to it or use a list of color and a Gradient will be created and applied to your Fillbar.
