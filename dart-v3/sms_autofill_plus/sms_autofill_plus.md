# sms_autofill_plus

**Tag**: web, mobile, ui

## 简介

Modern SMS OTP Autofill for Flutter. Support for SMS Retriever API, User Consent API, and WebOTP. Includes Material 3 UI components and easy integration with Firebase, Supabase, and more.
