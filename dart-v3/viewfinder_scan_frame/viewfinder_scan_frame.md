# viewfinder_scan_frame

**Tag**: camera, scanner, overlay, animation, widget, mobile, ui

## 简介

A camera scan-frame overlay for Flutter: breathing corner brackets, a sweep line, a spring lock-on to the detected region, and a shake on failure.
