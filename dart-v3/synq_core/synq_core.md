# synq_core

**Tag**: mobile, networking

## 简介

Offline-first CRDT sync engine for Flutter/Dart. Nested LWW-Map + RGA document model, Hybrid Logical Clocks, causal op buffering, and a storage-agnostic delta sync engine — for apps that must keep working (and merging correctly) with no network.
