# nosmai_moderation_sdk_flutter

**Tag**: moderation, nsfw, on-device, computer-vision, content-moderation, mobile

## 简介

On-device content + text moderation for Flutter — image NSFW, object detection (weapon/drug/cigarette/alcohol) and chat toxicity, powered by the native Nosmai SDK.
