# device_security_guard

**Tag**: security, root-detection, jailbreak-detection, banking, mobile, state-management

## 简介

A Flutter plugin that reports local Android/iOS security signals for debugger, emulator, ADB, hooking, repackaging, root, jailbreak, and bootloader state.
