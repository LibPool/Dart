# inapp_network_inspector

**Tag**: network, inspector, debug, http, developer-tools, web, mobile, serialization, networking

## 简介

A lightweight in-app HTTP/network inspector HUD for Flutter. Features floating debug badge, cURL export, search, latency badges, and JSON payload viewer.
