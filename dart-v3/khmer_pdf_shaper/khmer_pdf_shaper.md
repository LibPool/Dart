# khmer_pdf_shaper

**Tag**: khmer, pdf, font, typography, shaping, web

## 简介

A pure Dart package for rendering correctly shaped, searchable Khmer Unicode text in PDF documents with bundled Battambang font and cluster-safe wrapping.
