# flutter_ftp_dtp

**Tag**: web, mobile, serialization, networking

## 简介

Flutter package for LAN-based File Transfer Pattern (FTP) and Data Transfer Pattern (DTP) — one-shot JSON sharing over HTTP and realtime sync over WebSocket.
