# neuro_realm_common

**Tag**: mobile, tooling

## 简介

Hosts the common code shared between neuro_realm, neuro_realm_dart and neuro_realm_generator packages. This package is part of the very-unofficial Realm Flutter and Realm Dart SDKs.
