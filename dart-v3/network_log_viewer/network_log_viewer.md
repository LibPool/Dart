# network_log_viewer

**Tag**: flutter, logging, graphql, rest, analytics, web, mobile, networking

## 简介

Flutter package to log REST APIs, GraphQL (queries, variables, responses), and SDK events (Insider, Adjust, Amplitude) with an in-app viewer.
