# fps_payment_code

**Tag**: fps, faster-payment-system, fps-payment-code, payment-code, flutter, mobile, ui, tooling

## 简介

Payment code generator specifically for the Hong Kong Faster Payment System (FPS). This generator is designed to create codes that facilitate seamless transactions using various payment types, including phone numbers, IDs, and emails.
