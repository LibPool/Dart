# universal_barcode_scanner

**Tag**: barcode, qrcode, scanner, camera, reader, web, mobile, desktop, ui

## 简介

Barcode and QR code scanner for Flutter, on Android, iOS, Linux, macOS, web and Windows, from one widget and one callback.
