# image_processing

**Tag**: mobile

## 简介

A Flutter package for image processing that detects faces, estimates age and gender, and classifies NSFW (Not Safe for Work) content. This package uses advanced algorithms to analyze images and extract relevant data for face detection, demographic estimation, and content filtering.
