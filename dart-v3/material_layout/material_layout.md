# material_layout

**Tag**: layout, responsive, adaptive, material, ui, mobile

## 简介

Material 3 adaptive layouts for Flutter: the canonical list-detail, supporting-pane and feed layouts, adaptive navigation placement, resizable panes and adaptive sheets.
