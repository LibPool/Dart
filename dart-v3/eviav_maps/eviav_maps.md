# eviav_maps

**Tag**: web, mobile, ui

## 简介

Widget de mapa de Eviav para Flutter. Envuelve MapLibre con el estilo, el glow de ruta, los glass pins y los overlays de marca de Eviav. Acompaña al SDK REST `eviav` (api.eviav.com).
