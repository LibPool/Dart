# crisp_chess_engine

**Tag**: chess, engine, alpha-beta, game-ai, ui

## 简介

A pure-Dart chess engine — alpha-beta search with null-move pruning, PVS, quiescence and a transposition table. No native code; runs everywhere Dart does.
