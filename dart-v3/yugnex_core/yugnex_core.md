# yugnex_core

**Tag**: web, mobile, ui

## 简介

The NexUI design system for Flutter — theme engine, design tokens, and accessible widgets. Same color scale, spacing scale, radii, motion curves, and component variant vocabulary (variant/tone/size) as @yugnex/core for React, so one design language spans web and mobile.
