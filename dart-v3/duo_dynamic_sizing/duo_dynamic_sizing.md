# duo_dynamic_sizing

**Tag**: foldable, responsive, adaptive, layout, iphone

## 简介

Adaptive layout for the foldable iPhone Duo and any screen. Fold-aware modes, split panes, side navigation, safe areas, media fit and a pose simulator.
