# blossom_upload_queue_shim_for_ndk

**Tag**: nostr, ndk, blossom, offline-first, queue, web

## 简介

Offline-first wrapper around the ndk package's Blossom upload use case. Persists per-upload metadata to a sembast queue, reads blob bytes from a blossom_cache, and retries until every targeted server has acknowledged delivery.
