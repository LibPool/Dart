# tomg

**Tag**: toml, code-generation, configuration, obfuscation, ui, serialization, tooling

## 简介

Runtime for dart-tomg: annotations, the Obfuscated<D> interface, and the reversible codec behind .deobf. Generated code from tomgen depends on this at build time; apps depend on it at runtime.
