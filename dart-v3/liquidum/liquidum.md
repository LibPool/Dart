# liquidum

**Tag**: liquid-glass, tab-bar, cupertino, ios, glassmorphism, mobile, ui

## 简介

An iOS 26-style glass tab bar for Flutter, measured against UIKit: real refraction, a lifting lens, adaptive glass, a search tab, an accessory and minimizing.
