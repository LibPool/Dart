# lazy_sticky_sections

**Tag**: sliver, list, sticky-header, scroll, widget, mobile, ui, tooling

## 简介

Grouped Flutter lists with sticky section headers, where both the sections and the items inside them build lazily. A sliver for very long sectioned lists.
