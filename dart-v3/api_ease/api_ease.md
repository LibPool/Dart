# api_ease

**Tag**: api, networking, connectivity, retry, loading-state, web, mobile, state-management, tooling

## 简介

Eliminate API call boilerplate in Flutter. Auto internet check, loading states, response validation, retry, debounce — in one line. Works with any HTTP client.
