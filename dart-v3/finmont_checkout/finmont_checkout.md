# finmont_checkout

**Tag**: payments, checkout, payment-gateway, three-ds, fintech, mobile, ui

## 简介

Flutter SDK for FinMont payment orchestration — headless core and prebuilt UI supporting cards, wallets, bank redirects, APMs, 3DS, and split payments.
