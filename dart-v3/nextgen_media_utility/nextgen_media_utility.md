# nextgen_media_utility

**Tag**: media, camera, image-picker, audio, video, web, mobile

## 简介

A high-performance, modular Flutter media toolkit — hardware camera capture, multi-album gallery picker, creative image editor with filters & freehand drawing, waveform audio recorder/player, adaptive media display grid, and video trimmer. Zero-boilerplate drop-in API for any Flutter app.
