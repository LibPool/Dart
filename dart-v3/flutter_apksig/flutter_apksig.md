# flutter_apksig

**Tag**: apk, android, signing, security, verification, mobile

## 简介

Verify and sign Android APK files using the apksig-android library. Supports JAR signing (v1), APK Signature Scheme v2/v3/v4, certificate fingerprint verification, and keystore-based signing.
