# llm_tool_calling

**Tag**: llm, tool-calling, function-calling, ai-agents, codegen, serialization, tooling

## 简介

Turn Dart functions into LLM tools for OpenAI, Gemini and Claude. Annotate with @Tool to generate the JSON schema, argument validation and type-safe dispatch.
