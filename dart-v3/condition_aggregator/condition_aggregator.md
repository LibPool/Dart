# condition_aggregator

**Tag**: aggregator, advisory, winter-driving, meteorology, driver-assistance, state-management

## 简介

Source-neutral interface for severity-qualified meteorological-advisory aggregation. Defines Advisory event + AdvisoryProvider for per-source adapters. Pure Dart.
