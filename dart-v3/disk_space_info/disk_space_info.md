# disk_space_info

**Tag**: disk, storage, filesystem, ffi, mobile, desktop, ui, tooling

## 简介

Free, total and used disk space for any path, on Android, iOS, macOS, Windows and Linux. Pure Dart via dart:ffi, with no native build configuration.
