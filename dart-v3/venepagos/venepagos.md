# venepagos

**Tag**: mobile

## 简介

SDK oficial de Venepagos para Flutter. Integra fácilmente pagos con ventana emergente y callbacks.

## 官网

- 主页: https://venepagos.com.ve
- 源码仓库: https://github.com/marioagutierrez/flutter-venepagos
- pub.dev: https://pub.dev/packages/venepagos

## 历史版本号

- 1.0.1 (2025-07-09)

## 获取地址

- pub.dev: https://pub.dev/packages/venepagos
- pub 安装: `dart pub add venepagos`
- Flutter 安装: `flutter pub add venepagos`
- 最新版本: 1.0.1
- 最新版归档: https://pub.dev/api/archives/venepagos-1.0.1.tar.gz
