# arxdeus_lints

**Tag**: lints, analysis, linter, static-analysis, mobile, tooling

## 简介

A strict, opinionated set of Dart and Flutter analysis options, adopted with one include line. Enables the three strict language modes and 212 lints. Ships no Dart code.
