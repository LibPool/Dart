# orki_webchat

**Tag**: web, mobile, ui, security, tooling

## 简介

Official Flutter SDK for the Orki webchat — a WebView widget hosting the Orki chat UI, plus a headless OrkiChatClient for custom chat UIs. Supports authenticated identity via tenant-signed JWTs (setUser/updateToken), events, and a push-token capture seam.
