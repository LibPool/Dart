# mpv_kit

**Tag**: mpv, video, audio, media, ffi, web, tooling

## 简介

Complete, low-overhead Dart FFI bindings for libmpv (mpv 0.41, client API 2.5): the full client API, mpv_node conversion, an isolate-safe event loop and a typed high-level Player. Rendering lives in mpv_kit_video.
