# oka_web

**Tag**: build-system, cli, flutter, web, mobile, ui, tooling

## 简介

Web shell station for oka (ADR-0016): per-store web/index.html as typed, drift-checked Dart, replaceable emitters, and GitHub Pages / itch.io deploy targets. Not a platform pipeline.
