# tts_pcm

**Tag**: tts, text-to-speech, speech-synthesis, audio, pcm, mobile, desktop

## 简介

Speech synthesis to 16-bit PCM with the OS voices (AVSpeechSynthesizer, Android TextToSpeech, Windows.Media.SpeechSynthesis). Nothing is played.
