# ntech_grid

**Tag**: table, grid, data-table, flutter-grid, datagrid, web, mobile

## 简介

A full-featured, TanStack Table-inspired data grid for Flutter. Sorting, filtering, pagination, grouping, selection, column pinning, row pinning, expanding rows, server-side data sources — all via composable opt-in features.
