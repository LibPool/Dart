# itqan_cli

**Tag**: quran, flutter, assets, cli, mobile, tooling

## 简介

Install and pin Itqan Quranic assets (mushafs, tafsirs, translations) in Dart and Flutter projects. Runs the standalone itqan binary; no Python needed.
