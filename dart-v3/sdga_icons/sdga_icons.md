# sdga_icons

**Tag**: mobile, security

## 简介

A flutter icon package that contains +4000 icons in 7 variants, used by the Saudi Digital Government Authority (SDGA).

## 官网

- 主页: https://design.dga.gov.sa/guidelines/foundation/iconography
- 源码仓库: https://github.com/FlutterREDF/sdga_icons
