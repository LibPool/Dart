# deeplinkify

**Tag**: mobile

## 简介

Lightweight, pure Dart deep link routing library. One class per link: destinations declare their link pattern and handle navigation (Flutter Navigator, go_router, OS launcher), with middleware, identity fallback, and lifecycle events.
