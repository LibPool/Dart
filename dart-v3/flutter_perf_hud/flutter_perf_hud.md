# flutter_perf_hud

**Tag**: performance, profiling, debugging, devtools, overlay, mobile, ui, tooling

## 简介

In-app performance HUD for Flutter: FPS, jank, UI/raster thread times, memory, oversized images and rebuild counts, with a one-tap Markdown report.
