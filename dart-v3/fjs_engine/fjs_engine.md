# fjs_engine

**Tag**: mobile, ui

## 简介

FuickJS 是一个基于 **QuickJS** 引擎实现的 Flutter 动态化渲染框架。它允许开发者使用 **React** 语法编写业务逻辑和 UI，并通过 Flutter 原生组件进行高性能渲染。
