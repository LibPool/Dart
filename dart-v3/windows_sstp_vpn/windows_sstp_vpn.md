# windows_sstp_vpn

**Tag**: mobile, desktop, ui

## 简介

A lightning-fast, native Windows MS-SSTP VPN routing engine for Flutter. Bridges directly into Windows PowerShell and rasdial without requiring C++ or third-party TAP drivers.
