# infobip_mobilemessaging_huawei

**Tag**: flutter, huawei, infobip, notifications, mobile

## 简介

Android Flutter plugin for Infobip Huawei Mobile Messaging with HMS Push, Inbox, native and embedded Chat, outgoing RTC audio/video, and screen sharing.
