# loq_drift

**Tag**: logging, drift, sqlite, structured-logging, database, state-management

## 简介

Structured query logging interceptor for Drift, powered by loq. Logs SQL statements, durations, row counts, batches, and transactions as structured records aligned with OpenTelemetry database semantic conventions.
