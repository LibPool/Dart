# paste_anything

**Tag**: clipboard, html, paste, markdown, latex, web, tooling

## 简介

Copy and paste rich content on the web: reads Word, Excel, Google Docs, web pages, Markdown, LaTeX and images from the clipboard as clean HTML. Pure Dart, works with any editor.
