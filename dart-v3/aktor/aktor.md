# aktor

**Tag**: build-runner, development, codegen, metaprogramming, ui, tooling

## 简介

A simple tool that solves Dart's lack of metaprogramming features. Perfect for building scripts, background jobs, scheduled tasks, and development utilities like code generation, data processing, and more.
