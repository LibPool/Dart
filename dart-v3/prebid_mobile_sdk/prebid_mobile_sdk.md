# prebid_mobile_sdk

**Tag**: ads, prebid, advertising, header-bidding, monetization, mobile

## 简介

Unofficial Flutter plugin for the Prebid Mobile SDK 3.4: banner, interstitial, rewarded, native, multiformat and in-stream ads, targeting and privacy.
