# spring_boot_starter_test

**Tag**: dependency-injection, testing, spring, mobile

## 简介

Testing for spring_boot_dart apps and starters: springBootTest, bean overrides for mocks, ApplicationContextRunner, matchers and log capture. Works with flutter_test.
