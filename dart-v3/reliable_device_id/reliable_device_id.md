# reliable_device_id

**Tag**: mobile, ui

## 简介

Device unique ID plugin for Android & iOS (mainland-China friendly): persisted UUID (iOS Keychain ThisDeviceOnly / Android SharedPreferences with ANDROID_ID witness migration detection) plus raw device signals. No permissions, no GMS dependency, explicit-call-only collection for privacy-consent gating.
