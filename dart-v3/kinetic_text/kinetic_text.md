# kinetic_text

**Tag**: text, animation, typography, motion, shimmer, mobile, ui

## 简介

Kinetic typography for Flutter — per-letter, per-word and per-line text motion from ONE shaped paragraph: staggered reveals, sheen and shimmer sweeps, gradient and rainbow ink on any span, sparkle, marker highlight, draw-on underline, typewriter, and a text morph that rewrites a label in place. Every script (Arabic, Kurdish, ligatures, bidi) stays correctly joined, because the text is shaped once and the glyph clusters are re-drawn from that one layout. No shaders to ship, ZERO external dependencies.
