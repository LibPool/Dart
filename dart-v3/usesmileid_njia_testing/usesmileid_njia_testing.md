# usesmileid_njia_testing

**Tag**: ui, testing

## 简介

Fakes for testing code built on usesmileid_njia, Smile ID's flow navigation engine: a navigator that records a step's calls, a listener that records transitions, a scripted native engine for widget tests, and sendIdempotently.
