# becklinks_flutter

**Tag**: deep-linking, deferred-deep-linking, app-links, universal-links, attribution, mobile

## 简介

Flutter SDK for deep links, deferred deep links & install attribution. Universal Links, App Links, Play Install Referrer with no IDFA or fingerprinting.
