# constraint_layout

**Tag**: mobile, ui

## 简介

A Flutter layout widget inspired by Android's ConstraintLayout. Position children with constraint anchors (parent/sibling edges), guidelines, chains, bias, matchConstraint sizing, zIndex, and scroll support — all via a single custom RenderBox with topological dependency resolution.
