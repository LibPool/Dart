# simple_clean_architecture_cli

**Tag**: cli, flutter, clean-architecture, scaffolding, bloc, mobile, networking, state-management, tooling

## 简介

A Dart CLI that scaffolds Flutter projects with Clean Architecture: generates the full layer structure, BLoC, routing, network layer, and feature modules in seconds.
