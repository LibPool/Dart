# ember_dart_cast

**Tag**: cast, chromecast, airplay, dlna, streaming, web, ui, networking

## 简介

A pure Dart cross-platform casting package supporting Chromecast (CASTV2), AirPlay, and DLNA with built-in HTTP proxy for header injection.
