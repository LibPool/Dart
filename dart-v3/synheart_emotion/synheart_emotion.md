# synheart_emotion

**Tag**: emotion, biosignals, machine-learning, flutter, health, mobile

## 简介

On-device emotion inference from biosignals (HR/RR) for Dart/Flutter. Detects Baseline vs Stress using WESAD-trained ExtraTrees ONNX models.
