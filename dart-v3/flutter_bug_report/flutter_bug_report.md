# flutter_bug_report

**Tag**: bug-report, logging, crash-reporting, diagnostics, debugging, web, mobile, ui, serialization, networking, tooling

## 简介

Flutter bug reports with the log already attached. Captures logger output, debugPrint, HTTP and crashes, redacts secrets, and builds a bounded txt/json/zip. No vendor, no SDK.
