# ble_mesh_chat

**Tag**: bluetooth, ble, mesh, networking, offline, mobile, security

## 简介

Flutter plugin providing a dual-role Bluetooth Low Energy transport for offline mesh chat. The native layer moves links and frames; routing, queues, protocol, and crypto are implemented in shared Dart.
