# flutter_cpp_bridge

**Tag**: ffi, native, linux, plugin, mobile, desktop

## 简介

Bridge Flutter to C++ shared libraries via FFI. C++ owns all memory; Dart receives opaque message pointers with zero-copy, event-driven delivery.
