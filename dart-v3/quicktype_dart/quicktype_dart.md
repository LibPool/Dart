# quicktype_dart

**Tag**: codegen, build-runner, quicktype, json, cross-platform, ui, serialization, tooling

## 简介

Cross-platform type generation from JSON, JSON Schema, GraphQL, or TypeScript. Produces Dart, Kotlin, Swift, TypeScript, and 18 other languages — at build time via build_runner, or at runtime from in-memory data. A pigeon-analogue for arbitrarily-nested typed data.
