# live_island_kit

**Tag**: live-activities, dynamic-island, notifications, ios, android, web, mobile

## 简介

iOS Live Activities and Android Live Updates with a single Dart API, no Swift or Kotlin. Dynamic Island, lock screen, presets, charts and a live preview.
