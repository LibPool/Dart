# flutter_ime

**Tag**: ime, keyboard, input-method, windows, macos, mobile, desktop, ui, state-management, tooling

## 简介

Control IME (Input Method Editor) state from Dart. Switch to an English keyboard, detect input source changes, and monitor Caps Lock on Windows and macOS — with no native code and no build step.
