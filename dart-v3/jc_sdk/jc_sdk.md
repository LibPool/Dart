# jc_sdk

**Tag**: mobile

## 简介

JC Flutter SDK is a flutter plugin wrapper based on Juphoon RTC SDK (Android & IOS), providing real-time audio/video services.

## 官网

- 主页: https://rtc.juphoon.com/cn/
