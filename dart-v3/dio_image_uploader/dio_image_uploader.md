# dio_image_uploader

**Tag**: mobile

## 简介

A Flutter package that provides utilities for uploading files using Dio. 
It includes functionalities for obtaining pre-signed URLs for secure uploads, 
determining file extensions, and getting MIME content types based on file extensions. 
This package simplifies file management in Flutter applications and supports various document types.
