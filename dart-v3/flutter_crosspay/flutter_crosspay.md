# flutter_crosspay

**Tag**: flutter, in-app-purchase, crosspay, web, mobile, desktop

## 简介

Cross platform in app purchase plugin. Supports all flutter platforms. Desktop and web are supported through Stripe. Developed by Maxint Inc.
