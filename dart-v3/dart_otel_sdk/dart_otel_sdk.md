# dart_otel_sdk

**Tag**: web, mobile, ui, tooling

## 简介

Concrete OpenTelemetry SDK implementation: log and span processors. Depends on dart_otel_api. Pure Dart, no Flutter dependency — the Flutter-specific facade and session tracking live in flutter_otel, which builds on this package.
