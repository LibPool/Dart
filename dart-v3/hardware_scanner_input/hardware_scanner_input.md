# hardware_scanner_input

**Tag**: barcode, scanner, hid, android, keyboard, mobile, ui

## 简介

A Flutter widget that captures input from HID-mode hardware barcode scanners on Android without showing the software keyboard. Supports Enter-suffix and silence-flush scanners.
