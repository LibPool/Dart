# opensubtitles_hasher

**Tag**: opensubtitles, hash, subtitle, video, media, web, mobile, ui

## 简介

Fast OpenSubtitles hashing (128 KB only). Built-in movie picker for all platforms. Android: Play-safe system Documents default, optional SAF branded folder browser, legacy MediaStore when the host declares storage permissions.
