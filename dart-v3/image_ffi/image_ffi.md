# image_ffi

**Tag**: image, resize, jpeg, thumbnail, ffi, ui

## 简介

Fast native image resize, thumbnail and JPEG/PNG encode for Dart over FFI. Several times quicker than the pure-Dart image package; stb-backed, no prebuilt binary.
