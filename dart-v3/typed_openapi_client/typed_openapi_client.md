# typed_openapi_client

**Tag**: openapi, api-client, http, sse, json, web, serialization, networking, state-management, tooling

## 简介

The core of clients generated by typed_openapi: typed errors, Result, Patch for tri-state fields, JSON decoding with paths, parameter encoders, an SSE decoder and the ClientTransport interface a transport implements.
