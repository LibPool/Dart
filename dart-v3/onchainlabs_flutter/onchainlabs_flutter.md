# onchainlabs_flutter

**Tag**: web, mobile, networking

## 简介

Polygon EVM wallet helper for Flutter. Creates a wallet with mnemonic phrase and private key, registers it with https://api-ga.onchainlabs.ch, and stores the mnemonic locally.
