# flutter_floating_window

**Tag**: mobile, ui

## 简介

A comprehensive Flutter plugin for creating and managing floating window overlays on Android devices.
Features include interactive UI elements, real-time data synchronization, persistent storage, and
customizable window properties with proper permission handling.
