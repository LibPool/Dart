# smart_sync

**Tag**: web, mobile, ui

## 简介

A production-grade Flutter package that makes any application Offline First. Automatically synchronizes local data with any remote backend (REST, GraphQL, Firebase, Supabase, Laravel, etc.) with zero configuration. Built with Clean Architecture, SOLID principles, and enterprise-grade patterns.
