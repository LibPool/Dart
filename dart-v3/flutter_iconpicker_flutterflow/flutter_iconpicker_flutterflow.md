# flutter_iconpicker_flutterflow

**Tag**: mobile

## 简介

A Dialog for picking Icons in Flutter and use them anywhere. Can be used as a default Dialog or as a Adaptive Dialog (forking from ahmadre).

- 源码仓库: https://github.com/aaksa/FlutterIconPicker-FlutterFlow
