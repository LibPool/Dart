# ferro_ta

**Tag**: technical-analysis, finance, indicators, trading, ffi, mobile, ui

## 简介

Fast Rust-powered technical analysis for Flutter: 190+ indicators (RSI, MACD, Bollinger Bands, ATR, candlestick patterns) with prebuilt native binaries.
