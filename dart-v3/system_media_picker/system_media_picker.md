# system_media_picker

**Tag**: picker, media, images, video, photos, web, mobile

## 简介

Permission-free image and video picker for Flutter. Wraps the Android System Photo Picker and iOS PHPickerViewController behind a single Dart API — no READ_MEDIA_* / NSPhotoLibrary* declarations needed.
