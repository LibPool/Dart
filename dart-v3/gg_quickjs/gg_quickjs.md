# gg_quickjs

**Tag**: javascript, quickjs, ffi, sandbox, native-assets, ui, tooling

## 简介

QuickJS-ng for Dart - its C sources for the build hooks of native packages and a Dart binding with typed values, a background isolate and a sandbox.
