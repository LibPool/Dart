# beautiful_timeline

**Tag**: mobile, desktop, ui

## 简介

A beautiful, fully customizable, responsive timeline widget for Flutter. Supports 20 pre-built themes, 16 content types, 14 animated connector styles, 4 visual effects, and automatic responsive layout for mobile, tablet, and desktop.
