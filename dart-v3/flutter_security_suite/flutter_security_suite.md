# flutter_security_suite

**Tag**: security, encryption, root-detection, certificate-pinning, tamper-detection, mobile, ui

## 简介

Flutter security plugin with root/jailbreak and emulator checks, screen capture protection, tamper detection, runtime protection, certificate pinning, and encrypted storage.
