# smart_search_dropdown_pro

**Tag**: flutter, dropdown, searchable-dropdown, multi-select, autocomplete, web, mobile, ui

## 简介

A powerful Flutter searchable dropdown supporting autocomplete, multi-select, async API search, infinite scroll, grouping, icons, status tags, dark mode, and responsive UI.
