# frosted_ui_kit

**Tag**: ui, widgets, glassmorphism, toolkit, mobile

## 简介

A modern Flutter UI kit combining Apple's Liquid Glass aesthetics and Telegram's fluid Android UI. Includes blur cards, sliding tabs, and glass buttons.
