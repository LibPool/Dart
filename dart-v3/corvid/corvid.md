# corvid

**Tag**: library

## 简介

Dart FFI bindings for corvid — the embedded multi-modal data store — over the engine's published C-ABI artifacts (platform cdylib + corvid.h). Idiomatic Dart on top: Db/Collection/Query, Map/List value mapping, CorvidException, close() with NativeFinalizer backstops.
