# flutter_web3_webview

**Tag**: web3, webview, ethereum, solana, wallet, web, mobile, ui

## 简介

A Flutter WebView widget that bridges in-app web pages to a Web3 wallet over EIP-1193 (EVM) and the Solana wallet standard.
