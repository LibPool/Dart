# flutter_symbols

**Tag**: mobile

## 简介

The flutter_symbols package provides a collection of SymbolIcons, which function similarly to IconData in Flutter. It also includes a wide range of symbols such as ∕, allowing developers to easily integrate these symbols into their Flutter apps, improving the visual representation of content.
