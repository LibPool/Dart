# flutter_edge_ai_mediapipe

**Tag**: gemma, llm, mediapipe, on-device, ai, web, mobile, state-management

## 简介

MediaPipe (.task) on-device inference engine for flutter_edge_ai (Android/iOS/Web). Opt-in package; provides an InferenceEngineProvider. Bundles Google's MediaPipe Pod/Gradle deps.
