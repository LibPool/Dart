# notibase_flutter

**Tag**: push-notifications, notifications, fcm, firebase, messaging, web, mobile

## 简介

Notibase for Flutter: push notifications, in-app messages and an in-app inbox. Pure Dart, no platform channels — pass the firebase_messaging token and the rest is one call.
