# oluso_core

**Tag**: web, mobile, networking, tooling

## 简介

Framework-agnostic core for Oluso error monitoring: the HTTP client, breadcrumb/context scoping, sanitization, rate limiting, and fingerprint deduplication shared by the Flutter-specific `oluso` package. Usable directly in plain Dart (CLI tools, backends) with no Flutter dependency.
