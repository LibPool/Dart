# tinytuya

**Tag**: iot, smart-home, tuya, home-automation, web, mobile

## 简介

Dart/Flutter port of Python TinyTuya - Control Tuya WiFi smart devices over LAN. Supports v3.1-v3.5 protocols, device discovery, cloud API, and all device types.
