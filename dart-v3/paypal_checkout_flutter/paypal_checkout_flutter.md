# paypal_checkout_flutter

**Tag**: paypal, payments, checkout, subscriptions, in-app-purchase, web, mobile, ui

## 简介

Flutter PayPal integration — native SDK checkout, cards, vault, subscriptions, plans, products, orders & refunds. No WebView. Includes event streams, webhook helpers, analytics, and UI components.
