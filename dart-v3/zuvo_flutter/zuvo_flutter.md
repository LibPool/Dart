# zuvo_flutter

**Tag**: zuvo, supabase, auth, realtime, postgres, mobile, database, security, tooling

## 简介

Zuvo Flutter client — thin wrapper over supabase_flutter for Auth, Database, Realtime, and Storage against Zuvo project URLs.
