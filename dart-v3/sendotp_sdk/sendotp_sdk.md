# sendotp_sdk

**Tag**: web, mobile, ui, security, tooling

## 简介

A secure Flutter SDK for MSG91 OTP verification (SMS, Voice, Email, WhatsApp). Credentials never live in the client — the SDK proxies through your own backend, which holds the MSG91 widgetId and tokenAuth server-side.
