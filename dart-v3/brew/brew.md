# brew

**Tag**: crypto, events, offline-first, event-sourcing, encryption, ui, security

## 简介

Sealed event-first mesh engine: signed, multi-recipient-sealed records and tombstones over a Liquid relay. Headless, crypto-injected, offline-first.
