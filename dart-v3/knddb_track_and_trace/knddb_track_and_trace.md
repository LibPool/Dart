# knddb_track_and_trace

**Tag**: api, sdk, medicine, track-and-trace, knmdb, web, mobile, security

## 简介

Dart/Flutter SDK для Track and Trace API системы KNMDB / KNDDB (Кыргызская национальная база лекарственных средств): OAuth2-аутентификация, автопродление токена, смена пользователя «на ходу», все методы API и типизированные модели.
