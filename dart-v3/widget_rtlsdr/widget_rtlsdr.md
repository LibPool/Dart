# widget_rtlsdr

**Tag**: android, radio, sdr, widgets, ui, mobile

## 简介

Immersive, gqrx-inspired widget library for RTL-SDR on Flutter: waterfall, spectrum scope, S-meter and digit-tuner display widgets, plus adaptive panels and a distributable settings navigation (master-detail on large screens, drill-down subscreens on phones) — all built on top of the core_rtlsdr ChangeNotifier controllers.
