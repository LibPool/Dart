# pulseflow_flutter

**Tag**: flutter, performance, profiling, devtools, web, mobile, ui, networking, tooling

## 简介

App-side probes for PulseFlow: accurate frame timing, rebuild hotspots with source locations, HTTP capture, and memory-leak signals.
