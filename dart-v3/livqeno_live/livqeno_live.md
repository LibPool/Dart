# livqeno_live

**Tag**: live-streaming, streaming, video, webrtc, web, mobile

## 简介

Livqeno Live Streaming for Flutter — join a stream as a host or a viewer, with the room and the live chat that come with it. Composes livqeno_rtc and livqeno_chat; adds no media or messaging stack of its own.
