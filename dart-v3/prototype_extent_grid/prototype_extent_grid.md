# prototype_extent_grid

**Tag**: grid, sliver, layout, widget, performance, mobile, ui

## 简介

A Flutter grid whose cell size is measured from a prototype item, the grid counterpart of SliverPrototypeExtentList. No hard-coded tile heights.
