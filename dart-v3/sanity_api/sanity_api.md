# sanity_api

**Tag**: sanity, cms, groq, client, web, mobile, tooling

## 简介

Pure Dart client for the Sanity.io Content Lake: GROQ queries, document mutations, transactions and asset uploads. Runs on Dart servers, CLIs and Flutter apps.
