# w_tools_map

**Tag**: flutter, google-maps, maps, widgets, mobile, ui

## 简介

w_tools 的地图组件层：基于 google_maps_flutter 提供 WMap / WMapZone / WMapConfig，支持 Marker 渲染、选中与关闭相机动画及事件回调。
