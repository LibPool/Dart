# state_space

**Tag**: machine-learning, gaussian-process, time-series, statistics, kalman-filter, state-management

## 简介

Gaussian process regression for irregular time series: smoothed trends with uncertainty bands, forecasts and learned hyperparameters, in linear time. Pure Dart.
