# socrits

**Tag**: video, voip, webrtc, chat, calling, web, mobile, ui, tooling

## 简介

Socrits SDK for Flutter - video & voice calls, call invitations (ring/accept), and in-app chat. Drop-in prebuilt UI kit plus a low-level core client.
