# double_ratchet

**Tag**: cryptography, encryption, signal, e2ee, messaging, security

## 简介

The Signal protocol's X3DH key agreement and Double Ratchet in pure Dart: end-to-end encrypted sessions with forward secrecy and post-compromise security, following the published Signal specifications.
