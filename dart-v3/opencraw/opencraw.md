# opencraw

**Tag**: web, desktop

## 简介

Crawl with OpenCraw from Dart, with no Node to install - the engine through its driver, downloaded once. Desktop and server.

- 源码仓库: https://github.com/Open-Craw/OpenCraw
- pub.dev: https://pub.dev/packages/opencraw
