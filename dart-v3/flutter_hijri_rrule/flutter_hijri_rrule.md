# flutter_hijri_rrule

**Tag**: hijri, islamic-calendar, rrule, recurrence, calendar, mobile

## 简介

A comprehensive RFC 5545 recurrence rule library for the Hijri (Islamic) calendar. Supports Umm al-Qura and Tabular Islamic calendars.
