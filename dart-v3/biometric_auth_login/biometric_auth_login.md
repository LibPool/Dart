# biometric_auth_login

**Tag**: authentication, biometrics, security, local-auth, secure-storage, mobile

## 简介

Backend-agnostic biometric (Face ID / Touch ID / fingerprint) unlock gate with secure secret storage and a ready-made login button for Flutter.
