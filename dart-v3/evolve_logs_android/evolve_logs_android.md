# evolve_logs_android

**Tag**: web, mobile, tooling

## 简介

Android implementation of the evolve_logs federated plugin. Forwards the platform channel to the native e-volv Observer Android client (io.e-volv:logs-android), which owns the disk queue, retry and flush — including Launch flags.
