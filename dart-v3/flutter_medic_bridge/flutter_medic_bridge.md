# flutter_medic_bridge

**Tag**: mcp, ai, testing, debugging, mobile, ui

## 简介

Wires a Flutter app into flutter-medic's device bridge — a drop-in replacement for WidgetsFlutterBinding.ensureInitialized() so an AI agent can drive and inspect the app.
