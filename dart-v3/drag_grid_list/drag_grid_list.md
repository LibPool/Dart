# drag_grid_list

**Tag**: widgets, web, mobile, desktop, ui

## 简介

Reorderable list + responsive grid with drag & drop, reordering, and cross-group drag between multiple lists/grids. Long-press drag on mobile, mouse drag on desktop/web.
