# seeker_dart

**Tag**: solana, seed-vault, secure-element, ffi, mobile, testing

## 简介

Solana Seeker Seed Vault (secure element) for Dart and Flutter. Pure Dart (no Flutter dependency) with a native test-oracle core (SLIP-0010 ed25519 derive + sign) from Rust via FFI and a pluggable backend registry.
