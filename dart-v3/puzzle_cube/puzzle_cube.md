# puzzle_cube

**Tag**: cube, puzzle, three-dim, widget, mobile, ui

## 简介

An interactive 3D twisty-puzzle cube for Flutter, with a 3x3 model (turns, scrambling, validation) and a gesture-driven widget (orbit, drag-to-turn).
