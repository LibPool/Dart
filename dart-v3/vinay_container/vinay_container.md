# vinay_container

**Tag**: mobile, ui

## 简介

A Flutter plugin for creating customizable buttons with built-in navigation.
This plugin provides a set of UI components including `VinayButton` that allows developers
to easily create buttons that navigate to different pages in their Flutter apps.
It supports both Android and iOS platforms.
