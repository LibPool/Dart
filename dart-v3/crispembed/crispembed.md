# crispembed

**Tag**: embeddings, ocr, ffi, ggml, on-device

## 简介

Lightweight embedding + math OCR inference via ggml. Dense, sparse, ColBERT, cross-encoder reranking, and DeiT+TrOCR on-device math equation recognition.
