# tld_parser

**Tag**: solana, blockchain, domains, web3, crypto, web, security, state-management

## 简介

A Dart SDK for parsing AllDomains ANS Protocol domains on Solana. Supports any TLD including .skr, .abc, .poor, .bonk and more.
