# oka_core

**Tag**: build-system, cli, configuration, dart, pipeline, ui, serialization, tooling

## 简介

Core contracts for oka: typed build context, composable pipeline (BuildStep, Artifact, Pipeline), the declarative Oka composition root, and typed oka.yaml config values.
