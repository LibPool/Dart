# kletso_core

**Tag**: ai, chat, chatbot, sdk, websocket, web, mobile, networking, state-management, tooling

## 简介

Kletso client for Dart and Flutter: sessions, realtime chat with typed surfaces, actions, context, triggers, voice and avatar state. Bring your own model key.
