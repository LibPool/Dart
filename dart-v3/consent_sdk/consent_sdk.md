# consent_sdk

**Tag**: consent, privacy, gdpr, plugin, web, mobile, ui

## 简介

Flutter plugin for the Privasapien Consent SDK. Delegates all consent UI to native Android and iOS SDKs, enabling GDPR-compliant user consent flows.
