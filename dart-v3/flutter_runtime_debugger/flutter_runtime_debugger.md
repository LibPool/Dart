# flutter_runtime_debugger

**Tag**: debugging, logging, network, devtools, inspector, mobile, networking, state-management

## 简介

Zero-dependency Flutter on-device runtime debugger. Captures logs, network, BLoC state transitions, crashes, FPS, routes, and local storage — inspectable via a draggable overlay panel without leaving the app.
