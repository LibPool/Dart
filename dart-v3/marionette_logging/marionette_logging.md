# marionette_logging

**Tag**: mcp, ai, claude, agent, copilot, mobile

## 简介

Flutter extensions for AI agent interaction via MCP — lets Claude, Copilot, and Cursor tap, scroll, type, and screenshot your app. Log collector integration with the logging package.
