# form_validator_x

**Tag**: form, validation, flutter, validator, input, mobile

## 简介

A flexible and composable form validation library for Flutter. Define reusable validation rules (email, date, numeric, pattern, and more) and chain them on any TextFormField with zero external dependencies.
