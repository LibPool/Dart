# swalvo_chat

**Tag**: chat, messaging, realtime, web, mobile, networking

## 简介

Swalvo Chat for Flutter — real-time messaging with durable history, presence, typing indicators, reactions, read receipts and threads. Connect, send, and listen without writing WebSocket code.
