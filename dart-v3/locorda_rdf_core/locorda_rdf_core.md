# locorda_rdf_core

**Tag**: rdf, linked-data, semantic-web, knowledge-graph, turtle, web

## 简介

A Dart library for RDF with Turtle, TriG, N-Triples, and N-Quads parsers. Type-safe RDF graph model for linked data and knowledge graph applications.
