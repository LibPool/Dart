# ikon_sdk

**Tag**: ikon, ai, sdk, flutter, web, mobile, ui, tooling

## 简介

Official Ikon AI client SDK for native Flutter frontends — connect to an Ikon server and render the server-driven Parallax UI with audio streaming.
