# rune_bloc

**Tag**: rune, bridge, bloc, state-management, flutter-bloc, mobile, ui, tooling

## 简介

flutter_bloc bridge for the rune package. Registers BlocProvider, BlocBuilder, and BlocListener widgets on a RuneConfig so Rune source can express BLoC-pattern state.
