# dart_monty_native

**Tag**: python, sandbox, ffi, flutter, web, mobile, desktop, ui

## 简介

Native plugin for dart_monty (replaces dart_monty_desktop). Pure Dart bindings for Monty — a restricted sandboxed Python interpreter built in Rust.
