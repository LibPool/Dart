# biovida_face_liveness

**Tag**: mobile, ui, serialization

## 简介

AWS Rekognition Face Liveness for Flutter apps built with FlutterFlow. Self-contained Android Activity, Cognito guest credentials resolved at runtime from an Identity Pool id — no amplifyconfiguration.json, no MainActivity changes, no native project edits.
