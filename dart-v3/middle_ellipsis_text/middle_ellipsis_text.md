# middle_ellipsis_text

**Tag**: text, widget, ellipsis, flutter-ui, mobile, ui

## 简介

A lightweight Flutter widget that truncates long text with ellipsis (...)  in the middle — perfect for filenames, URLs, and long identifiers.
