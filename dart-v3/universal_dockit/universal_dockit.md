# universal_dockit

**Tag**: pdf-viewer, office, excel, powerpoint, epub, mobile

## 简介

A Flutter plugin for viewing PDF, Word, Excel, PowerPoint, EPUB, CBZ, TXT, CSV, RTF, and OpenDocument files on Android and iOS.
