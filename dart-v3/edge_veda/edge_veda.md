# edge_veda

**Tag**: ai, machine-learning, on-device, llm, inference, mobile

## 简介

On-device AI runtime for Flutter. Text, vision, speech-to-text, text-to-speech, image generation, embeddings, RAG, and function calling. Metal GPU on iOS, CPU on Android. Zero cloud.
