# gcc_validators

**Tag**: validation, iban, forms, saudi-arabia, uae, mobile

## 简介

Validation and normalization for GCC identifiers: IBAN, Saudi national ID and Iqama, Emirates ID, mobile numbers and VAT numbers. Pure Dart, Arabic-digit aware.
