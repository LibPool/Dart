# dbus_wifi

**Tag**: mobile, desktop, networking

## 简介

A simple library to connect to Wi-Fi networks and run Bluetooth LE peripherals using D-Bus (NetworkManager and BlueZ) on Linux.
This library is intended for use with the dbus package in Dart and Flutter.
