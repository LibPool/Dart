# flutter_network_core

**Tag**: dio, network, http, interceptor, authentication, web, mobile, networking, security

## 简介

Cross-platform Dio network layer for Flutter. HTTP methods, connectivity, timeouts, queued access/refresh tokens, and typed exceptions.
