# uxf

**Tag**: web, mobile, networking

## 简介

A Command line tool to download packages from https://uxflutter.com

## 官网

- 主页: https://uxflutter.com
- pub.dev: https://pub.dev/packages/uxf

## 历史版本号

- 1.1.2 (2024-10-18)
- 1.1.0 (2024-10-18)
- 1.0.0 (2024-10-17)

## 获取地址

- pub.dev: https://pub.dev/packages/uxf
- pub 安装: `dart pub add uxf`
- Flutter 安装: `flutter pub add uxf`
- 最新版本: 1.1.2
- 最新版归档: https://pub.dev/api/archives/uxf-1.1.2.tar.gz
- 版本锁定: `uxf: ^1.1.2`
- 中央仓库: https://pub.dev/
