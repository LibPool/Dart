# dartway_auth_apple

**Tag**: dartway, auth, apple, sign-in, flutter, web, mobile, security

## 简介

Sign in with Apple for a DartWay app, reached as dw.signInWithApple(): the nonce Apple's flow needs, the one-time authorization code the server must have to revoke tokens later, and the name Apple tells only once.
