# fxdart_lints

**Tag**: lints, analyzer, functional, state-management, tooling

## 简介

Analyzer lints for fxdart: unbounded Future.wait, bare catch in either blocks, lazy pipelines returned from raise scopes, and attempt before retryOn. Dev-dependency only; fxdart itself stays zero-runtime-dep.
