# nepal_admin_widgets

**Tag**: web, mobile, ui

## 简介

Flutter dropdowns for Nepal's administrative divisions — 7 provinces, 77 districts, 753 local bodies. Bilingual (English + Devanagari), offline, and backed by the verified nepal_admin_api dataset.
