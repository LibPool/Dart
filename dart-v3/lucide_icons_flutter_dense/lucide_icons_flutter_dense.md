# lucide_icons_flutter_dense

**Tag**: lucide, lucide-icons, feather, feather-icons, icons, mobile

## 简介

A denser-weight Lucide icon library package for Flutter applications with 0.25 stroke-width steps from 0.5 to 3.0.
