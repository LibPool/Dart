# sunat_cpe_dart

**Tag**: sunat, cpe, facturacion-electronica, ubl, peru

## 简介

Librería Dart para la construcción, validación y emisión de Comprobantes de Pago Electrónico (CPE) conforme a los estándares UBL y normativas SUNAT.
