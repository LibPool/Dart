# admob_flutter_plus

**Tag**: ads, admob, google-mobile-ads, android, mobile

## 简介

Community Flutter plugin for Google Mobile Ads Next-Gen SDK (Android): banners, interstitials, rewarded, native templates, picture-in-picture, preloaders, UMP, app open.
