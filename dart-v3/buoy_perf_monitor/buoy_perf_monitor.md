# buoy_perf_monitor

**Tag**: mobile, desktop

## 简介

Buoy performance monitor for Flutter — a pure-Dart sampler (FrameTiming FPS/jank + ProcessInfo RSS) driving a live on-device HUD that streams to Buoy Desktop.
