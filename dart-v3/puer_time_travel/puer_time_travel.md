# puer_time_travel

**Tag**: state-management, architecture, unidirectional-data-flow, mvi, time-travel, mobile

## 简介

Drop-in time-travel debugging for puer. Record every message and state snapshot, then step backward and forward through history using Flutter DevTools extension.
