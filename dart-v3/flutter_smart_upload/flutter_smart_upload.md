# flutter_smart_upload

**Tag**: upload, files, chunked, resumable, compression, mobile

## 简介

Backend-agnostic, memory-efficient file uploads for Flutter — chunked, resumable, retrying, with pause/resume/cancel, a concurrency-limited queue and pluggable adapters.
