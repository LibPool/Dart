# dart2tinygo

**Tag**: embedded, tinygo, microcontroller, ui, tooling

## 简介

Transpiles a subset of Dart into TinyGo source code so it can run on microcontrollers. CLI (`dart2tinygo build/check`) plus the conversion engine.
