# flutter_quill_kit_clipboard

**Tag**: editor, rich-text, quill, clipboard, mobile, ui, tooling

## 简介

Rich clipboard support for flutter_quill_kit: paste HTML from other apps as formatted content, copy selections as HTML, and paste images.
