# w_tools_toast

**Tag**: flutter, toast, notifications, ui, mobile

## 简介

w_tools 的轻量提示层：基于 bot_toast 封装文本、成功、错误、警告、加载与自定义提示，统一配置样式、位置与关闭行为。
