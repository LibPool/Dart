# native_encryptor

**Tag**: native-encrypt-decrypt-plugin, encryption, decryption, encryption-decryption-with-salt, swift-java-encryption-decryption, web, mobile, security

## 简介

Securely encrypt/decrypt data in your Flutter app using native code. Add random salt and IV for enhanced security. Easy-to-use API, cross-platform compatible.
