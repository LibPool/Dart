# oxibase

**Tag**: oxibase, oxidb, database, backend, postgrest, web, mobile, security, tooling

## 简介

Dart and Flutter client for OxiBase — documents with row-level rules, SQL, time-series, file storage, realtime and auth, behind one URL. Targets Android and iOS.
