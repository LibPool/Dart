# terradart_cli

**Tag**: terraform, opentofu, infrastructure, cli, serialization, tooling

## 简介

The terradart command — synth, plan, apply and migrate a TerraDart Stack or an existing Terraform tree, and write outputs as a --dart-define-from-file JSON.
