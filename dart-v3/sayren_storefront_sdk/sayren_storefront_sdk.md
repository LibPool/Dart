# sayren_storefront_sdk

**Tag**: ecommerce, sdk, api, payments, web, mobile, security

## 简介

Flutter SDK for the sayren storefront API — catalog, cart, checkout, payments, buyer auth and analytics. Same API as @sayren/storefront-sdk.
