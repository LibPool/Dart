# ripplefx_engine

**Tag**: interactive-fiction, narrative, game-development, ffi, flame, web, mobile

## 简介

Play a campaign written in the Ripple Effect editor from Dart or Flutter — a Flame game, an app, a server — with the engine's own story, dice and soundscape scheduling, over its C ABI.
