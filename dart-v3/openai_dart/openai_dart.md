# openai_dart

**Tag**: nlp, gen-ai, llms, openai, gpt, web, networking, tooling

## 简介

Dart client for the OpenAI REST APIs and realtime WebSocket/WebRTC workflows with type-safe access to GPT, image, audio, and Responses APIs.
