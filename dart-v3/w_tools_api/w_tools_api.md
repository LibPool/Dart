# w_tools_api

**Tag**: flutter, dio, networking, interceptors, web, mobile

## 简介

w_tools 的网络层：基于 Dio 提供多客户端注册、日志与 Token 拦截器、统一错误处理及 Repository 基类，可按域名管理多个客户端。
