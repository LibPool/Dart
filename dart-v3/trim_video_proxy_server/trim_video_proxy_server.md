# trim_video_proxy_server

**Tag**: http, proxy, video, streaming, authentication, web, mobile, ui, networking, security

## 简介

A lightweight HTTP proxy server for Dart applications. Automatically adds authentication headers to video requests (m3u8 playlists and TS segments). Ideal for video playback scenarios requiring authentication.
