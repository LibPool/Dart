# glassy_ui_ios

**Tag**: ios, liquid-glass, swiftui, ui, widget, mobile

## 简介

90 native iOS components for Flutter built with SwiftUI and UIKit. Real Liquid Glass on iOS 26+, classic styling on iOS 17-18, customizable from Dart.
