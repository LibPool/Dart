# skeuomorphic_ui

**Tag**: mobile, desktop, ui

## 简介

A production-ready Flutter UI library bringing back the tactile, hyper-realistic iOS 6 / early macOS skeuomorphic design language. Features rich textures, depth, shadows, reflections, and material surfaces that mimic real-world objects.
