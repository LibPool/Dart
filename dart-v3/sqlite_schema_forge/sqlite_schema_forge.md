# sqlite_schema_forge

**Tag**: sqlite, schema, migration, ui, database, tooling

## 简介

Declarative SQLite schema and auto-migration for Dart: define tables as immutable objects and let the differ plan and apply safe CREATE, ALTER, and rebuild steps.
