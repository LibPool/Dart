# dartway_cli

**Tag**: dartway, cli, flutter, fullstack, deploy, mobile, ui, tooling

## 简介

DartWay command-line tool: print the agent setup brief, check prerequisites, create projects from the canonical template, install the AI toolkit, run convention checks, deploy.
