# ytdlp_flutter

**Tag**: mobile, desktop

## 简介

Run yt-dlp on-device from Flutter. Android via youtubedl-android (bundled Python + updatable yt-dlp), macOS via the official self-updating yt-dlp binary, iOS via an embedded CPython running a bundled yt-dlp.
