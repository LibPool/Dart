# rakomi_flutter

**Tag**: auth, oauth, authentication, jwt, sdk, web, mobile, security

## 简介

Rakomi Flutter SDK — RFC 8252-compliant OAuth/PKCE authentication for Flutter apps targeting iOS, Android and Flutter Web. Platform-native secure storage, biometric unlock, MFA (TOTP), offline-tolerant JWKS verification.
