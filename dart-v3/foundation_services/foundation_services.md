# foundation_services

**Tag**: web, ui, state-management

## 简介

This package provides a centralized service to manage app-wide settings, including theme mode, language, and internet connectivity status. It offers reactive streams, persistent storage, and a clean API to keep UI and system states synchronized across the entire application.
