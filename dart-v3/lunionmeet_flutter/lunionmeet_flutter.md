# lunionmeet_flutter

**Tag**: web, mobile, desktop

## 简介

SDK Flutter de lunion.meet — appels audio et vidéo temps réel à intégrer dans votre application Flutter (iOS, Android, web ; desktop macOS/Linux). Se connecte au SFU str0m (WebRTC standard, sans mediasoup) via un jeton émis par votre serveur (@lunionlab/meet-server-sdk).
