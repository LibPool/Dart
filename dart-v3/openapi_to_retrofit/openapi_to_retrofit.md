# openapi_to_retrofit

**Tag**: openapi, codegen, retrofit, swagger, web, serialization, tooling

## 简介

Generates retrofit clients and json_serializable data classes from an OpenAPI 3.x document, carrying the contract's own constraints into the generated decoders.
