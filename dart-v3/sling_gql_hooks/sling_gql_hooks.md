# sling_gql_hooks

**Tag**: graphql, hooks, flutter-hooks, mobile, ui, tooling

## 简介

flutter_hooks adapter for sling_gql: useSlingQuery, useSlingMutation and useSlingSubscription, the QueryBuilder / MutationBuilder / SubscriptionBuilder of a HookWidget.
