# diana

**Tag**: server, framework, http, dependency-injection, backend, web, networking

## 简介

Diana is a Spring-inspired, annotation-driven backend framework for Dart. Compile-time dependency injection, declarative controllers, middleware, configuration and validation — no reflection.
