# error_catch_boundary

**Tag**: error-handling, error-boundary, ui, fallback, robustness, mobile, tooling

## 简介

A React-inspired error boundary package for Flutter that catches subtree build errors, prevents UI crashes, logs exceptions, and displays customizable/localizable fallback UI.
