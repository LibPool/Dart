# sunmi_citybank

**Tag**: mobile, security

## 简介

A Flutter plugin for Sunmi / City Bank POS (PayExplorer Connect V4.7) payment integration. Supports Sale, Void, Refund, Settlement, Pre-Auth, and Status Query.
