# zego_express_engine_for_uikit

**Tag**: web, mobile, ui

## 简介

ZegoExpressEngine Flutter SDK is a flutter plugin wrapper based on ZEGO Express RTC SDK (Native & Web), providing live video and real-time audio/video services.
