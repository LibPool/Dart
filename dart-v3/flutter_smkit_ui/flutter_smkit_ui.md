# flutter_smkit_ui

**Tag**: flutter, fitness, assessments, workouts, pose, mobile, ui

## 简介

Flutter plugin for Sency's SMKitUI SDK on iOS and Android, including assessments, workouts, guidance, summaries, and runtime configuration.
