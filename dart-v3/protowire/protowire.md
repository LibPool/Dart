# protowire

**Tag**: protobuf, pxf, sbe, wire-format, encoding, web, ui, serialization

## 简介

Dart port of protowire — PXF text format, SBE binary, struct-tag protobuf, and standard API response envelope. Verified for byte-equivalence with the canonical Go reference and seven other sibling ports.
