# group_flutter_ui

**Tag**: mobile, ui

## 简介

É um projeto de componentes Flutter para uso em diversos projetos internos. O projeto capacita as equipes a entregar interfaces de alta qualidade, reduzindo a redundância e aprimorando a colaboração em toda a organização.
