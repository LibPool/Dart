# zenoh_dart

**Tag**: zenoh, ffi, pubsub, networking, robotics, mobile, desktop

## 简介

Dart bindings for Zenoh, the pub/sub/query protocol, via FFI to zenoh-c 1.8.0. Linux and Android.
