# fiber_foundation_icons

**Tag**: mobile, ui

## 简介

A Flutter package providing adaptive icons (Material and Cupertino) with an explicit, controller-driven animation system. AppIcon allows you to display platform-aware icons and trigger consistent, reusable icon animations with full control over timing, repetition, and icon transitions.
