# nibite_spinner

**Tag**: mobile, ui

## 简介

Este pacote Flutter fornece um widget personalizável que inclui um spinner, dois botões e uma caixa de texto entre os botões. É altamente flexível e pode ser facilmente integrado em qualquer aplicativo Flutter.
