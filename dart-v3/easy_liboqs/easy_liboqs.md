# easy_liboqs

**Tag**: cryptography, post-quantum, ml-kem, ffi, liboqs, mobile, security

## 简介

Post-quantum cryptography (liboqs) for Dart and Flutter with the native library bundled automatically. Wraps the oqs package, with no manual setup.
