# flutter_permission_validator

**Tag**: flutter, permissions, cli, code-analysis, development-tools, mobile, serialization, tooling

## 简介

A CLI tool that analyzes Flutter projects to detect unused permissions in AndroidManifest.xml and Info.plist. Helps avoid app store rejections by ensuring permission declarations match actual usage in your code.
