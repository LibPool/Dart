# minted_chronology

**Tag**: validation, type-safety, dates, domain-driven-design, standards, ui

## 简介

Well-modelled Dart value types for calendar dates and durations: Date, Year, Month, DayOfMonth, Weekday and Iso8601Duration. Parse, don't validate. Part of the minted family.
