# awesome_flutter_auth

**Tag**: authentication, auth, flutter, wasm, web, mobile, security, tooling

## 简介

A Flutter/Dart authentication client for awesome-lang-auth servers. Supports web (including WASM) via cookie + CSRF and native platforms via Bearer token.
