# adaptable_remote_config

**Tag**: remote-config, app-update, firebase, feature-flags, flutter, web, mobile, ui, networking

## 简介

Firebase, HTTP, or custom remote config for Flutter as plain key/value pairs, with typed reads, a cached last-good snapshot, and optional/required app-update gates.
