# minadesign

**Tag**: ui, widget, container, animation, design, mobile

## 简介

Beautiful, highly customizable Flutter containers with dotted borders, 3D layered shadows, image containers, swipe-to-action, split-color layouts, custom dialogs, activity cards, tracker items, and task cards. Smooth RxDart-powered animations with preset animation types.
