# pyrx_synapse_ios

**Tag**: pyrx, synapse, ios, push-notifications, web, mobile

## 简介

iOS implementation of the PYRX Synapse Flutter SDK. Bridges Dart calls to the published `PYRXSynapse` Swift SDK from CocoaPods Trunk / SPM, and forwards the SDK's AsyncStream<PyrxEvent> observer surface to Dart through Pigeon-generated event channels.
