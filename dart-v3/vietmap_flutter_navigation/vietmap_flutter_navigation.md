# vietmap_flutter_navigation

**Tag**: vietmap, flutter-map, navigation, routing, turn-by-turn, web, mobile

## 简介

A Flutter plugin for find a route and navigating user using Vietmap api and vietmap_flutter_gl. Supports Android and iOS.

## 官网

- 主页: https://maps.vietmap.vn
- 源码仓库: https://github.com/vietmap-company/vietmap-flutter-navigation/
- pub.dev: https://pub.dev/packages/vietmap_flutter_navigation
