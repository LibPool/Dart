# esp_prov_ble_universal

**Tag**: esp32, provisioning, bluetooth, ble, ui

## 简介

Bluetooth LE transport for esp_prov_core built on universal_ble: scanning, endpoint discovery and serialised protocomm transactions on six platforms.
