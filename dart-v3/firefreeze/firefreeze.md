# firefreeze

**Tag**: firebase, remote-config, code-generation, riverpod, freezed, web, state-management

## 简介

Generate type-safe Dart accessors, defaults and Riverpod providers from a Firebase Remote Config template automatically. Reads parameter value types directly from the Remote Config Admin API.
