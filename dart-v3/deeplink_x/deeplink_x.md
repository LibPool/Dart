# deeplink_x

**Tag**: deeplink, app-links, maps, navigation, open-store, web, mobile

## 简介

Type-safe Flutter deeplinks for WhatsApp, Telegram, Instagram, YouTube, Google Maps, Waze and app stores, with automatic store and web fallback.
