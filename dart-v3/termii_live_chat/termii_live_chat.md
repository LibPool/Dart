# termii_live_chat

**Tag**: web, mobile, ui

## 简介

Termii Live Chat SDK for Flutter. Embeds the Termii live chat widget in a WebView with a typed native bridge (user identification, close/unread events) so any Flutter app can offer in-app customer support.
