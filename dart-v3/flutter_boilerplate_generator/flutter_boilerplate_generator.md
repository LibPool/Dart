# flutter_boilerplate_generator

**Tag**: mobile, serialization, state-management, tooling

## 简介

A Dart code generator for Flutter boilerplate: model, entity, hive, cubit state, and route management. Generates JSON serialization, copyWith, value equality, entity/Hive mapping, pattern-matching extensions, and route registration.
