# gt_sizer

**Tag**: responsive, sizer, scaling, ui, layout, mobile, desktop

## 简介

A responsive sizing utility for Flutter with hybrid scaling for width, height, fonts, icons, and spacing across mobile, tablet, and desktop devices.
