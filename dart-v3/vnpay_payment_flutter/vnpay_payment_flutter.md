# vnpay_payment_flutter

**Tag**: mobile

## 简介

Plugin Flutter giúp tích hợp Cổng thanh toán VNPAY (Việt Nam) vào ứng dụng di động. Hỗ trợ tạo URL thanh toán và kiểm tra chữ ký bảo mật (HMAC-SHA512).
