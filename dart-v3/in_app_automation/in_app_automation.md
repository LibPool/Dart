# in_app_automation

**Tag**: testing, automation, ui-testing, integration-testing, mobile, ui

## 简介

In-app UI automation and an interactive on-device test runner for Flutter: widget finders, tap/type/scroll actions, assertions, and a visual inspector overlay.
