# graft

**Tag**: state-management, reactivity, performance, dependency-injection, widgets, mobile, ui, tooling

## 简介

Self-optimizing state management engine for Flutter: BLoC-style domain models, Signals-level micro-rebuild precision, and register-level CPU bitmask diffing.
