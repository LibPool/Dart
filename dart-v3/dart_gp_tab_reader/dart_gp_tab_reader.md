# dart_gp_tab_reader

**Tag**: guitar, tablature, music, parser, ui

## 简介

Pure-Dart, read-only reader for Guitar Pro tablature files (GP3, GP4, GP5, GP6 .gpx and GP7/GP8 .gp). Parses them into a Song > Track > Measure > Voice > Beat > Note tree.
