# dart_db_server

**Tag**: database, sql, vector-search, embeddings, full-text-search, web, ui

## 简介

A pure-Dart SQL database (SQLite-inspired) with a built-in vector search engine, FTS5-lite full-text search, and hybrid retrieval — plus a TCP server and MySQL-wire compatibility layer.
