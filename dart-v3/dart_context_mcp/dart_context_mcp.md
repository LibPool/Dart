# dart_context_mcp

**Tag**: dart, flutter, mcp, ai, agent, web, mobile, tooling

## 简介

Local Dart/Flutter code context CLI and MCP server for AI agents: symbol lookup, impact analysis, and a dependency graph, without reading every file.
