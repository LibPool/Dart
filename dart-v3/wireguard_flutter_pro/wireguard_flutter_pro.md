# wireguard_flutter_pro

**Tag**: wireguard, vpn, flutter-plugin, network-extension, mobile, desktop, networking

## 简介

A Flutter plugin to configure and control WireGuard VPN tunnels on Android, iOS, macOS, Windows, and Linux.
