# appplayer_ui_view

**Tag**: ui, appplayer, viewer, flutter, mcp, mobile

## 简介

Read-only Flutter viewer for target-native UI outputs (Flutter, LVGL, Qt, ...). Each target plugs in via a UiRuntimePort.
