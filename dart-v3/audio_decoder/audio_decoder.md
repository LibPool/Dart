# audio_decoder

**Tag**: audio, audio-processing, decoder, pcm, flutter-plugin, web, mobile, ui

## 简介

Decode MP3, M4A, AAC, FLAC, OGG & more to WAV/PCM using native platform APIs. Convert, trim, and analyze audio — no FFmpeg required.
