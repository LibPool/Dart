# utd_gift_kit

**Tag**: gifts, live-streaming, voice-chat, realtime, mobile

## 简介

In-room virtual gifts for Flutter: a typed gift protocol and a play queue that serialises overlapping gifts. No plugin dependencies. Transport-agnostic — works in an audio room, a live stream, or any room that can send and receive data.
