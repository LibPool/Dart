# iptv_org_api

**Tag**: iptv, streaming, epg, tv, api-client, web, mobile, serialization, tooling

## 简介

Enterprise-Grade IPTV Core SDK for Flutter & Dart. Multi-source M3U/M3U8 parsing, XMLTV EPG sync, Xtream Codes, Stalker Portal, stream health validation, local persistence & player abstractions.
