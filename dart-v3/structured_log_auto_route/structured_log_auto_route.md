# structured_log_auto_route

**Tag**: logging, auto-route, navigation, routing, structured-logging, web

## 简介

StructuredLogAutoRouteObserver — logs every auto_route navigation (push, pop, remove, tab change) as structured_log entries, with token-like parameters in the location redacted.
