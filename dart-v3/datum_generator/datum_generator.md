# datum_generator

**Tag**: offline-first, synchronization, database, flutter, supabase, mobile, ui, tooling

## 简介

Code generator for the Datum framework — derives toDatumMap, fromMap, copyWith, and diff for entities via build_runner, wire-compatible with the runtime typed-schema layer.
