# eter_oprf

**Tag**: web, mobile

## 简介

RFC 9497 (2HashDH) OPRF protocol on P-256 for Dart/Flutter. Interoperable with @noble/curves server implementations. Supports threshold 3-of-3 additive OPRF. No P-256 OPRF library exists for Dart.
