# byte_message

**Tag**: byte-message, protocol, inter-chip

## 简介

Inter-chip 协议编码/解码的纯 Dart 库：提供数据包模型、常量、工具方法、编码器与解码器，支持 |Flag|Len|LenH|Cmd|Payload|Checksum| 格式。
