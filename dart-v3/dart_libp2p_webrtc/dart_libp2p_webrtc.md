# dart_libp2p_webrtc

**Tag**: libp2p, webrtc, p2p, networking, ffi, web, mobile

## 简介

libp2p WebRTC transport (/webrtc) for dart-libp2p: Dart and Flutter apps and js-libp2p browsers connect directly, via libdatachannel and dart:ffi.
